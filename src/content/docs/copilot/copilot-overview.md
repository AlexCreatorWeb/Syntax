GitHub Copilot is the AI pair programmer from GitHub/Microsoft: it suggests code inline as you type, answers questions in a chat panel (VS Code, JetBrains, Visual Studio, Neovim), and works right on github.com — in pull requests, issues and the web code view. If you already use GitHub, Copilot is available in the same account.

## Core capabilities

- Inline completions — ghost-text suggestions for the next line or the whole function, accepted with Tab.
- Copilot Chat — `@workspace` context: refactor a file, write tests, explain an error, with references to your code.
- Copilot on github.com — summaries of PRs, issue generation from a description, answers over the repository code.
- Copilot agent mode — autonomous work: a task, a branch, a pull request with the result.

## Getting started

```text
1. Install the "GitHub Copilot" extension in VS Code (Marketplace).
2. Sign in with your GitHub account; choose a plan (Free / Pro).
3. Start typing — accept suggestions with Tab.
4. Open Chat (Cmd/Ctrl+I) and try:
   "explain this file", "write unit tests for this module".
```

## Основные возможности

- Инлайн-дополнения — ghost-text подсказки следующей строки или всей функции, принимаются Tab'ом.
- Copilot Chat — контекст `@workspace`: рефакторинг файла, написание тестов, объяснение ошибки — со ссылками на ваш код.
- Copilot на github.com — саммари PR'ов, генерация issue из описания, ответы по коду репозитория.
- Агентский режим Copilot — автономная работа: задача, ветка, pull request с результатом.

```text

3. Начните печатать — принимайте подсказки Tab'ом.
4. Откройте чат (Cmd/Ctrl+I) и попробуйте:
   «объясни этот файл», «напиши unit-тесты для этого модуля».
```
