# Урок 1. NoSQL и MongoDB: отличие от SQL, mongosh и Compass

## Цель

После урока студент сможет: объяснять, что такое NoSQL и документные базы данных, сравнивать реляционный (SQL) и документный (MongoDB) подходы и называть случаи для каждого, работать в **mongosh** (MongoDB Shell): подключаться к серверу, создавать БД/коллекцию, добавлять документ, и понимать, что такое **Compass** (GUI-клиент).

## Теория

### Почему NoSQL

«NoSQL» — не «без запросов», а **Not Only SQL**: подходы к хранению данных вне классических таблиц. MongoDB — **документная** БД: данные хранятся как **документы** (объекты, похожие на JSON), а не строки в таблицах с фиксированными столбцами.

Разница подходов (кратко):

- **SQL (PostgreSQL/MySQL)**: таблицы со строгой схемой (столбцы заданы заранее), JOIN'ы, транзакции «всё или ничего». Сильна там, где данные **реляционные** (пользователи-заказы-позиции, деньги, аналитика).
- **MongoDB**: коллекции документов, схема **гибкая** (каждый документ может иметь разные поля), данные **вложены** (объект внутри объекта, массивы). Сильна там, где данные **группируются** (каталог товаров с разным набором характеристик, комментарии, события/логи, контент).

Когда MongoDB: гибкая/меняющаяся схема, вложенные данные, быстрый рост «вширь» (новые поля без миграции таблиц), prототипирование. Когда SQL: жёсткая нормализация, сложные JOIN'ы, строгие транзакции по деньгам.

### Монго — это «объекты»

В MongoDB вы сохраняете **тот же объект**, что работает в JS:

```
{ "_id": ObjectId("…"), "title": "Первый документ", "tags": ["a", "b"], "meta": { "views": 3 } }
```

Без `CREATE TABLE`: первая запись в коллекцию **создаёт** коллекцию (и базу).

### Инструменты

- **mongod** — сервер (демон), хранит данные на диске (по умолчанию `./data/db`).
- **mongosh** — интерактивный шелл (Node.js-консоль): подключается к серверу, выполняет JS-операции. Команды вида `db.collection.find()`.
- **Compass** — GUI: визуальный просмотр БД/коллекций, построитель запросов, «попробовать» операторы без запоминания синтаксиса.
- **Driver / Mongoose** — доступ из Node.js (наш основной путь, модуль 7).

Подключение в mongosh: `mongosh` (локально, порт 27017) или `mongosh "mongodb://user:pass@host:27017/?authSource=admin"`.

TIP: начинайте с **mongosh + Compass** (видите данные сразу), а «боевой» код пишите через драйвер/Mongoose. Shell — для отладки и разовых операций.

NOTE: в платформе Syntax mongo-задания выполняются в **песочнице Node-раннера**: `new MongoClient(url)` — in-memory-имитация (тот же API, данные живут до перезагрузки страницы). В терминале — настоящий mongod: `mongod` (или Docker) + `mongosh`.

## Пример

В **mongosh** (запускаем `mongosh`, дальше — строки шелла):

```js
// выбрать/создать базу и показать её
use blog
db

// создать коллекцию первой записью
db.posts.insertOne({ title: "Привет, MongoDB", tags: ["intro"], views: 0 })
// → { acknowledged: true, insertedId: ObjectId("665f…") }

db.posts.find()          // все документы
db.posts.countDocuments() // 1

// посмотреть коллекции и базы
show collections
show dbs
```

В **Node.js** (то же через драйвер — то, что мы будем писать в заданиях):

```js
import { MongoClient } from "mongodb";

const client = new MongoClient(process.env.MONGO_URL || "mongodb://localhost:27017");
await client.connect();
const db = client.db("blog");
const posts = db.collection("posts");

const res = await posts.insertOne({ title: "Первый пост", tags: ["intro"], views: 0 });
console.log("Вставили, _id:", res.insertedId);
console.log("Всего постов:", await posts.countDocuments({}));
```

## Частые ошибки

WARN: ждёте `CREATE TABLE` / `CREATE DATABASE` в MongoDB. Базы и коллекции создаются **при первой записи** (implicit creation). В mongo «схема» — это данные, а не DDL.

WARN: пишете `db.posts.find()` в **Node-коде** (это синтаксис mongosh). В коде — драйвер: `client.db("blog").collection("posts")`. Не смешивайте два мира в одном файле.

WARN: выбираете MongoDB «потому что модно», когда задача чисто реляционная (денежные транзакции, сложные JOIN). Сравнивайте (реляционная vs документная) — это навык, а не религия.

## Практическое задание

1. В `models.js`: подключитесь к `mongodb://localhost:27017` (через `process.env.MONGO_URL` с фолбэком), `client.db("course")`, коллекция `students`.
2. Вставьте документ `{ name: "Студент 1", course: "Mongo", skills: ["js"] }` — выведите `insertedId`.
3. Выведите `countDocuments({})` и результат `find()` (JSON.stringify).
4. В комментарии вставьте эквивалентные **mongosh**-команды (use course / db.students.insertOne / db.students.find) — для повторения в терминале.
5. (В терминале) Запустите `mongosh`, выполните эти команды и сравните результат с консолью Node.
