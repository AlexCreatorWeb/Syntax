# Урок 1. Vue: первое приложение и структура SFC

## Цель

После урока студент сможет: объяснить, что такое Vue 3 и для чего нужен SPA-фреймворк, открыть проект Vue в Vite, разобрать структуру единого файлового компонента (SFC: template / script setup / style) и запустить первое приложение.

## Теория

### Что такое Vue

Vue — фреймворк для построения пользовательских интерфейсов. Главная идея Vue — **декларативность**: ты описываешь, как UI выглядит для каждого состояния данных, а Vue сам обновляет DOM, когда данные меняются. Формула та же, что в любом современном фреймворке: `UI = f(состояние)`.

Без фреймворка ты вручную ищешь элементы (`document.querySelector`) и меняешь их текст и атрибуты при каждом изменении данных. Vue заменяет эту ручную работу: ты объявляешь связь между данными и разметкой, а дальше обновления происходят автоматически.

Vue работает в браузере и собирается в приложение — **SPA** (Single Page Application): страница загружается один раз, а дальше фреймворк рендерит и обновляет интерфейс без перезагрузки.

### Структура SFC

Основной строительный блок Vue — **единый файловый компонент** (Single File Component, SFC) — файл с расширением `.vue`. Внутри три блока:

- `<template>` — разметка, которую Vue отрисует (HTML с директивами);
- `<script setup>` — логика на JavaScript: импорты, состояние, функции. Это **Composition API** — современный способ писать логику компонента;
- `<style>` — стили компонента (обычно с атрибутом `scoped`, чтобы не трогать остальное приложение).

Все три блока описывают **один компонент**. Babel/Vite (а в платформе Syntax — наш раннер) превращают SFC в JavaScript-модуль, который можно импортировать.

### Первый запуск

Стандартный способ создать проект — Vite: команда `npm create vue@latest` задаст имя, включит Router/Pinia (по желанию) и создаст структуру. Точка входа — `main.js`:

- создаём приложение из компонента `App.vue` функцией `createApp`;
- монтируем его в DOM-элемент `<div id="app">`.

Компонент `App.vue` — корень всего дерева: всё, что он рендерит, и всё, что он подключает (роутер, стейт), становится приложением.

NOTE: в платформе Syntax файл задания Vue-трека — **App.vue** с блоком `<script setup>`. Нажми **Run** — раннер скомпилирует SFC прямо в браузере и покажет результат в превью.

## Пример

Полное `App.vue` — первое приложение:

```vue
<script setup>
import { ref } from "vue";

const message = ref("Привет, Vue 3!");
</script>

<template>
  <div class="card">
    <h1>Моё первое Vue-приложение</h1>
    <p>{{ message }}</p>
    <!-- Задача: поменяй текст message -->
  </div>
</template>

<style scoped>
.card {
  font-family: sans-serif;
  padding: 24px;
}
</style>
```

`main.js`, который запускает приложение (в Vite-проекте создаётся автоматически):

```js
import { createApp } from "vue";
import App from "./App.vue";

createApp(App).mount("#app");
```

Что происходит:

1. `ref("Привет, Vue 3!")` создаёт реактивную переменную (подробнее — в уроке 05);
2. `{{ message }}` в шаблоне показывает её текущее значение;
3. `createApp(App).mount("#app")` рендерит компонент внутрь элемента с id `app`.

## Частые ошибки

WARN: забыл `<script setup>` — написал логику в обычный `<script>`, но переменные из него не видны в `<template>`. Внутри `<script setup>` всё, что объявлено в верхнем уровне блока, автоматически доступно в шаблоне. Без `setup` (то есть в Options API) пришлось бы возвращать объект — на этом курсе мы так не работаем.

WARN: забыл `import { ref } from "vue"` — ошибка «ref is not defined». Композиционный API — это обычные JS-импорты из пакета `vue`: `ref`, `reactive`, `computed`, `watch` и хуки жизненного цикла импортируются явно.

WARN: `createApp(App)` требует **компонент**, а не HTML-строку — в аргумент передаётся импорт компонента, не его разметку. Если передать `{ template: "..." }` — будет работать только с полным сбором Vue; не делай так в Vite.

## Практическое задание

Открой `App.vue` в редакторе и сделай:

1. Добавь в `<script setup>` вторую переменную `const author = ref("…")` со своим именем.
2. Выведи `author` в шаблоне отдельным `<p>`.
3. Поменяй текст `message` так, чтобы приветствие содержало твоё имя.
4. В блоке `<style scoped>` добави свой класс и стили для карточки (например, цвет рамки).
5. Нажми **Run** и убедись, что карточка обновилась без перезагрузки кода целиком.
