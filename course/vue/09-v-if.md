## Цель

После урока студент сможет: условно рендерить элементы через `v-if` / `v-else-if` / `v-else`, отличать `v-if` от `v-show` (и выбирать между ними), использовать `v-if` с ключами на «переключаемых» ветках и понимать, что происходит с DOM при каждом подходе.

## Теория

### v-if: условная разметка

`v-if="условие"` **добавляет элемент в DOM**, только когда условие истинно; иначе элемента **нет** (не «скрыт» — отсутствует). Это полноценное ветвление:

```html
<p v-if="isAdmin">Админ-панель</p>
<p v-else-if="isModerator">Панель модератора</p>
<p v-else>Обычный текст</p>
```

Цепочка `v-if → v-else-if → v-else` работает как `if/else if/else` в JavaScript. Важно: элементы ветвей должны идти **друг за другом** (без других элементов между `v-if` и `v-else`).

### v-show: скрытие через CSS

`v-show="условие"` **всегда** рендерит элемент в DOM, но прячет через `style="display: none"`. Т.е.:

- `v-if` — элемент **нет** в DOM;
- `v-show` — элемент **есть**, но скрыт.

Разница влияет на **производительность** и **поведение**:

- `v-if` — дешевле при **редком** переключении (нет чего создавать/удалять), но дорого **переключать** (создание/уничтожение DOM, перезапуск хуков жизненного цикла вложенных компонентов).
- `v-show` — дорого **первоначальный рендер** (элемент всегда в DOM), но дёшево **переключать** (только `display`).

**Правило выбора:**

- переключение **частое** (табы, дропдауны, «показать ещё») → `v-show`;
- ветка **редкая** или **тяжёлая** (админ-панель, модальная форма, большой список) → `v-if`.

### v-if и ключи на «переключаемых» ветках

Если `v-if`/`v-else` переключают **разные** компоненты/структуры, Vue корректно создаст/удалит нужную ветку. Но если обе ветки — **один и тот же** тег/компонент с разным содержимым — Vue может **перезаиспользовать** его (и состояние «протечет» между ветками). Для принуждения к **полной замене** используй `:key` (или `v-if`/`v-else` с разными `key`):

```html
<MyComp v-if="mode === 'a'" key="a" />
<MyComp v-else key="b" />
```

TIP: `v-if` перезапускает **жизненный цикл** вложенных компонентов (`onMounted`/`onUnmounted`). Если нужно «сохранить состояние» между переключениями — `v-show` или оберни в `<KeepAlive>`.

NOTE: в раннере Syntax `v-if`/`v-show` работают в обычном DOM — проверь DevTools-ом (в превью можно открыть инспектор), что элемент реально отсутствует/скрыт.

## Пример

```vue
<script setup>
import { ref } from "vue";

const isAdmin = ref(false);
const isLoggedIn = ref(false);
const showDetails = ref(true);
const mode = ref("a");
</script>

<template>
  <div class="demo">
    <!-- v-if / v-else-if / v-else -->
    <div class="panel">
      <p v-if="isAdmin">Ты админ</p>
      <p v-else-if="isLoggedIn">Ты вошёл</p>
      <p v-else>Ты гость</p>
    </div>
    <label><input type="checkbox" v-model="isLoggedIn" /> Войти</label>
    <label><input type="checkbox" v-model="isAdmin" /> Админ</label>

    <!-- v-show: частое переключение -->
    <button @click="showDetails = !showDetails">Показать/скрыть</button>
    <p v-show="showDetails">Эти детали всегда в DOM (скрыты через display)</p>

    <!-- v-if: тяжёлая ветка -->
    <div v-if="mode === 'a'">Режим A (тяжёлый)</div>
    <div v-else>Режим B</div>
    <button @click="mode = mode === 'a' ? 'b' : 'a'">Переключить режим</button>
  </div>
</template>
```

Что проверить:

- `v-if`/`v-else-if`/`v-else` — текст меняется в зависимости от чекбоксов;
- `v-show` — при «скрыть» элемент **остаётся** в DOM (проверь инспектором);
- `v-if` — при переключении режима старый `div` **удаляется**, новый создаётся.

## Частые ошибки

WARN: путаешь `v-if` и `v-show`. Для **частого** переключения лёгких элементов `v-if` будет медленно (создание/уничтожение DOM). Для **редких/тяжёлых** веток `v-show` держит лишний DOM. Выбирай по частоте и весу.

WARN: ставишь `v-else` **не сразу** после `v-if` (между — другой элемент). Тогда `v-else` «оторвётся» и не сработает. Ветви должны быть соседними.

WARN: обе ветки `v-if`/`v-else` — один и тот же компонент, и ты ждёшь полного сброса состояния. Vue перезаиспользует компонент (состояние «протечет»). Добавь `:key` для принуждения к замене.

WARN: `v-if="0"` — falsy, элемент не отрисуется. Помни: `v-if` проверяет **истинность** (как JS), а не «пустую строку». Для «пустая ли строка» — `v-if="str !== ''"`.

## Практическое задание

В `App.vue` сделай:

1. `const tab = ref("home")` и три «страницы»: `home`, `about`, `contact`.
2. Рендер через `v-if="tab === 'home'"` / `v-else-if="tab === 'about'"` / `v-else` — разные блоки.
3. Навигация: три кнопки, выставляющие `tab`.
4. `const expanded = ref(false)` и блок «Детали», который переключается через **`v-show`**.
5. Добавь `const heavy = ref(false)` и тяжёлую ветку через `v-if` (например, список из 100 элементов через `v-for`).
6. Запусти **Run**: проверь, что «Детали» (v-show) всегда в DOM, а «heavy» (v-if) — только когда `heavy === true` (инспектор DOM).
