## Цель

После урока студент сможет: выводить данные в шаблон через мустачи `{{ }}`, отличать их от `v-text`, использовать JavaScript-выражения в шаблоне и понимать, что разрешено, а что запрещено писать в интерполяции.

## Теория

### Мустачи (mustache)

Основной способ показать данные в шаблоне — **интерполяция** `{{ выражение }}`. Vue вычисляет выражение и вставляет **строковое значение** в DOM:

- `{{ name }}` — значение переменной `name`;
- `{{ 1 + 1 }}` — любые JS-выражения: арифметика, тернарник, вызовы функций;
- `{{ user.name }}` — доступ к вложенным свойствам;
- `{{ items.length }}` — методы массивов тоже работают.

Важно: мустачи вставляет значение **как текст**. Если захочешь показать HTML-строку — она не отобразится как разметка, а выведется буквально (это правильно и безопасно).

### v-text

Директива `v-text` делает то же самое, что мустачи, но заменяет **весь** текст элемента:

- `<p>{{ a }} <b>жирный</b></p>` — мустачи только внутри, остальная разметка жива;
- `<p v-text="a">запасной текст</p>` — всё содержимое элемента будет равно значению `a` (HTML-разметка «запасного текста» исчезает).

`v-text` полезнее, когда внутри элемента нет вложенной разметки, а значение может содержать спецсимволы.

### Выражения, а не инструкции

В шаблоне пишут **выражения**: `a + b`, `ok ? "да" : "нет"`, `items.filter(...)`. Разрешены только выражения — **не инструкции**: `if`, `for`, `let`/`const` в шаблоне писать нельзя (условия — это `v-if`, циклы — `v-for`).

TIP: шаблон — не место для сложной логики. Если выражение стало длиннее строки — вынеси его в `computed` (урок 06) или в функцию в `<script setup>`.

### Отслеживание

Vue сам отслеживает, какие реактивные значения используются в шаблоне: если значение поменялось — перерисовывается только та часть DOM, где оно участвует. Никаких ручных «обнови элемент» не нужно.

NOTE: в раннере платформы Syntax всё это работает так же, как в Vite: мустачи, `v-text` и выражения — базовый синтаксис, который раннер понимает сразу.

## Пример

```vue
<script setup>
import { ref } from "vue";

const user = ref({ name: "Анна", level: 7, pro: true });
const tags = ref(["vue", "reactivity", "sfc"]);

const greeting = () => `Привет, ${user.value.name}!`;
const nextLevel = user.value.level + 1;
</script>

<template>
  <div class="demo">
    <!-- мустачи: переменные и выражения -->
    <p>{{ user.name }} — уровень {{ user.level }}, следующий: {{ user.level + 1 }}</p>
    <p>{{ user.pro ? "Продвинутый студент" : "Новичок" }}</p>
    <p>{{ greeting() }}</p>

    <!-- мустачи показывает HTML как текст -->
    <p>{{ "<b>не отобразится как разметка</b>" }}</p>

    <!-- v-text заменяет всё содержимое -->
    <p v-text="tags.join(', ')">старый текст исчезнет</p>

    <!-- доступ к свойствам массива -->
    <p>Первый тег: {{ tags[0] }}, всего: {{ tags.length }}</p>
  </div>
</template>
```

Обрати внимание:

- `{{ user.name }}` — мустачи автоматически «разворачивает» `ref`: в шаблоне `.value` не пишут;
- `{{ "<b>…</b>" }}` — HTML не парсится, видно литерально;
- `v-text="tags.join(', ')"` — метод массива прямо в шаблоне;
- `const nextLevel = user.value.level + 1;` в скрипте — так можно, но для реактивного вычисленного значения лучше `computed` (урок 06).

## Частые ошибки

WARN: пытаешься написать инструкцию в шаблоне: `{{ if (x > 0) … }}` или `{{ let y = 1 }}` — синтаксическая ошибка. Условия — `v-if`, объявления переменных — в `<script setup>`.

WARN: пишешь `{{ user.value.name }}` в шаблоне — лишнее `.value`! В шаблоне `ref` разыменовывается автоматически; `.value` нужен только в JavaScript.

WARN: ждёшь, что `{{ htmlString }}` отрисует разметку. Мустачи экранирует HTML (защита от XSS). Для «сырого» HTML есть `v-html` — используй только для доверенного контента (например, после своей очистки).

## Практическое задание

В `App.vue` сделай:

1. Объяви `const student = ref({ name: "…", course: "Vue", progress: 40 })` со своими данными.
2. Выведи строку: `«{name} изучает {course}: {progress}%»` — через мустачи.
3. Добавь выражение: проценты до 100 (`100 - progress`) — «до конца курса осталось N%».
4. Выведи массив `const skills = ref([…])` через `v-text="skills.join(' → ')"` — цепочку навыков.
5. Сделай `v-html`-парagraf со строкой `"<strong>Готово!</strong>"` и сравни, как он отличается от мустачи с той же строкой.
6. Запусти **Run** и проверь каждое утверждение.
