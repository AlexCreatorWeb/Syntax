# Урок 13. Создание и регистрация компонентов

## Цель

После урока студент сможет: создавать компоненты (SFC и в том же файле), регистрировать их локально через `import` + `defineComponent`/`components`, понимать, что компонент — это «переиспользуемый фрагмент UI с собственным состоянием», и рендерить несколько экземпляров одного компонента.

## Теория

### Компонент как «строительный блок»

Компонент — **переиспользуемый фрагмент интерфейса** со своей разметкой (`<template>`) и логикой (`<script setup>`). Один и тот же компонент можно:

- использовать **несколько раз** (каждый экземпляр — **своё** состояние);
- передавать в него данные (props — урок 14);
- получать от него события (emits — урок 15);
- вкладывать в него **свой** контент (slots — урок 16).

### Два способа создать

1. **SFC-файл** (`.vue`) — отдельный файл. Стандарт для реальных проектов.
2. **Внутри файла** — объект компонента через `defineComponent` (или обычный объект) и использование в шаблоне того же файла.

В раннере Syntax (один файл `App.vue`) удобнее **второй** способ: объявить вспомогательные компоненты **внутри `<script setup>`** как **константы-объекты** и использовать их в шаблоне.

### Локальная регистрация

Компонент **виден** в шаблоне только если он **импортирован** (для SFC) или **объявлен** (для inline) в `<script setup>`. Vue 3 `<script setup>` **автоматически** делает доступными:

- импортированные компоненты (SFC);
- переменные-компоненты, объявленные в `setup` (inline-объекты).

Т.е. `import Card from "./Card.vue"` → `<Card/>` доступен. Или `const Card = { template: "…", setup() { … } }` → `<Card/>` доступен.

### Экземпляр и состояние

Каждый `<Card/>` в шаблоне — **отдельный экземпляр** с **своим** `ref`/`reactive`. Два `<Card/>` рядом **не делят** состояние (если не передали общее через props/provide).

TIP: разбивай UI на **небольшие** компоненты (один компонент = одна ответственность). Чем меньше компонент, тем проще тестировать и переиспользовать.

NOTE: в раннере Syntax можно объявить **несколько** компонентов в одном `App.vue` (как inline-объекты) — это допустимо для учебных целей. В реальном проекте — отдельный файл на компонент.

## Пример

В `App.vue` — «Карточка товара», используемая **несколько раз**:

```vue
<script setup>
import { ref } from "vue";

// Inline-компонент (в реальном проекте — отдельный .vue файл)
const ProductCard = {
  props: { name: String, price: Number },
  setup(props) {
    const inCart = ref(false);
    function toggle() { inCart.value = !inCart.value; }
    return { inCart, toggle };
  },
  template: `
    <div class="card">
      <h4>{{ name }}</h4>
      <p>{{ price }} ₽</p>
      <button @click="toggle" :class="{ added: inCart }">
        {{ inCart ? "В корзине" : "В корзину" }}
      </button>
    </div>
  `,
};

const products = [
  { name: "Курс Vue", price: 1000 },
  { name: "Курс React", price: 1200 },
  { name: "Курс Node", price: 900 },
];
</script>

<template>
  <div class="demo">
    <ProductCard v-for="p in products" :key="p.name" :name="p.name" :price="p.price" />
  </div>
</template>
```

Что проверить:

- `ProductCard` — inline-компонент (объект с `template`);
- `v-for` создаёт **3 экземпляра**;
- каждый экземпляр имеет **своё** `inCart` (нажал «В корзину» на одном — другие не изменились);
- `props` (`name`, `price`) — данные извне (подробнее — урок 14).

## Частые ошибки

WARN: используешь компонент **без регистрации** (не импортировал/не объявил). В `<script setup>` — только то, что в области видимости. Иначе Vue предположит, что это **нативный** HTML-тег, и рендерит как обычный элемент (с предупреждением в консоли).

WARN: **разные** экземпляры «делят» состояние. Нет: каждый экземпляр — **своё** состояние. Если нужно общее — через props (вверх/вниз) или provide/inject (урок 18).

WARN: inline-компонент с `template` — работает, но **нет** `scoped`-стилей и HMR «как у SFC». Для учебной цели ок, для проекта — SFC-файл.

WARN: имя компонента **в одно слово** (`<Card>`) — Vue может спутать с нативным тегом. Используй **camelCase** (`ProductCard`) или **дефис** (`product-card`).

## Практическое задание

В `App.vue` сделай «Галерею аватаров»:

1. Объяви inline-компонент `Avatar` (объект):
   - `props: { name: String, color: String }`;
   - `template` — кружок с инициалами (первые буквы) и подписью `name`;
   - свойство `size` — `ref` внутри (по умолчанию 48), кнопка «+» увеличивает на 8.
2. В `App.vue`: `const users = [{ name: "Анна", color: "#e91e63" }, { name: "Борис", color: "#3f51b5" }, …]` (3-4 пользователя).
3. Рендер `v-for="u in users"` → `<Avatar :name="u.name" :color="u.color" :key="u.name" />`.
4. Убедись, что `size` **свой** у каждого экземпляра (нажал «+» на одном — другие не изменились).
5. Запусти **Run** и проверь независимость состояний.
