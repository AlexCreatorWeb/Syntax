# Урок 3. Строки и f-строки: срезы, методы, форматирование

## Цель

После урока студент сможет: работать со строками (индексы, **срезы** `s[1:3]`, отрицательные индексы, шаг), применять методы (`upper`, `strip`, `replace`, `split`, `join`, `startswith`), форматировать через **f-строки** (включая `{expr}`, выравнивание, преобразование) и понимать, что строки — **неизменяемые** (иммутабельные).

## Теория

### Строки неизменяемы

`str` — **иммутабельны**: «изменить» символ = создать **новую** строку. `s[0] = "X"` → TypeError. Все методы возвращают **новую** строку (`s.upper()` не меняет `s`).

### Индексы и срезы

```python
s = "Python"
s[0]     # "P"
s[-1]    # "n" (от конца)
s[1:4]   # "yth" (от 1 до 4, не включая 4)
s[:3]    # "Pyt"
s[2:]    # "thon"
s[::2]   # "Pto" (шаг 2)
s[::-1]  # "nohtyP" (разворот!)
```

Срез `s[начало:конец:шаг]` — «наибольший» инструмент для текста. Никогда не «выпадает» за границы (просто короче).

### Основные методы

- **Изменение регистра**: `upper()`, `lower()`, `title()`, `capitalize()`, `swapcase()`.
- **Обрезка**: `strip()` (пробелы с обоих концов), `lstrip()`/`rstrip()`, `strip(" \t#")` (конкретные символы).
- **Замена**: `replace(old, new)`, `removeprefix("http://")`, `removesuffix(".py")` (3.9+).
- **Разбор/сборка**: `split(",")` → список, `",".join(["a","b"])` → строка.
- **Проверки**: `startswith()`, `endswith()`, `in` (`"py" in s`), `isalpha()`, `isdigit()`, `isalnum()`.

### Форматирование: f-строки

**f-строки** (3.6+) — стандарт: `f"привет, {name}, возраст {age + 1}"`. Внутри `{…}` — **любое выражение**. Опции: `f"{value:.2f}"` (2 знака), `f"{name:>10}"` (выравнивание), `f"{value:#x}"` (hex).

Сравнение (для понимания эволюции):
```python
"привет, %s" % name              # старое (не используем)
"привет, {}".format(name)        # .format (редко)
f"привет, {name}"                # f-строка (наш стандарт)
```

TIP: для «шаблона с подстановкой» — f-строка; для «много строк с одинаковыми данными» — f-string-многострочник (f"""…""").

NOTE: в песочнице — настоящий CPython: срезы, методы, f-строки — идентичны терминалу.

## Пример

`main.py`:

```python
"""Строки и f-строки."""

s = "  Hello, Python World!  "
print("С原文:", s)
print("strip:", s.strip())
print("upper:", s.strip().upper())
print("replace:", s.replace("Python", "Syntax"))

t = "python"
print("Индексы:", t[0], t[-1])
print("Срезы:", t[1:4], t[:3], t[2:], t[::2], t[::-1])

# split / join
csv = "apple,banana,cherry"
fruits = csv.split(",")
print("split:", fruits, "| len:", len(fruits))
print("join:", " | ".join(fruits))
print("join обратный:", "".join(reversed(fruits)))  # через reversed

# Проверки
word = "Syntax2026"
print("isalpha:", word.isalpha(), "| isalnum:", word.isalnum(), "| isdigit:", word.isdigit())
print("startswith:", s.strip().startswith("Hello"), "| in:", "World" in s)

# f-строки
name, age, score = "Аня", 30, 94.678
print(f"Привет, {name}! Тебе {age + 1} в следующем году.")
print(f"Балл: {score:.2f} | hex: {255:#x} | выравнивание: {'код':>10} |")
print(f"Многострочный шаблон:\n  имя={name}\n  возраст={age}")

# removeprefix / removesuffix (3.9+)
url = "https://example.com/page"
print("removeprefix:", url.removeprefix("https://"))
print("removesuffix:", "main.py".removesuffix(".py"))
```

## Частые ошибки

WARN: пытаетесь «изменить» символ: `s[0] = "X"` → TypeError (строки **иммутабельны**). Новая строка: `s = "X" + s[1:]` или `replace`.

WARN: **забываете `f`** перед строкой: `"Привет, {name}"` — буквально `{name}` (не подставится). f-строка — с `f`.

WARN: `.strip()` «без аргумента» убирает **пробельные** (пробел, \t, \n); для «убрать `#» — `strip("#")` (и с обоих концов!).

WARN: `split()` без аргумента — по **любому** пробельному (несколько пробелов = один разделитель); `split(" ")` — по **одному** пробелу (пустые строки в списке). Не путайте.

5. В комментарии: почему строки неизменяемы (1–2 предложения: хешируемость, безопасность).
