# Урок 1. Python и интерпретатор: как запускать код

## Цель

После урока студент сможет: объяснить, что Python — интерпретируемый язык (в отличие от «компиляции в файл»), запускать скрипт командой `python main.py`, работать в **REPL** (интерактивном режиме), использовать `print` (sep, end), писать комментарии (`#`) и документ-строки (docstring), и понимать разницу между `python main.py` и `python` (REPL).

## Теория

### Интерпретатор

Python — **интерпретируемый** язык: код исполняет **интерпретатор** (CPython — стандартная реализация). Нет «компиляции в .exe»: вы пишете `main.py` и запускаете `python main.py`. Внутри интерпретатор превращает код в **байт-код** (машину — «Pyc»-файлы в `__pycache__`), но для вас это «просто запуск».

Версии: курс на **Python 3.10+** (f-строки, type hints, `match`, `X | None`). Проверяйте: `python --version`.

### Два режима

1. **Скрипт**: `python main.py` — исполняет файл (ваши задания).
2. **REPL** (Read-Eval-Print Loop): `python` без аргумента — интерактивная консоль: ввели выражение → сразу результат. Отлично для экспериментов (но не для «проекта»).

### print

```python
print("Привет")                     # базовый вывод
print(1, 2, 3)                      # sep=" " по умолчанию
print(1, 2, 3, sep="-")             # разделитель: 1-2-3
print("строка", end="")             # без перевода строки в конце
print(f"итог: {1+2}")               # f-строка (урок 3)
```

`print` — «главный» инструмент отладки (позже — `logging`, урок 27).

### Комментарии и docstring

- `# комментарий` — одна строка (для себя/команды).
- **docstring** — строка в начале модуля/функции/класса (внутри `"""…"""`): «документация» (доступна как `obj.__doc__`, читают автодоки):

```python
"""Утилита для расчёта итогов."""   # docstring модуля

def total(items):
    """Сумма списка чисел."""        # docstring функции
    return sum(items)
```

TIP: «называйте» код через имена (переменные/функции) и docstring — комментарий нужен только для «почему», а не «что» (что видно из кода).

NOTE: в платформе Syntax Python-задания выполняются в песочнице (CPython через Pyodide — настоящий интерпретатор в браузере). print → панель консоли под редактором. В терминале — python main.py (или python3).

## Пример

`main.py`:

```python
"""Мой первый Python-скрипт."""

# Это комментарий (одна строка)
name = "студент"
version = 3.10

print("Привет, Python!")
print("Среда:", name, "| версия курса:", version)
print("Разделители:")
print(1, 2, 3, sep=" → ")
print("Без новой строки:", end=" ")
print("OK")

# Типы «на пальцах»
print("int:", 42, "| float:", 3.14, "| str:", "текст", "| bool:", True)
print("Сумма:", 2 + 3, "| Строка+число через f:", f"{2} + {3} = {2 + 3}")

# docstring функции
def greet(who: str) -> str:
    """Возвращает приветствие."""
    return f"Привет, {who}!"

print(greet(name))
print("Документация:", greet.__doc__)
```

Запуск: `python main.py` (терминал) или **Run** (песочница).

## Частые ошибки

WARN: запускаете python main.py без установки Python (или python = 2.7 на старых системах). Проверяйте python --version (нужен 3.10+); на маке/Linux часто python3.

WARN: пишете код в REPL как «проект» (закрыли терминал — пропало). REPL — для экспериментов; код — в файле .py и python main.py.

WARN: путаете комментарий (#) и docstring ("""…"""): первый — «для глаз», второй — объект __doc__ (автодоки, инструменты).

WARN: ожидаете «компиляцию» и .exe-файл. Python исполняет интерпретатором; __pycache__ — кэш байт-кода (не ваш бинарник).

2. Напечатайте строку «A B C» тремя способами: `print("A B C")`, `print("A", "B", "C")`, `print("A", "B", "C", sep=" | ")`.
3. Напишите функцию `banner(text: str) -> None` (docstring!) — печатает `*** text ***`. Вызовите 3 раза.
4. В REPL (терминале `python`): посчитайте `2 ** 10`, выведите `type(3.14)`, `type("x")`. Что возвращает `print`? (проверьте `type(print("x"))`).
5. В комментарии: чем `python` (REPL) отличается от `python main.py`, и когда что использовать.
