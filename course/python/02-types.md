# Урок 2. Переменные и базовые типы: int, float, str, bool

## Цель

После урока студент сможет: объяснять **динамическую типизацию** Python (тип у значения, а не у переменной), оперировать `int`/`float`/`bool`/`str`, проверять тип через `type()` и `isinstance()`, преобразовывать значения (`int()`, `float()`, `str()`, `bool()`), применять операторы `//`, `%`, `**`, и понимать сравнение `==` vs `is`.

## Теория

### Динамическая типизация

В Python **тип у значения**, переменная — «ярлык». Переприсвоить переменную другому типу — можно (иногда — плохо, но синтаксически ок):

```python
x = 10        # x → int
x = "десять"  # x → str (прежний int «забыт», если нет ссылок)
type(x)       # <class 'str'>
```

**Проверка типа**: `type(x) is int` (строго) или `isinstance(x, int)` (учитывает наследование — **предпочтительнее**).

### Числа: int и float

- `int` — целые **без ограничения** разрядности (10^100 — ок, в отличие от JS/C).
- `float` — «вещественные» (IEEE 754, двойная точность): `0.1 + 0.2 == 0.3` → **False** (знаменитая ловушка!).
- Деление: `/` → float (`7 / 2 == 3.5`), `//` → целая часть (`7 // 2 == 3`), `%` → остаток (`7 % 2 == 1`), `**` → степень (`2 ** 10 == 1024`).

### str и bool

- `str` — текст (урок 3 — подробно).
- `bool` — `True`/`False` (заглавные!). `bool` — **наследник** `int`: `True == 1`, `False == 0` (поэтому `isinstance(True, int)` → True — странность, но факт).

### Преобразования

`int("42")` → 42; `int("3.14")` → **ValueError** (сначала `float`); `float("3.14")` → 3.14; `str(42)` → "42"; `bool("")` → False, `bool("0")` → True (нестрокая строка — всегда True).

### == vs is

- `==` — **равны ли значения** (`5 == 5.0` → True).
- `is` — **один и тот же объект** в памяти (`[1] is [1]` → False, два разных списка). Для сравнения значений — почти всегда `==`; `is` — для `None` (`x is None`) и `True/False`.

TIP: «число из ввода/JSON» — `int`/`float` через преобразование; «деньги» — в **целых** единицах (копейки/центы) или `Decimal` (не float!).

NOTE: в песочнице — настоящий CPython: типы, `//`, `%`, `**`, `0.1+0.2` — всё как в терминале.

## Пример

`main.py`:

```python
"""Переменные и базовые типы."""

x = 10
print("type(x):", type(x))          # <class 'int'>
x = "десять"
print("type(x) теперь:", type(x))   # <class 'str'>

# Числа
a, b = 7, 2
print("a / b =", a / b)     # 3.5 (float)
print("a // b =", a // b)   # 3 (целая часть)
print("a % b =", a % b)     # 1 (остаток)
print("2 ** 10 =", 2 ** 10) # 1024 (степень)
print("Большой int:", 10 ** 100 > 0)  # без ограничения разрядности

# Знаменитая float-ловушка
print("0.1 + 0.2 == 0.3:", 0.1 + 0.2 == 0.3)   # False!
print("0.1 + 0.2 =", repr(0.1 + 0.2))           # 0.30000000000000004

# Преобразования
s = "42"
n = int(s)
print("int('42') =", n, "| int('42') + 8 =", n + 8)
print("float('3.14') =", float("3.14"))
try:
    int("3.14")
except ValueError as e:
    print("int('3.14') → ValueError:", e)
print("str(42) =", str(42), "| type:", type(str(42)))

# bool и его «странности»
print("bool('') =", bool(""), "| bool('0') =", bool("0"), "| bool(0) =", bool(0))
print("True == 1:", True == 1, "| isinstance(True, int):", isinstance(True, int))

# == vs is
print("5 == 5.0:", 5 == 5.0, "| [1] is [1]:", [1] is [1])
print("None check:", (x if x is None else "не None"))
```

## Частые ошибки

WARN: сравниваете float «ровно»: `0.1 + 0.2 == 0.3` → False. Для «примерно» — `abs(a - b) < 1e-9`; для денег — int (центы) или `Decimal`.

WARN: `int("3.14")` → ValueError. Сначала `float`, потом `int` (если нужно целое).

WARN: сравниваете через `is` для значений (`[1,2] is [1,2]` → False, это **разные** объекты). `is` — для `None`/`True`/`False`; значения — `==`.

WARN: «забываете», что `bool` — int (`if some_list:` — ок, а `count == True` — кривой стиль). Проверяйте «пусто/не пусто» через truthiness (урок 6), не через `== True`.
