# Курс «Cursor: ИИ-редактор, который пишет код» — 18 уроков (roadmap + контракт)

Цепочка: что такое Cursor → установка и первый запуск → 4 инструмента (Chat, Cmd+K, Tab, Composer) → что нового в 2.0 → лайфхаки рабочего процесса → Cursor Rules → @-упоминания и индексация → Agent mode → Background Agents → MCP → Git и коммиты → тестирование → отладка → вайбкодинг → практика: красивые сайты → критический обзор и альтернативы (TRAE, Windsurf) → тарифы и экономия → финальный проект (сайт с нуля без ручного кода).

## Контракт урока (жёсткий, QC сидера падает при нарушении)

1. 5 разделов строго: `## Цель`, `## Теория`, `## Пример`, `## Частые ошибки`, `## Практическое задание`.
2. Минимум 1 `TIP:` или `NOTE:` И минимум 1 `WARN:` (ошибки оформляются WARN-пунктами).
3. Callout-строки — plain text: внутри TIP/NOTE/WARN никаких `**` и backtick'ов.
4. Без таблиц, без markdown-ссылок `[t](url)`.
5. Объём content (после mdToLite) 4000–7000 зн.
6. В «Пример» — блок ```bash (терминал: cursor CLI и команды проекта).
7. `code/NN.md` = скелет ЗАДАНИЯ (.cursorrules с `<!-- TODO -->`, не решение!), открывается в редакторе как файл урока трека.
8. В прозе без `**bold**` (только заголовки).
9. Единая сквозная метафора курса: студент строит лендинг «Зерно» — кофейня специализированного кофе — на Cursor, и каждый урок заканчивается тем, что он добавляет в его файл .cursorrules правила, изученные в уроке. К уроку 18 файл собран полностью и ведёт финальный проект.

## Спринты (связи между уроками)

- 1–4: знакомство (что это, установка, 4 инструмента, Cursor 2.0).
- 5–9: рабочий процесс (лайфхаки, Rules, контекст @, Agent mode, Background Agents).
- 10–13: качество работы (MCP, git/коммиты, тестирование, отладка).
- 14–18: вайбкодинг и практика (что это, красивые сайты, критика/альтернативы, экономика, финальный проект).
