# Cursor 2.0: что изменилось (агент, Tab 2, background)

## Цель

После урока студент сможет: объяснить, что Cursor 2.x сместил центр тяжести с «редактора с ИИ» на «агентную среду», назвать три ключевых изменения второго поколения (агент как основной режим, Tab 2, параллельные и облачные агенты) и объяснить, как эти изменения меняют повседневный рабочий процесс разработчика.

## Теория

До второго поколения Cursor был «редактором с очень хорошим ИИ»: ты писал код, а ИИ помогал. Cursor 2.x перевернул схему: ты ставишь задачи, а ИИ (агент) пишет код. Конкретно в 2.x произошло три вещи, которые стоит знать независимо от актуальных названий функций — архитектура важнее маркетинговых имён.

Первое — агент стал основным режимом. Если в 1.x Composer был «одной из функций», то в 2.x вся логика редактора построена вокруг параллельных агентов: можно запустить несколько задач одновременно (например, одну — в локальном редакторе, другую — в облаке), следить за их состоянием, сравнивать результаты. Оконная структура редактора изменилась именно под это: панель агентов, статусы, диффы. Привычка «один чат — одна задача» заменяется «несколько задач — параллельно».

Второе — Tab 2. Автодополнение переделали: новая модель Tab 2 делает упор на латентность (ответы почти мгновенные, «как локальный движок») при сохранении понимания контекста проекта. Практический смысл: Tab 2 можно «включить насовсем» — он не мешает, а ускоряет печать. Отдельная история — экономика: Tab 2 дешевле по расходу лимитов, чем премиум-модели в чате, поэтому «печатать с Tab, а премиум-модели звать на задачи» — базовая экономия (уроки 5 и 17).

Третье — облачные агенты (Background Agents). Агент запускается на серверах Cursor: ты описываешь задачу (или превращаешь в неё git-задачу/ишью), агент в выделенной среде (собственный checkout репозитория) делает правки, запускает тесты и собирает pull request. Ты можешь закрыть ноутбук — агент продолжит работать; результат придёт как PR, который ты принимаешь как обычную работу коллеги. Это качественно меняет масштаб: раньше «агент = пока я за компьютером», теперь «агент = пока я жив». Детальный разбор — в уроке 9.

Что ещё изменилось вокруг: улучшенный контроль (агент работает с разрешениями на команды, как в Claude Code — урок «разрешения» в курсе по Claude Code переносится один в один), интеграция с экосистемой (MCP — урок 10), Bugbot (ревью PR — урок 13), мобильное приложение для управления облачными агентами. Общий вектор: редактор превращается в «оркестратор флотилии агентов», а человек — в «техлида, который ставит задачи и ревьюит диффы».

NOTE: Cursor 2.x — активная ветка: названия режимов, кнопки и точный набор функций меняется от сборки к сборке. В доках и обзорах ориентируйся на три постоянных: параллельные агенты, Tab 2 и облачные агенты — они и есть «2.0», а остальное — обвес.

TIP: если перешёл с 1.x — дай себе неделю «только новые режимы»: ставь минимум одну задачу в день параллельно (локальный + облачный агент) и сравнивай с привычным «чатаю и печатаю». Через неделю разница в скорости работы становится ощутимой — и назад уже не хочется.

## Пример

```bash
# Сценарий: параллельная работа с двумя агентами.
# 1) Локальный агент (в редакторе): «Добавь секцию «О нас» и подключи её к меню»
# 2) Облачный агент (Background): задача «Сделай адаптивную сетку для мобильных»
#    — агент в облаке проверит репозиторий, сделает правки и откроет PR.

# Пока облачный агент работает — локально продолжаем:
# Composer: «Напиши контент для секции меню (8 позиций с ценами)»

# Статус облачного агента — в панели агентов (и в мобильном приложении);
# результат — pull request:
git fetch origin
git log --oneline -3
```

Смотри структуру дня: облачный агент работает в фоне (его «рабочий день» длиннее твоего), локальный агент решает текущие задачи, Tab 2 молча ускоряет ручную печать. Три слоя параллельно — и ни один не ждёт другого.

## Частые ошибки

WARN: работать в Cursor 2.x «как в 1.x»: один чат, одна задача, печатаешь сам. Новые режимы (параллельные и облачные агенты) не включаются автоматически — ими пользуются, когда перестаёшь думать «редактор» и начинаешь думать «команда».

WARN: закидывать в облачный агент «мелочь»: облачный запуск — это полный цикл (checkout, работа, тесты, PR) и он оптимален для задач на 30 минут–2 часа. Однострочные правки так медленнее и дороже, чем Ctrl+K в редакторе.

WARN: путать Tab 2 и премиум-модели: Tab 2 — для печати (дешёвый, быстрый), премиум-модели — для задач (умные, дорогие). «Премиум на всё» сжигает лимиты; «Tab 2 на задачи» — разочаровывает в качестве.

WARN: гнать пять агентов и не ревьюить диффы: параллельность без контроля — путь к конфликтам слияний. Правило: у каждого агента — свой файл/область (или свой ветку), дифф читается до merge (уроки 11 и 16).
