# Что такое Cursor: ИИ-редактор вместо VS Code

## Цель

После урока студент сможет: объяснить, что такое Cursor и чем он принципиально отличается от «обычного» редактора с ИИ-плагином, назвать компанию-разработчика и год появления, перечислить четыре ключевых ИИ-инструмента редактора (Chat, Cmd+K, Tab, Composer) и объяснить, почему для курса его выбирают как основную среду разработки.

## Теория

Cursor — это десктопный редактор кода, разработанный компанией Anysphere (San Francisco, основана в 2022 году, редактор выведен в 2023-м). Технически Cursor — форк VS Code: у него те же расширения из рынка Visual Studio Code, те же горячие клавиши и та же система настроек, но ИИ встроен в сам редактор «из коробки», а не докупается плагинами. Это ключевое архитектурное отличие: плагин (как GitHub Copilot) работает в чужом редакторе и получает только то, что редактор ему покажет, а Cursor знает структуру проекта целиком — файлы, зависимости, контекст — и может сам читать и менять несколько файлов сразу.

Первое, что отличает Cursor от VS Code с плагином, — автодополнение Tab. Обычный автокомплит дописывает строку, а Tab в Cursor предсказывает целые блоки: функцию целиком, следующую правку в другом месте того же файла, даже переход к другому файлу, где логично продолжить правку. Работает он на собственной модели компании, специально обученной на последовательностях правок (не на «продолжении текста»), поэтому реагирует быстрее и точнее, чем LLM-комплит в чужих IDE. С 2025 года модель обновлена до Tab 2 — она догоняет в латентности «локальные» комплит-движки и при этом понимает контекст проекта.

Второй столп — ИИ-чат, встроенный прямо в редактор. Chat (горячая клавиша Ctrl+L) — это ассистент, который видит твой проект: можно попросить «найди, где мы обрабатываем ошибки сети», и Cursor semantic-поиском пройдёт по кодовой базе. Комбинация Ctrl+K — inline-правка: выделяешь фрагмент и по фразе «переделай на async/await» — модель меняет код прямо в файле. Composer (в версиях 2.x — Agent mode) — полноценный агент: получает задачу на языке естественного языка, сам читает нужные файлы, правит сразу несколько, запускает команды в терминале и показывает результат. Четвёртый инструмент — Background Agents: агенты, которые работают в облаке Cursor, пока ты занимаешься другим (об этом в уроке 9).

Важно понимать позиционирование: Cursor не «ChatGPT с редактором», а «редактор, в котором ИИ — основной способ работы». Компания намеренно строит инфраструктуру вокруг этого: собственный индекс кодовой базы, свои модели для комплита, свои облачные агенты. Поэтому Cursor платный (базовый Pro-тариф около 20 долларов в месяц), тогда как Copilot — плагин, который можно бесплатно попробовать. Разница в модели: плагин — это «подсказка на 10–30% времени», Cursor — среда, где агент ведёт 50–80% рутинных правок.

NOTE: Cursor обновляется очень быстро: названия инструментов, горячие клавиши и тарифы меняются от релиза к релизу. Ориентируйся не на конкретные цифры из статей, а на принципы: есть чат, есть inline-правка, есть автодополнение, есть агент — а конкретные имена и клавиши сверяй с актуальными доками Cursor.

TIP: если ты уже работаешь в VS Code — Cursor будет ощущаться как «VS Code, который знает тебя лучше»: те же keybindings, те же расширения, но ИИ на каждом шагу. Переезд занимает минуты: при первом запуске Cursor сам предлагает импортировать настройки, темы и расширения из VS Code — об этом в следующем уроке.

## Пример

```bash
# Cursor ставится как обычное приложение (скачиваем с сайта компании),
# затем проект открывается командой из терминала:
cursor .

# Проверить версию CLI и открыть конкретный файл:
cursor --version
cursor src/index.html --goto 12

# Внутри редактора:
# Ctrl+L — открыть чат и спросить: «Опиши структуру этого проекта»
# Ctrl+K — выделить блок кода и попросить его переписать
# Tab — принять предсказание
```

В примере мы открываем пустой проект будущего лендинга «Зерно». Спроси в чате про структуру — даже у пустого проекта Cursor ответит, что пока нет файлов, но уже предложит каркас: index.html, styles.css, скрипт. Это первая привычка курса: сначала спросить, потом делать.

## Частые ошибки

WARN: считать Cursor «ChatGPT с редактором»: это не веб-чат с прикрученным Monaco, а редактор с собственным индексом кодовой базы и агентной инфраструктурой. Отсюда и цена, и возможности — и ожидания должны соответствовать.

WARN: путать Cursor и GitHub Copilot: Copilot — плагин (в VS Code и других IDE, работает с чужим контекстом), Cursor — самостоятельный редактор (форк VS Code). Переносить привычки одного на другое — источник раздражения: у них разные модели, разные клавиши, разная экономика.

WARN: ждать, что ИИ сразу знает, что ты хочешь: без описания проекта (для чего сайт, какой стек, кто аудитория) агент будет гадать. Лечится одним файлом с правилами проекта — им мы занимаемся весь курс, начиная с этого урока.

WARN: сразу покупать Pro и «раскачивать» лимиты: сначала пройди уроки 2–5, посмотри, какие режимы реально используешь, и только потом решай, какой тариф под твой объём. Экономия — в уроке 17.

## Практическое задание

В файле .cursorrules (открыт в редакторе) опиши проект «Зерно»: что это за сайт, для кого он, какой стек будет использоваться и каких 2–3 главных страниц в нём минимум. Заполни раздел «О проекте» по шаблону — убери все плейсхолдеры и TODO. Этот файл станет «памятью» Cursor на весь курс: редактор читает его при каждой сессии, и все 17 следующих уроков будут наращивать его новыми правилами.
