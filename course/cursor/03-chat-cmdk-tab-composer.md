# Chat, Cmd+K, Tab, Composer: четыре инструмента редактора

## Цель

После урока студент сможет: уверенно различать четыре ИИ-инструмента Cursor — Chat, inline-правка (Ctrl+K), автодополнение Tab и Composer/Agent — и для любой конкретной задачи (объяснить, поправить строку, дописать блок, переделать несколько файлов) выбирать правильный инструмент, а не «один чат на всё».

## Теория

Главная ошибка новичка — использовать только чат. У Cursor четыре инструмента, и каждый закрывает свой тип задачи. Разбор по порядку: от самого частого к самому мощному.

Tab (автодополнение) — работает всегда, без нажатия: печатаешь код, Cursor предсказывает продолжение — строку, блок, следующую правку в файле, переход в другой файл (multi-tab). Это «шумоподавление» рутинной печати: на связках, повторных паттернах и повторяющемся CSS/HTML Tab экономит бóльшую часть символов за день. Навык не в том, чтобы «включить», а в том, чтобы не сопротивляться: увидел предсказание — Tab, не то — Esc. С Tab 2 (обновление 2025) латентность стала ниже, и «ловля» предсказаний встроилась в ритм печати.

Chat (Ctrl+L) — вопросы и объяснения: «что делает этот файл», «найди, где мы валидируем форму», «объясни, как тут работают эти функции». Чат видит контекст активного файла (и при @-упоминаниях — нужные куски проекта; об этом урок 7), отвечает текстом и может предложить правки кнопкой, но по умолчанию ничего не меняет. Чат — это «спросить», не «сделать».

Ctrl+K (inline-правка) — точечные правки внутри выделенного: выделяешь фрагмент и фразой задаёшь изменение — «переделай на классы», «добавь обработку пустого значения», «сократи до трёх строк». Результат появляется прямо в выделении; принимаешь (Enter) или отбрасываешь (Esc). Это инструмент «мелких хирургических» правок: когда файл и место ты уже знаешь.

Composer (в Cursor 2.x — Agent mode) — полноценная задача: «сделай форму обратной связи с валидацией и подключи к main.js». Агент сам читает нужные файлы, создаёт и правит сразу несколько, может запустить команду в терминале (npm, git) и показать изменения диффом. Это инструмент «задачи целиком», а не строки. Разница с чатом в том, что чат отвечает словами (и при желании — патчем), а агент действует: меняет файлы без твоего пофайлового подтверждения (с контролем через дифф).

Правило выбора, которое экономит годы: одна строка — Tab; фрагмент в известном месте — Ctrl+K; «как это устроено / где это» — Chat; задача с несколькими файлами или с запуском команд — Composer. Нарушение правила (например, Composer для переименования одной переменной) стоит дороже: агент дольше думает, дороже по токенам и иногда «доделывает» лишнее.

TIP: в чате всегда смотри, какой контекст агент берёт (справа в окне чата — список файлов/упоминаний): если в контексте пусто, ответ будет «общим». Добавь @-упоминания нужных файлов (урок 7) — и ответ станет конкретным. Это первое правило качественного промпта в Cursor.

NOTE: горячие клавиши в разных версиях немного различаются: в свежих версиях Composer вызывается и через Ctrl+I (или переключателем режима Agent), чат — Ctrl+L. Если клавиша «не та» — посмотри актуальные в настройках Keyboard Shortcuts; принцип четырёх инструментов от версии не меняется.

## Пример

```bash
# Каркас для практики создаём через Composer (задача в Agent mode):
# «Создай лендинг из index.html и styles.css: шапка, секция меню, подвал.
#  В main.js — обработчик формы меню (console.log отловленных данных).»

# Проверка в терминале, что файлы на месте:
ls

# Затем — четыре инструмента по порядку:
# Tab:      печатаем «const menu = [» и принимаем предсказание массива
# Ctrl+K:   выделяем блок секции → «добавь data-атрибуты для будущего JS»
# Ctrl+L:   «Сколько секций на странице и зачем нужна каждая?»
# Composer: «Добавь тёмную тему: переменные CSS и кнопку-переключатель в шапке»
```

Смотри, как каждый инструмент попадает в своё задание: Tab — печать массива, Ctrl+K — правка внутри секции, чат — вопрос о структуре, Composer — задача на два-три файла. Если ты поймал себя на «Composer для одной строки» — переключись на Ctrl+K: это и быстрее, и дешевле.

## Частые ошибки

WARN: один чат на всё: задачи, которые решаются Tab или Ctrl+K за пять секунд, тащить в Composer — это лишние секунды ожидания, лишний расход лимитов и риск «довёрнутых» правок. Правило «строка — Tab, фрагмент — Ctrl+K, вопрос — чат, задача — Composer» снимает 90% раздражения.

WARN: гонять Ctrl+K без выделения или с огромным выделением: инструмент точечный — выделяй ровно то, что менять (плюс-минус контекстные строки). Выделил полфайла и попросил «исправь» — получишь перепишут всё, включая то, что работало.

WARN: верить Tab вслепую: автодополнение — предсказание, а не истина. На критичных местах (условия, индексы, имена функций) проверяй принятый блок глазами — особенно длинные multi-tab-переходы в другие файлы.

WARN: в чате спрашивать без контекста и недовольствовать «общими» ответами: «почему форма не работает» — без ссылки на файл и ошибки — получит философский ответ. Добавь @file и текст ошибки — и ответ станет прикладным (урок 7).
