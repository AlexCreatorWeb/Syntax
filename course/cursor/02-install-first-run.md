# Установка Cursor и первый запуск: импорт расширений из VS Code

## Цель

После урока студент сможет: скачать и установить Cursor на macOS или Windows, пройти первый запуск (аккаунт, лицензия, импорт из VS Code), открыть в редакторе свой проект и убедиться, что ИИ-инструменты работают: чат отвечает, Tab дописывает строку, Ctrl+K доступен.

## Теория

Cursor устанавливается как обычное десктопное приложение: скачиваешь установщик с официального сайта компании, запускаешь, на macOS — перетаскиваешь в Applications, на Windows — обычный инсталлятор. Отдельно ставится CLI-команда cursor: во время установки есть галочка «Install command 'cursor' in PATH» (или её доставляют через Command Palette — «Shell Command: Install 'cursor' command in PATH»). С этой команды можно открыть любой каталог в редакторе прямо из терминала — то же, что code . в VS Code.

Первый запуск — самое ценное, что даёт Cursor новичку: мастер импорта. Если у тебя стоит VS Code, Cursor находит его профиль и предлагает перенести: тему, настройки (settings.json), горячие клавиши (keybindings.json), список расширений. Расширения ставятся из того же VS Code Marketplace, что и в оригинале — совместимость почти полная. Исключение — расширения, которые напрямую используют внутренние API VS Code, которые Cursor изменил (их единицы, и в списке импорта они помечаются). Перенос занимает минуты, и после него Cursor ощущается как «родной» VS Code — а не чужая программа с чужими клавишами.

Аккаунт: при первом запуске Cursor просит войти (или создать аккаунт) — без входа редактор почти бесполезен: ИИ-инструменты работают через облако компании. На бесплатном тарифе (Free/Hobby) есть месячный лимит «премиум-запросов» (сообщения в чате на топовых моделях, прогоны агента на дорогих моделях) и лимиты на автодополнение — этого достаточно, чтобы пройти весь курс. Оплата и тарифы разбираем в уроке 17; пока выбирай Free и просто отмечай для себя, какие режимы используешь чаще.

Открываем проект: из терминала cursor . в каталоге или через File → Open. Дальше — первый дымовой тест ИИ. Тест первый: Ctrl+L — чат. Спрашиваем что-то про открытый файл: «Опиши, что делает этот документ» (для HTML — структуру). Тест второй: Tab. Ставим курсор в конец строки с кодом и просто ждём полупрозрачное дополнение — если оно появляется и принимаетсся Tab, автокомплит жив. Тест третий: Ctrl+K — выделяем пару строк и вводим «переверни порядок этих строк»; если блок изменился в файле — inline-правка работает. Три «зелёных» — можно переходить к уроку 3 и осваивать инструменты по-настоящему.

TIP: не пропускай импорт, даже если VS Code у тебя «настроен минимально»: перенесённый набор расширений и hotkeys экономит час настройки. Если VS Code нет вовсе — импортируй из «всё по умолчанию» и не переживай: Cursor сам предложит базовый набор (форматтеры, Prettier, Git-интеграция встроена).

NOTE: на macOS под чипами Apple Silicon (M1–M4) Cursor ставится нативной сборкой и работает быстро; на Intel — тоже есть сборка, но ИИ-локализация тяжелее. На Windows — обычный x64-установщик. Если редактор открывается, а ИИ молчит, первым делом проверь интернет: все ИИ-запросы идут в облако, локально у редактора нет модели.

## Пример

```bash
# macOS: после установки из .dmg — регистрируем CLI из терминала
# (или: Command Palette → «Shell Command: Install 'cursor' command in PATH»)

# Windows: ставим с галочкой «Install command in PATH», затем в новом терминале:
cursor --version

# Открываем проект будущего лендинга «Зерно»:
mkdir zerno-site && cd zerno-site
cursor .

# Дымовой тест из терминала — открыть файл и сразу в редакторе:
# 1) Ctrl+L → «Опиши структуру этого каталога»
# 2) Tab — принять автодополнение
# 3) Ctrl+K на двух строках → «переведи комментарии на английский»
```

После cursor . редактор поднимет пустой каталог: это нормально — в уроке 3 мы попросим Composer создать каркас сайта, а пока проверили, что ИИ отвечает. Если чат молчит больше 10 секунд — проверь подключение и что ты вошёл в аккаунт (аватар в правом верхнем углу).

## Частые ошибки

WARN: ставить Cursor без CLI-галочки и потом «не найти» команду cursor: лечится через Command Palette (Ctrl+Shift+P → «Shell Command: Install 'cursor' command in PATH»), но проще сразу. После установки PATH иногда нужно перезапустить терминал.

WARN: пропускать импорт из VS Code и потом заново «нащупывать» свои hotkeys: мастер импорта в первом запуске — разовая экономия часа. Если пропустил — можно запустить заново из настроек (импорт из VS Code доступен не только в первом окне).

WARN: открывать сразу огромный проект (монорепо на 500 000 строк) и ждать мгновенного ИИ: индексация кодовой базы занимает время, и до её завершения semantic-поиск работает на неполном индексе. Научись на своём проекте-лендинге, а тяжёлые репозитории подключай потом.

WARN: считать бесплатные лимиты «на день»: у Free-тарифа лимиты премиум-запросов считаются за период (месяц), и их видно в настройках аккаунта. Не сжигай их на «спроси, а что если…»: сначала сформулируй задачу, потом — запрос.

## Практическое задание

Установи Cursor (или проверь, что установлен), импортируй профиль из VS Code (если он есть), открой в редакторе пустой каталог zerno-site и пройди дымовой тест: чат ответил, Tab дописал, Ctrl+K переписал. Затем в файле .cursorrules заполни раздел «Редактор»: какие расширения и hotkeys ты используешь, какая тема, и одну привычку, которую берёшь с VS Code.
