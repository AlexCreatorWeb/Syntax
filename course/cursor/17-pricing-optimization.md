# Тарифы и оптимизация: unlimited, бесплатно, экономия токенов

## Цель

После урока студент сможет: объяснить структуру тарифов Cursor (Free/Pro/Ultra/Teams и «премиум-запросы»), выбрать тариф под свой объём работы и применить 5–7 конкретных приёмов экономии (что «дорого», что «дёшево», как «не сжигать» лимиты).

## Теория

«Сколько стоит Cursor?» — вопрос, на который «20 $/мес» — неполный ответ. Экономика Cursor — «две скорости»: (1) «дешёвый» слой (Tab, авто-режим на собственной модели) — «почти безлимит» (в пределах тарифа); (2) «дорогой» слой (премиум-модели в чате/агентах: GPT, Claude, Gemini) — «премиум-запросы» (лимит, который горит). Тарифы (Free/Pro/Ultra/Teams) — «разные объёмы» «дорогого» слоя + «функции» (облачные агенты, Teams-фичи).

Структура (по состоянию на 2025–2026; точные цифры — в доках, они «меняются»): (1) Free/Hobby — «месячный» пул премиум-запросов (хватает на «курс» и «легкую» работу) + базовые лимиты Tab; (2) Pro (~20 $/мес) — «больший» пул премиум-запросов + «авто-режим» (собственная модель, «почти безлимит») + облачные агенты; (3) Ultra (~200 $/мес) — «для «тяжёлой» агентной работы» (больший пул, приоритеты); (4) Teams (~40 $/пользователь/мес) — «организационные» фичи (разделение лимитов, админка, SSO). «Безлимит» (в названиях) — «про «дешёвый» слой» (Tab/авто-режим), а не «про премиум-модели» (они — «всегда» лимитированы, «просто» объём «разный»).

Что «дорого», что «дёшево» (и как «не сжигать»). «Дорого»: премиум-модели в агентах (большие задачи, «умные» модели), облачные агенты (полный цикл), «большие» контексты (много файлов в @-упоминаниях). «Дёшево»: Tab (собственная модель, «быстрая» и «дешёвая»), авто-режим (собственная модель), «мелкие» правки (Ctrl+K). Семь приёмов экономии: (1) Tab «насовсем» (печать — «дешёвый» слой, «не зови» премиум для «опечаток»); (2) «правильный» инструмент (строка — Tab, фрагмент — Ctrl+K, задача — агент; «агент» для «одной строки» — «дорого» и «медленно» — урок 3); (3) «минимальный» контекст (много файлов в @ = много токенов; «минимум достаточный» — урок 7); (4) «правила» вместо «повторов» (.cursorrules — «один раз», а не «в каждом промпте» — урок 6); (5) «маленькие» задачи (агенту — 1–3 файла; «полпроекта» — «дорого» и «не точно» — урок 8); (6) «авто-режим» для «скучного» (переименования, генерация заглушек — «собственная» модель, «почти бесплатно»); (7) «смартфон-контроль» (видеть расход: в настройках аккаунта — «сколько премиум-запросов осталось»; «не сжигай» весь пул в «первый день»).

«Бесплатно» — «реально?» Да, для «курса» и «лёгкой» работы: Free-тариф (месячный пул премиум-запросов + Tab) — «хватает» на 18 уроков и «Зерно». «Платить» стоит, когда: (1) «облачные» агенты (Pro — обязательны); (2) «тяжёлая» агентная работа «каждый день» (Pro/Ultra — «больший» пул); (3) «команда» (Teams). «Курс» (и «Зерно») — «на Free» (с «оптимизацией» из 7 приёмов).

Экономика «агентной» работы: «агент» — «не «бесплатный»» (каждый запуск = токены + «премиум-запрос» (если «умная» модель)). «Экономия» — «не «жалеть»», а «правильно» (дешёвый слой для «дешёвого», «умный» — для «умного»). «Жалеть» (не запускать агента, «когда надо») — «дороже», чем «агент» (твоё время — «дороже» токенов).

TIP: «правило «двух слоёв»»: «рутина» (печать, мелкие правки, «скучное») — «дешёвый» слой (Tab/авто-режим); «задачи» (архитектура, «умное», «большое») — «умные» модели. Одно правило — и «расход» «падает» на 30–50% (без «потери» качества).

NOTE: тарифы/цифры «меняются» (Cursor — «быстрый» релиз, «цены» — «часть» «быстрого»). Точные цифры — «в доках на сегодня»; «принцип» («дешёвый/дорогой» слои, «правильный» инструмент, «минимальный» контекст) — «постоянный». Оптимизируй «принцип», а не «цифры из последнего твиттера».

## Пример

```bash
# «Экономия» в «Зерно» (7 приёмов в «работе»):
# 1. Печать (контент, CSS) — Tab (дешёвый слой).
# 2. «Переименовать классы» — авто-режим (собственная модель, «почти бесплатно»).
# 3. «Секция галереи» (задача, 2 файла) — агент (умная модель, «премиум-запрос»).
# 4. Контекст: @gallery.html + @styles.css (минимум, а не «полпроекта»).
# 5. Правила: стек/стиль — в .cursorrules (не «в промпте» каждый раз).
# 6. «Облачный» агент — «только» для «большого» (адаптивность, тесты).
# 7. Контроль: «сколько премиум-запросов осталось» (настройки аккаунта).
#
# Итог: «Зерно» (18 секций + тесты) — «в рамках» Free-тарифа (с «оптимизацией»).
```

Смотри на «распределение»: 80% «работы» — «дешёвый» слой (Tab/авто), 20% — «умные» модели (агенты на «задачи»). «Обратное» (80% «умных») — «сжигает» пул за «неделю».

## Частые ошибки

WARN: «премиум на всё»: «умная» модель для «опечатки» = «сжигание» пула. «Дешёвый» слой (Tab/авто) для «рутины» — «экономия» без «потери».

WARN: «агент» для «одной строки»: агент (запуск, «умная» модель, «премиум-запрос») для «Ctrl+K»-правки = «дорого» и «медленно». «Правильный» инструмент (урок 3).

WARN: «большие» контексты «на всякий»: 10 файлов в @ = 10× токенов. «Минимум достаточный» (урок 7) — «экономия» и «точность».

WARN: «жалеть» агента (не запускать, «когда надо»): «экономия» токенов за «счёт» твоего времени = «дорого» (твоё время — «дороже» токенов). «Правильно», а не «жалеть».
