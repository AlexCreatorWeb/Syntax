# Критический разбор: это развод? Альтернативы (TRAE, Windsurf)

## Цель

После урока студент сможет: без «фанатизма» оценить сильные и слабые стороны Cursor (что реально работает, а что — маркетинг), сравнить его с основными альтернативами (TRAE, Windsurf, GitHub Copilot) по критериям (модель, агенты, цена, экосистема) и принять решение «какая среда — под какую задачу», а не «какая круче».

## Теория

«Это развод?» — правильный вопрос, и честный ответ: «зависит». Cursor — не «волшебная кнопка» и не «мошенник»: это инструмент с сильными сторонами, слабыми сторонами и ценой. Разберём без «фанатизма» (и без «хейта»).

Сильные стороны (реальные, не маркетинг): (1) Tab — лучшее автодополнение на рынке (собственная модель, обученная на правках, а не на «продолжении текста»); (2) агентная инфраструктура (локальные + облачные агенты, PR-цикл) — зрелая и «из коробки»; (3) индекс кодовой базы (semantic search) — работает, и работает быстро; (4) экосистема VS Code (расширения, hotkeys) — «переехал и забыл». Слабые стороны (реальные): (1) цена (Pro ~20 $/мес, и «премиум-запросы» — лимит, который горит при активной агентной работе); (2) «агент уехал» (без ясной задачи — «средний по выборке» результат); (3) привязка к облаку (без интернета — «просто редактор»); (4) «быстрая» эволюция (названия/клавиши/тарифы меняются — доки «не успевают»).

Альтернативы (три основных, по состоянию на 2025–2026): (1) TRAE (ByteDance) — «бесплатный Cursor»: агентный редактор, есть «SOLO»-режим (автономный агент), бесплатная модель (и премиум-по запросу). Сильная сторона: цена (0 $ для старта). Слабая: экосистема моложе (меньше расширений/интеграций), облачные агенты — «не как у Cursor». (2) Windsurf (Codeium) — «агентный редактор» с «Cascade» (агент, который «помнит контекст сессии»). Сильная: Cascade (длинный контекст, «агент не забывает»). Слабая: экосистема и «зрелость» — «не Cursor». (3) GitHub Copilot — «плагин-гигант»: в VS Code (и других IDE), «классический» автокомплит + чат + агент (Copilot Coding Agent). Сильная: «везде» (VS Code, JetBrains, CLI), интеграция с GitHub (PR, issues). Слабая: «плагин» (а не «среда» — контекст «чужого» редактора).

Как выбирать (критерии, а не «какая круче»): (1) Цена: 0 $ (TRAE) / ~20 $ (Cursor Pro, Windsurf) / «по подписке» (Copilot). (2) Агенты: локальные + облачные + PR (Cursor) / SOLO (TRAE) / Cascade (Windsurf) / Copilot Agent (GitHub). (3) Экосистема: VS Code-совместимые (Cursor, TRAE) / свой (Windsurf) / «везде» (Copilot). (4) Твои задачи: фронтенд-вайбкодинг (Cursor/TRAE), «длинный контекст» (Windsurf), GitHub-центричный workflow (Copilot).

«Вердикт» (честный): Cursor — «зрелая» агентная среда (платная), TRAE — «бесплатный старт» (молодая экосистема), Windsurf — «контекст» (специфичная ниша), Copilot — «везде» (плагин, а не среда). Для курса (и для «Зерно») — Cursor: Tab + агенты + MCP + VS Code-экосистема. Но «знать альтернативы» — часть «критического» взгляда: «если Cursor станет дороже/хуже — есть план Б».

Ошибка «одна среда навсегда»: инструменты меняются (и Cursor, и TRAE, и Windsurf — «живые» проекты с «быстрыми» релизами). Навык — «работать с агентом» (задачи, диффы, git, тесты — уроки 8–13), а не «нажимать кнопки Cursor». Среда — «оболочка», навык — «ядро». Оболочку поменяешь — ядро останется.

TIP: держи «критерии выбора» в .cursorrules (раздел «Инструменты»: почему Cursor, что — план Б). Когда (если) среда поменяется — «критерии» (а не «привычка к кнопкам») будут «навигацией».

NOTE: рынок «агентных редакторов» — «быстрый» (новые игроки, «быстрые» релизы, «смена» цен). Конкретные цифры/функции в доках — «на сегодня»; «принципы» (агенты, диффы, git, тесты) — «постоянные». Сравнивай «принципы», а не «фичи из последнего твиттера».

## Пример

```bash
# «Сравнительная таблица» (в терминале — как заметка):
#                     | TRAE          | Cursor      | Windsurf    | Copilot
# Цена (старт)        | 0 $           | ~20 $/мес   | ~15–20 $/мес| ~10 $/мес
# Агенты              | SOLO          | локальные+облачные+PR | Cascade | Copilot Agent
# Экосистема          | VS Code-сов.  | VS Code     | свой        | «везде»
# Сильная сторона     | цена          | зрелость    | контекст    | «везде»+GitHub
# Слабая сторона      | молодость     | цена        | ниша        | «плагин»
#
# Решение для «Зерно»: Cursor (Tab + агенты + MCP + VS Code).
# План Б (если Cursor «дорого/хуже»): TRAE (старт) → Copilot (если GitHub-центричный).
```

Смотри на «критерии» (а не на «какая круче»): цена, агенты, экосистема, твои задачи. Четыре вопроса — и решение «принято» (а не «по твиттеру»).

## Частые ошибки

WARN: «фанатизм» («Cursor — лучший, точка»): «лучший» — «под твои задачи». Критерии (цена/агенты/экосистема/задачи) — а не «фан».

WARN: «хейт» («Cursor — развод, точка»): «развод» — «если ожидания «волшебная кнопка»». Инструмент (с сильными и слабыми сторонами) — а не «развод».

WARN: «одна среда навсегда»: инструменты меняются. Навык (задачи/диффы/git/тесты) — «ядро», среда — «оболочка». Оболочку поменяешь — ядро останется.

WARN: сравнивать «по твиттеру» (последний релиз/твит): «быстрый» рынок — «быстрые» изменения. Сравнивай «принципы» (агенты/контекст/цена), а не «фичу из последнего поста».
