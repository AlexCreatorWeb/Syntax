# Что такое Claude Code: терминальный ИИ-агент (vs Cursor / Copilot)

## Цель

После урока студент сможет: объяснить, что такое терминальный ИИ-агент, назвать его отличия от IDE-встраиваний (Copilot) и AI-редакторов (Cursor), описать, где Claude Code силён, а где — слабее, и выбрать подходящий инструмент под конкретную задачу.

## Теория

Claude Code — это агент, который живёт в терминале. Ты запускаешь команду claude в каталоге проекта, и дальше работаешь как с командным ассистентом: описываешь задачу словами, агент читает файлы, правит их, запускает тесты, делает коммит — а ты смотришь на то, что он делает, и можешь в любой момент вмешаться, поправить направление или остановить.

Сравни это с двумя другими категориями инструментов. Инлайн-ассистенты (Copilot, Codeium) — это автодополнение: ты пишешь, а подсказка предлагает следующие строки. Управление остаётся за человеком на каждой строке. AI-редакторы (Cursor, Windsurf) — это привычный редактор с ИИ-панелью: агент правит файлы, но в рамках GUI. И, наконец, терминальные агенты (Claude Code, Codex CLI): весь контекст — в терминале, весь контроль — через текст, и именно это делает их наиболее «автономными».

Почему терминал? Потому что терминал — это универсальный интерфейс. Через него можно запустить тесты, собрать проект, развернуть docker, проверить git — не выходя из контекста. Агент, живущий в терминале, получает доступ к всему окружению разработчика, а не только к файлам редактора. Ему не нужно «уходить в другую вкладку», чтобы что-то проверить.

Теперь главное отличие — уровень автономии. Инлайн-ассистент предлагает одну строку. AI-редактор выполняет правку, которую ты явно указал. Терминальный агент получает задачу целиком: «добавь логин по email» — и сам решает, какие файлы читать, какие функции менять, какие тесты запустить, чтобы убедиться, что ничего не сломалось. Ты не микроуправляешь, ты задаёшь цель и проверяешь результат.

Это не значит, что Claude Code лучше всех инструментов сразу. Он слабее в точечных правках одной функции (для этого инлайн-ассистент быстрее), слабее в визуальном редакторе кода (для этого GUI удобнее), но сильно выигрывает в больших задачах, которые требуют чтения десятков файлов, запуска команд и итеративной отладки.

TIP: не выбирай «один инструмент для всего». Профессионалы используют и инлайн-ассистент для мелких правок, и терминальный агент для больших задач, и GUI-редактор для визуальных задач. Инструменты взаимодополняют, а не заменяют друг друга.

NOTE: терминальный агент — это не «чёрный ящик». Ты видишь каждую команду, которую он запускает, каждый файл, который он правит. Прозрачность — часть дизайна: агент всегда может быть остановлен, отменён, переделан. Это отличает его от «автопилота», который летит сам.

## Пример

```bash
# Запускаем сессию в каталоге проекта
cd my-project
claude

# Задача целиком — агент сам решает, что делать
> добавь обработку ошибок в fetch, добавь тесты, запусти тесты

# Видим, какие команды агент запускает (прозрачность)
# npm test, npx jest --coverage, и т.д.

# Вмешиваемся, если нужно
> подожди, сначала перепиши функцию parseInput

# Отменяем, если пошло не так
# Ctrl+C — остановить текущее действие
```

В примере видно ключевое: агент работает автономно, но ты видишь каждый шаг и можешь в любой момент вмешаться.

## Частые ошибки

WARN: считать терминальный агент «чёрным ящиком»: он прозрачен — видишь каждую команду и правку. Замыкаясь на этом, ты теряешь главный инструмент контроля.

WARN: использовать его для мелких правок: для изменения одной строки инлайн-ассистент быстрее и дешевле. Терминальный агент окупается на задачах, требующих чтения файлов и запуска команд.

WARN: ждать, что он «просто работает»: агент — это инструмент, а не маг. Качество результата сильно зависит от качества задачи и контекста, который ты ему дал.

WARN: забывать про разрешения: агент не может бесконечно запускать команды и править файлы — есть система разрешений, которую мы разберём в уроке 7.

## Практическое задание

В файле CLAUDE.md (открыт в редакторе) зафиксируй, какие инструменты ты используешь и для каких задач: инлайн-ассистент для мелких правок, терминальный агент для больших, GUI-редактор для визуальных. Заполни разделы по шаблону и устрани все TODO. А через месяц работы ты сам почувствуешь, где терминальный агент экономит часы, а где — наоборот, и будешь выбирать инструмент осознанно, а не по привычке.
