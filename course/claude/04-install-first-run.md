# Установка Claude Code (Mac / Windows) и первый запуск

## Цель

После урока студент сможет: установить Claude Code на Mac и Windows, пройти первый запуск с onboarding, выполнить простейшую задачу и убедиться, что среда настроена правильно, а PATH и версии совместимы.

## Теория

Claude Code — это CLI-приложение, которое устанавливается через npm (Node.js). Минимальное требование — Node.js 18 или новее. На Mac можно установить напрямую через npm; на Windows — через WSL2 (рекомендуется) или напрямую, если Node.js установлен глобально и ты готов к небольшим сюрпризам с bash-инструментами.

Почему WSL2 на Windows? Потому что Claude Code опирается на Unix-инструменты: bash, git, ls, grep — и на их поведение (кодировки, пути, права доступа). В WSL2 с дистрибутивом Linux они работают нативно, а в «чистой» Windows через Git Bash возможны расхождения. Если у тебя уже есть WSL2 с Ubuntu — используй его. Если нет — установка: команда wsl --install в PowerShell от имени администратора, дождаться загрузки, создать пользователя дистрибутива. Это делается один раз, дальше WSL2 работает как обычный Linux-контейнер.

После установки запускаешь claude в каталоге проекта. Первый запуск — это onboarding: вход в аккаунт (OAuth через браузер), выбор модели по умолчанию, и сразу можно работать. Onboarding занимает пару минут; если браузер не открылся автоматически — ссылка появится в терминале, открываете вручную.

Первая задача должна быть простой, чтобы убедиться, что весь цикл работает. Хороший кандидат: «прочитай README и расскажи, что это за проект» — агент прочитает файл, ответит, и ты видишь полный цикл: задача → чтение → ответ. Вторая задача — «запусти тесты и скажи, что упало» — агент запустит команду, прочитает вывод, расскажет про ошибки. Если обе задачи прошли штатно — среда готова к курсу.

NOTE: при первом запуске Claude Code попросит разрешения на некоторые операции (запуск команд, запись в файлы). Это система разрешений — в уроке 7 разберём её подробно. На первом запуске просто соглашайся: ты в своём проекте, и агент делает ровно то, что ты просишь.

TIP: если ты используешь nvm, volta или fnm для управления версиями Node — убедись, что в активной версии установлен claude и что она же подхватывается в терминале. Проверка простая: команда which claude (Mac/Linux) или where claude (Windows) показывает путь к бинарнику, а node --version — активную версию. Если версии не совпадают с той, где ставил — переустанови в активной.

## Пример

```bash
# Mac: установка через npm
npm install -g @anthropic-ai/claude-code

# Windows (WSL2): то же самое внутри дистрибутива
npm install -g @anthropic-ai/claude-code

# Проверяем установку и версию Node
claude --version
node --version

# Переходим в каталог проекта
cd my-project

# Первый запуск
claude
# onboarding: вход по email (OAuth), выбор модели

# Первая задача — проверка цикла «чтение»
> прочитай README и расскажи, что это за проект

# Вторая задача — проверка цикла «запуск команд»
> запусти тесты и скажи, что упало
```

После onboarding ты видишь промпт агента — можно работать. Обе проверки должны пройти без вопросов.

## Частые ошибки

WARN: установка на Windows без WSL2: в большинстве случаев работает, но bash-инструменты и пути могут вести себя не так, как ожидается. Если есть WSL2 — используй его и не думай.

WARN: Node.js ниже 18: Claude Code требует 18+. Проверка: node --version. Если меньше — обнови Node через nvm или установщик.

WARN: команда claude не находится в PATH: типично, если ставил в одну версию Node, а активна другая. which claude покажет, где бинарник; если «не найдено» — проверь, в какой версии Node ставил.

WARN: первый запуск вне каталога проекта: агент не знает, над чем работать, и отвечает в общем. Всегда запускай claude в каталоге, где лежат файлы проекта — это не формальность, а часть контекста.

## Практическое задание

В файле CLAUDE.md (открыт в редакторе) зафиксируй своё окружение: ОС и её версию, способ установки (npm/WSL2), версию Node.js, путь к бинарнику claude. Заполни разделы по шаблону и устрани все TODO. Это базовый контекст, который агент будет читать в начале каждой сессии. Если что-то из этого списка не заполнил — дозаполни в первой же сессии: две минуты на CLAUDE.md сейчас экономят двадцать минут разговоров с агентом потом, когда он будет каждый раз переспрашивать про окружение. И если через месяц установка «развалится» — переустановка занимает пять минут: одна npm-команда. Не держи в голове окружение — оно в CLAUDE.md.
