# Курс «Claude Code: агенты, которые пишут код» — 18 уроков (roadmap + контракт)

Цепочка: Anthropic/Claude → что такое Claude Code → регистрация из РФ → установка → базовый цикл агента → CLAUDE.md → режимы/разрешения → контекст и /compact → best practices → git/worktrees → тестирование (Playwright) → отладка → MCP → hooks → субагенты → Skills → токены/оплата → финальный проект (Next.js + PostgreSQL, vibe coding).

## Контракт урока (жёсткий, QC сидера падает при нарушении)

1. 5 разделов строго: `## Цель`, `## Теория`, `## Пример`, `## Частые ошибки`, `## Практическое задание`.
2. Минимум 1 `TIP:` или `NOTE:` И минимум 1 `WARN:` (ошибки оформляются WARN-пунктами).
3. Callout-строки — plain text: внутри TIP/NOTE/WARN никаких `**` и backtick'ов.
4. Без таблиц, без markdown-ссылок `[t](url)`.
5. Объём content (после mdToLite) 4000–7000 зн.
6. В «Пример» — блок ```bash (терминал Claude Code: команды и промпты).
7. `code/NN.md` = скелет ЗАДАНИЯ (CLAUDE.md с `<!-- TODO -->`, не решение!), открывается в редакторе как файл урока трека.
8. В прозе без `**bold**` (только заголовки).
9. Единая сквозная метафора курса: студент ведёт реальный проект «Трекер привычек», и каждый урок заканчивается тем, что он добавляет в его CLAUDE.md правила/навыки, изученные в уроке.

## Спринты (связи между уроками)

- 1–4: знакомство (модели, что это, аккаунт, установка).
- 5–8: рабочий процесс (цикл агента, память CLAUDE.md, режимы, контекст).
- 9–12: качество работы (best practices, параллельная работа с git, тесты, отладка).
- 13–17: инструменты (MCP, hooks, субагенты, Skills, экономика токенов).
- 18: финальный проект — приложение с нуля.
