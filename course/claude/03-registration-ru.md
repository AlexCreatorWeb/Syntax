# Регистрация из России: как пользоваться без банов

## Цель

После урока студент сможет: пройти регистрацию аккаунта Anthropic из России, понимать, какие практики увеличивают риск бана, настроить аккаунт так, чтобы работать спокойно, и предусмотреть план Б на случай проблем с оплатой.

## Теория

Claude Code — облачный сервис: модель работает на серверах Anthropic, а твой клиент только шлёт запросы и показывает результат. Для работы нужен аккаунт Claude с подпиской Pro или Max, либо API-ключ. Для большинства студентов подходит подписка: фиксированная цена в месяц и большая квота использования. API-ключ — вариант «платишь за токены», он удобнее для скриптов и автоматизации, но для интерактивной работы быстро становится дороже подписки.

Регистрация из России имеет нюансы, и главный барьер — платёжная система. Банки из РФ не принимают оплату напрямую, поэтому нужен способ оплаты из юрисдикции, где Stripe работает штатно. Варианты: карта иностранного банка (если есть родственники или друзья за рубежом), виртуальная карта из сервисов, поддерживающих Stripe, или оплата через посредников. Выбор способа — личное решение, но главное — иметь стабильный канал оплаты: подписка, слетающая в середине проекта, — худший сценарий.

Теперь про баны. Риск бана появляется не от самого факта регистрации из РФ, а от «сомнительных» паттернов: оплата картой из юрисдикции, не совпадающей с geolocation; частая смена IP из разных стран за короткий период; одна карта, оплачивающая несколько аккаунтов. Если всё стабильно — один аккаунт, одна карта, один регион — риск минимален. Платёжные системы хорошо tolerate аккуратные постоянные паттерны и плохо — хаотичные.

Самые безопасные практики: регистрируйся один раз и больше не трогай настройки аккаунта; используй стабильный IP (домашний VPN или конкретный региональный выход — не «прыгай» между странами); оплачивай той же картой каждый месяц; не переиспользуй одну карту на несколько аккаунтов. Если что-то пошло не так — бан или проблема с оплатой — пиши в поддержку Anthropic: шанс восстановления высокий, особенно если история использования аккуратная и платёж можно подтвердить.

NOTE: не путай «бан» и «проблему с оплатой». Если карта отклонилась — это не бан, это просто не прошла транзакция. Бан — это когда аккаунт закрывают из-за нарушения правил. Первое лечится сменой карты, второе — перепиской с поддержкой. Симптом у обоих похож («не работает»), но лечение разное.

Второй по важности вопрос — email. Используй постоянный адрес, по которому ты реально получаешь письма: сюда приходят подтверждения оплаты, уведомления о проблемах с аккаунтом и письма поддержки. Временные «разовые» адреса удобны для регистраций на сайтах, но для подписки на месяцы — плохая идея: потеряешь доступ к переписке.

TIP: держи аккаунт «чистым» с первого дня: один аккаунт на человека, стабильная оплата, стабильный регион. Это не только снижает риск бана, но и упрощает отчёты: ты всегда понимаешь, сколько потратил и на что. Аккуратная история — это твоя страховка при любой претензии платёжной системы.

## Пример

```bash
# Регистрируемся на сайте Anthropic (в браузере):
# - постоянный email
# - пароль
# - оплата: карта из подходящей юрисдикции

# Подписываемся на Pro (или Max, если нужен больше квот)

# Логируемся и запускаем Claude Code
claude
# при первом запуске — вход по email (OAuth через браузер)

# Проверяем, что сессия жива
claude --version
```

После регистрации и оплаты ты видишь в Claude Code свою сессию — агент готов к работе. Если OAuth не сработал с первого раза — переподключи VPN в том же регионе, что и при оплате.

## Частые ошибки

WARN: «прыгать» между странами в VPN: сегодня Германия, завтра США, послезавтра Литва — это красный флаг для платёжной системы. Выбери один регион и оставайся в нём на месяцы, а не на дни.

WARN: одна карта на несколько аккаунтов: если платёжная система увидит, что одна карта оплачивает пять аккаунтов, это подозрительно. Один аккаунт — одна карта, и не обсуждается.

WARN: временный email: если аккаунт заблокируют, восстановить его по временному адресу будет невозможно. Используй постоянный адрес, по которому ты реально читаешь письма.

WARN: смена способа оплаты в середине цикла: если карта отклонилась, не торопись оформлять другую — сначала проверь, что проблема именно в карте (баланс, регион), а не в сервисе или VPN.

## Практическое задание

В файле CLAUDE.md (открыт в редакторе) зафиксируй свои настройки: способ оплаты, регион, уровень подписки, email аккаунта (без полного пароля — это не хранилище секретов). Заполни разделы по шаблону и устрани все TODO. Это твой «паспорт» для работы с Claude Code на весь курс.
