# Курс «GitHub Copilot: ИИ на GitHub и в вашем редакторе» — 18 уроков (roadmap + контракт)

Цепочка: что такое Copilot → установка в VS Code → JetBrains и доступ из России → чат и @workspace/@terminal → автодополнение GPT-4o → кастомные инструкции → Coding Agent → agent mode vs coding agent → Copilot CLI → MCP → тестирование/TDD → Copilot Workspace → code review → автоматизация (Actions, Skills) → практика в ежедневном процессе → тарифы и оплата из России → критический взгляд и статистика багов → бесплатные альтернативы и выбор инструмента.

## Контракт урока (жёсткий, QC сидера падает при нарушении)

1. 5 разделов строго: `## Цель`, `## Теория`, `## Пример`, `## Частые ошибки`, `## Практическое задание`.
2. Минимум 1 `TIP:` или `NOTE:` И минимум 1 `WARN:` (ошибки оформляются WARN-пунктами).
3. Callout-строки — plain text: внутри TIP/NOTE/WARN никаких `**` и backtick'ов.
4. Без таблиц, без markdown-ссылок `[t](url)`.
5. Объём content (после mdToLite) 4000–7000 зн.
6. В «Пример» — блок ```bash (терминал: gh, code --install-extension, copilot CLI).
7. `code/NN.md` = скелет ЗАДАНИЯ (файл copilot-instructions.md с `<!-- TODO -->`, не решение!), открывается в редакторе как файл урока трека.
8. В прозе без `**bold**` (только заголовки).
9. Единая сквозная метафора курса: студент ведёт публичный GitHub-репозиторий taskit — маленькую Python CLI-утилиту «список задач» (add/list/done, данные в JSON-файле) — и каждый урок заканчивается тем, что он добавляет в его файл copilot-instructions.md (настоящий .github/copilot-instructions.md) правила, изученные в уроке. К уроку 18 файл собран полностью.

## Спринты (связи между уроками)

- 1–3: знакомство (что это, VS Code, JetBrains/доступ из России).
- 4–6: инструменты в редакторе (чат и mentions, автодополнение, кастомные инструкции).
- 7–10: агенты (Coding Agent, agent mode vs coding agent, Copilot CLI, MCP).
- 11–14: качество и автоматизация (TDD, Workspace, code review, Actions/Skills).
- 15–18: практика и экономика (ежедневный процесс, тарифы, критический взгляд, альтернативы).
