# Тарифы, бесплатные планы, оплата из России

## Цель

После урока студент сможет: объяснить структуру тарифов GitHub Copilot (Free / Pro / Pro+ / Business) и что входит в каждый, собрать свой путь оплаты из России (студенческий, App Store, карта), посчитать, сколько premium-запросов нужно на месяц под свой workflow, и принять решение «какой тариф под мой объём» без «на всякий случай».

## Теория

Тарифы Copilot (цифры меняются — сверяй с актуальной страницей, это ориентир на 2026):

- Free: 2000 автодополнений и 50 premium-запросов чата в месяц, базовый доступ к агенту (с лимитами). Для курса — достаточно: 18 уроков уложатся в лимит, если не «гонять» комплит на автомате.
- Pro: ~10 $/мес, больше premium-запросов (сотни), полный доступ к агенту, MCP, Workspace. «Основной» тариф для активного разработчика.
- Pro+: ~39 $/мес, ещё больше запросов, «тяжёлые» модели, приоритет. Для тех, кто «живёт» в ИИ (8+ часов в агенте).
- Business: ~19 $/мес за пользователя (организация), управление, метрики, «приватность» (код не используется для обучения). Для команд.

Что такое «premium-запрос» (и почему это не «строка»): premium-запрос — «дорогой» вызов модели (чат с большим контекстом, агент, Workspace). Автодополнение — «дешёвое» (считается отдельно, по лимиту 2000/мес на Free). Когда видишь «premium request» — это «мы вызвали модель с большим контекстом», и лимит на Free (50/мес) кончается за 2–3 дня активного использования. Отсюда правило: «дорогие» вызовы (агент, Workspace) — осознанно, «дешёвые» (комплит, чат без контекста) — свободно.

Оплата из России (по убыванию «болёвки»):

- Студенческий: Pro бесплатен на год (верификация .edu или студенческая). Лучший вариант, если студент — не платишь вообще.
- App Store / Google Play: приложение Copilot (iOS/Android), оплата картой, которую принимает магазин. Работает без VPN.
- Зарубежная карта (родственники, сервисы): оплата на сайте GitHub, VPN только на момент платежа.
- Корпоративный: если работодатель платит (Business-тариф) — не платишь сам.

Посчитать «мой объём» (правило урока): посмотри в Billing and plans (github.com → Settings → Billing → Copilot) — сколько premium-запросов ушло за неделю. Если «до лимита Free» больше 2 недель — Free хватает. Если «кончается за 3 дня» — Pro. Не «на всякий случай», а по цифрам.

TIP: перед покупкой Pro «на неделю» проверь: (1) сколько premium-запросов ушло за последнюю неделю (Billing), (2) что именно «съедает» (агент? Workspace? чат с большим контекстом?), (3) можно ли «перевести» часть на Free (комплит вместо агента для «маленького»). 5 минут аналитики — и решение «Pro или Free» будет осознанным.

NOTE: лимиты и цены GitHub меняет (добавляет модели, меняет «премиум-запрос» на «кредиты»). Не калибруй «навсегда» на цифрах из этого урока: проверь актуальные в Billing and plans перед покупкой.

## Пример

```bash
# 1. Проверь свой объём (в браузере):
#    github.com → Settings → Billing and plans → Copilot
#    (там: тариф, автодополнения, premium-запросы, история)

# 2. Пример расчёта: за неделю ушло 30 premium-запросов.
#    За месяц: ~120. Free-лимит (50) — кончится за 2 недели.
#    Вывод: если работаешь «активно» (ежедневно) — Pro.
#    Если «по 2–3 часа в неделю» — Free (120/мес < 50*2? нет, > 50) —
#    всё-таки Pro, но можно «снизить» (меньше агента, больше чата).

# 3. Студенческий (если применимо):
#    github.com → Settings → Billing → Copilot → Student plan
#    → верификация (.edu) → Pro бесплатен на год.
```

Сценарий «посмотри цифру → посчитай месяц → реши» — это и есть «осознанный» выбор тарифа. Не «всем Pro», а «под мой объём».

## Частые ошибки

WARN: покупать Pro «на всякий случай»: если «активность» 2–3 часа в неделю, Free хватит на месяц. Pro — для ежедневной работы (8+ часов). Проверь цифру (Billing), а не «ощущение».

WARN: не следить за лимитом: 50 premium-запросов на Free кончаются за 2–3 дня активного использования, и «агент» перестанет работать (тихо). Следи за счётчиком (Billing), и «сбрасывай» (в конце месяца) осознанно.

WARN: платить «с карты, которая не пройдёт»: Russian-карты (МИР) на сайте GitHub не работают. Путь: App Store / зарубежная карта / студенческий. Не «мучай» оплату — выбери рабочий путь (урок 3 — детали).

WARN: путать «premium-запрос» с «строкой кода»: один «премиум» — это «вызов модели с контекстом», а не «строка». Один агентский «запуск» может съесть 5–10 «премиум» (зависит от задачи). Отсюда «считай по задачам», а не «по строкам».

## Практическое задание

Посмотри свой объём (Billing and plans), посчитай «месяц» (неделя * 4) и реши: Free / Pro / студенческий. Запиши в copilot-instructions.md раздел «Бюджет и лимиты»: какой тариф, сколько premium-запросов в месяц (цель), что «дорогое» (агент, Workspace), что «дешёвое» (комплит, чат), правило «дорогие — осознанно, дешёвые — свободно». Эти правила будут читать и ты (перед «запуском агента»), и агент (в отчёте).
