# Установка и настройка: VS Code

## Цель

После урока студент сможет: установить и активировать GitHub Copilot в VS Code через GitHub-аккаунт, настроить три ключевых параметра (автодополнение, inline-редактирование, чат), назвать горячие клавиши чата и inline-правки и диагностировать ситуацию «Copilot не подсказывает» по контрольному списку из пяти шагов.

## Теория

Установка расширения — одна команда или один клик в маркете: GitHub.copilot. После установки VS Code попросит войти: кнопка Log in opens browser — откроется GitHub, ты авторизуешь расширение по существующему аккаунту. Аккаунт GitHub и аккаунт Copilot — одно и то же: биллинг, лимиты, история чатов и агентские сессии живут на стороне GitHub (settings → Billing → Copilot). Если ты студент с .edu-адресом — на этом же экране будет верификация студенческого статуса: Pro становится бесплатным на год.

После логина важно проверить три настройки (Settings → скопируй туда блок из «Примера»):

- github.copilot.editor.enableAutoCompletions: автодополнение включено (в новых сборках по умолчанию true, но при бесплатном тарифе иногда нужно явно включить).
- github.copilot.editor.enableEditorStatus / inline edit: доступ к Ctrl+I (inline-правка) — в 2025-м она стала частью ядра, и отдельная фиче-флаг не нужен, но клавиша должна быть назначена.
- github.copilot.chat.terminalRecommendationEnabled: чтобы чат предлагал команды и мог читать вывод (@terminal).

Горячие клавиши, которые мы используем весь курс: Ctrl+L — чат в боковой панели, Ctrl+I — inline-правка выделенного (на macOS — Cmd+I), # — упоминание открытого файла, @ — упоминание сущности (workspace, terminal, git), Tab — принять подсказку. На старых раскладках Ctrl+I может конфликтовать с «вставить символ» — переназначь в Keyboard Shortcuts.

Контрольный список «Copilot не подсказывает»: (1) вошёл ли ты в аккаунт (иконка человека в панели Copilot), (2) не истёк ли бесплатный лимит (в панели снизу — счётчик), (3) не отключено ли автодополнение для конкретного языка (Settings → Language Overrides), (4) не мешает ли другое расширение автодополнения (всемирная классика: IntelliSense-подобные плагины), (5) обновлён ли VS Code (Copilot требует свежий редактор). В девяти случаях из десяти лечится пунктами 1 и 5.

TIP: установи сразу и расширение GitHub Pull Requests (GitHub.pull-request): в нём будут жить PR от Coding Agent, ревью и комментарии — с 7-го урока это один из главных рабочих экранов.

NOTE: на бесплатном тарифе лимиты считаются по месяцам и сбрасываются автоматически; premium-запросы (чат с большим контекстом, агент) расходуют отдельную квоту, а обычные автодополнения — свою. Не сжигай квоту чатом «на всякий случай» — к уроку 7 у агентов она понадобится.

## Пример

```bash
# Установка расширения командой:
code --install-extension GitHub.copilot
code --install-extension GitHub.pull-request

# Проверка, что расширение на месте:
code --list-extensions | grep -i copilot

# В редакторе (Settings, JSON) блоки, которые мы дописываем:
# {
#   "github.copilot.editor.enableAutoCompletions": true,
#   "github.copilot.chat.terminalRecommendationEnabled": true,
#   "editor.inlineSuggest.enabled": true
# }
```

Открой settings в JSON (Ctrl+Shift+P → Preferences: Open User Settings (JSON)) и допиши три строки. Затем создай файл hello.py, напиши `def greet(name):` — если серым курсивом дописалась строка `return "Hello, " + name` — комплит жив. Нажми Ctrl+L, спроси «кто ты и какой у меня тариф?» — чат жив. Если оба теста зелёные, настройка завершена.

## Частые ошибки

WARN: устанавливать два «копилота» (официальное расширение + сторонние LLM-плагины) и удивляться конфликтам подсказок: оставь только GitHub.copilot, сторонние отключи — конфликты автодополнения лечатся именно так.

WARN: настраивать Copilot в Workspace Settings (папка .vscode) вместо User Settings: личные клавиши и включение комплита живут в пользовательских настройках; workspace-настройки имеют смысл, когда правила команды — а это отдельная тема (бизнес-тариф).

WARN: забыть про лимит бесплатного тарифа: 2000 автодополнений в месяц кончается у активных студентов за две недели «на автомате». Следи за счётчиком в панели Copilot — и отключай комплит в файлах, где он мешает (настройку по языку мы поставим в уроке 5).

WARN: искать кнопки, показанные в 2024-м, в 2026-м GitHub: интерфейс чата и агентов обновлялся несколько раз, часть пунктов переехала в меню «...» у чата. Если пункта нет — посмотри в меню «...», а не гугли старые скриншоты.

## Практическое задание

Закрой настройку: оба теста из «Примера» (комплит + чат) зелёные, расширение Pull Requests установлено. Затем в copilot-instructions.md заполни раздел «Команды»: какие терминальные команды запускают утилиту, тесты и линтер (для taskit — python taskit.py add «задача», python -m pytest, ruff check .). Эти команды будут читать и чат, и агент — без них Copilot запускает тесты наугад.
