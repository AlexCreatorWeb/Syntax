# Автодополнение кода: модель GPT-4o

## Цель

После урока студент сможет: объяснить, как работает автодополнение Copilot (модель GPT-4o-класса и механизм «следующей правки», а не просто «продолжения строки»), принимать и отвергать подсказки по правильной механике, настраивать комплит по языкам и файлам и понимать, от чего подсказки становятся точными (контекст, стиль, размер правок).

## Теория

Автодополнение — самая «бесшумная» фича Copilot: серым курсивом строка дописывается прямо в редакторе, Tab принимает, Esc отменяет. Но под капотом уже не «автодополнение по префиксу», как в старых IDE: с 2024 года GitHub перевёл комплит на модель GPT-4o-класса, которая видит не только текущий файл, но и соседние (открытые вкладки, импорты), а с 2025-м — и весь workspace через индекс.

Ключевая фича, ради которой и стоит новый комплит — Next Edit Suggestions: модель предсказывает не только «дальше по строке», но и следующую правку в другом месте того же файла. Ты изменил подпись функции — и комплит сам предлагает обновить её вызовы внизу файла. Это сокращает ритуал «поменял, потом нашёл все вызовы» до одного Tab.

Что делает подсказки точными — и это главная наука урока:

- Пиши сначала «каркас»: сигнатуру функции, коммент-описание, тест с ожидаемым результатом. Модель продолжает твою логику, а не угадывает её.
- Делай правки маленькими шагами: комплит обучен на реальных последовательностях правок, и длинная ручная вставка без остановок сбивает его контекст.
- Держи файл читаемым: неформатированный код даёт модели неформатированные подсказки. Fmt-команда перед сессией окупается.
- Дай модели твой стиль: комплит подстраивается под синтаксический сахар файла (f-строки вместо concat, type hints да/нет). Поэтому «Стиль кода» в инструкциях (задание урока) реально влияет на подсказки.

Настройка: Settings → Language Overrides позволяет выключить комплит для конкретных языков (например, для markdown-файлов, где серые строки мешают), а «Enable suggestions on trigger» — чтобы подсказка появлялась не после каждого символа, а по явному запросу (Esc/Tab-триггер) — это экономит лимит на бесплатном тарифе.

TIP: если подсказка «молчит» в новом файле — это не поломка: в пустом файле комплиту нечего продолжить. Напечатай первую строку (import или комментарий) и подожди секунду: модель «запустится».

NOTE: лимит бесплатного тарифа (2000 автодополнений в месяц, цифры меняются) считает принятые и показанные подсказки по-разному в разных версиях — ориентир: не гоняй комплит «на автомате» в файлах, где ты в любом случае пишешь руками (конфиги, разметка), чтобы квота дожил до уроков с агентами.

## Пример

```bash
# 1. Открой taskit.py и напиши каркас команды done (без тела):
#    def mark_done(task_id: int) -> None:
#        """Отметить задачу выполненной; неизвестный id — ошибка."""
#    Подожди: комплит предложит тело функции (чтение tasks.json,
#    поиск id, установка done=True, сохранение).
#    Tab — принять (или принять частями: Esc и переписать кусок).

# 2. Проверь Next Edit Suggestions: измени подпись
#    (добавь параметр) — комплит предложет обновить вызовы в main().

# 3. Проверь, что комплит подхватил стиль: напечатай начало
#    f-строки в выводе list — модель продолжит f-строкой,
#    а не "%s" % или concat'ом.

# 4. Запусти утилиту:
python taskit.py done 1
python taskit.py list
```

Сценарий «каркас → комплит достроил → проверил» — это и есть работа с GPT-4o-комплитом: ты управляешь логикой (имена, сигнатуры, docstring), модель заполняет рутину. Если тело пришло не тем — не сражайся: Esc, поправь docstring точнее, запроси заново.

## Частые ошибки

WARN: принимать подсказки «серым потоком», не глядя: комплит GPT-4o-класса правдоподобен, но выдумывает имена функций и импорты (в 2025-м исследовании METR разработчики с Copilot ловили на себе «впечатляюще выглядящие» баги). Правило курса: подсказка = черновик, тест = правду скажет тест.

WARN: писать код «спереди назад» одним потоком: длинные ручные вставки без остановок сбивают контекст модели, и следующие подсказки становятся хуже. Правильно: каркас → принять → посмотреть → следующая функция.

WARN: держать комплит включённым везде: в markdown, в YAML, в конфигурациях серые подсказки чаще мешают, чем помогают. Language Overrides — и ты не будешь «бороться с курсором» в каждом файле.

WARN: жать Tab на «почти подходящей» подсказке и потом разгребать: Esc дешевле. Принимай, когда совпадает на 90%+, остальное дописывай сам — комплит не обязан быть идеальным, он обязан быть быстрым.

## Практическое задание

В taskit.py доведи до конца команду list (каркас + комплит: таблица задач, отметка выполненных, сортировка по дате создания) — не больше двух ручных функций, остальное принимай из подсказок. Затем заполни в copilot-instructions.md раздел «Стиль кода»: форматирование (ruff), типы (type hints обязательно), docstring (каждый публичный), ф-строки, обработка ошибок (свои исключения или ValueError). Этот раздел реально меняет подсказки: проверь на следующей функции.
