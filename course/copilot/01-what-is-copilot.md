# Что такое GitHub Copilot: возможности и для кого

## Цель

После урока студент сможет: объяснить, что такое GitHub Copilot и чем плагин принципиально отличается от ИИ-редактора, назвать разработчика и год появления, перечислить пять главных функций (автодополнение, чат, inline-правка, агент в редакторе, облачный Coding Agent) и объяснить, почему для курса мы работаем с нашим же GitHub-репозиторием taskit, а не с чистым проектом.

## Теория

GitHub Copilot — продукт Microsoft и GitHub: анонсирован в 2021 году, общедоступен (GA) с 2022-го. Это не отдельный редактор, а плагин, который вставляется в редактор, с которого ты и работаешь: VS Code (родная среда, максимальный функционал), JetBrains (PyCharm, IntelliJ), Neovim, Xcode и несколько других. Архитектурное отличие от Cursor, который мы рассматривали на отдельном треке: Cursor — это форк редактора, и ИИ «из коробки» видит весь проект, тогда как Copilot — гость в чужом редакторе. Он получает контекст, который редактор ему передаёт: открытый файл, выделенный код, а с 2024 года — семантическую индексацию всего репозитория (@workspace) и даже терминал (@terminal).

Под капотом — семейство моделей OpenAI (GPT-4o-класс для комплита и чата), а в новых версиях GitHub добавлял и другие модели (Claude, Gemini) с переключателем. Не стоит привязываться к конкретной модели как к фиче: GitHub обновляет «модельный мотор» от релиза к релизу, а интерфейс — чат, комплит, агент — остаётся.

Пять функций, которые мы пройдём в курсе:

- Автодополнение кода (Tab): модель дописывает строку или функцию целиком прямо в редакторе.
- Чат (Ctrl+L): диалог с кодовой базой — @workspace ищет по смыслу, @terminal читает вывод команд.
- Inline-правка (Ctrl+I): выделяешь код, просишь переписать — модель меняет место на месте.
- Agent mode в редакторе: агент правит несколько файлов, запускает команды, показывает diff.
- Coding Agent: облачный агент, которому можно задать issue прямо на GitHub — он отработает в облаке и прислает pull request.

Для кого Copilot: для разработчика, который живёт в экосистеме GitHub (репозитории, issues, pull requests, Actions) — плагин связывает ИИ с этой экосистемой напрямую, чего не умеет ни один локальный чат-бот. Второй профиль — студент: бесплатный тариф (2000 автодополнений и 50 premium-запросов чата в месяц, цифры меняются — сверяй с актуальной страницей тарифов) даёт достаточно объёма на весь курс, а бесплатные студенческие планы делают Pro бесплатным.

NOTE: GitHub очень быстро добавляет фичи и переименовывает их (agent mode, Workspace, CLI — часть из этого появилась только в 2025 году). Ориентируйся на принципы из этого курса, а конкретные меню и клавиши сверяй со своими версиями VS Code и GitHub.

TIP: чтобы курс давал результат, нужен настоящий GitHub-репозиторий: создай публичный репозиторий taskit (можно пустым) — все 18 уроков мы будем делать в нём: issues, pull request, review, Actions. Работа «в одиночной папке» лишит нас половины механики.

## Пример

```bash
# 1. Устанавливаем VS Code (пример — Linux; macOS/Windows — инсталлятор)
code --version

# 2. Ставим расширение GitHub Copilot из терминала:
code --install-extension GitHub.copilot

# 3. Создаём будущий проект:
mkdir taskit && cd taskit
git init && touch taskit.py README.md
gh repo create taskit --public --source=. --push
```

В примере мы только готовим поле: устанавливаем расширение и поднимаем пустой репозиторий taskit. В редакторе VS Code после установки появится панель Copilot: логин по GitHub-аккаунту, выбор тарифа (Free), и на строке `import json` комплит предложит дописать `import sys` — первый контакт. Запиши в чат (Ctrl+L): «какие фичи Copilot доступны в моей версии?» — ответ будет точным под твою сборку, а не из статей.

## Частые ошибки

WARN: считать Copilot «автодополнением, как в старом Eclipse»: современный Copilot — это пять разных инструментов (комплит, чат, inline, агент в редакторе, облачный агент). Если видишь только дописывающиеся строки — включи чат и agent mode в настройках, а не разочаровывайся.

WARN: путать Copilot с Cursor: Copilot — плагин (работает в твоём редакторе и на твоём аккаунте GitHub), Cursor — отдельный редактор с собственной экономикой. Привычки (клавиши, лимиты, цены) переносить нельзя — на треке Cursor это отдельная тема.

WARN: запускать курс без GitHub-репозитория: половина механики (issues, Coding Agent, review, Actions) живёт на стороне GitHub, а не в редакторе. Локальная папка без git — только половина курса.

WARN: ждать, что Copilot сам знает твой проект: комплит знает открытый файл, чат — только то, что ты ему покажешь (#файл, @workspace). «Память» проекта — это файл инструкций, которым мы займёмся в уроке 6.

## Практическое задание

В файле copilot-instructions.md (открыт в редакторе) опиши проект taskit: что это за утилита, кто её пользователь, на каком языке она написана и какие три команды она должна уметь к концу курса. Заполни раздел «О проекте» по шаблону — убери все плейсхолдеры и TODO. Этот файл станет «памятью» проекта на весь курс: GitHub читает его в чате и в агенте автоматически, и 17 следующих уроков будут наращивать его новыми секциями.
