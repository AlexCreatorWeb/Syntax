# Установка в JetBrains (PyCharm / IntelliJ) и доступ из России

## Цель

После урока студент сможет: установить GitHub Copilot в PyCharm или IntelliJ IDEA через маркетплейс плагинов, объяснить, чем функционал JetBrains-версии отличается от VS Code (что есть, что пришло позже), и собрать свой способ входа и оплаты подписки из России (безлимит вариантов: бесплатный тариф, студенческий, App Store, карта).

## Теория

Плагины для JetBrains — PyCharm, IntelliJ IDEA, WebStorm, GoLand и остальных: ставятся из маркетплейса (Settings → Plugins → Marketplace → «GitHub Copilot»), после установки нужен перезапуск IDE и логин по тому же GitHub-аккаунту — лимиты общие с VS Code, два редактора не «удваивают» бесплатный объём, а делят его.

Что доступно в JetBrains и в чём разница с VS Code (ситуация меняется от релиза к релизу, это ориентир на 2026 год): автодополнение — есть, работает в том же режиме; чат — есть, со своими окнами (в PyCharm это отдельная панель «Copilot Chat»), @workspace и @terminal пришли в 2025-м; inline-правка — есть; Agent mode в редакторе — есть, но исторически отставал от VS Code на 1–2 квартала; облачный Coding Agent — не зависит от редактора (живёт на GitHub, работает одинаково из любой IDE); Copilot CLI — тоже не зависит от IDE (это отдельная программа). Вывод: всё «облачное» у GitHub единое, «локальное» в JetBrains чуть отстаёт. Поэтому в курсе мы ставим JetBrains-плагины, но основную практику ведём в VS Code — там самые свежие фичи.

Доступ из России — разобрать честно по слоям. Слой 1 — аккаунт: GitHub и Microsoft-аккаунт работают как обычно, логин без VPN. Слой 2 — бесплатный тариф: работает без оплаты, лимиты те же, это минимум, достаточный для курса. Слой 3 — оплата Pro (если захочешь): варианты по убыванию «болёвки»: (1) студенческий статус — Pro бесплатен, нужен .edu или студенческая верификация, это лучший вариант; (2) оплата через App Store / Google Play (iOS/Android-приложение Copilot) — работают карты, которые принимают магазин; (3) зарубежная карта (родственники, сервисы) + VPN только на момент оплаты; (4) корпоративный тариф от работодателя. VPN нужен не «для GitHub» (он открыт), а только для платежей — и то не всегда.

TIP: если ты работаешь в PyCharm по основной работе — ставь оба: плагины в PyCharm + расширение в VS Code. Лимит общий, но привычка «спрашивать чат до того, как писать код» закрепится в обоих редакторах.

NOTE: у GitHub бывают периоды, когда страница оплаты Pro недоступна напрямую из России, а сам сервис (редактор, чат, агент) при этом работает. Не путай «не открывается касса» с «сервис заблокирован»: проверь бесплатный лимит в настройках GitHub — если он есть, платишь не за что.

## Пример

```bash
# 1. В PyCharm: Settings → Plugins → Marketplace → «GitHub Copilot» → Install → Restart
# 2. Логин: кнопка Login в панели Copilot (тот же GitHub-аккаунт, что в VS Code)
# 3. Проверка бесплатного лимита в браузере:
#    github.com → Settings → Billing and plans → Copilot
#    (там: тариф, оставшиеся auto-completions и premium-requests)
# 4. Терминал PyCharm, проверка, что проект на месте:
cd taskit && git status
python taskit.py add "настроить jetbrains"
```

В примере мы не «ставим что-то командой» (JetBrains ставит плагины мышкой), а проверяем экономику: заходишь в Billing and plans, смотришь цифры. Если студент — видишь «Student — Free». Если лимит автодополнений уже на нуле — включи в настройках IDE только чат и отключи комплит до сброса месяца.

## Частые ошибки

WARN: думать, что два редактора дают вдвое больший бесплатный объём: лимит привязан к аккаунту GitHub, а не к редактору. Если в VS Code улетело 1800 автодополнений, в PyCharm останется 200 — и наоборот.

WARN: мучить JetBrains-версию фичами, которые там ещё не вышли (новый Agent mode, Workspace): часть фич приходит в IDE с задержкой 1–2 квартала. Если кнопки нет — это не баг, а очередь; экзотику делай в VS Code.

WARN: покупать Pro «для надёжности» из России через сомнительные сервисы оплаты: при первой же смене IP-региона GitHub может попросить подтверждение. Порядок всегда такой: бесплатный тариф → студенческий → App Store → зарубежная карта.

WARN: не включать Copilot там, где он мешает: в JetBrains-IDE комплит иногда спорит с собственным completion IDE — в настройках плагина есть опция «подсказывать только если IDE молчит» (enable suggestions on trigger); включи её, и конфликты уйдут.

## Практическое задание

Установи плагин в IDE, которую используешь по основной работе (PyCharm или IntelliJ): логин по аккаунту GitHub, тест — напечатай в консоли/скрипте `for i in range(5):` и проверь, что комплит дописывает тело цикла. Затем заполни в copilot-instructions.md раздел «Стек»: какие редакторы и IDE используются в проекте, какой из них основной (VS Code), и где лежит актуальная страница тарифов — чтобы Copilot в чате отвечал на «а мне что покупать?» по-твоему, а не из старых статей.
