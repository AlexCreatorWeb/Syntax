# Бесплатные альтернативы и выбор инструмента

## Цель

После урока студент сможет: объяснить, какие бесплатные/открытые альтернативы GitHub Copilot существуют (Aider, Continue, Cline, Tabby, Gemini Code Assist, Zed AI) и чем они отличаются, принять решение «какой инструмент под мою задачу» (а не «какой модный»), и сформулировать главный вывод курса: инструмент меняется, а навык (уметь задать и проверить) — нет.

## Теория

Урок 17 — «нужен ли Copilot», и урок 18 — «а если не он». Рынок ИИ-инструментов для кода в 2025–2026 «кипит»: каждый месяц появляются новые, и «выбор» становится частью навыка. Разберём «ландшафт» (не «рейтинг», а «характер»).

Категории (и примеры):

- CLI-агенты (открытые): Aider — «парный» агент в терминале (git-интеграция, «работает» с репозиторием), Cline/Roo — VS Code-расширения (агент, «как» Copilot Agent mode, но «открытые» и «без» привязки к GitHub). Для «тех, кто хочет» «агента» «без» «подписки» (и «с» «своими» «ключами» API).
- Автодополнение (self-hosted): Tabby — «свой» комплит-сервер (модель на «твоём» железе, код «не уходит»). Для «приватности» (и «без» лимитов).
- «Бесплатные» планы «больших» инструментов: Gemini Code Assist (Google, бесплатен для «открытых» проектов), Zed AI (редактор с «встроенным» ИИ, «бесплатный»), Cursor Hobby (бесплатный «тариф» «с» лимитами). «Альтернативы» «Copilot Free» — «с» «другим» «характером».
- «Локальные» LLM (Ollama + «расширение»): «модель» «на» «твоём» «железе» (коды «не» «уходят», «но» «модель» «слабее» «облачной»). Для «экспериментов» (и «приватности»).

Чем «отличаются» (и «как» «выбирать»):

- «Характер» (агент / комплит / чат): Copilot — «всё» (комплит + чат + агент + «облако»). Aider — «агент» «в» «терминале». Tabby — «комплит». «Выбирай» «под» «задачу» («агент» → Aider/Cline, «комплит» → Tabby, «всё» → Copilot).
- «Приватность» (куда «уходит» «код»): «облачные» (Copilot, Cursor) — «код» «уходит» (на «модель»). Self-hosted (Tabby, Ollama) — «код» «остается». Для «приватного» «проекта» — self-hosted.
- «Цена» (и «лимиты»): «бесплатные» (Aider + «свой» «ключ» API, Tabby, Gemini) — «без» «подписки» (но «с» «своими» «ограничениями»: «железо», «API-квота»). «Платные» (Copilot Pro) — «с» «лимитом» (но «без» «железа»).
- «Экосистема» (GitHub / Git / «ничего»): Copilot — «GitHub» («issues», «PR», «Actions»). Aider — «git» («commit», «branch»). Tabby — «ничего» («только» «комплит»). Для «GitHub-проекта» — Copilot.

Главный «вывод» «курса» («и» «урока»): «инструмент» «меняется» («каждый» «год»), а «навык» («уметь» «задать» «и» «проверить») — «нет». «Три» «точки» «контроля» («план», «диф», «тесты») — «работают» «в» «любом» «инструменте» (Copilot, Aider, Cursor, «что» «будет» «в» «2027»). «Выбрать» «инструмент» — «не» «проблема» («попробуй» «3–4», «и» «выбери» «под» «задачу»); «проблема» — «навык» («и» «он» «не» «зависит» «от» «инструмента»).

TIP: «попробуй» «не» ««выбери»». «На» «одной» «небольшой» «задаче» (например, «taskit»: «добавь» «команду» «archive») «пройди» «3» «инструмента» (Copilot, Aider, «ещё» «один») — «и» «сравни» («что» «быстрее», «что» «точнее», «что» «удобнее»). «Через» «час» «у» «тебя» «будет» «своё» «мнение» («не» ««рейтинг» «из» «интернета»).

NOTE: «Рынок» «меняется» «быстро»: «сегодня» ««Aider» «популярен», «завтра» ««Cline» «добавит» «фичу». «Не» ««калибруй» «навсегда» «на» ««сегодняшнем» «виде»: «выбери» «под» «задачу», «и» «пересматривай» «раз» «в» «квартал» («не» ««каждый» «день»).

## Пример

```bash
# 1. Aider (CLI, «открытый» «агент»):
#    pip install aider-chat
#    aider taskit.py   # (в «папке» «проекта»)
#    «добавь» «команду» «archive»: «перемещает» «выполненные»
#    «задачи» «в» «archived.json»
#    (агент «работает», «git» «commit» «автоматически»)

# 2. Сравни «с» «Copilot» («та» «же» «задача», «Workspace»):
#    (открой «Workspace», «issue» ««archive»», «план», «старт»)
#    Что «быстрее»? Что «точнее»? Что «удобнее»?

# 3. Запиши «в» «issue»: «сравнение» «инструментов» «на» «задаче»
#    «archive»: Aider — «быстрее», «но» ««без» «ревью»;
#    Copilot — «медленнее», «но» ««с» «ревью» «и» «PR».
```

Сценарий «одна задача, три инструмента» — это «и» «есть» «выбор». Не «рейтинг» (чужое мнение), а «своё» (на «своей» «задаче»).

## Частые ошибки

WARN: «выбирать» «по» ««рейтингу»: «рейтинг» — «чужое» «мнение» («на» «чужой» «задаче»). «Своя» «задача» (и «своё» «сравнение») — «твой» «аргумент». «Попробуй» «3–4» («на» «одной» «задаче») — «и» «выбери».

WARN: «привязываться» «к» «инструменту»: «сегодня» «Copilot», «завтра» ««Aider» «добавит» «фичу», «послезавтра» ««Cline» «станет» «бесплатным». «Навык» («план», «диф», «тесты») — «не» «зависит» «от» «инструмента». «Инструмент» — «меняй», «навык» — «держи».

WARN: «переходить» ««каждый» «месяц: «смена» «инструмента» — «ценность» («новая» «конфигурация», «новые» «привычки»). «Пересматривай» «раз» «в» «квартал» («не» ««каждый» «день»). «Смена» ««ради» «смены» — «потеря» «времени».

WARN: «считать» ««бесплатный» ««лучшим»: «бесплатный» (Aider + «свой» «ключ» API) — «с» «своими» «ограничениями» («API-квота», «железо»). «Платный» (Copilot Pro) — «с» «лимитом», «но» «без» «железа». «Выбирай» «под» «объём» («не» ««под» «цену»).

## Практическое задание

Пройди «одну» «задачу» («taskit»: «добавь» «команду» «archive») «в» «трёх» «инструментах (Copilot + два «из» «списка» (Aider, Continue, Gemini — «что» «доступно»). Сравни («быстрее/точнее/удобнее»), «запиши» «в» «issue». «Затем» «доведи» copilot-instructions.md «до» «финальной» «версии: «проверь» «все» «разделы» («уроки» «1–17»), «убери» ««повторы», «добавь» «раздел» ««Выбор» «инструмента» («мой» «выбор» «и» «почему»). «Файл» «собран» «полностью» — «и» «курс» «завершён.
