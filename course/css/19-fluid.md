# Урок 19. Fluid-дизайн: min, max, clamp

## Цель
После урока студент сможет: объяснить, чем min()/max()/clamp() отличаются от media queries; собрать «резиновый» размер (font-size, padding, width), плавно растущий с вьюпортом; рассчитать «предпочтительное» значение clamp (min + slope×vw + offset) и избежать «прыжков» на брейкпоинтах.

## Теория
### Проблема дискретных брейкпоинтов
Media query «переключает» значения: до 768px — font-size 1.5rem, после — 2rem. Между 767 и 769px — «прыжок». На «серых» ширинах (600, 700px) значения «не те»: ни «мобильные», ни «desktop». **Fluid-дизайн** убирает «ступеньки»: размер **плавно** растёт (или сжимается) в зависимости от ширины вьюпорта.

### Три функции: min, max, clamp
CSS-функции «выражают» размер через **выражения**:

- **min(а, б)** — меньшее из двух: width: min(100%, 600px) — «до 600px, но не шире вьюпорта» (классика «ограниченного» контейнера БЕЗ media query);

- **max(а, б)** — большее: padding: max(1rem, 2vw) — «хотя бы 1rem, но на широких экранах — 2vw»;

- **clamp(мин, предпочтительное, макс)** — «предпочтительное, но не меньше мин и не больше макс»: font-size: clamp(1.25rem, 1rem + 1vw, 2rem) — «растёт от 1rem + 1vw, но в диапазоне 1.25–2rem».

**clamp** — рабочая лошадка: три значения задают «полосу», в которой размер «дышит». На узком вьюпорте — мин, на широком — макс, между — «предпочтительное» (линейная от vw).

### «Предпочтительное»: формула и расчёт
«Предпочтительное» в clamp — это **выражение**: a + b×vw. Как рассчитать:

1. Зафиксируйте два «якорных» размера: на узком (например, 360px) — 1.25rem, на широком (1200px) — 2rem;

2. **slope** (b) = (разр_широкое − разр_узкое) / (широкий − узкий) в vw: (2 − 1.25)rem / (1200 − 360)px = 0.75rem / 840px ≈ 0.0009rem/px → в vw: 0.75 / 8.4 ≈ **0.089vw** (1vw = 1% ширины, 840px = 8.4×100px… упрощённо: slope_vw = Δrem / (Δpx / 100) = 0.75 / 8.4 ≈ 0.089);

3. **offset** (a) = узкое − slope × узкий_vw: 1.25rem − 0.089 × 3.6 ≈ 1.25 − 0.32 = **0.93rem**;

4. Итог: font-size: clamp(1.25rem, 0.93rem + 0.089vw, 2rem).

На практике — «округляете» до «красивых» чисел (0.9rem + 0.9vw) и **проверяете** в DevTools на ключевых ширинах: «глазное» расчётное значение лучше «идеального» формульного.

### Где применять

- **типографика**: h1, подзаголовки (основной текст — фиксированный 1rem, «дышит» заголовок);

- **отступы**: padding секций (max(1rem, 4vw) — «больше на широких»);

- **ширины**: max-width: min(100%, 700px) — «ограничение БЕЗ media query»;

- **НЕ применяйте** «на всё»: иконки, бордеры, мелкие элементы — фиксированные (px/rem), «дышащие» — только крупные «опорные» размеры.

TIP: **min(100%, 60rem)** — «заменитель» max-width: 60rem для контейнеров с «защитой» от переполнения: width: min(100%, 60rem); margin: 0 auto — без media query, без box-sizing-«сюрпризов».

NOTE: vw — 1% ширины **вьюпорта** (а не контейнера!): на мобильных с «адресной строкой» vw «прыгает» при открытии/закрытии панели (dvh — для высоты, для ширины — vw «стабилен»). Для контейнерной «резиновости» — cqw (урок 18).

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 19. Fluid</title>
</head>
<body>
  <section class="hero">
    <h1 class="h1">Заголовок «дышит»</h1>
    <p class="lead">Подзаголовок тоже.</p>
  </section>
  <div class="boxed">Контейнер min(100%, 40rem)</div>
</body>
</html>
```
CSS:
```css
body {
  font-family: system-ui, sans-serif;
  margin: 0;
}

.hero {
  padding: max(2rem, 6vw) 1rem; /* "отступы растут с шириной" */
  background: #e7f5ff;
  text-align: center;
}

.h1 {
  font-size: clamp(1.75rem, 1.2rem + 2.5vw, 3.5rem); /* "резиновый" h1 */
  line-height: 1.1;
  margin: 0;
}

.lead {
  font-size: clamp(1rem, 0.9rem + 0.6vw, 1.375rem);
  color: #495057;
}

.boxed {
  width: min(100%, 40rem); /* "не шире 40rem, но не уже вьюпорта" */
  margin: 2rem auto;
  padding: 1rem;
  background: #fff4e6;
  border-radius: 8px;
}
```
Разбор: .h1 «растёт» от 1.75rem (узкий) до 3.5rem (широкий) **плавной** кривой (1.2rem + 2.5vw «внутри»). Отступы .hero — max(2rem, 6vw): на узком — 2rem, на широком — 6vw («растут»). .boxed — «ограниченный» контейнер БЕЗ media query: на узком 100%, на широком 640px. Сузьте/расширьте окно — все три значения «дышат».

## Частые ошибки
WARN: clamp «с синтаксисом через запятые» — clamp(1rem, 2vw, 3rem) — ТОЧКА С ЗАПЯТОЙ (не пробел): clamp(1rem 2vw 3rem) — синтаксическая ошибка (в отличие от rgb/hsl — там пробел).
WARN: «предпочтительное» = фиксированное (clamp(1rem, 2rem, 3rem)) — «не дышит»: мин/макс «выбираются», среднее «игнорируется»; «предпочтительное» — ВЫРАЖЕНИЕ с vw.
WARN: vw «масштабирует» от контейнера — нет, от **вьюпорта**; для «контейнерной» резиновости — cqw (урок 18). На мобильных vw «прыгает» при панели адреса (высота — dvh, ширина — стабильна).
WARN: clamp «на всё» — «дышащие» бордеры/иконки/мелкие отступы «моргает» при ресайзе; «резиновые» — только крупные «опорные» размеры (h1, секции-отступы, max-width).
WARN: min(100%, 60rem) «вместо» max-width — работает, но «не считается» в box-sizing: width: min(100%, 60rem) + padding — «переполнит» без border-box (урок 7); глобальный сброс ОБЯЗАТЕЛЕН.

## Практическое задание

1. Соберите каркас из Примера и реализуйте fluid-правила со скелета задания.

2. В DevTools прогнайте ширину 320→1400px — запишите фактические font-size h1 на 360, 768, 1200px (Computed) и сравните с «расчётными» по формуле.

3. Пересчитайте .h1: «якоря» 2rem на 400px и 4rem на 1400px — найдите slope/offset и обновите clamp. Проверьте на 400 и 1400.

4. Замените .boxed width: min(100%, 40rem) на max-width: 40rem + margin: 0 auto — и объясните, в ЧЁМ разница (подсказка: padding).

5. Бонус: соберите «резиновую» сетку карточек: grid-template-columns: repeat(auto-fit, minmax(min(100%, 240px), 1fr)) — и объясните, что даёт min(100%, 240px) «внутри» minmax (защита от переполнения на «очень» узком).
