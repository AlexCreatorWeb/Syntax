# Урок 3. Селекторы II: псевдоклассы, псевдоэлементы, :has()

## Цель
После урока студент сможет: стилизовать состояния элемента (наведение, фокус, N-й по счёту); добавлять декоративный контент псевдоэлементами ::before/::after; находить элементы по атрибутам и «сверху вниз» через :has().

## Теория
### Псевдоклассы: состояние, а не элемент
Псевдокласс выбирает элемент в **состоянии** или по **положению**. Один знак «:» — это псевдокласс:

- **состояние** — `:hover` (курсор сверху), `:focus` (фокус с клавиатуры или кликом), `:focus-visible` (только «видимый» фокус с клавиатуры — современный стандарт для кнопок), `:active` (кликают прямо сейчас), `:disabled`, `:checked`;

- **позиция** — `:first-child`, `:last-child`, `:nth-child(2n)` (каждый второй), `:nth-child(3n+1)` (каждый третий, начиная с первого), `:only-child`;

- **отрицание** — `:not(.hide)`: все, КРОМЕ совпадения.

Счёт в `:nth-child` идёт по ВСЕМ детям родителя, а не по «однотипным»: `p:nth-child(2)` — это абзац, который является вторым ребёнком, а не «второй абзац». Если в DOM перед ним div, то он уже не второй ребёнок. Для «второго именно абзаца» — `:nth-of-type(2)`.

### Псевдоэлементы: контент, которого нет в HTML
Два знака «::» — псевдоэлемент: браузер «придумывает» виртуальный элемент и его можно стилизовать:

- `::before` — вставка ПЕРЕД содержимым, `::after` — ПОСЛЕ (нужно свойство content, можно пустая строка content: "";);

- `::first-letter` — первая буква (инициал в журнале), `::selection` — выделенный пользователем текст.

Псевдоэлементы — это не теги в DOM: их нельзя наделить поведением (click, ссылки), зато они снимают с разметки весь «декор»: точки маркеров, кавычки в блоках цитат, иконки перед пунктами меню.

### Атрибуты и :has() — селектор «сверху вниз»
Атрибутный селектор ищет элемент по наличию/значению атрибута: `a[target="_blank"]` (внешние ссылки), `input[type="email"]`, `img[alt]`, `a[href^="https://"]` (начинается с), `a[href$=".pdf"]` (заканчивается на), `a[href*="doc"]` (содержит).

**:has()** — современный селектор (2023, поддерживается всеми актуальными браузерами): выбирает элемент, у КОТОРОГО внутри есть совпадение. До :has() селекторы «смотрели вниз» (родитель → ребёнок), теперь возможен обратный ход: `.card:has(img)` — карточка, в которой есть картинка; `li:has(> input:checked)` — пункт списка с отмеченным чекбоксом; `body:has(dialog[open])` — страница с открытым диалогом. Это закрывает десятки ситуаций, на которые раньше нужен был JavaScript.

TIP: :focus и :focus-visible — разные вещи. Уберите outline: none без замены на :focus-visible — и клавиатурная навигация слепнет: пользователь не видит, где он. Современная практика: outline задавать через :focus-visible.

NOTE: :has() работает только в актуальных браузерах (Chrome 105+, Safari 15.4+, Firefox 121+). Для критичных раскладок делайте «работает без :has» — как progressive enhancement.

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 3. Псевдоклассы</title>
</head>
<body>
  <button class="btn">Наведи и нажми</button>
  <ol class="steps">
    <li>Шаг один</li>
    <li>Шаг два</li>
    <li>Шаг три</li>
    <li>Шаг четыре</li>
  </ol>
  <ul class="cards">
    <li class="card">Карточка с картинкой</li>
    <li class="card">Карточка без картинки</li>
  </ul>
</body>
</html>
```
CSS:
```css
.btn:hover {
  background: #1971c2;
}

.btn:focus-visible {
  outline: 3px solid #74c0fc;
  outline-offset: 2px;
}

.steps li:nth-child(2n) {
  color: #862e9c;
}

.steps li::before {
  content: "— ";
}

.card:has(img) {
  border: 2px solid #2b8a3e;
}

.card::after {
  content: "";
}
```
Разбор: кнопка реагирует на ховер (попробуйте в превью) и показывает кольцо фокуса при Tab со клавиатуры. Каждый второй пункт шагов — фиолетовый, `::before` добавляет тире перед текстом без правки HTML. `:has(img)` окрасил бы рамку ту карточку, где появилась бы `<img>` — добавьте её в разметку и посмотрите.

## Частые ошибки
WARN: один или три знака двоеточия перепутаны — :before с одним знаком «работает» как устаревшая запись, но ::before — современный стандарт; для псевдоэлементов всегда пишите два знака.
WARN: nth-child считает ВСЕХ детей — p:nth-child(2) молча промахнулся, потому что перед абзацем стоял div; для «N-го по типу» используйте :nth-of-type(N).
WARN: ::before/::after без content — псевдоэлемент с пустым content (кроме content: "") вообще не отображается: без него display не применится.
WARN: убрали :focus (outline: none) и не вернули через :focus-visible — клавиатурные пользователи потеряли индикатор позиции; это a11y-баг.
WARN: :has() без запасного плана — на старых браузерах правило молча игнорируется (это штатно, каскад просто пропускает), но если раскладка зависит от него — нужен fallback.
