# Урок 2. Селекторы I: элементы, классы, id, комбинаторы

## Цель
После урока студент сможет: написать селектор по тегу, классу и id; объединить несколько целей в одном правиле запятой; навести правило на элементы с учётом их соседства (потомок, ребёнок, сосед) и объяснить, чем эти подходы отличаются.

## Теория
### Три базовых селектора
Селектор отвечает на вопрос «кого стилизуем». Три кита:

- **по тегу** — `p`, `h2`, `a`: находит ВСЕ элементы такого имени, где бы они ни были;

- **по классу** — `.card`, `.btn-primary` (точка в начале): находит элементы с этим классом в атрибуте class; у одного элемента может быть НЕСКОЛЬКО классов через пробел: class="card card--big";

- **по id** — `#header` (решётка в начале): находит элемент с этим id; id у элемента — только ОДИН, и на странице id должно быть уникальным.

Когда что выбрать: тег — редко (закрашивает все такие элементы, трудно изолировать); класс — рабочий инструмент на 90% вёрстки; id — для якорей и DevTools-навигации, стилизовать через id не принято (высокая специфичность, урок 5).

### Списки селекторов: запятая — «ИЛИ»
Селекторы соединяются запятой — это логическое ИЛИ: один блок правил применяется ко всем совпадениям:
```css
h1, h2, .title { font-weight: 700; }
```
Запятая — НЕ вложенность и не «и то и другое одновременно». Частая ошибка новичка: `.card .title { ... }` — это НЕ «карточка и заголовок», а заголовок ВНУТРИ карточки (про комбинаторы ниже).

### Комбинаторы: как элементы расположены друг к другу
Базовые селекторы можно **комбинировать** — тогда правило срабатывает на элементах в определённом окружении:

- **пространство (потомок)** — `.menu a`: любая ссылка ВНУТРИ элемента с классом menu, на любой глубине вложенности;

- **> (ребёнок)** — `.menu > a`: только ПРЯМЫЕ дети menu, вложенные глубже — нет;

- **+ (ближайший следующий)** — `h2 + p`: абзац, который стоит СРАЗУ ПОСЛЕ h2 (если между ними другой тег — не сработает);

- **~ (все следующие)** — `h2 ~ p`: все абзацы-следователи h2 в том же родительском блоке, не только первый.

Пространство — самый частый и самый «непредсказуемый»: правило `.card p { color: grey }` ударит по любому абзацу, спрятанному где угодно внутри карточки. Если нужна точность — используйте `>` или стилизуйте сам абзац классом.

TIP: имена классов — английские, в формате kebab-case (short-dash), описывают роль, а не вид: .card, .nav-link, .badge. Плохо: .block1, .red-box, .div_2 — «красный» завтра станет синим, а «block1» не говорит ничего.

NOTE: порядок классов в атрибуте значения не имеет: class="a b" и class="b a" — один и тот же элемент. Классы не «цепляются» в последовательность — это частое заблуждение.

## Пример
Каркас (index.html):
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 2. Селекторы</title>
</head>
<body>
  <header id="site-header">
    <nav class="menu">
      <a href="#">Главная</a>
      <div><a href="#">Вложенная ссылка</a></div>
    </nav>
  </header>
  <main class="content">
    <h2>Раздел</h2>
    <p class="lead">Первый абзац раздела.</p>
    <p>Второй абзац.</p>
    <p class="lead">Третий абзац.</p>
  </main>
</body>
</html>
```
CSS:
```css
#site-header {
  background: #f1f3f5;
}

.menu a {
  color: #1971c2;
}

.menu > a {
  font-weight: bold;
}

h2 + p {
  font-size: 1.25rem;
}

h2 ~ .lead {
  color: #2b8a3e;
}
```
Разбор: `.menu a` подсветит и верхнюю, и вложенную ссылку; `.menu > a` — только верхнюю (вложенная прячется в div, она не прямой ребёнок). `h2 + p` увеличит только «Первый абзац» (ближайший следующий), второй и третий — нет. `h2 ~ .lead` закраст ОБА абзаца с классом lead — они оба следуют за h2. Сравните четыре результата в превью.

## Частые ошибки
WARN: класс и id перепутаны — .header пишет класс, #header — id; селектор с точкой на элемент с id ничего не найдёт (и наоборот), а ошибки в консоли не будет: просто «не окрасилось».
WARN: запятую принимают за вложенность — .card .title значит «.title внутри .card», а не «оба»; «и то и другое» пишется запятой: .card, .title.
WARN: пробел «потомок» переширокий — .form input зацепит любой input во всех формах сайта, включая вложенные поля; для точности — .form > input или классы на полях.
WARN: + ожидает ровно одного соседа — h2 + p молча не сработает, если между ними <div>; для «всех следующих» нужен ~.
WARN: id дублируется на странице — HTML требует уникальности, а CSS наложит стили на ОБА элемента, и валидатор это отметит.

## Практическое задание

1. Создайте index.html с каркасом из Примера и реализуйте в styles.css все пять селекторов из Примера (скелет уже размечен TODO).

2. Добавьте в nav третий уровень вложенности (div внутри div с ссылкой) и объясните по превью, какие селекторы её зацепят, а какие — нет.

3. Напишите ОДНО правило с запятой, которое сразу стилизует h2 и первый псевдо-абзац (подсказка: h2 + p).

4. В DevTools у элемента .lead найдите в панели Matched Rules все правила, которые к нему применились (должно быть больше одного).

5. Бонус: замените в проекте все селекторы по тегу (p, h1) на классы и убедитесь, что результат в превью тот же.
