# Урок 9. Типографика: шрифты, line-height, шкалы

## Цель
После урока студент сможет: собрать корректный font-family со стеком и generic-семейством; задать читабельный ритм текста (line-height, max-width, letter-spacing) и собрать базовую текстовую шкалу (шкалу размеров заголовков и абзацев).

## Теория
### font-family: стек, а не «шрифт»
font-family — это **список**: браузер идёт по нему слева направо, пока не найдёт установленный/загруженный шрифт. В конце списка ОБЯЗАТЕЛЕН generic-семейство (sans-serif, serif, monospace, cursive) — «досыпающий» шрифт, который гарантированно есть в системе:
```css
body {
  font-family: "Inter", "Segoe UI", system-ui, sans-serif;
}
```
Если «Inter» не загружен — будет Segoe UI (Windows) / системный / любой sans-serif. Без generic-хвоста — непредсказуемый fallback. Для кириллицы проверяйте, что шрифт её ПОДДЕРЖИВАЕТ: «Inter» — да, но, например, некоторые decorative-шрифты — латиница only, и русские буквы «отвалится» в fallback посреди слова.

Системный стек (без загрузки шрифта): system-ui, -apple-system, "Segoe UI", Roboto, sans-serif — быстро и нативно. Моноширинные для кода: "JetBrains Mono", "Fira Code", Consolas, monospace.

### Ритм текста: line-height и ширина строки

- **line-height** — межстрочный интервал. Правильная запись — **без единицы** (множитель): line-height: 1.5 — считается от текущего font-size (у заголовка 2rem → 3rem, у текста 1rem → 1.5rem). Запись в px «ломает» наследование: абзац 16px с line-height: 24px, внутри span 24px получит 24px → строки «впритык»;

- **max-width строки** — 45–75 символов (или 45–75ch): длинная строка утомляет, короткая — «дёргает» взгляд. Классика: max-width: 65ch или 700px для колонки текста;

- **letter-spacing** — межбуквенный: для заголовных (uppercase) — 0.05em–0.1em в плюс; для основного текста — 0 (системные шрифты уже настроены);

- **text-transform** — uppercase/lowercase/capitalize; capitalise для подзаголовков, uppercase — только для коротких надписей (бейджи, навигация).

### Шкала размеров: не «пиксели по вкусу»
Типографика проекта — это **шкала** (type scale): набор размеров, из которого собраны все тексты. Минимальный набор:

- body — 1rem (16px) / line-height 1.5–1.6;

- h1 — 2rem–2.5rem, h2 — 1.5rem, h3 — 1.25rem (или 1.125rem);

- мелкий текст (подписи, бейджи) — 0.875rem.

Связные размеры — обычно степень 1.2–1.334 (minor third / major third). Не «подбирайте пиксели», а выберите базу и множитель — и типографика соберётся сама. Для адаптивного масштаба — clamp (урок 19): h1 { font-size: clamp(2rem, 1.5rem + 2vw, 3rem) }.

TIP: line-height для ЗАГОЛОВКОВ короче, чем для текста: 1.1–1.3 у h1–h3 (высокие строки у заголовков «разносят» блоки), 1.5–1.7 у абзацев. Одно значение на всё — компромисс, два-три — осознанный выбор.

NOTE: web-шрифты (@font-face, Google Fonts) — отдельная тема: weight/italic-варианты грузятся отдельными файлами, font-display: swap решает, показывать ли «fallback до загрузки». В курсе — только системные стеки; @font-face пригодится, когда подключите свой набор.

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 9. Типографика</title>
</head>
<body>
  <main class="article">
    <h1>Заголовок статьи</h1>
    <p class="subtitle">Подзаголовок с capitalise</p>
    <p>Абзац текста. Хорошая строка — 45–75 символов, больше — утомительно читать, меньше — глаз «складывается».</p>
    <p>Внутри абзаца <strong>жирный</strong>, <em>курсив</em> и <code>код</code> наследуют line-height родителя — проверьте, что строки ровные.</p>
    <h2>Раздел</h2>
    <p>Продолжение после раздела.</p>
  </main>
</body>
</html>
```
CSS:
```css
body {
  font-family: system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
  color: #212529;
}

.article {
  max-width: 65ch;
  margin: 0 auto;
  padding: 1rem;
}

h1 {
  font-size: 2.25rem;
  line-height: 1.15;
}

h2 {
  font-size: 1.5rem;
  line-height: 1.25;
}

.subtitle {
  text-transform: capitalize;
  letter-spacing: 0.02em;
  color: #495057;
}
```
Разбор: body задаёт «базовый ритм» (1rem/1.6), заголовки — свои (крупнее, короче line-height). max-width: 65ch удерживает строку в читабельном диапазоне: сузьте окно — колонка не «растянется» во всю ширину. Внутри абзаца <strong>/<em> наследуют line-height (множитель!), поэтому строки не «поедут».

## Частые ошибки
WARN: line-height в px — наследуется как ABSOLUTED: крупный span внутри мелкого абзаца «придавит» строки; всегда без единицы (1.5–1.6 для текста).
WARN: font-family без generic-хвоста — если все шрифты стека «не найдены», поведение браузера непредсказуемо (обычно default serif — «Times-вспомогательный»); заканчивайте список sans-serif/serif/monospace.
WARN: кириллица «ломается» посреди слова — шрифт не поддерживает русский; проверьте в DevTools: выделенный текст → панель Fonts покажет, каким глифом отрисована каждая буква.
WARN: letter-spacing по умолчанию «на всём» — у основного текста межбуквенные 0.05em уже включены в дизайн шрифта; дополнительный spacing «разносит» текст; uppercase-бейджи — другое дело.
WARN: «красивый» шрифт без проверки weight-ов — font-weight: 700 при отсутствии bold-варианта в стеке → браузер «синтетический» жирный (рисуется обводкой), выглядит грубо.

## Практическое задание

1. Соберите каркас из Примера и реализуйте типографику со скелета задания.

2. Задайте body line-height: 24px (в px) и вложите в абзац span с font-size: 1.5em — посмотрите, как «придавило» строки; верните 1.6 и сравните.

3. Уберите max-width у .article и растяните окно — объясните, почему длинная строка хуже (сколько символов стало в строке?).

4. Соберите шкалу: body 1rem, h1 2.25rem, h2 1.5rem, h3 1.25rem — и проверьте, что line-height у заголовков КОРОтче, чем у текста.

5. Бонус: добавьте в тело .article префикс «Примечание:» через span с letter-spacing: 0.1em и text-transform: uppercase — и объясните, почему у основного текста spacing не нужен.
