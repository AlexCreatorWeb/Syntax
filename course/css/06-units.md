# Урок 6. Единицы: px, rem, em, %, vw/vh

## Цель
После урока студент сможет: объяснить, от чего зависит размер в rem, em, %, vw и px; выбрать единицу под задачу (текст, отступы, бордеры, layout) и предсказать, как элементы поведут себя при изменении корневого шрифта.

## Теория
### Относительные и абсолютные единицы
CSS-размер — это значение + единица. Единицы делятся на **абсолютные** (не зависят от ничего: `px` — CSS-пиксель, логическая единица; на «ретинах» браузер сам масштабирует) и **относительные** (зависят от чего-то):

- **rem** — relative to root: всегда от шрифта корневого элемента `html` (по умолчанию 16px). 1rem = 16px, 2.5rem = 40px. Главное свойство: **не накапливается** во вложенности — rem в глубоко вложенном элементе всё равно от html;

- **em** — от шрифта СОБСТВЕННОГО (у font-size) или родительского (у остальных свойств): font-size: 1.2em у вложенного в 1.2em элемента = 1.44em от базы — «эмовый эффект». Для font-size em опасен именно этим;

- **%** — от родителя: width: 50% — половина ширины родителя; font-size: 100% — как у родителя; padding: 10% — от ШИРИНЫ родителя (даже для высоты — частая подстава);

- **vw/vh** — от вьюпорта: 1vw = 1% ширины окна, 100vh = высота окна. dvh — «динамическое», учитывает collapsing-панель мобильного браузера (адресная строка): 100vh на телефоне «уезжает» под панель, 100dvh — нет;

- **ch** — ширина символа «0» в текущем шрифте: max-width: 60ch — классика типографики (урок 9).

### Что куда — правила выбора
Практика современности:

- **текст и отступы** — rem: шрифт 1rem/1.25rem, padding 0.5rem/1rem. Пользователь, увеличивший базовый шрифт в браузере, получит пропорционально увеличенную СТРАНИЦУ (a11y);

- **бордеры и тонкая графика** — px: 1px бордер в rem превратится в «плавающий» размер при нестандартном корне;

- **layout-ширины** — % и fr (Grid): column width 50% или 1fr;

- **экранозависимые** — vw/vh/dvh: hero-секция height: 100dvh, крупный заголовок clamp с vw (урок 19);

- **не используй** — float, absolute-позиционирование в px «на откате», font-size в px (теряется a11y-масштабирование).

TIP: не меняйте font-size у html «весьма на всякий случай» — вся rem-сетка проекта масштабируется от него. Если и менять, то осознанно: html { font-size: 100% } (стандарт) или конкретный размер с комментарием.

NOTE: px в CSS — это «логический» пиксель, а не физический: на 2x-экране 1px CSS = 2 физических пикселя. Поэтому «1px бордер на ретине тоньше» — это уже физический уровень, в CSS работаем в логических единицах.

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 6. Единицы</title>
</head>
<body>
  <div class="box box--rem">rem</div>
  <div class="box box--em">em (вложенный)</div>
  <div class="box box--pct">50%</div>
  <div class="hero">100dvh — не проверяем здесь, посмотрите в теории</div>
</body>
</html>
```
CSS:
```css
body {
  font-size: 16px; /* база для сравнения */
  padding: 1rem;
}

.box {
  margin-bottom: 1rem;
  border: 1px solid #adb5bd;
  padding: 0.5rem 1rem;
}

.box--rem {
  width: 10rem; /* 160px — не зависит от родителя */
}

.box--em {
  font-size: 1.5em; /* 24px = 1.5 × 16px родителя */
  padding-left: 2em; /* 48px = 2 × СОБСТВЕННЫЙ 24px */
}

.box--pct {
  width: 50%; /* половина ширины родителя (body) */
}
```
Разбор: box--rem всегда 160px (при корне 16px), box--pct «дышит» вместе с окном, а box--em показывает «эффект эма»: font-size 1.5em = 24px, и padding-left: 2em считается уже от 24px (48px), а не от 16. Увеличьте font-size у body до 20px и посмотрите, как пересчитались rem- и em-элементы, а 50% — нет.

## Частые ошибки
WARN: font-size в px — пользователь с крупным системным шрифтом (a11y) не масштабирует вашу типографику; используйте rem (1rem = 16px по умолчанию).
WARN: em для font-size во вложенных компонентах — «накопительный» эффект: каждое вложенное 1.2em умножается, и глубина DOM диктует размер текста; для размеров текста — rem.
WARN: 100vh на мобильных — «заплывающая» высота: браузерная панель накладывается на контент; для полноэкранных секций — 100dvh (с vh fallback).
WARN: % в padding/margin считается от ШИРИНЫ родителя, даже у вертикальных свойств: padding-top: 10% — это 10% ширины, а не высоты (так задумано, так работает).
WARN: vw «на откате» в текстовых величинах — на узком окне 1vw мало, на широком много; для текстов — clamp (урок 19), а не голый vw.

## Практическое задание

1. Соберите каркас из Примера и реализуйте в styles.css все правила со скелета задания.

2. Установите html { font-size: 20px } (временно, в конце файла) и сравните: что изменилось у .box--rem, .box--em, .box--pct, body padding?

3. Задайте .box--pct width: 60% и margin: 0 auto — что произошло (подсказка: margin auto центрирует блок-элементы при заданной ширине)?

4. Создайте элемент с height: 100dvh (можно отдельным div-полосой) и проверьте на мобильной ширине DevTools (эмулятор Chrome → Toggle device toolbar), что dvh ≠ vh при открытом адресном баре.

5. Бонус: перепишите все отступы в вашем styles.css в rem (если остались в px), а бордеры оставьте в px — объясните выбор комментарием в коде.
