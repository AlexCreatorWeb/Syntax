# Урок 13. Flexbox II: grow, shrink, wrap, паттерны

## Цель
После урока студент сможет: управлять размером flex-элементов через flex-grow/flex-shrink/flex-basis и сокращение flex: N; отлаживать «переполнение» через min-width: 0; собирать типовые паттерны (равные карточки, «святой грааль», sticky-колонки).

## Теория
### flex-basis, flex-grow, flex-shrink: размер элемента в flex
После «раздачи» основного размера (width/height) flex-контейнер **перераспределяет** свободное (или недостающее) место по элементам:

- **flex-basis** — «стартовый» размер элемента ДО перераспределения (по умолчанию auto = width/height элемента);

- **flex-grow** (0) — доля, с которой элемент ЗАБИРАЕТ свободное место: два элемента с grow: 1 и grow: 2 делят свободное 1:2;

- **flex-shrink** (1) — доля, с которой элемент УСАДИВАЕТСЯ при нехватке места (коэффициенты пропорциональны «штрафу»);

- **flex: 1** = grow 1, shrink 1, basis 0% — «забери равную долю» (самое частое); **flex: 0 0 200px** = «ровно 200px, не расти, не садись» (sidebar-колонка).

Классика: `display: flex; gap: 1rem` + `flex: 1` на карточках — **равные карточки в ряд** без единого percentage-расчёта.

### flex-wrap и «переполнение»
**flex-wrap: nowrap** (по умолчанию) — все в ОДНУ строку, при нехватке места — «уезжают» за край (flex-shrink сажает, но контент может «продавить»). **flex-wrap: wrap** — «не влезло — на следующий ряд».

**Главный flex-баг — min-width: auto.** У flex-элемента минимальная ширина по умолчанию = **ширина содержимого** (min-width: auto). Длинное слово/URL/таблица «распирает» колонку, и переполнение «не лечится» shrink-ом. Лечение: **min-width: 0** у flex-элемента (или overflow: hidden/auto) — и текст/контент «усадится» как надо.

### Паттерны, которые встречаются всегда

- **«равные карточки»**: .grid { display: flex; gap: 1rem } .card { flex: 1; min-width: 0 } — строка равных колонок с переносом (flex-wrap: wrap; flex-basis: calc(33.333% - 1rem));

- **«святой грааль» (шапка-содержимое-подвал)**: .page { display: flex; flex-direction: column; min-height: 100dvh } .main { flex: 1 } — контент «заполняет» окно, подвал прижат к низу (даже при пустом контенте);

- **«sidebar + контент»**: .layout { display: flex } .sidebar { flex: 0 0 260px } .content { flex: 1; min-width: 0 };

- **«одинокий элемент в центр»**: justify-content: center + align-items: center (урок 12) или margin: auto на элементе.

TIP: flex: 1 ≠ width: 50%. flex: 1 — «забери свободное место долями»: если у соседа фиксированный 200px, «flex: 1» займёт ОСТАТОК. width: 50% — «половину родителя», независимо от соседей. В 90% layout-задач — flex-доли, не проценты.

NOTE: order меняет **визуальный** порядок, но НЕ DOM-порядок: tab-навигация с клавиатуры идёт по DOM, а не по order. Для «логического» порядка — меняйте разметку или flex-direction, а order — только для визуальных «косуек» (иконка после текста при DOM-порядке текст→иконка).

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 13. Flexbox II</title>
</head>
<body>
  <div class="page">
    <header class="topbar">Шапка</header>
    <div class="layout">
      <aside class="sidebar">Sidebar (260px)</aside>
      <main class="content">
        <p>Основной контент. <span class="long">Супердлинныйнепрерывныйсловосочетание1234567890</span> — проверка min-width: 0.</p>
      </main>
    </div>
    <footer class="footer">Подвал — прижат к низу даже при коротком контенте</footer>
  </div>
</body>
</html>
```
CSS:
```css
.page {
  display: flex;
  flex-direction: column;
  min-height: 100dvh; /* "святой грааль" */
}

.topbar, .footer {
  padding: 0.75rem 1rem;
  background: #f1f3f5;
}

.layout {
  display: flex;
  flex: 1; /* занимает "остаток" между шапкой и подвалом */
}

.sidebar {
  flex: 0 0 260px; /* ровно 260px, не тянется и не сжимается */
  background: #e7f5ff;
  padding: 1rem;
}

.content {
  flex: 1;       /* "остаток" ширины */
  min-width: 0;  /* КЛЮЧЕВОЙ приём против переполнения */
  padding: 1rem;
}
```
Разбор: .page — колонка на всю высоту окна (min-height: 100dvh), .layout с flex: 1 «растягивается» между шапкой и подвалом — подвал «прижат» к низу даже при пустом контенте. .sidebar — фиксированный 260px, .content — «остаток». min-width: 0 у .content — без него длинное слово .long «продавит» колонку и появится горизонтальный скролл. Уберите min-width: 0 и сравните.

## Частые ошибки
WARN: переполнение от длинного слова/URL — flex-элемент «не сжимается» из-за min-width: auto; добавьте min-width: 0 (или overflow: hidden) у flex-колонки.
WARN: flex: 1 у ВСЕХ детей — «равные доли», но не «равные ширины», если у кого-то контент шире: basis 0% + grow 1 дают равные ДОЛИ свободного; при разном контенте — flex: 1 1 0 и min-width: 0.
WARN: flex-wrap: wrap «не переносит» — элементы не «влезли», но shrink (по умолчанию 1) их «усадил»; для «жестких» карточек — flex: 0 0 280px (не сжиматься).
WARN: order «для навигации» — визуальный порядок ≠ tab-порядок; для «переставить пункты меню» — меняйте DOM или direction, а не order.
WARN: flexbox для «сетки 3×3» — можно, но мучительно (wrap + basis-проценты + gap-вычисления); для 2D-сетки — Grid (урок 14).

## Практическое задание

1. Соберите каркас из Примера и реализуйте layout со скелета задания.

2. Уберите min-width: 0 у .content — длинное слово «продавит» колонку (горизонтальный скролл). Верните и объясните формулу: почему flex-shrink «не сработал».

3. Задайте .sidebar flex: 1 — что произошло с пропорциями? Верните flex: 0 0 260px.

4. Соберите «ряд равных карточек»: 4 div-карточки в flex-контейнере с gap: 1rem, каждая flex: 1; min-width: 0 — и проверьте, что ширины РАВНЫ при разном тексте.

5. Бонус: уберите min-height: 100dvh у .page — подвал «уплыл» сразу под контент. Верните и объясните, что делает flex: 1 у .layout в колонке.
