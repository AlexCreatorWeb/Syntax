# Урок 16. Subgrid: раскладка внутри раскладки

## Цель
После урока студент сможет: объяснить, зачем нужен subgrid (выравнивание строк ВНУТРИ карточек-контейнеров); применить grid-template-rows/columns: subgrid и собрать «честную» таблицу из карточек; подготовить fallback для проектов без subgrid.

## Теория
### Проблема, которую решает subgrid
Классическая «сетка карточек»: каждая карточка — свой flex/grid-контейнер (заголовок, текст, кнопка). Контент у карточек РАЗНОЙ длины → строки «едут»: заголовки на разной высоте, кнопки «вразнобой». Старые «лечения»: фиксированные высоты, grid-auto-rows: 1fr (только для одного ряда), JS-выравнивание.

**subgrid** (2021–2023, полная поддержка во всех актуальных браузерах) позволяет **вложенному** grid «унаследовать» треки внешнего: карточки становятся **ячейками** внешней сетки, а их ВНУТРЕННЯЯ раскладка (строки) — «дочерними» для родительских. Результат: строки ВСЕХ карточек выравниваются — заголовки на одной линии, кнопки на одной линии, НЕСМОТРЯ на разный контент.

### Как это работает
Внешний контейнер — grid с рядами. Карточка-«прокладка» (обёртка) получает:
```css
.card {
  display: grid;
  grid-template-rows: subgrid; /* "унаследовать" строки от родителя */
  grid-row: span 3;            /* карточка занимает 3 "родительских" ряда */
}
```
Родительская сетка задаёт grid-template-rows: repeat(2, auto) — «на 2 карточки по 3 ряда», и каждый .card «входит» в свои 3 родительских ряда. Внутри карточки элементы (заголовок, текст, кнопка) встают в 1-й, 2-й, 3-й родительский ряд — и **выравниваются между карточками**.

Аналогично **grid-template-columns: subgrid** — «унаследовать» столбцы (алгоритм «колонка-колонка» в формах: label-колонка + input-колонка выравниваются между строками формы).

### Fallback: что делать без subgrid
Современные браузеры (Chrome 117+, Firefox 71+, Safari 16+) — subgrid работает. Для legacy:

- **grid-auto-rows: 1fr** на контейнере с ОДНИМ рядом карточек — равные высоты (но строки ВНУТРИ карточек «едут»);

- **фиксированные min-height** на «секциях» карточки (заголовок 40px, текст 80px) — «жёстко», но предсказуемо;

- **flex + align-items: stretch** на карточках (равная высота ряда) + margin-top: auto у кнопки («прижать кнопку к низу») — классика «кнопки внизу» без subgrid.

TIP: subgrid — «последняя миля» выравнивания. Если карточки РОВНОГО содержимого (галерея картинок) — subgrid не нужен: auto-fit + minmax (урок 15) достаточно. Subgrid «раскрывается», когда «карточки-контейнеры» с РАЗНЫМ количеством текста.

NOTE: subgrid работает только если родитель — **grid** (и у него есть «свои» ряды/столбцы). display: flex + subgrid — не работает. И grid-row: span N у карточки — ОБЯЗАТЕЛЬНО (иначе «унаследовать» нечего).

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 16. Subgrid</title>
</head>
<body>
  <div class="cards">
    <article class="card">
      <h3>Карточка А</h3>
      <p>Короткий текст.</p>
      <button>Подробнее</button>
    </article>
    <article class="card">
      <h3>Карточка Б</h3>
      <p>Заметно более длинный текст, который занимает две-три строки и «раздвигает» среднюю секцию.</p>
      <button>Подробнее</button>
    </article>
    <article class="card">
      <h3>Карточка В</h3>
      <p>Средний текст.</p>
      <button>Подробнее</button>
    </article>
  </div>
</body>
</html>
```
CSS:
```css
.cards {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: repeat(2, auto); /* 2 "ряда карточек" по 3 "внутренних" ряда */
  gap: 1rem;
  padding: 1rem;
}

.card {
  display: grid;
  grid-template-rows: subgrid; /* "унаследовать" 3 ряда от родителя */
  grid-row: span 3;            /* каждая карточка = 3 "родительских" ряда */
  gap: 0.5rem;
  padding: 1rem;
  border: 1px solid #dee2e6;
  border-radius: 8px;
  align-items: start;
}

.card button {
  justify-self: start;
}
```
Разбор: без subgrid (закомментируйте 2 строки у .card) — кнопки «едут»: у «Б» (с длинным текстом) кнопка ниже. С subgrid — все три кнопки на ОДНОЙ линии (3-й «родительский» ряд), заголовки — на ОДНОЙ линии (1-й ряд). Ряд 2 (текст) — «авто-высоты» под самый длинный текст.

## Частые ошибки
WARN: subgrid без grid-row: span N — «унаследовать» нечего: карточка занимает 1 «родительский» ряд, и внутренних 3 ряда «не влезает»; span N — ОБЯЗАТЕЛЕН.
WARN: родитель не grid (flex) — subgrid молча «не работает» (карточка ведёт себя как обычный grid со своими рядами); родитель ОБЯЗАН быть grid с «своими» template-rows.
WARN: grid-template-rows: subgrid + свои rows — «конфликт»: subgrid ЗАМЕНЯЕТ template, свои ряды «теряются»; если нужны «свои» — это не subgrid.
WARN: legacy «без fallback» — на старых браузерах subgrid «не работает»: карточки станут обычными grid (свои ряды) — «не сломаются», но кнопки «поедут»; для legacy — flex + margin-top: auto (fallback-паттерн).
WARN: gap в subgrid «двойной» — у родителя gap, у карточки СВОЙ gap: промежутки «суммируются» визуально (родительский между карточками + внутренний между секциями); это нормально, но планируйте значения.

## Практическое задание

1. Соберите каркас из Примера и реализуйте subgrid-раскладку со скелета задания.

2. Закомментируйте grid-template-rows: subgrid и grid-row: span 3 — кнопки «поедут». Верните и объясните, ЧТО именно выравнивается (строки 1, 2, 3).

3. Добавьте 3-ю карточку с «ещё более длинным» текстом — проверьте, что кнопки ВСЕХ 4 на одной линии (имплицитный «родительский» ряд 2 «вырос»).

4. Соберите fallback-вариант (без subgrid): .card { display: flex; flex-direction: column } .card button { margin-top: auto } + .cards { align-items: stretch } — сравните с subgrid: где «плюсы» каждого?

5. Бонус: реализуйте «форму» с subgrid: .form { grid-template-columns: subgrid } внутри родительской 2-колоночной сетки (label | input) — и объясните, почему label-колонка выравнивается между строками.
