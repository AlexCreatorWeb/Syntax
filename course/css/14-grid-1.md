# Урок 14. Grid I: треки, fr, minmax, gap

## Цель
После урока студент сможет: включить CSS Grid и задать явную сетку (grid-template-columns/rows); использовать fr, minmax(), repeat(); разместить элемент в ячейках (grid-column/row) и объяснить разницу Grid и Flexbox в выборе.

## Теория
### Grid — раскладка по двум осям сразу
**display: grid** превращает контейнер в 2D-раскладку: вы задаёте **столбцы** (grid-template-columns) и **ряды** (grid-template-rows), и дети («grid-элементы») раскладываются по **ячейкам** (intersection строки и столбца) **слева направо, сверху вниз** — по порядку DOM.

Базовый набор свойств контейнера:

- **grid-template-columns: 200px 1fr 2fr** — три столбца: первый 200px, два следующих делят остаток 1:2;

- **repeat(3, 1fr)** — сокращение: три равных столбца (повторяется 3 раза);

- **minmax(200px, 1fr)** — «от 200px до «равной доли»»: столбец не уже 200px, но может «расти» до доли свободного;

- **gap: 1rem** (row-gap/column-gap) — промежутки между строками/столбцами (как в flex);

- **grid-template-rows** — аналогично для рядов.

**fr** (fraction) — «доля свободного места»: 1fr 1fr 1fr = три равных столбца; 1fr 2fr — второй ВДВОЕ шире. fr считается ПОСЛЕ размещения «жёстких» (px/%)-треков: «200px 1fr» = 200px + «остаток».

### Размещение элементов: grid-column / grid-rows
Каждый grid-элемент можно «переместить» в сетке:

- **grid-column: 1 / 3** — от линии 1 до линии 3 (занимает 2 столбца);

- **grid-column: span 2** — «на 2 столбца вправо»;

- **grid-row: 1 / 3**, **grid-row: span 2** — аналогично по рядам;

- **grid-column: 1 / -1** — «всю ширину» (от первой линии до последней) — классика «баннер над сеткой».

Линии нумеруются с 1, отрицательные — «с конца»: -1 — последняя линия. «Клетка» (1,1) — это ПЕРЕСЕЧЕНИЕ линии 1 столбца и линии 1 ряда.

### Grid против Flexbox: когда что
Правило выбора: **одна ось (строка ИЛИ колонка, «распределить по линии») — Flexbox; две оси (и строки, и столбцы одновременно) — Grid.** На практике: навигация/тулбар/«карточки в ряд» — flex; страница целиком, дашборд, галерея — Grid. Они **комбинируются**: Grid для «каркаса» страницы, flex — внутри карточек (заголовок + кнопка в строку).

TIP: **minmax(0, 1fr)** — «защитный» шаблон: minmax(0, 1fr) вместо 1fr, когда в ячейке может «раздуться» контент (таблицы, длинные строки, pre). По умолчанию min-у 1fr — auto (= содержимое), и длинное слово «проткнёт» сетку. minmax(0, 1fr) — «от 0 до доли» — сетка держится.

NOTE: Grid-элементы (дети) по умолчанию «растягиваются» на всю ячейку (justify-items/align-items: stretch) — как flex-stretch, только в 2D. Для «по размеру содержимого» — justify-items: start или размеры на самом элементе.

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 14. Grid I</title>
</head>
<body>
  <div class="dashboard">
    <div class="cell banner">Баннер (вся ширина)</div>
    <div class="cell">Ячейка 1</div>
    <div class="cell">Ячейка 2</div>
    <div class="cell tall">Ячейка 2 ряда</div>
    <div class="cell">Ячейка 4</div>
    <div class="cell">Ячейка 5</div>
  </div>
</body>
</html>
```
CSS:
```css
.dashboard {
  display: grid;
  grid-template-columns: repeat(3, minmax(0, 1fr));
  gap: 1rem;
  padding: 1rem;
}

.banner {
  grid-column: 1 / -1; /* "вся ширина" */
  background: #e7f5ff;
}

.tall {
  grid-row: span 2; /* "на 2 ряда" */
  background: #fff4e6;
}

.cell {
  padding: 1rem;
  border: 1px solid #dee2e6;
  border-radius: 8px;
  background: #fff;
}
```
Разбор: 3 равных столбца (repeat(3, minmax(0, 1fr))). .banner «перекрывает» все 3 столбца первой строки (1 / -1). .tall «растягивается» на 2 ряда — ячейки 4 и 5 встают ПОЗАД неё (grid «обтекает» занятые места). Ряды **имплицитные**: grid-template-rows не задан — браузер создаёт столько строк, сколько нужно, с высотой auto.

## Частые ошибки
WARN: 1fr «раздута» длинным контентом — min у 1fr равен auto; для «честной» доли — minmax(0, 1fr) (особенно с таблицами/pre/длинными строками в ячейке).
WARN: gap «не считается» в расчётах fr — fr делит «свободное ПОСЛЕ gap»: 2 столбца по 1fr с gap 16px в контейнере 1000px = по 492px (а не 500).
WARN: grid-column: 2 без «до» — это «от линии 2 до ИМPLICIT-следующей» (на 1 столбец); для «с 2-го по 4-й» — 2 / 4, для «на 2 столбца» — span 2.
WARN: Grid для «одной строки кнопок» — можно, но избыточно: для 1D-раскладки — flex (меньше свойств, проще wrap-поведение).
WARN: процентные ширины у grid-детей «ломают» сетку — размер ячейки задаёт КОНТЕЙНЕР (template), а не child: width: 50% у ячейки — 50% ОТ ЯЧЕЙКИ, а не от сетки.

## Практическое задание

1. Соберите каркас из Примера и реализуйте grid-правила со скелета задания.

2. Замените grid-template-columns на 200px 1fr 2fr — описать, как изменились ширины (и почему средний «уже» бокового).

3. Добавьте седьмую .cell с grid-column: 2 / 4 — какой «кусок» сетки она займёт и куда «уедет» 6-я ячейка?

4. Задайте .dashboard grid-template-rows: 60px auto auto — и объясните, что стало с первой строкой (баннером).

5. Бонус: соберите «галерею» 6 карточек: 2 столбца, первые 2 — «на всю ширину» (grid-column: 1 / -1), остальные по 2 в ряд.
