# Урок 1. CSS: как присоединить стили к HTML

## Цель
После урока студент сможет: объяснить, что такое правило CSS (селектор, свойство, значение); присоединить внешний файл стилей к странице тремя способами и выбрать правильный; открыть DevTools и найти правило, которое стилизует конкретный элемент.

## Теория
### Правило CSS — из чего оно состоит
CSS (Cascading Style Sheets) описывает, КАК выглядит разметка: цвета, размеры, отступы, расположение. Строка CSS — это правило, и у правила всегда две части: селектор (кого стилизуем) и блок деклараций (что делаем):

- селектор — `h1` (элемент), `.card` (класс), `#logo` (id);

- блок `{}` содержит декларации: `свойство: значение;` — например `color: teal;`.

Одно правило может задавать несколько свойств, а одно свойство — переопределяться несколькими правилами (это каскад — подробно в уроках 4–5).

### Три способа вставить CSS
Первый — **инлайн-атрибут** `style="color: teal"` прямо в теге. Работает, но стиль «приклеен» к одному элементу, не переиспользуется и живёт в разметке. Второй — **внутренний блок** `<style>` в head: всё в одном файле, удобно для прототипов и email-рассылок. Третий — **внешний файл**: `<link rel="stylesheet" href="styles.css">` в head, а правила лежат в отдельном файле .css.

### Почему внешний файл — стандарт
Внешний файл подключается к десяткам страниц одним тегом: поменял styles.css — поменялся весь сайт. Браузер **кэширует** CSS: при переходе между страницами файл не скачивается заново, а стили применяются ещё до того, как браузер дошёл до конца head. Поэтому структура любого реального проекта — `index.html` + `styles.css` (и больше CSS-файлов по частям), а не стили внутри HTML.

TIP: в DevTools (F12) → вкладка Elements кликните по элементу — справа панель Styles покажет ВСЕ правила, которые на него повлияли, и какие свойства зачёркнуты (то есть проиграли каскад). Это главный инструмент отладки CSS на весь курс.

### Порядок подключения
`<link>` обычно пишут после `meta`-тегов в head. Если правил много и есть несколько файлов, порядок `<link>`-тегов имеет значение: stylesheet, подключённый ПОЗЖЕ, «выше» по каскаду — при равной специфичности выигрывает его правило. Внутренний `<style>` и инлайн-атрибут приравниваются к правилам того же автора, но инлайн выигрывает у любых правил файла (это тоже специфичность — урок 5).

NOTE: в редакторе Syntax два файла (index.html и styles.css) подхватываются превью АВТОМАТИЧЕСКИ — `<link>` не нужен. Но в «настоящей» жизни на диске без link стили не применятся: это первое, что проверяет студент, когда «CSS не работает».

## Пример
HTML-каркас (создайте рядом файл index.html и вставьте):
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 1. Подключение CSS</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
  <h1>Мой первый CSS</h1>
  <p class="note">Абзац с классом note.</p>
  <p>Обычный абзац без класса.</p>
</body>
</html>
```
CSS (это и есть ваш styles.css, скелет задания):
```css
h1 {
  color: #0b7285;
  margin-bottom: 1rem;
}

p {
  line-height: 1.5;
}

.note {
  color: #e8590c;
  font-weight: bold;
}
```
Разбор: `h1` — селектор по тегу, закрашивает ВСЕ h1. `.note` — селектор по классу, находит только абзац с class="note". Свойство `margin-bottom` задаёт отступ снизу (урок 7), `line-height` — межстрочный интервал (урок 9). Откройте превью: второй абзац «теплый», первый — обычный.

## Частые ошибки
WARN: стили в атрибуте style="..." — они живые, но не переиспользуемые: два элемента с одинаковым инлайн-стилем = дубли, и поменять их надо вручную в каждом.
WARN: забыл тег <link> в head — файл CSS существует, но браузер о нём не знает; страница отрисовывается «голая», ошибок в консоли НЕТ (это главная причина вопроса «почему не работает»).
WARN: href="styles.CSS" или "style.css" — имя файла в href должно совпадать с именем на диске ДО Точки, включая расширение и регистр.
WARN: link без rel="stylesheet" — браузер может решить, что это загрузка для печати или что-то другое; всегда rel="stylesheet".
WARN: стили не видны после правки — файл сохранён не в ту папку (styles.css лежит не рядом с index.html, а, например, в подпапке css/ — тогда href="css/styles.css").

## Практическое задание

1. Создайте index.html с каркасом из Примера и рядом файл styles.css со скелетом задания; в редакторе превью появится автоматически.

2. Реализуйте TODO: задайте h1 цвет из палитры урока, а абзацам — font-size и line-height по 1.5.

3. В DevTools → Elements кликните по h1: найдите своё правило в панели Styles и проверьте, что оно НЕ зачёркнуто.

4. Добавьте в body третий абзац с class="note" и убедитесь, что оба «note»-абзаца закрашены, а обычный — нет.

5. Бонус: уберите <link> из head, сохраните и посмотрите на превью — затем верните. Запишите своими словами, почему страница стала «голой».
