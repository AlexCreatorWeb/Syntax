# Курс «CSS: от синтаксиса к современной вёрстке» — дорожная карта (22 урока)

Целевая аудитория: студент, прошедший курс HTML (или знающий базовую разметку). Результат: студент верстает современные адаптивные раскладки на Flexbox/Grid, работает с каскадом осознанно, использует медиа- и контейнерные запросы, переменные и анимации — без устаревших хаков (float-сеток, table-layout, position-хаков).

Источники: MDN Web Docs (CSS Reference, Learning CSS), CSS Living Standard (W3C), WCAG 2.2 (контраст, reduced-motion).

## Логика цепочки
01 → 02: без файла стилей нечего писать — дальше селекторы (кем находить). 02 → 03: базовые селекторы → состояния, псевдоэлементы, :has. 03 → 04: правила заданы — что выигрывает при конфликте: каскад. 04 → 05: «позднее выигрывает» — но есть и вес правила: специфичность. 05 → 06: выигравшее значение — в каких единицах его писать. 06 → 07: единицы описывают размеры — а размер элемента это box model. 07 → 08: размеры заданы — как элемент стоит в потоке (display) и что делают его margin. 08 → 09: внутри блока живёт текст — типографика. 09 → 10: текст и фон — цвет. 10 → 11: поток → исключения из потока: position. 11 → 12: в потоке элементы выстраиваем Flexbox-ом. 12 → 13: flex-оси → размер в flex (grow/shrink) и паттерны. 13 → 14: 2D-раскладка — Grid. 14 → 15: треки → области и автоматические сетки. 15 → 16: вложенные сетки — subgrid. 16 → 17: раскладка готова — как она меняется на экранах. 17 → 18: «экран» → «контейнер»: container queries. 18 → 19: дискретные брейкпоинты → плавные значения (clamp). 19 → 20: значения → система: переменные и темы. 20 → 21: живая страница: transition/animation. 21 → 22: всё вместе — финальный проект.

## Контракт строки БД (таблица lessons)
- tech: 'css' (строчные).
- title: 3–6 слов, без нумерации (номер фронт выдаёт по порядку id).
- content: markdown-lite. Структура ОБЯЗАТЕЛЬНА: `## Цель` (1 абзац) → `## Теория` (2–5 абзацев, `###` подтемы, минимум 1 `TIP:`) → `## Пример` (рабочий HTML-каркас ```html + CSS ```css + разбор) → `## Частые ошибки` (3–5 `WARN:`-пунктов) → `## Практическое задание` (нумерованный список). Минимум 1 `TIP:` и 1 `WARN:` на урок.
- Форматирование: **жирный**, *курсив*, `инлайн-код`, ```-блоки, ##/###. Таблиц и [ссылок](url) НЕТ — URL текстом. Callout'ы в начале строки: `TIP:` / `NOTE:` / `WARN:` (текст callout'а — без ** и `).
- code: стартовый код ЗАДАНИЯ (не решение) — CSS-скелет `styles.css` с `/* TODO */`; хранится в `code/NN.css`. HTML-каркас — в материале урока (студент создаёт index.html рядом; превью редактора подхватит оба файла).
- Объём content: 4–7 КБ. Язык — русский.
- Порядок = порядок вставки (id): от простого к сложному, последний — «Финальный проект».
