# Урок 10. Цвет и прозрачность: hex, rgb, hsl

## Цель
После урока студент сможет: записать цвет в hex (с альфой), rgb() и hsl(); смешивать цвета прозрачностью (альфа-канал); проверить контраст текста/фона по WCAG и выбрать «рабочую» палитру из 4–6 цветов.

## Теория
### Три записи одного цвета
Один и тот же цвет пишется тремя способами:

- **hex** — #RRGGBB (например, #1971c2) или короткий #RGB (= #RRGGBB: #f0c = #ff00cc); **альфа** — 8 цифр #RRGGBBAA (#1971c280 = на 50% прозрачный синий);

- **rgb()** — современный синтаксис через пробел: rgb(25 113 194) или с альфой: rgb(25 113 194 / 0.5) (запятый вариант rgb(25,113,194,0.5) работает, но «старый»);

- **hsl()** — hue (оттенок 0–360°), saturation (насыщенность 0–100%), lightness (светлота 0–100%): hsl(215 79% 45%) ≈ тот же синий; с альфой: hsl(215 79% 45% / 0.5).

HSL — «человеческая» модель: hue двигает цвет по кругу (0 — красный, 120 — зелёный, 240 — синий), lightness — 0% чёрный, 100% белый, 50% «чистый». Палитру удобнее строить в HSL: выбрал hue и варьируешь lightness (tint/shade) — получишь семейство оттенков одного цвета.

### Прозрачность: альфа-канал vs opacity
Два разных механизма:

- **альфа в цвете** (rgb(... / 0.5), #00000080) — прозрачен ТОЛЬКО этот цвет: элемент с полупрозрачным фоном и непрозрачным текстом — текст «целый»;

- **opacity: 0.5** — прозрачна ВСЯ подсистема элемента: фон, текст, дети (для контейнера — «призрак» со всем содержимым).

Для «серых» состояний (disabled, secondary text) — альфа в цвете (цвет наследует «оттенок» бренда): color: rgb(33 37 41 / 0.6). opacity — для «уходящих» состояний (hover-эффекты, loading).

currentColor — особое «значение»: берёт color текущего элемента (border-color: currentColor — рамка цвета текста).

### Контраст и a11y: 4.5:1
WCAG 2.2: **основной текст** — контраст ≥ **4.5:1** к фону; **крупный текст** (≥18pt / 24px или ≥14pt / 18.5px bold) — ≥ **3:1**. Серый текст на белом #767676 — это «граница» 4.5:1; светлее — уже a11y-баг. Инструменты: DevTools → вкладка «Contrast» (Chrome: выделите элемент → панель Accessibility), онлайн-калькуляторы (webaim.org/resources/contrastchecker).

Правило выбора палитры: 1 нейтральный (текст), 1 фон, 1 акцент (ссылки, кнопки), 1–2 «статусных» (успех/ошибка), и НЕ больше 6 цветов в макете. Остальное — оттенки (tint/shade) через lightness/альфу.

TIP: храните цвета как **кастомные свойства** (урок 20): :root { --accent: #1971c2; --text-muted: rgb(33 37 41 / 0.6); } — и меняйте тему одним блоком, а не 40 строчками.

NOTE: «контраст» считается по итоговому цвету СМЕСИ: полупрозрачный текст на цветном фоне — считайте фактический цвет (DevTools покажет computed). #000 с альфой 0.5 на белом ≈ #808080 — на грани 4.5:1.

## Пример
Каркас:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Урок 10. Цвет</title>
</head>
<body>
  <div class="card">
    <h2>Заголовок карточки</h2>
    <p>Основной текст.</p>
    <p class="muted">Второстепенный текст (альфа).</p>
    <a class="link" href="#">Ссылка-акцент</a>
    <button class="btn">Кнопка</button>
  </div>
  <div class="banner">Баннер с полупрозрачным фоном</div>
</body>
</html>
```
CSS:
```css
body {
  font-family: system-ui, sans-serif;
  background: #fff;
  color: #212529;
}

.card {
  max-width: 420px;
  margin: 1rem auto;
  padding: 1.5rem;
  border: 1px solid #dee2e6;
  border-radius: 12px;
}

.muted {
  color: rgb(33 37 41 / 0.6); /* альфа, а не "серый" */
}

.link {
  color: #1971c2;
}

.btn {
  background: hsl(215 79% 45%);
  color: #fff;
  border: none;
  padding: 0.5rem 1rem;
  border-radius: 8px;
}

.banner {
  background: rgb(25 113 194 / 0.1); /* полупрозрачный акцент */
  color: #1971c2;
  padding: 1rem;
}
```
Разбор: .muted — тот же «тёмный» цвет с альфой 0.6 (наследует оттенок, не «внешний» серый). Кнопка — hsl-запись акцента, баннер — 10%-прозрачная версия того же цвета (tint). Проверьте контраст .muted и .link в DevTools — оба проходят 4.5:1.

## Частые ошибки
WARN: серый текст «на глазок» — без проверки контраста; #999 на белом = 2.8:1 — a11y-баг; проверяйте каждый цвет текста/фона парой (DevTools → Contrast).
WARN: opacity: 0.5 для «приглушить текст» — прозрачным становится ВСЁ, включая иконки/дети; для приглушения цвета — альфа в color: rgb(33 37 41 / 0.6).
WARN: #fff на ярком фоне (жёлтый, оранжевый) — «красиво в макете», но контраст 1.6:1; тёмный текст на светлом акценте — проверьте пару.
WARN: hex-альфа #1971c280 — 8-значный hex не поддерживается самыми старыми браузерами (IE); в современных проектах — ок, для legacy — rgb/hsl с альфой.
WARN: «палитра на 20 цветов» — каждый новый цвет = новая точка контроля контраста и совместимости; 4–6 цветов + оттенки — рабочий предел.

## Практическое задание

1. Соберите каркас из Примера и реализуйте цвета со скелета задания (hex/rgb-альфа/hsl по местам).

2. В DevTools → Contrast проверьте пары: .muted/фон карточки, .link/фон, .btn-текст/фон кнопки — запишите коэффициенты.

3. Замените .muted на opacity: 0.6 и добавьте внутрь <strong> — что произошло с жирным словом (подсказка: opacity «заразительна»)?

4. Соберите «семейство» из одного hue: hsl(215 79% 90%), 70%, 50%, 30% — и назначьте их фоном, баннером, акцентом, hover-кнопки.

5. Бонус: задайте .btn:hover через currentColor-приём — color: #fff у кнопки, а border: 2px solid currentColor — и объясните, что даст это при смене color.
