# Урок 5. Навигация сайта и вкладки

## Цель
После урока студент сможет: собрать связанный многостраничный сайт (единое меню, относительные пути), разметить хлебные крошки и пагинацию, сделать «текущую» страницу видимой и построить вкладки/аккордеон без единой строчки JS.

## Теория
### Сайт — это несколько файлов
Реальный сайт — не один index.html, а структура: index.html, about.html, catalog.html, blog/index.html... Страницы связываются ссылками с относительными путями: `about.html` (рядом), `blog/post.html` (в подпапке), `../index.html` (на уровень вверх).

Единый `<header>` с меню копится в каждую страницу вручную (без сервера «включение» файлов невозможно) — поэтому меню держим компактным и дублируем его строго одинаковым.

### Паттерн навигации: меню
Меню — это `<nav><ul><li><a>` (список из урока 7 будет позже — пока пишем ul «по образцу»): ul внутри nav, li — пункты, a — ссылки. Маркеры CSS'ом отключаются, семантика сохраняется. Текущая страница помечается `aria-current="page"` — скринридер скажет «текущая страница». Глубина меню — один уровень: «Все товары → Кредитки → 3D-принтеры» — это уже хлебные крошки и пагинация, а не меню.

### Хлебные крошки и пагинация
Хлебные крошки — `<ol>` (это упорядоченный ПУТЬ: главный → раздел → текущая): `<nav aria-label="Хлебные крошки"><ol>...`. Первый пункт — «Главная» (ссылка на index.html), последний — ТЕКУЩАЯ страница: она — `<span>`, не ссылка.

Пагинация — `<nav aria-label="Пагинация">` со ссылками на страницы; текущая — `aria-current="page"`.

### Вкладки и аккордеон без JS
Раскрывающийся блок — `<details>/<summary>` (работает нативно, урок 15): это «аккордеон». Полноценные вкладки на радио-кнопках требуют CSS (:checked) — на чистом HTML делаем аккордеон: несколько details, раскрыт один. Мобильное меню — тоже details: `<summary>Меню</summary>` + ul ссылок.

TIP: имена файлов — латиницей, строчными, через дефис (about-us.html): Windows не отличает регистр, Linux — да, и «About-Us.HTML» на сервере станет 404.

### Почему aria-current важнее «жирного» пункта
«Текущая страница» в меню — не только визуальный акцент: скринридер в режиме навигации по меню скажет «Главная, текущая страница» — пользователь поймёт, где он, не глядя. Без aria-current пункт различим только глазом.

## Пример
```html
<header>
  <nav aria-label="Главное меню">
    <ul>
      <li><a href="index.html" aria-current="page">Главная</a></li>
      <li><a href="catalog.html">Каталог</a></li>
      <li><a href="about.html">О нас</a></li>
    </ul>
  </nav>
</header>
<main>
  <nav aria-label="Хлебные крошки">
    <ol>
      <li><a href="index.html">Главная</a></li>
      <li><a href="catalog.html">Каталог</a></li>
      <li><span>Товар</span></li>
    </ol>
  </nav>
  <h1>Товар</h1>
  <h2>Дополнительно</h2>
  <details open>
    <summary>Характеристики</summary>
    <p>Вес, габариты, материалы.</p>
  </details>
  <details>
    <summary>Отзывы</summary>
    <p>12 отзывов.</p>
  </details>
  <nav aria-label="Пагинация">
    <a href="page-1.html">←</a>
    <span aria-current="page">1</span>
    <a href="page-2.html">2</a>
    <a href="page-3.html">3</a>
    <a href="page-2.html">→</a>
  </nav>
</main>
```

## Частые ошибки
WARN: в хлебных крошках текущая страница — ссылка на саму себя; она должна быть span без href.
WARN: пагинация сделана div'ами — скринридер не объявляет «навигация, 5 страниц».
WARN: абсолютные пути в духи C:\Users\... в href — переносимая вёрстка использует только относительные.
WARN: вкладки на div onclick — нет клавиатурного фокуса и состояния; на чистом HTML — details/summary.
WARN: меню в каждой странице «допиливают» по-разному — дивергент: меню копируется идентично.

## Практическое задание
1. В стартовом файле соберите меню ul из 4 пунктов, отметив текущий aria-current="page".
2. Добавьте хлебные крошки ol: «Главная / Каталог / Товар» (последний — span).
3. Сделайте аккордеон из 3 details-блоков (первый open).
4. Добавьте пагинацию: ← 1 2 3 → (текущая — span с aria-current).
5. Бонус: создайте в редакторе второй файл about.html с тем же меню (aria-current на «О нас») и проверьте переходы между файлами.
