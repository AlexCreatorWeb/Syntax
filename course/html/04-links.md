# Урок 4. Ссылки: от якорей до rel

## Цель
После урока студент сможет: строить внутренние и внешние ссылки, якорные переходы по странице, ссылки-картинки и группы навигации, понимать `rel` и `target` и не создавать «ссылку в ссылке».

## Теория
### Анатомия ссылки
`<a>` — самый важный тег HTML: именно ссылки превращают документы в «сеть». Всё, что можно щёлкнуть, — это `<a>` (или `<button>` — в уроках о формах).

Атрибут `href` — куда ведёт ссылка. Четыре варианта: абсолютный адрес (https://...), относительный путь (docs/page.html, ../img/cat.jpg), якорь (#section — переход к элементу с таким id на этой странице) и специальные схемы (mailto:, tel:, download). Относительные пути считаются от текущего файла — переносите папку со страницами вместе, и ссылки «доживают».

### Внешние ссылки и target
Внешняя ссылка в новой вкладке: `target="_blank" rel="noopener"`. Пара обязана быть целой: `noopener` страхует от того, что новая страница через `window.opener` «перехватит» вашу. Ссылка на файл (docs/report.pdf) — браузер откроет PDF, не уходя с сайта.

### nav
`<nav>` — контейнер для основной группы ссылок (меню, хлебные крошки, пагинация). У страницы может быть несколько nav. Без него скринридеру приходится искать ссылки наугад — с ним он прыгает к меню сразу.

### Ссылка — интерактивный элемент
Внутри `<a>` не должно быть других интерактивных элементов: второй `<a>`, `<button>`, `<input>`. Это классическая невалидность («a inside a»): браузер сам «латает» дерево, вырывая внутренний тег наружу, — и структура рушится.

### Ссылка-кнопка против кнопки
Частый вопрос: «`<a>` или `<button>`?». Правило: `a` — ПЕРЕХОД (на другую страницу, файл, якорь), `button` — ДЕЙСТВИЕ (отправить, очистить, открыть диалог). «Ссылка-кнопка» (ссылка, стилизованная под кнопку) — нормальный и частый паттерн: это всё равно `a` с href. А `div` с onclick для любого из двух случаев — ловушка: нет клавиатурного фокуса и срабатывания на Enter (урок 13).

TIP: якорный пункт href="#" — «мёртвая» ссылка: прыжок вверх и хэш-мусор в URL. Кнопка без действия лучше как button (урок 9), а ссылка — только с реальным href.

## Пример
```html
<header>
  <nav aria-label="Главное меню">
    <a href="#features">Возможности</a>
    <a href="#contacts">Контакты</a>
    <a href="https://developer.mozilla.org/" target="_blank" rel="noopener">MDN</a>
  </nav>
</header>
<main>
  <h1 id="top">Главная</h1>
  <section id="features">
    <h2>Возможности</h2>
    <p>Смотрите контакты ниже или отчёт:
       <a href="docs/report.pdf">отчёт в PDF</a>.</p>
    <a href="images/hero.jpg">
      <img src="images/hero.jpg" alt="Открыть галерею"
           width="640" height="400">
    </a>
  </section>
  <section id="contacts">
    <h2>Контакты</h2>
    <p><a href="mailto:hello@example.com">Написать</a> или
       <a href="tel:+79991234567">позвонить</a>.</p>
    <p><a href="#top">Наверх ↑</a></p>
  </section>
</main>
```
Разбор: width/height у img внутри ссылки резервируют место до загрузки — страница не «прыгает» (CLS). Ссылка-картинка: `alt` = цель ссылки, а не описание картинки.

## Частые ошибки
WARN: ссылка-картинка без alt — скринридер скажет просто «картинка»; alt несёт смысл ссылки (например, «Купить билет»).
WARN: target="_blank" без rel="noopener" — новая страница видит window.opener и может перехватить окно.
WARN: ссылка в ссылке (<a><a>) — невалидно, парсер «вырывает» внутренний тег наружу.
WARN: href="#" повсюду «пока не знаю, куда» — клик прыгает вверх, в URL остаётся хэш-мусор.
WARN: весь абзац обёрнут в ссылку ради одного слова — огромная «кликабельность», потеря структуры; ссылка — на слово/фразу.

## Практическое задание
1. В стартовом файле соберите меню: 3 якорных ссылки на секции страницы + 1 внешняя (target и rel).
2. Добавьте ссылку-картинку (alt = цель), ссылки mailto: и tel:, «Наверх ↑» на h1.
3. Проверьте: клики по якорям работают, в адресе появляется #...; Tab проходит по всем ссылкам по порядку.
4. Проверьте на validator.w3.org — 0 ошибок.
5. Бонус: откройте любой сайт в DevTools и найдите в его HTML все rel= — объясните вслух, что делают найденные значения.
