# Урок 1. Структура HTML-документа

## Цель
После урока студент сможет: открыть любой HTML-файл и объяснить, зачем нужна каждая его часть; написать валидный «скелет» страницы с нуля и проверить его на validator.w3.org.

## Теория
### HTML — это разметка, а не программирование
HTML описывает структуру страницы: браузер читает теги сверху вниз и строит из них дерево (DOM). Операторов и логики нет — только элементы и их атрибуты, поэтому важны не «синтаксис», а порядок и вложенность тегов.

### Как браузер разбирает страницу
Браузер делает три вещи: скачивает документ, разбирает его в дерево элементов (парсинг) и отрисовывает. Парсинг идёт посимвольно, «на лету»: встретил `<h1>` — сразу начал строить заголовок, не дожидаясь конца файла. Поэтому ошибка в одном теге может «сдвинуть» всю остальную вёрстку.

### Два блока: head и body
`<head>` — метаданные, которые НЕ видны на странице: кодировка, заголовок вкладки, размер вьюпорта, ссылка на CSS. `<body>` — всё, что ВИДНО: текст, картинки, кнопки. Это «братья» по вложенности, оба — внутри `<html>`.

Три обязательных тега в `<head>`:
- `<meta charset="utf-8">` — кодировка (обязательно первой строкой head, подробно — урок 2).
- `<meta name="viewport" content="width=device-width, initial-scale=1">` — без него мобильный браузер «сжимает» страницу под фиксированные 980px, и мобильная вёрстка не работает.
- `<title>` — текст вкладки и строка в поисковой выдаче.

### Теги, атрибуты, пустые элементы
Тег пишется в двух формах: `<p>текст</p>` — открывающий и закрывающий. У части тегов закрытие не нужно (пустые элементы, void): `<br>`, `<img>`, `<meta>`, `<input>`. Атрибуты — параметры элемента: `<img src="cat.jpg" alt="Кот">`; значение атрибута — всегда в кавычках. HTML нечувствителен к регистру, но по конвенции пишем в нижнем.

TIP: откройте DevTools (F12) → вкладка Elements — там дерево вашей страницы. Браузер «дописывает» пропущенные теги сам, и по дереву видно, что он понял неправильно.

`lang="ru"` на `<html>` — язык страницы: скринридер читает текст «голосом» этого языка, поисковик учитывает его при выдаче. Это первый и самый дешёвый шаг к доступности.

NOTE: двойной клик по файлу открывает его по протоколу file:// — для чистого HTML+CSS этого достаточно, но часть возможностей (fetch, часть API) без локального сервера не работает. Для курса этого хватает.

### Хороший title
Заголовок вкладки — это ещё и строка в поиске и в закладках: 10–60 символов, суть страницы, без «Новый документ» и «Страница 1». `title` пишется один раз в head, но его «читают» все, кто откроет вашу ссылку.

## Пример
Минимальный валидный документ. Скопируйте в файл index.html и откройте в браузере:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Моя первая страница</title>
  <meta name="description" content="Первая страница курса по HTML">
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая HTML-страница. Она состоит из head и body.</p>
</body>
</html>
```
Разбор по частям: `<!DOCTYPE html>` — «разбирай по современным правилам» (без него — «режим совместимости» с багами). `<meta name="description">` — сниппет под заголовком в поиске. Проверка: вставьте код в validator.w3.org — получите «HTML5 Pass».

## Частые ошибки
WARN: нет <!DOCTYPE html> на первой строке — браузер уходит в quirks mode: ломаются отступы и размеры блоков.
WARN: meta charset написан после title или скриптов — браузер уже успел угадать кодировку неверно, буквы превращаются в кракозябры.
WARN: кавычки в атрибутах опущены (src=cat.jpg) — валидатор ругается, на значениях с пробелами ломается; всегда «в кавычках».
WARN: lang на <html> забыт — скринридер читает русский текст английским голосом, поисковик гадает о языке.
WARN: имя файла «Индекс (1).html» — пробелы и кириллица ломают ссылки и деплой; пишем index.html латиницей.

## Практическое задание
1. Создайте в редакторе index.html: doctype, html lang="ru", head с charset, viewport, title, description.
2. В body: h1 с вашим именем, два абзаца p о себе и hr между ними.
3. Проверьте на validator.w3.org — 0 ошибок.
4. В DevTools → Elements найдите своё дерево: head и body — соседи внутри html, а не вложенные друг в друга.
5. Бонус: уберите doctype и сравните отступы в браузере (quirks mode) — запомните, почему первая строка обязательна.
