# Урок 1. Структура HTML-документа

## Цель
После урока студент сможет: открыть любой HTML-файл и объяснить, зачем нужна каждая его часть; написать валидный «скелет» страницы с нуля.

## Теория

**HTML — это разметка, а не программирование.** Браузер читает страницу сверху вниз и строит из тегов дерево (DOM). Поэтому порядок и вложенность тегов важнее, чем «синтаксис» — в HTML нет операторов, есть только элементы и их атрибуты.

Каждая страница обязана начинаться с `<!DOCTYPE html>` — он говорит браузеру «разбирай по современным правилам» (иначе — «режим совместимости» с багами старых браузеров).

Дальше два основных блока:

- **`<head>`** — метаданные: то, что НЕ видно на странице. Кодировка, заголовок вкладки, размер вьюпорта, ссылка на CSS, мета для поисковиков и соцсетей.
- **`<body>`** — всё, что ВИДНО: текст, картинки, кнопки.

Три критически важных тега в `<head>`:

1. `<meta charset="utf-8">` — кодировка. Обязательно в первую строку head (до `<title>`): если браузер прочитает файл в «не той» кодировке раньше, чем увидит meta, русские буквы превратятся в кракозябры.
2. `<meta name="viewport" content="width=device-width, initial-scale=1">` — говорит мобильному браузеру «не сжимай страницу под 980px». Без него мобильная верстка не работает.
3. `<title>` — текст вкладки и результат поиска. Без него страница «безымянная».

Короткие факты, которые сэкономят часы:
- Тег пишется в двух формах: `<p>текст</p> — открывающий и закрывающий. У некоторых тегов закрытие не нужно (`<br>`, `<img>`) — они называются пустыми (void elements).
- Атрибуты задают параметры элемента: `<img src="cat.jpg" alt="Кот">`. Значения атрибутов — всегда в кавычках.
- HTML нечувствителен к регистру, но по конвенции теги и атрибуты — в нижнем регистре.

## Пример

Минимальный валидный документ. Скопируйте в файл `index.html` и откройте в браузере:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Моя первая страница</title>
  <meta name="description" content="Первая страница курса по HTML">
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая HTML-страница. Она состоит из head и body.</p>
</body>
</html>
```

Разбор по частям:
- `lang="ru"` — язык страницы. Скринридеры читают текст «голосом» этого языка, поисковики учитывают его при выдаче. Это первый и самый дешёвый шаг к доступности.
- `<meta name="description">` — не обязателен, но поисковики показывают его как сниппет под заголовком.

Проверка валидности: [validator.w3.org](https://validator.w3.org) — вставляете код, получаете «HTML5 Pass».

## Частые ошибки новичков

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Забыт `<!DOCTYPE html>` | Браузер уходит в «quirks mode»: ломаются отступы и размеры | Всегда первая строка файла |
| `charset` написан после `<title>` или скриптов | Браузер успел угадать кодировку неправильно | `<meta charset="utf-8">` — первое, что идёт в head |
| Кавычки в атрибутах опущены: `src=cat.jpg` | Хрупко, ломается на пробелах, валидатор ругается | Значения атрибутов — всегда в `"..."` |
| `<html lang>` забыт | Скринридер читает русский текст английским голосом | `lang` на `<html>` всегда |
| Закрыли `<body>` внутри `<head>` | Переворачивает DOM | Учимся читать вложенность: head и body — братья, а не дедушка с внуком |
| Имена файлов `Индекс (1).html` | Пробелы и кириллица ломают ссылки и деплой | `index.html`, латиница, без пробелов |

## Практическое задание

1. Создайте файл `index.html` с валидным скелетом: doctype, `<html lang="ru">`, head с charset/viewport/title/description, body.
2. В body добавьте: заголовок `h1` с вашим именем, два абзаца `p` (о себе в двух предложениях), пустой `p` — нет, замените на `<hr>`.
3. Проверьте страницу на validator.w3.org — 0 ошибок.
4. Бонус: откройте страницу в DevTools (F12) → вкладка Elements и найдите там своё дерево. Найдите, где браузер «дописал» за вас атрибут `xml:lang`.
