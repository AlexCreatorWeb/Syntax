# Урок 11. Семантическая структура страницы

## Цель
После урока студент сможет: собрать каркас любой страницы из семантических landmarks (`header`, `nav`, `main`, `article`, `section`, `aside`, `footer`), применить правила вложенности и объяснить, почему `div` — последнее средство.

## Теория
### Landmarks — «роли» блоков
Все предыдущие уроки давали «атомы» (текст, ссылки, картинки, таблицы, формы). Семантика — сборка атомов в осмысленные блоки, у каждого из которых есть РОЛЬ. Браузер, поисковик и скринридер «перемещаются» по странице по ролям, а не по пикселям.

Каркас: `<header>` — вводный блок (логотип, меню, hero); `<nav>` — группа ссылок (может быть несколько); `<main>` — УНИКАЛЬНЫЙ контент страницы, ОДИН на страницу; `<article>` — самодостаточный блок; `<section>` — тематический раздел со СВОИМ заголовком; `<aside>` — «смежный» второстепенный контент; `<footer>` — служебный блок.

### article против section
`<article>` — «самодостаточность»: блок, который имеет смысл ОТДЕЛЬНО от остального (публикация, карточка товара, комментарий). Тест: можно ли вынести блок в RSS/архив, и он останется понятным? Да → article. `<section>` — тематический разрез, который ИМЕЕТ ЗАГОЛОВОК (h2/h3 внутри); раздел без заголовка — просто div (или переосмыслить, нужен ли он вообще).

### Вложенность и «свои» header/footer
`<main>` — ровно один, прямой ребёнок body; article/section/aside/nav/header/footer не должны быть его «родителями» на верхнем уровне. У `article` и `section` могут быть СВОИ `header`/`footer` (футер статьи «обновлено: …»). `<aside>` — контент СВЯЗАННЫЙ с основным, но второстепенный. `<div>`/`<span>` — «безымянные» контейнеры, когда семантический тег не найден: нормально, но сначала ищем осмысленный.

TIP: в DevTools (расширения accessibility / tree-view) landmarks видны как «карта» страницы: banner, navigation, main, contentinfo. Если карты нет — семантики тоже нет.

### nav — не «группа ссылок»
`<nav>` — для ПОВТОРЯЮЩЕЙСЯ навигации (меню, крошки, пагинация). Разовые «ссылки в тексте» — не навигация, nav не нужны. Иерархия заголовков и landmarks — дополняют друг друга: h1 — тема, h2 — секции; landmarks их «рамляют».

## Пример
```html
<body>
  <header>
    <h1>Блог о вёрстке</h1>
    <nav aria-label="Разделы">
      <a href="/">Главная</a>
      <a href="/blog">Статьи</a>
    </nav>
  </header>
  <main>
    <article>
      <header>
        <h2>Как мы переверстали сайт на семантике</h2>
        <p><time datetime="2026-01-15">15 января 2026</time> · 7 мин</p>
      </header>
      <p>Рассказываем, как отказались от вёрстки на div'ах…</p>
      <section aria-labelledby="why">
        <h3 id="why">Почему семантика</h3>
        <p>Landmarks дают скринридеру «карту» страницы…</p>
      </section>
      <footer>
        <p>Метки: html, a11y</p>
      </footer>
    </article>
    <aside aria-label="Похожие статьи">
      <h2>Ещё по теме</h2>
      <ul>
        <li><a href="/post/tables">Таблицы: данные, а не вёрстка</a></li>
      </ul>
    </aside>
  </main>
  <footer>
    <p>© 2026 Syntax</p>
  </footer>
</body>
```
Разбор: один main, внутри — article (пост) + aside; у article свои header/footer; section имеет h3 внутри; time — машино-читаемая дата (урок 15).

## Частые ошибки
WARN: два <main> или main внутри article — нарушение уникальности, landmarks-хаос; один main, прямой ребёнок body.
WARN: div на всё «потому что CSS не cares» — landmarks не объявлены, a11y-навигация слепая.
WARN: <section> без заголовка — «секция без темы»; заголовок внутри или это просто div.
WARN: <article> на каждый блок текста — «самодостаточность» нарушена; это section или div.
WARN: h1 на каждый «большой» заголовок (карточки, секции) — иерархия сломана: h1 один, h2/h3 по структуре.

## Практическое задание
1. В стартовом файле выполните TODO: замените div'ы на header/nav/main/section/aside/footer по комментариям.
2. Убедитесь: ровно один main, секции имеют h2, aside — второстепенный контент.
3. Проверьте на validator.w3.org — 0 ошибок.
4. В DevTools → Accessibility (tree) найдите landmarks: banner, navigation, main, contentinfo.
5. Бонус: добавьте time datetime на дату и aria-labelledby на одну секцию (готовимся к уроку 13).
