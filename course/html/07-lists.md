# Урок 7. Списки: ul, ol, dl

## Цель
После урока студент сможет: выбрать правильный тип списка (unordered/ordered/description) по смыслу, встроить вложенные списки и разметить меню, инструкции, глоссарии и хлебные крошки.

## Теория
### Три вида — выбор по смыслу
`<ul>` (unordered) — набор элементов, порядок НЕ имеет значения: навигация, характеристики, теги. Маркеры — кружки.

`<ol>` (ordered) — порядок имеет значение: шаги инструкции, очередь, ранги, ПУТЬ (хлебные крошки). Нумерацию ведёт браузер автоматически: удалите второй пункт — остальные перенумеруются сами.

`<dl>` (description list) — пары «термин → описание»: глоссарий, характеристики товара, метаданные. Из двух тегов: `<dt>` (термин) и `<dd>` (описание). Один `dt` может иметь несколько `dd`.

### Вложенность
Внутри `<li>` может быть что угодно: текст, ссылки, вложенный список. Вложенный `<ul>`/`<ol>` — это список ВНУТРИ родительского `<li>`, и это обязательно, если есть иерархия («раздел → подразделы»).

NOTE: нумерация ol рисуется браузером по порядку li и НЕ хранится в разметке: удалите второй li — номера автоматически перескочат. Атрибут `start="5"` начинает нумерацию с 5, `reversed` — «обратный» отсчёт (красив для «последние новости»).

### Меню и крошки
Меню навигации — `<ul>` внутри `<nav>` (урок 5), а не «слова через запятую» и не таблица. Маркеры отключаются CSS'ом одной строкой — семантика при этом сохраняется. Хлебные крошки — `<ol>` (упорядоченный путь) с `aria-label`.

Kуда списки НЕ подходят: «лента статей» (это article/main — урок 11), «сравнение характеристик в сетке» (таблица — урок 8), «одна фраза с запятыми» (это просто текст в абзаце).

### Частые сценарии списков
Инструкция/рецепт — `ol` (порядок шагов). Меню и навигация — `ul` внутри `nav`. Хлебные крошки — `ol` (путь). Характеристики товара, глоссарий, «ключ: значение» — `dl`. Теги статьи, «что включено» — `ul`. Один и тот же макет «мелкие пункты» может быть любым списком — выбор всегда по смыслу, а не по маркеру.

TIP: перед тем как написать список, спросите: «важен порядок?» Да → ol, нет → ul, «термин=описание» → dl. Если сомневаетесь — это, скорее всего, не список, а абзацы.

## Пример
```html
<nav aria-label="Меню курса">
  <ul>
    <li><a href="#m1">Основы</a>
      <ul>
        <li><a href="#m1-1">Структура</a></li>
        <li><a href="#m1-2">Текст</a></li>
      </ul>
    </li>
    <li><a href="#m2">Контент</a></li>
    <li><a href="#m3">Формы</a></li>
  </ul>
</nav>
<h2>Как запустить страницу</h2>
<ol>
  <li>Сохраните файл как index.html.</li>
  <li>Создайте папку img и положите в неё изображения.</li>
  <li>Откройте файл двойным кликом.</li>
  <li>Проверьте валидность на validator.w3.org.</li>
</ol>
<h2>Характеристики</h2>
<dl>
  <dt>Вес</dt>
  <dd>120 грамм</dd>
  <dt>Материалы</dt>
  <dd>Алюминий</dd>
  <dd>Матовое стекло</dd>
  <dt>Гарантия</dt>
  <dd>24 месяца</dd>
</dl>
```
Обратите внимание: вложенный ul — внутри первого li; у «Материалы» два dd; ol нумерует сам. Скринридер прочитает dl как «описание: термин — значение».

## Частые ошибки
WARN: «1. 2. 3.» набраны в тексте вместо <ol> — нет перенумерации при удалении пункта, скринридер не видит «список из N».
WARN: вложенный список вынесен ВНУТРЬ li (сразу после </ul> родителя) — иерархия ломается; вложенный список — внутри родительского li.
WARN: меню из div/span — скринридер не объявляет «меню», нет клавиатурной логики; пишем nav > ul > li > a.
WARN: dl для «названия: описание», но dt и dd разбросаны по разным местам — dl это последовательность пар, не сетка.
WARN: «список» из абзацев с маркером • набранным вручную — нет семантики; используйте ul.

## Практическое задание
1. В стартовом файле соберите вложенное меню (2 уровня): nav > ul > li, вложенный ul у первого пункта.
2. Напишите пошаговую инструкцию ol (5 шагов) как открыть и проверить HTML-файл.
3. Разметьте характеристики товара dl: 4 термина, у одного — 2 описания.
4. Добавьте хлебные крошки ol с aria-label="Хлебные крошки".
5. Бонус: в DevTools → Accessibility проверьте, что списки объявляются «список, N элементов».
