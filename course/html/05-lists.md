# Урок 5. Списки: ul, ol, dl

## Цель
После урока студент сможет: выбрать правильный тип списка (unordered/ordered/description) по смыслу, встроить вложенные списки, убрать «визуальную» навигацию из вёрстки и разметить списки с текстом и ссылками.

## Теория

HTML знает ТРИ вида списков — и выбор между ними почти всегда о **смысле**, а не об wyglądании:

1. **`<ul>` (unordered)** — набор элементов, порядок НЕ имеет значения: навигация, характеристики, теги, список товаров в корзине. Маркеры — кружки.
2. **`<ol>` (ordered)** — порядок имеет значение: шаги рецепта, очередь, ранги. Нумерация автоматическая: если удалить 2-й пункт, браузер сам перенумерует остальные.
   - Атрибуты `start`, `reversed`, `type` (A., a., i., I.) — для особых случаев; чаще нумерацию переделывают CSS'ом.
3. **`<dl>` (description list)** — пары «термин → описание»: глоссарий, характеристики товара, метаданные. Из пары тегов: `<dt>` (термин) и `<dd>` (описание). Один `dt` может иметь несколько `dd`.

Внутри `<li>` может быть что угодно: текст, ссылки (список-меню — это `ul` из `a`), вложенные `ul`/`ol`, картинки, целые блоки. **Вложенные списки** — это список ВНУТРИ пункта, и они обязательны, если есть иерархия («Секция → подпункты»).

Классическая ловушка: **меню навигации — это `<ul>` внутри `<nav>`, а не «точки через запятую» и не таблица/дивы.** Маркеры и отступы отключаются одной CSS-строкой (`list-style: none`) — семантика при этом сохраняется.

Куда списки НЕ подходят: «список статей на странице» (это `article`/`main`, урок 9), «таблица характеристик» (таблица, урок 6), «шаги, где каждый шаг — крупный блок с картинкой» (тогда ol допустим, но чаще семантика слабее — спорный случай).

## Пример

```html
<!-- Навигация: ul внутри nav (из урока 3) -->
<nav aria-label="Меню курса">
  <ul>
    <li><a href="#m1">Основы</a>
      <ul>
        <li><a href="#m1-1">Структура</a></li>
        <li><a href="#m1-2">Текст</a></li>
      </ul>
    </li>
    <li><a href="#m2">Контент</a></li>
    <li><a href="#m3">Формы</a></li>
  </ul>
</nav>

<!-- Пошаговая инструкция: ol -->
<h2>Как запустить страницу</h2>
<ol>
  <li>Сохраните файл как <code>index.html</code>.</li>
  <li>Создайте папку <code>img</code> и положите в неё изображения.</li>
  <li>Откройте файл двойным кликом — браузер отрисует страницу.</li>
  <li>Проверьте валидность на <a href="https://validator.w3.org/">validator.w3.org</a>.</li>
</ol>

<!-- Свойства продукта: dl -->
<h2>Характеристики</h2>
<dl>
  <dt>Вес</dt>
  <dd>120 грамм</dd>
  <dt>Материалы</dt>
  <dd>Алюминий</dd>
  <dd>Матовое стекло</dd>
  <dt>Гарантия</dt>
  <dd>24 месяца</dd>
</dl>

<!-- Маркировка: ul со ссылками -->
<ul>
  <li><a href="https://mdn.dev/">MDN</a></li>
  <li><a href="https://validator.w3.org/">HTML Validator</a></li>
</ul>
```

## Частые ошибки новичков

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| `1. 2. 3.` набраны в тексте (а не `<ol>`) | Нет нумерации при удалении пункта, скринридер не понимает «список из N» | `<ol>` — нумерацию ведёт браузер |
| `<ol type="I">` для «красивых» заглавных, `<ul type="square">` | HTML4-настройки, в HTML5 стилистика — дело CSS | Списки — по смыслу, вид — CSS |
| Вложенный список вынесен ВНУТРЬ `</li>` наружу (не в li) | Ломается иерархия, валидатор ругается | Вложенный `<ul>`/`<ol>` — ВНУТРИ родительского `<li>` |
| Меню из `<div>`/`<span>`/«слешей» | Скринридер не объявляет «меню из N», нет клавиатурной логики | `<nav><ul><li><a>` |
| `<li>` без содержимого / пустые пункты | Валидатор ругается, скринридер читает «пусто» | Каждый li несёт смысл |
| `dl` для «названия: описание» в одной строке, но dt/dd в разных местах | dl = последовательность пар, не таблица | Если нужна сетка — таблица (урок 6) |
| Список «хлебных крошек» через запятые в `p` | Нет ссылок-структуры, a11y-паттерн breadcrumbs теряет смысл | `ol` (это упорядоченный путь) с `aria-label` |
| `<ol>` для «топов» в случайном порядке | Топ = ранг, это упорядочено — но если порядок «по популярности, изменится» — допустим ol; если «выборка без порядка» — ul | Оцените: важен порядок ИЛИ набор? |

## Практическое задание

1. Сделайте вложенное меню (2 уровня) для курса: `nav > ul > li`, вложенный `ul` у первого пункта. CSS'ом уберите маркеры, оставьте структуру.
2. Напишите пошаговую инструкцию (5 шагов) как оформить изображение с `srcset` (используя знания урока 4).
3. Разметьте характеристики товара через `dl` (4 терминa, у одного — 2 описания).
4. Проверьте валидатором и в DevTools → Accessibility: список объявляется «список, N элементов».
5. Бонус: сделайте «хлебные крошки» (`ol` + `aria-label="Хлебные крошки"`) и список тегов (`ul` со ссылками).
