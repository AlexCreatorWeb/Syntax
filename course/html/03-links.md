# Урок 3. Ссылки: от якорей до rel

## Цель
После урока студент сможет: строить внутренние и внешние ссылки, якорные переходы по странице, ссылки-кнопки и навигационные группы, понимать `rel` и `target` и не создавать «ссылку в ссылке».

## Теория

`<a>` — самый важный тег HTML: именно ссылки превращают документы в «сеть». Всё, что можно щёлкнуть, — это `<a>` (или `<button>`, о котором в уроке о формах).

**Анатомия ссылки:**
- `href` — куда ведёт. Абсолютный адрес (`https://...`), относительный (`/docs/`, `../img/cat.jpg`, `page.html`), якорный (`#section`), специальный (`mailto:`, `tel:`, `download`).
- `#id` внутри `href` — переход к элементу с таким `id` на той же странице (или к другому документу: `page.html#section`).

**Типы ссылок и `rel`:**
- Обычная ссылка внутри сайта — ничего не пишем.
- Внешний сайт — `target="_blank" rel="noopener"` (новая вкладка + страховка от `window.opener`).
- Картинка, ведущая на страницу — просто `<a>` вокруг `<img>`.
- Ссылка на саму страницу в другом формате (PDF) — `rel="preload"` не нужен; достаточно `href="doc.pdf"`.

**`<nav>`** — контейнер для основной группы ссылок (меню). У страницы может быть несколько `nav` (главное меню, навигация по статье, «доп. ссылки в футере»). Без `nav` скринридеру приходится искать ссылки наугад — с `nav` он прыгает к нему сразу.

**Ссылка — интерактивный элемент.** Внутри `<a>` не должно быть других интерактивных элементов: второй `<a>`, `<button>`, `<input>`. Это классическая невалидность («a inside a»): браузер сам «латает» дерево, вырывая внутренний тег наружу — и структура рушится.

Якорный пункт `href="#"` — «мёртвая» ссылка: прыгает в начало страницы и оставляет хэш в адресе. Для «кнопки, которая пока ничего не делает» в вёрстке это допустимо, но лучше не оставлять её в готовом продукте.

## Пример

Полный рабочий фрагмент (вставьте в body):

```html
<header>
  <nav aria-label="Главное меню">
    <a href="#features">Возможности</a>
    <a href="#pricing">Цены</a>
    <a href="#contact">Контакты</a>
    <a href="https://developer.mozilla.org/" target="_blank" rel="noopener">MDN</a>
  </nav>
</header>

<main>
  <h1 id="top">Главная</h1>

  <section id="features">
    <h2>Возможности</h2>
    <p>Смотрите <a href="#pricing">цены</a> или
       <a href="docs/report.pdf">отчёт в PDF</a>.</p>
    <a href="images/hero.jpg">
      <img src="images/hero.jpg" alt="Скриншот продукта" width="640" height="400">
    </a>
  </section>

  <section id="pricing">
    <h2>Цены</h2>
    <p><a href="mailto:hello@example.com">Написать нам</a> или
       <a href="tel:+79991234567">позвонить</a>.</p>
  </section>

  <section id="contact">
    <h2>Контакты</h2>
    <p><a href="#top">Наверх ↑</a></p>
  </section>
</main>
```

Разбор:
- `width`/`height` на `img` внутри ссылки — резервируют место до загрузки картинки, страница не «прыгает» (CLS — метрика Core Web Vitals).
- `aria-label="Главное меню"` — имя для скринридера; в уроке 11 разберём, когда оно нужно.
- `<a href="docs/report.pdf">` — ссылка на файл: браузер скачает/откроет PDF, не уходя с сайта.

## Частые ошибки новичков

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| `<a href="https://site.ru/"><img ...></a>` без `alt` у картинки | Ссылка-картинка без имени — скринридер скажет «картинка» | `alt` = смысл ссылки: `alt="Купить билет"` |
| `target="_blank"` без `rel="noopener"` | Старые браузеры: новая страница видит `window.opener` и может перехватить | Всегда пара: `target="_blank" rel="noopener"` |
| Ссылка в ссылке (`<a><a>`) | Не валидно, парсер «вырывает» тег | Внешнюю ссылку даём отдельным элементом |
| `href="#"` повсюду «пока не знаю куда» | Клик = прыжок вверх, хэш-мусор в URL | Честный `a` только с реальным `href`; «кнопку» без действия делаем `button` (урок 7) |
| Относительные пути наугуд: `img/cat.jpg`, `../cat.jpg` | Сломанные картинки при переносе сайта | Считаем уровни от ТЕКУЩЕГО файла; лучше абсолютные от корня `/img/cat.jpg` |
| Якорь без `id` или `id` без якоря | Переход «в никуда» | `href="#x"` обязан иметь `<... id="x">` |
| Весь абзац обёрнут в `<a>` ради одной ссылки | Огромная нечитаемая «кликабельность», потеря структуры | Ссылка — только на слово/фразу/картинку |
| Кнопка в меню сделана через `<div onclick>` | Нет клавиатурного фокуса, нет срабатывания на Enter | `<a>` или `<button>` |

## Практическое задание

1. В странице курса сделайте меню из 4 пунктов: 3 якорных (на секции страницы) + 1 внешняя (`target="_blank" rel="noopener"`).
2. Добавьте: ссылку-картинку (какую угодно картинку → MDN), `mailto:`-ссылку, «Наверх ↑» (якорь на `<h1 id="top">`).
3. Оберните меню в `<nav>` с `aria-label`.
4. Проверьте: клики по якорям работают, в адресе появляется `#...`; валидатор — 0 ошибок; Tab по странице — фокус проходит по всем ссылкам по порядку.
5. Бонус: откройте сайт в DevTools и найдите в его HTML все `rel=` — объясните вслух, что делают найденные значения.
