# Урок 6. Таблицы и их доступность

## Цель
После урока студент сможет: разметить табличные данные со всеми обязательными частями (`caption`, `thead`, `th` с `scope`), правильно выбрать «головные» ячейки для сложных схем и понять, когда таблицу НЕ нужно использовать.

## Теория

**Таблица — это ДАННЫЕ, а не вёрстка.** Таблица в HTML описывает структуру информации: строки × столбцы, где каждая ячейка относится к заголовку своего ряда/колонки. Вёрстка сеток (карточки товаров, колонки страницы) — задача CSS Grid/Flexbox; «табличка-конструктор» 2005 года — антипаттерн, который ломает семантику и доступность.

Критерий: если данные можно выразить как «столбец X по строкам Y» — это таблица. Если «карточка из 3 колонок» — это не таблица.

**Анатомия валидной таблицы:**
- `<table>` — контейнер.
- `<caption>` — заголовок таблицы (первый дочерний элемент). Виден (обычно сверху), скринридер объявляет его как «имя» таблицы. Для данных почти всегда обязателен.
- `<colgroup>` + `<col>` — стилизация/атрибуты СТОЛБЦОВ (редко нужен; для `span`-групп).
- `<thead>` — строки заголовков. `<tbody>` — тело. `<tfoot>` — итоги/итоги внизу.
- `<th>` — ячейка-заголовок (жирная, центр). Ключевой атрибут — `scope`:
  - `scope="col"` (значение по умолчанию для th в thead) — «я заголовок СТОЛБЦА».
  - `scope="row"` — «я заголовок СТРОКИ» (левая колонка с названиями показателей).
  - `scope="rowgroup"` / `colgroup` — для заголовков групп (сложные схемы).
- `<td>` — обычная ячейка данных.

Зачем `scope`? Скринридер в режиме «навигация по таблице» при фокусе на ячейке данных скажет: «45, строка 3, колонка 2: **Выручка**» — берёт имя из связанного `th` по scope. Без `scope` (или при «заголовках-td») — «колонка 2» без имени.

**Сложные схемы:**
- Объединение ячеек: `colspan` (по горизонтали), `rowspan` (по вертикали).
- Когда у ячейки данных «несколько» заголовков (двухуровневая шапка), `scope` не работает — связываем вручную: `id` на `th` + `headers="id1 id2"` на `td`.
- Сводные таблицы (pivot) — частая боль a11y: иногда честнее дать ДВЕ простые таблицы, чем одну со `headers`-архитектурой.

## Пример

**1. Простая таблица (столбцовые заголовки):**

```html
<table>
  <caption>Выручка по кварталам, млн ₽</caption>
  <thead>
    <tr>
      <th scope="col">Квартал</th>
      <th scope="col">2024</th>
      <th scope="col">2025</th>
      <th scope="col">Изменение</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Q1</th>
      <td>120</td>
      <td>145</td>
      <td>+20,8%</td>
    </tr>
    <tr>
      <th scope="row">Q2</th>
      <td>132</td>
      <td>158</td>
      <td>+19,7%</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Итого</th>
      <td>252</td>
      <td>303</td>
      <td>+20,2%</td>
    </tr>
  </tfoot>
</table>
```

Здесь левая колонка («Q1», «Итого») — тоже заголовки строк: `th scope="row"`. Итого в `tfoot` — браузер может выводить его НАВЕРХ (зависит от CSS), это норма.

**2. Двухуровневая шапка (связка через `headers`):**

```html
<table>
  <caption>Продажи магазинов по месяцам</caption>
  <thead>
    <tr>
      <th scope="col" rowspan="2">Магазин</th>
      <th scope="colgroup" colspan="2">2024</th>
      <th scope="colgroup" colspan="2">2025</th>
    </tr>
    <tr>
      <th scope="col" id="jan24">Янв</th>
      <th scope="col" id="feb24">Фев</th>
      <th scope="col" id="jan25">Янв</th>
      <th scope="col" id="feb25">Фев</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Центральный</th>
      <td headers="jan24">40</td>
      <td headers="feb24">42</td>
      <td headers="jan25">51</td>
      <td headers="feb25">55</td>
    </tr>
  </tbody>
</table>
```

## Частые ошибки новичков

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| Таблица для вёрстки страницы (3 колонки-карточки) | Скринридер читает «таблица 3 колонки» для контента, который не данные; при переносе на мобильный вёрстка рвётся | Сетки/карточки — CSS Grid/Flexbox |
| Заголовки сделаны `<td>` (жирные через CSS) | У ячеек данных нет «имени столбца» для a11y | `<th scope="col">` |
| Нет `caption` | Таблица без имени: «таблица из 4 колонок, без темы» | `<caption>` — первый элемент table |
| `th` без `scope` в body (левая колонка) | Скринридер не знает, что это заголовок строки | `scope="row"` |
| `border="1"` — атрибуты HTML4 | Мёртвый в HTML5 | Границы — CSS |
| Пустые ячейки без `&nbsp;`/текста | Клетки «пропадают» из навигации | Пустая ячейка данных = `<td></td>` (валидно), но подумайте о смысле |
| Две «независимые» таблицы в одном `<table>` (с пустой строкой между) | Одна логическая таблица = одни заголовки | Разделите на два `<table>` с разными `caption` |
| Сложная схема с rowspan/colspan без headers | a11y-навигация «теряет» имена | `headers`-связки или упростить до двух таблиц |
| Таблица с одной колонкой данных и одной заголовков, но без thead | Валидно, но thead/tbody — явная структура | Всегда пишем thead/tbody явно |

## Практическое задание

1. Разметите таблицу «Расписание занятий» (дAYS × периоды): `caption`, `thead` с `th scope="col"`, `tbody`, левая колонка дней — `th scope="row"`, итоговая строка в `tfoot`.
2. Сделайте двухуровневую шапку (как в примере 2) для «Продажи по филиалам и месяцам» и провяжите ячейки через `headers`.
3. Проверьте валидатором. Бонус a11y: включите скринридер (NVDA/VoiceOver) или DevTools → Accessibility, фокусируйтесь на ячейках — скринридер называет столбец и строку.
4. Найдите на любом сайте таблицу, «сделанную через дивы» (сетка карточек, стилизованная как таблица) — переделайте её в настоящий `<table>` или честно признайте, что это НЕ таблица.
5. Бонус: попробуйте `colgroup` с `span` для подсветки группы столбцов.
