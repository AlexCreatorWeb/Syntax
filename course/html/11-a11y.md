# Урок 11. a11y: ARIA, клавиатура, чек-лист

## Цель
После урока студент сможет: объяснить «первое правило ARIA», добавить необходимые `aria-*` атрибуты (label, labelledby, live, hidden), проверить страницу с клавиатуры и по чек-листу WCAG 2.2.

## Теория

**Доступность (accessibility, a11y)** — страница работает для ВСЕХ: со скринридером (не видит экран), с клавиатуры (нет мыши), при слабом контрасте (слабое зрение), на маленьком экране, без JS. HTML-семантика (урок 9) — **бесплатная** a11y: landmarks, заголовки, таблицы, формы — уже «читаются» скринридером. ARIA — **дополнение** для случаев, где семантики не хватает.

**Первое правило ARIA: «Не используй ARIA, если есть нативный элемент».**
- `<button>` лучше `<div role="button">`.
- `<nav>` лучше `<div role="navigation">`.
- `<label for>` лучше `<input aria-label="...">`.
- `details/summary` (урок 12) лучше `<div onclick>` + `aria-expanded`.

Когда ARIA НУЖНА:
- **`aria-label`** — имя для элемента БЕЗ видимой подписи: иконка-кнопка (иконка «поиск»), `nav` без видимого «Меню».
- **`aria-labelledby`** — имя = текст СУЩЕСТВУЮЩЕГО элемента (id на заголовке): `<section aria-labelledby="features-h">`.
- **`aria-hidden="true"`** — «скрой от скринридера»: декоративные иконки, дублирующий текст.
- **`aria-live`** — «объяви изменения»: `polite` (ожидает паузу), `assertive` (сразу), `role="status"` (готовый «polite»). Для уведомлений, счётчиков, «сохранено».
- **`aria-expanded`** — «развёрнуто/свёрнуто»: для бургера, аккордеона. `true`/`false`.
- **`aria-current`** — «текущий»: `page` (активная вкладка), `step`, `location`.
- **`role`** — «переименование» элемента: `role="search"`, `role="tab"`, `role="alertdialog"`. Только если нативного тега нет.

**Клавиатура — «первый пользователь».** Чек:
1. `Tab` / `Shift+Tab` — цикл по интерактивным элементам. Фокус ВИДИМ (не `outline: none` без замены).
2. `Enter`/`Space` — активирует (у `a` — Enter, у `button` — Enter+Space, у `input` — Enter).
3. `Esc` — закрывает модалку/меню.
4. Фокус НЕ «застревает» в скрытых элементах (`display:none` — не фокусируется; `visibility:hidden` — тоже).
5. Ловушки: `<div onclick>` без `tabindex`/`role` — не фокусируется (недоступно).

**Контраст (WCAG 2.2, уровень AA):**
- Текст ≥ 18.66px (или 24px bold) — контраст ≥ 4.5:1.
- Текст ≥ 24px (или 32px bold) — ≥ 3:1.
- Инструменты: DevTools → Lighthouse, WebAIM Contrast Checker.

**Чек-лист страницы (выжимка WCAG 2.2):**
1. `html lang` — есть (урок 1).
2. Один `h1`, иерархия h1→h2→h3 (урок 2, 9).
3. У каждого `img` — осмысленный `alt` / `alt=""` для декора (урок 4).
4. У `iframe` — `title` (урок 10).
5. У каждого `input` — `label` (урок 7). Радио-группа — `fieldset`+`legend`.
6. У ссылок — различимый текст (не «кликните здесь» без контекста).
7. Контраст текста ≥ 4.5:1.
8. Фокус видим, Tab-порядок логичен.
9. Кнопки/ссылки — достаточный размер (≥ 24×24px, WCAG 2.2 Target Size).
10. `:focus-visible` не отключён «насовсем».
11. Медиа — `poster`, `controls`, `track` (урок 10).
12. `aria-live` для динамических изменений (если есть JS).
13. Нет «вспышек» > 3 раз/сек (эпилепсия).
14. Зум 200% без потери контента (responsive + вёрстка без фиксированных px на всём).

**Скринридеры:** NVDA (Windows, бесплатно), JAWS (платный), VoiceOver (macOS/iOS), TalkBack (Android). Тест: включите и «прочитайте» свою страницу.

## Пример

```html
<!-- 1. Иконка-кнопка: нет видимой подписи → aria-label -->
<button type="button" aria-label="Поиск">
  <svg width="20" height="20" aria-hidden="true">…</svg>
</button>

<!-- 2. Декоративная иконка: скрыта от скринридера -->
<p>Отлично! <span aria-hidden="true">✔</span></p>

<!-- 3. Секция с именем из заголовка -->
<section aria-labelledby="faq-h">
  <h2 id="faq-h">Вопросы и ответы</h2>
  …
</section>

<!-- 4. Уведомление: aria-live -->
<p id="save-status" role="status" aria-live="polite"></p>
<!-- JS: saveStatus.textContent = "Сохранено ✓" -->

<!-- 5. Бургер-меню: aria-expanded -->
<button type="button" aria-expanded="false" aria-controls="mobile-menu">
  Меню
</button>
<nav id="mobile-menu" hidden> … </nav>

<!-- 6. Текущая страница в меню -->
<nav aria-label="Разделы">
  <a href="/" aria-current="page">Главная</a>
  <a href="/blog">Блог</a>
  <a href="/about">О нас</a>
</nav>

<!-- 7. Таблица: th scope (урок 6) — a11y уже в разметке -->
<table>
  <caption>Сравнение тарифов</caption>
  <thead>
    <tr>
      <th scope="col">Тариф</th>
      <th scope="col">Цена</th>
      <th scope="col">Фичи</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Базовый</th>
      <td>0 ₽</td>
      <td>1 проект</td>
    </tr>
  </tbody>
</table>
```

## Частые ошибки новичков

| Ошибка | Почему плохо | Как правильно |
|---|---|---|
| `outline: none` на `:focus` без замены | Фокус «невидим» — клавиатурный пользователь «слеп» | `:focus-visible` с видимым стилем |
| `role="button"` на `<div>` | Нарушение «первого правила ARIA» | `<button>` |
| `aria-label` на элемент с видимым текстом | Дублирование: скринридер читает дважды | `aria-label` — только БЕЗ видимой подписи |
| `aria-hidden="true"` на элемент с фокусируемым потомком | Скрыт, но Tab-фокус «застревает» | Скрытое — без `tabindex`/`a`/`button` внутри |
| «Кликните здесь» / «Подробнее» без контекста | Скринридер: «ссылка, кликните здесь» — куда? | Текст ссылки = цель: «Скачать отчёт (PDF)» |
| Контраст 3:1 для «маленького» текста | Ниже WCAG AA (4.5:1) | Проверить WebAIM Contrast Checker |
| Модалка без «ловушки фокуса» и Esc | Фокус «уходит» за модалку, Esc не закрывает | JS: trap focus, Esc, вернуть фокус на триггер |
| `aria-live="assertive"` на «Сохранено» | «Прыжок» озвучки каждый раз | `polite`/`role="status"` |
| Иконка `img` с `alt="иконка"` | Мусор в озвучке | `alt=""` (декор) или `aria-hidden` на svg |
| `display:none` + `tabindex="0"` | Элемент невидим, но Tab-фокусируется | `hidden` или `inert` (новый атрибут) |

## Практическое задание

1. Возьмите страницу курса. Проверьте по чек-листу (14 пунктов): найдите 3+ проблемы и исправьте.
2. Пройдите страницу ТОЛЬКО клавиатурой (Tab/Shift+Tab/Enter/Space/Esc). Запишите: где фокус «застрял», где «перескочил» логически.
3. Добавьте `aria-label` на 2 иконки-кнопки, `aria-hidden` на 3 декоративных svg, `role="status"` на «Сохранено» (с мини-JS: `setTimeout` меняет textContent).
4. Включите скринридер (NVDA/VoiceOver) и «прочитайте» страницу: landmarks, заголовки, таблицы, формы объявлены?
5. Бонус: проверьте контраст 2 текстов (WebAIM Contrast Checker) и исправьте через CSS (токены темы).
