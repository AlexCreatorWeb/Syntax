# Курс «HTML5 с нуля» — дорожная карта

Целевая аудитория: новичок без опыта вёрстки. Результат: студент умеет собирать валидные, семантические, доступные страницы на современном HTML5.

Источники: MDN Web Docs (HTML Reference, Accessibility), HTML Living Standard (WHATWG), WCAG 2.2.

## Структура

| Модуль | Урок | Тема |
|---|---|---|
| M1. Основа | 01 | Структура HTML-документа |
| M1. Основа | 02 | Текст и заголовки |
| M2. Контент и навигация | 03 | Ссылки: от якорей до rel |
| M2. Контент и навигация | 04 | Изображения: img, srcset, picture |
| M2. Контент и навигация | 05 | Списки: ul, ol, dl |
| M3. Данные и ввод | 06 | Таблицы и их доступность |
| M3. Данные и ввод | 07 | Формы I: каркас и типы input |
| M3. Данные и ввод | 08 | Формы II: валидация и спецэлементы |
| M4. Семантика | 09 | Семантическая структура страницы |
| M4. Семантика | 10 | Медиа: video, audio, iframe |
| M5. Доступность | 11 | a11y: ARIA, клавиатура, чек-лист |
| M6. Практика | 12 | Современные элементы: dialog, details, time и др. |
| M6. Практика | 13 | Финальный проект: семантическая страница |

## Логика цепочки
1 → 2: нет документа — нет текста. 2 → 3: ссылками связываем созданный текст. 3 → 4: картинки часто являются ссылками/якорями. 4 → 5: медиа и списки — «атомы» контента. 5 → 6: списки → табличные данные. 6 → 7: данные → ввод данных. 7 → 8: поля → валидация полей. 8 → 9: все «атомы» упаковываются в landmarks. 9 → 10: в семантическую страницу встраивается медиа. 10 → 11: готовая страница делается доступной. 11 → 12: доступная страница пополняется новыми элементами. 12 → 13: всё вместе — финальный проект.

## Шаблон урока
1. Название + цель («после урока студент сможет…»)

4. Частые ошибки новичков
