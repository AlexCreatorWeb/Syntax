# Курс «HTML5 с нуля» — дорожная карта (16 уроков)

Целевая аудитория: новичок без опыта вёрстки. Результат: студент умеет собирать валидные, семантические, доступные страницы на современном HTML5 (чистый HTML — без CSS/JS-тем).

Источники: MDN Web Docs (HTML Reference, Accessibility), HTML Living Standard (WHATWG), WCAG 2.2.

## Логика цепочки
1 → 2: нет валидного head — нет гарантий кодировки. 2 → 3: корректные символы → текст. 3 → 4: ссылками связываем созданный текст. 4 → 5: ссылки → навигация сайта (мультистраничность, вкладки). 5 → 6: картинки — атомы контента (чаще внутри ссылок). 6 → 7: списки. 7 → 8: списки → табличные данные. 8 → 9: данные → ввод данных. 9 → 10: поля → валидация. 10 → 11: все атомы упаковываются в landmarks. 11 → 12: в страницу встраивается медиа. 12 → 13: готовая страница делается доступной. 13 → 14: доступная страница «узнаётся» поиском и мессенджерами (head). 14 → 15: пополнение новыми элементами. 15 → 16: всё вместе — финальный проект.

## Контракт строки БД (таблица lessons)
- tech: 'html' (строчные).
- title: 3–6 слов, без нумерации (номер фронт выдаёт по порядку id).
- content: markdown-lite. Структура ОБЯЗАТЕЛЬНА: `## Цель` (1 абзац) → `## Теория` (2–5 абзацев, `###` подтемы, минимум 1 `TIP:`) → `## Пример` (рабочий ```html-блок + разбор) → `## Частые ошибки` (3–5 `WARN:`-пунктов) → `## Практическое задание` (нумерованный список). Минимум 1 `TIP:` и 1 `WARN:` на урок.
- Форматирование: **жирный**, *курсив*, `инлайн-код`, ```html-блоки, ##/###. Таблиц и [ссылок](url) НЕТ — URL текстом. Callout'ы в начале строки: `TIP:` / `NOTE:` / `WARN:` (текст callout'а — без ** и `).
- code: стартовый код ЗАДАНИЯ (не решение) — валидный, запускаемый скелет с `<!-- TODO -->`; хранится в `code/NN.html`.
- Объём content: 4–7 КБ. Язык — русский.
- Порядок = порядок вставки (id): от простого к сложному, последний — «Финальный проект».

## Пересид
Сидер: `seed-html-course.mjs` (из корня репо: `node seed-html-course.mjs`). Читает `01..16-*.md` + `code/01..16.html`, конвертит md в markdown-lite (убирает `# Заголовок`), удаляет ВСЕ строки tech='html' и вставляет 16 с упорядоченными id. После любой доработки урока — повторный запуск.
