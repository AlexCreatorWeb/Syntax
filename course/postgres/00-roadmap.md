# Курс «PostgreSQL с нуля» — 20 уроков (roadmap + контракт)

Цепочка: RDBMS и psql → типы → DDL/ограничения → ALTER/ENUM/schemas → INSERT/upsert → WHERE/NULL → сортировка/пагинация → агрегаты → связи/ключи → JOIN → подзапросы/CTE/LATERAL → оконные функции → транзакции → конкурентность/локи → индексы → EXPLAIN → JSONB → views → PL/pgSQL → финальный проект.

## Контракт урока (жёсткий, QC сидера падает при нарушении)
1. 5 разделов строго: `## Цель`, `## Теория`, `## Пример`, `## Частые ошибки`, `## Практическое задание`.
2. Минимум 1 `TIP:` или `NOTE:` И минимум 1 `WARN:` (ошибки оформляются WARN-пунктами).
3. Callout-строки — plain text: внутри TIP/NOTE/WARN никаких `**` и backtick'ов.
4. Без таблиц, без markdown-ссылок `[t](url)`.
5. Объём content (после mdToLite) 4000–7000 зн.
6. В «Пример» — блок ```sql (рабочий PostgreSQL-диалект).
7. `code/NN.sql` = скелет ЗАДАНИЯ с `-- TODO` (не решение!), запускаемый в psql.
8. В прозе без `**bold**` (только заголовки) — избегаем артефактов рендера.
9. Примеры должны работать в чистой БД (создают свой schema/data внутри или описывают в комментарии, на что опираются).

## Спринты (связи между уроками)
- 1–4: фундамент (psql, типы, DDL, структура).
- 5–8: DML + SELECT (вставка, фильтрация, пагинация, агрегаты).
- 9–11: реляционная модель (связи, JOIN, подзапросы).
- 12–14: продвинутое SQL + ACID вглубь (окна, транзакции, локи).
- 15–18: производительность и прод (индексы, EXPLAIN, JSONB, views).
- 19–20: PL/pgSQL и финальный проект (e-commerce).
