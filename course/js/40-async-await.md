## Теория
### async «и** await: ««синтаксический** ««сахар** «над** «Promise**
**async** «—» ««маркер** ««функции**, «которая** ««возвращает** «Promise** (««автоматически**: ««значение** «return** ««обёрнуто** «в** «resolved Promise**).
**await** «—» ««ожидать** «Promise** ««пока** ««не** ««определится** «(«развернуть** ««значение** «(успех**) «или** ««бросить** «ошибка** «(reject**). «Работает** «только** «в** «async** «(функции** «(и** ««топ-уровень** «в** «модулах** «(«браузер** «без** «модулей** «—» «нет** ««топ-уровень** await**.

```js
async function loadUser(id) {
  const res = await fetch(`/api/users/${id}`);
  const user = await res.json();
  return user; // ««автоматически** «Promise
}
```
««Сравнивать** «с** «then-цепочкой** «(урок** 39**): ««те же** ««шаги**, «но** ««линейно** («как** «синхронный** «код** «с** ««паузами**). «Ошибки** — «try/catch** «(«классически** «(урок** 28**).

### «Последовательность** «и** ««параллель**
««Один** «за** «другим** «(«зависимые** ««данные**):
```js
async function load() {
  const user = await fetchUser(1); // ««сначала**
  const posts = await fetchPosts(user.id); // ««потом** («нужен** «user.id**)
  return { user, posts };
}
```
««Параллельно** «(«не** ««зависят** «друг** «от** «друга** — ««сэкономить** ««время**):
```js
async function load() {
  const [user, posts] = await Promise.all([fetchUser(1), fetchPosts(1)]);
  return { user, posts };
}
```
«Promise.all** «+** «await** «—» ««классика** ««параллельного** ««запроса** («общий** ««время** «—» ««самый** ««долгий** «запрос** «(не «сумма**).

### «Ошибки**: try/catch «на** await
```js
async function load() {
  try {
    const res = await fetch("/api");
    if (!res.ok) throw new Error(`HTTP ${res.status}`);
    return await res.json();
  } catch (err) {
    console.error("«сбой**:", err.message);
    throw err; // ««перекинуть** ««верх** «или** ««обработать**
  } finally {
    hideLoading();
  }
}
```
«Каждый** «await** «может** ««бросить** («reject** «Promise**) — ««ловите** «try/catch** «(«урок** 28** ««в** ««асинхронном** «виде**).

### «Где** «нельзя** «await** «(топ-уровень** «в** «браузере**
«В** «браузере** «(обычный** «скрипт** «(без** «модулей** «type="module"**) «—» ««нет** ««топ-уровень** await** («await** «только** «в** «async** «функции**). «Обёртка**: (async () => { /* «await** «здесь** */ })(); «(IIFE** «(урок** 14**). «В** «редакторе** Syntax: «ваш** «JS** «выполняется** «как** ««обычный** «скрипт** «(нет** «модулей**) — «используйте** «IIFE** «или** «async-функцию** «для** ««топ-уровень** await**.

TIP: ««преference**: async/await «для** ««секвенций** «(«линейно**, «try/catch** ««честно**). «then-цепочки** «—» ««остаются** ««важными** «для** ««цепей** «без** ««ошибок** «(«коротко**) «и** ««понимания** ««внутреннего** ««работы**. ««Смешивать** «—» ««нормально** («Promise.all «с** «await** «—» ««стандарт**).

NOTE: await ««останавливает** ««только** «async-функцию** («не** ««поток** «(main thread) — ««остальные** ««код** ««выполняется** «(event loop** «(урок** 38**). ««Пока** «await** ««ждёт** «(Promise** ««не** ««определён**), «функция** ««высвобождает** ««поток** «(««не** ««блокирует** ««страницу**).

## Пример
```js
// «Имитация** «API**:
const fakeApi = (data, ms, fail = false) =>
  new Promise((resolve, reject) =>
    setTimeout(() => (fail ? reject(new Error("«сбой** API")) : resolve(data)), ms)
  );

// ««Последовательность**:
async function loadSeq() {
  const user = await fakeApi({ id: 1, name: "A" }, 200);
  const posts = await fakeApi(["p1", "p2"], 200);
  console.log("«секв**:", user.name, posts.length); // ~400ms
  return { user, posts };
}

// ««Параллельно**:
async function loadPar() {
  const [user, posts] = await Promise.all([
    fakeApi({ id: 1, name: "A" }, 300),
    fakeApi(["p1", "p2"], 100),
  ]);
  console.log("«пар**:", user.name, posts.length); // ~300ms «(«самый** ««долгий**)
  return { user, posts };
}

// «Ошибки**:
async function loadFail() {
  try {
    const data = await fakeApi(null, 100, true);
  } catch (err) {
    console.error("«поймали**:", err.message); // "«сбой** API"
  } finally {
    console.log("«всё равно**");
  }
}

// «Запуск** «(«обычный** «скрипт** «—» «без** ««топ-уровень** await** «(IIFE** «или** «then**):
loadSeq().then(() => console.log("«секв** ««готово**"));
loadPar().then(() => console.log("«пар** ««готово**"));
loadFail();
```
Разбор: «async/await** «—» ««линейный** «асинхронный** «код**, «try/catch** «для** «ошибок**, Promise.all «—» ««параллельно** (««быстрее** «чем** ««секвенция**).

## Частые ошибки
WARN: await «вне** «async** «(обычная** «функция** «/» ««топ-уровень** «скрипт** «в** «браузере**) — «SyntaxError**; «async** «обёртка** «или** «IIFE**.
WARN: ««последовательные** «await** «для** ««независимых** ««запросов** (««сумма** ««времени**) — ««потеря** ««времени**; «Promise.all «(««параллельно**, ««самый** ««долгий** «запрос** «определяет** ««время**).
WARN: «забыли** «return «из** «async** «(««значения** ««потеряны** «для** ««цепочки**); «return** ««обёрнется** «в** «Promise** «(««автоматически**).
WARN: await «на** ««не** «Promise** («число**, ««объект** «(«сразу** ««разворачивается** «(без** ««паузы**)) — ««работает**, «но** ««обманчиво** «(«выглядит** ««асинхронно** «(на** ««самом** ««деле** «синхронно**).
