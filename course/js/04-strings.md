# Урок 4. Строки и template literals

## Цель
После урока студент сможет: выбрать кавычки (', ", `) под задачу; собрать строку через template literals с выражениями; использовать основные string-методы (slice, split, replace, trim, toUpperCase) и не перепутать «индексацию» с «субстроингом».

## Теория
### Кавычки: три способа
- **'одинарные'** и **"двойные"** — «одинаковые» для JS (выберите ОДИН стиль в проекте — и держитесь);
- **`template literals`** (обратные кавычки) — «шаблонные» строки:
  - **${выражение}** — «вставка» любого выражения: `Привет, ${name}! Уровень: ${level * 2}`;
  - **многострочность** — переносы строк «как есть» (без \n);
  - «экранирование»: \` — «обратная кавычка», \${ — «буквальный» $.

Правило: если в строке «есть» переменные/выражения — template literals; если «нет» — обычные кавычки (короче).

### Индексация и длина
Строка — «последовательность» символов (с 0): "hello"[0] → "h", .length → 5. Отрицательные индексы «не работают» (undefined) — «с конца» через slice(-n). Unicode-сюрприз: эмодзи — «несколько» кодов: "👍".length → 2 (для «человеческого» счёта символов — [...str].length).

### Основные методы (все «возвращают» НОВУЮ строку — строки неизменяемы)
- **s.slice(a, b)** — «кусочек» [a, b) (b не включая); **s.slice(-3)** — «последние» 3;
- **s.split("sep")** — «в массив» (разделитель): "a,b,c".split(",") → ["a","b","c"];
- **s.replace(паттерн, замена)** — «первое» вхождение (без г — только первое; для «всех» — replaceAll или regex /g);
- **s.trim()** — «обрезает» пробелы по краям; **trimStart/trimEnd** — «по одному»;
- **s.toUpperCase() / toLowerCase()** — «регистр»;
- **s.includes("x")** — true/false; **s.startsWith("x") / s.endsWith("x")** — «края»;
- **s.repeat(n)** — "ab".repeat(3) → "ababab"; **s.padStart(5, "0")** — "7" → "00007".

**Иммутабельность**: const s = "hi"; s.toUpperCase() «не меняет» s (строки «закрытые»): «новая» строка «возвращается». s[0] = "H" — «молча» не сработает (в strict — TypeError).

TIP: «собираете» строку в цикле (+= в loop) — «медленно» (каждый раз «новая» строка + «копирование»). Для «больших» сборок — массив + .join(""): parts.push(...); parts.join(","). Для «коротких» — template literals «прямо» в шаблоне.

NOTE: `\n` — «перенос» (в обычных кавычках), `\t` — «табуляция». В HTML-выводе \n «не видно» (урок 31: white-space: pre-line). В template literals «настоящие» переносы — «как написали».

## Пример
```js
const name = "Syntax";
const level = 3;

// Template literals:
console.log(`Привет, ${name}! Уровень: ${level * 2}`);

const template = `
Имя: ${name}
Уровень: ${level}
Статус: ${level > 2 ? "профи" : "новичок"}
`;
console.log(template); // многострочный «как есть»

// Методы:
const s = "  JavaScript ES6  ";
console.log(s.trim().length);           // 14
console.log(s.slice(2, 12));            // "JavaScript"
console.log("a,b,c".split(","));        // ["a", "b", "c"]
console.log("price: 100".replace("100", "200")); // "price: 200" (первое)
console.log("7".padStart(5, "0"));      // "00007"
console.log("ab".repeat(3));            // "ababab"
console.log("Hello".toLowerCase().startsWith("he")); // true

// «Сборка» в цикле:
const items = ["js", "css", "html"];
console.log(items.join(" + "));         // "js + css + html"
```
Разбор: template literals — «главный» инструмент (выражения в ${}). Методы «не меняют» исходную (возвращают «новые»). split/join — «пара»: «разобрать» и «собрать».

## Частые ошибки
WARN: «собираете» строку через += в цикле «тысячи» раз — «медленно» (каждый раз «копирование»); массив + .join() — «в разы» быстрее.
WARN: s.replace("a", "b") «ждёте» «все» замены — «заменит» только ПЕРВОЕ (без /g); для «всех» — s.replaceAll("a", "b") (или regex).
WARN: «индексы» со знаком: s[-1] — undefined (не «последний»); «с конца» — s.slice(-1).
WARN: «сравниваете» строки «по-числовому»: "10" > "9" → true (лексикографически, "1" < "9"); «сравнивайте» после Number() (урок 6).
WARN: length «считает» эмодзи как 2 — "👍👍".length → 4; для «человеческого» счёта — [...s].length (spread по кодам).
