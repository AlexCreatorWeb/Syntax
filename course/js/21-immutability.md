# Урок 21. Иммутабельность и копирование массива

## Цель
После урока студент сможет: отличать «копию** «от** «ссылки** (примитивы «копируются** «по** «значению», объекты/массивы — «по** «ссылке»); «копировать** «поверхностно** ([...], slice, { ...}) «и** «глубоко** (structuredClone); «изменять** «один** «элемент** «без** «mutations** «оригинала**.

## Теория
### «По** «значению** «vs** «по** «ссылке**
**Примитивы** (number, string, boolean, null, undefined, symbol, bigint) — «копируются** «по** «значению**: let a = 5; let b = a; b = 6; — a «остался** 5.

**Объекты** (массивы, «обычные** «объекты», «функции») — «передаются** «по** «ссылке**: const b = a; b.push(4) — a «тоже» [.., 4] (b «и** a — «один** «объект** «в** «памяти»).

«Следствия**:
- «аргументы** «функции**: примитивы — «копии» («изменение** «внутри** «не** «влияет»), «объекты** — «ссылки** («изменение** «свойств** «внутри** «влияет** «на** «оригинал»;
- «возврат**: «объект** «возвращается** «ссылкой** («изменение** «внешнее** «влияет** «на** ««возвращённый»).

### «Поверхностная** «копия**
**Массив**: const copy = [...orig] «или** orig.slice() — «новый** «массив**, «но** «элементы** — «те же** «ссылки**:
```js
const a = [{ x: 1 }];
const b = [...a];      // «новый** «массив»
b[0].x = 99;           // «мутируем** «вложенный** «объект**
console.log(a[0].x);   // 99 («оригинал** «тоже» «изменён»!)
b.push({ y: 2 });      // «добавили** «в** b
console.log(a.length); // 1 («оригинал** «не** «тронут** «по** «длине»)
```
**Объект**: const copy = { ...orig } — «то же**: «новый** «объект**, «свойства** — «ссылки**. «Вложенные** «объекты** «— «общие**.

«Замена** «элемента** (не «мутация»): const b = [...a]; b[0] = { x: 2 }; — a «не** «изменён** («b[0] — «новая** «ссылка»).

### «Глубокая** «копия**
**structuredClone(obj)** — «полная** «копия** («все** «вложенные** «объекты** «новые»). «Работает** «с** «массивами/объектами/Date/Map/Set/RegExp». «Не** «работает** «с** «функциями/DOM» (они «не** «клонируемы»).

«Когда** «что**:
- «изменить** «один** «элемент/свойство** «в** «копии** → «поверхностная** ([...], { ...});
- «изменить** «вложенные** «глубоко** → structuredClone;
- «просто** «передать** «в** «функцию** «и** «бояться** «мутации** → «зависит** (если «функция** «мутирует** «вложенные** — «глубокая).

### «Иммутабельный** «стиль** (паттерн)
«Модерн** «практика**: «состояние** ««не** «мутируем», «создаём** «НОВОЕ** «значение**:
```js
const users = [{ id: 1, name: "a" }];
const updated = users.map((u) => (u.id === 1 ? { ...u, name: "A" } : u));
```
«Почему**: «предсказуемость** (где «изменилось** «видно** «по** «ссылке»), «отладка** («старое** «состояние** «цело»), «основа** «фреймворков** (React «сравнивает** «ссылки»).

TIP: «быстрая** «проверка** ««копия** «или** «ссылка**: const b = a; b === a → true = «ссылка» («один** «объект**). «Для** «поверхностной**: b === a → false, «но** b[0] === a[0] → true («вложенные** «общие»).

NOTE: Object.assign({}, a, b) — «как** { ...a, ...b } (поверхностное «объединение**, «позднее** «перебивает**). «Для** «глубины**: Object.assign «не** «помогает** (тоже «поверхностно**); structuredClone.

## Пример
```js
// «Ссылка** vs «копия» (примитивы):
let a = 5, b = a; b = 6;
console.log(a); // 5 («копия** «значения»)

// «Массив** «ссылка**:
const orig = [1, 2, 3];
const ref = orig;
ref.push(4);
console.log(orig); // [1, 2, 3, 4] («ссылка»!)

// «Поверхностная** «копия**:
const a = [{ x: 1 }];
const b = [...a];
b[0].x = 99;        // «вложенный** «мутирован»
console.log(a[0].x); // 99 («оригинал** «тоже»)
b.push({ y: 2 });
console.log(a.length); // 1 («длина** «оригинала** «не** «изменилась»)

// «Замена** «элемента** (без «мутации»):
const c = [...a];
c[0] = { x: 42 };
console.log(a[0].x); // 99 («a** «не** «изменён** «по** «первому** «элементу»)

// «Глубокая**:
const d = structuredClone(a);
d[0].x = 7;
console.log(a[0].x); // 99 («a** «цел»)

// «Иммутабельное** «обновление** «объекта** «в** «массиве»:
const users = [{ id: 1, name: "a" }];
const updated = users.map((u) => (u.id === 1 ? { ...u, name: "A" } : u));
console.log(updated[0].name, users[0].name); // "A" "a" («оригинал** «цел»)
```
Разбор: примитивы — «значения», «объекты** — «ссылки». «Поверхностная** «копия** — «новый** «контейнер**, «вложенные** «общие». structuredClone — «всё** «новое».

## Частые ошибки
WARN: const b = a «для** «копии** «объекта/массива** — «ссылка» (b.push «изменит** a); [...a] / { ...a } / structuredClone.
WARN: [...arr] «ожидаете** «глубокую** «копию** — «поверхностная»: «вложенные** «объекты** «— «ссылки» (b[0].x = 99 «изменит** a[0].x); structuredClone «для** «глубины».
WARN: { ...obj } «с** «вложенными** «объектами** — «те же** «ссылки**; «изменение** «вложенного** «в** «копии** «влияет** «на** «оригинал».
WARN: «функция** «мутирует** «аргумент-объект** (obj.x = ...) — «вызывающий** «не** «ожидал**; «возвращайте** «новое** ({ ...obj, x }).
WARN: JSON.parse(JSON.stringify(obj)) «для** «копии** — «работает**, но** ««терять** «Date/Map/Set/undefined/функции»; structuredClone «лучше**.
