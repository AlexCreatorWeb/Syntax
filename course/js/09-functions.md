# Урок 9. Функции: параметры и return

## Цель
После урока студент сможет: объявить функцию (декларация и expression) и выбрать между ними; работать с параметрами и return (одно значение, «ранний» return); объяснить, чем «вызов» отличается от «ссылки» (fn vs fn()).

## Теория
### Функция: «именованный» блок «с» «входом» и «выходом»
Функция — «переиспользуемый» «блок» кода «с» «входом» (параметры) «и» «выходом» (return). Два «основных» «способа» «объявления»:
- **декларация**: function add(a, b) { return a + b; } — «всплывает» (hoisting: «доступна» «выше» «строки» «объявления»);
- **expression** (в «переменную»): const add = function (a, b) { return a + b; } — «не» «всплывает» (TDZ «до» «строки»).

«Для» «обычного» кода — «декларация» (чище, «всплывает»). «Для» «анонимных» «колбэков» (урок 14) — expression/стрелка.

### Параметры и аргументы
**Параметр** — «имя» «в» «объявлении» (function f(a, b)), **аргумент** — «значение» «в» «вызове» (f(1, 2)). «Правила»:
- **недостаточно** «аргументов» → «остальные» — undefined: f(1) «с» (a, b) → b === undefined;
- **лишние** «аргументы» → «игнорируются» (но «доступны» через arguments — «артефакт», «не» «используйте»);
- «порядок» — «важен»: f(1, 2) ≠ f(2, 1) (для «некоммутативных»).

**return**: «выход» «из» «функции» «с» «значением»: return a + b;. «После» return — «код» «не» «выполняется». **Ранний return** — «выход» «с» «условия» (урок 7): if (!x) return null; // «дальше» — «x» «валидный». «Функция» «без» return (или return «без» «значения») → undefined.

### «Одно» «значение» «на» «выходе»
return «возвращает» ОДНО значение (но это «может» быть «объект/массив»):
```js
function calc(a, b) { return { sum: a + b, diff: a - b }; }
const { sum, diff } = calc(5, 3); // деструктуризация (урок 23)
```
return [a, b] — «массив» (разбор: const [x, y] = f()). «Множественный» return (return a, b) — «работает», но «анти-паттерн» (запятая — «оператор», «не» «пара»).

### «Вызов» vs «ссылка»
const double = (x) => x * 2; — «создал» «функцию». double — «ссылка» «на» «функцию» («объект»). double(5) — «вызов» («результат»). «Частая» «ошибка»: const r = double; r === 10? — «нет»: r — «функция» («не» «результат»). «Ссылку» «можно» «передать» «вдругую» «функцию» (колбэк, урок 14).

TIP: «название» «функции» — «глагол» (calculate, validate, fetch, format). «Функция» «делает» ОДНО (и «название» «отражает»): «плохо» — process() («что?»), «хорошо» — calcTotal() / validateEmail(). «Длина» «тела» — «до» ~20 «строк» («больше» — «разбейте»).

NOTE: «функция» — «объект» «первого» «класса»: «хранится» «в» «переменной», «передаётся» «в» «аргумент», «возвращается» «из» «функции». «Это» «основа» «колбэков» (урок 14), «замыканий» (12) «и» «всего» «функционального» «стиля».

## Пример
```js
// Декларация «и» expression:
function add(a, b) { return a + b; }
const mul = function (a, b) { return a * b; };
console.log(add(2, 3), mul(2, 3)); // 5 6

// «Недостаточно» «аргументов»:
function greet(name, greeting) { return `${greeting}, ${name}`; }
console.log(greet("A")); // "undefined, A" (greeting → undefined)

// «Ранний» return:
function divide(a, b) {
  if (b === 0) return null; // «невалидно» — «выход»
  return a / b;
}
console.log(divide(10, 2), divide(10, 0)); // 5 null

// «Объект» «на» «выходе»:
function calc(a, b) { return { sum: a + b, diff: a - b }; }
const res = calc(5, 3);
console.log(res.sum, res.diff); // 8 2

// «Вызов» vs «ссылка»:
const double = (x) => x * 2;
console.log(double);    // «функция» (source)
console.log(double(21)); // 42 («результат» «вызова»)
```
Разбор: return — «выход» «с» «значением» («ранний» — «защита»). «Одно» «значение» «на» «выходе» (объект/массив — «для» «пар»). double «и» double(21) — «разные» «вещи».

## Частые ошибки
WARN: fn «вместо» fn() — «ссылка» «на» «функцию», «не» «результат» (r === [Function], «не» «число»); «вызов» — «со» «скобками».
WARN: «код» «после» return «в» «функции» — «не» «выполнится» («мёртвый»): return x; console.log(...) — «никогда».
WARN: «много» «return» (return a, b) — «анти-паттерн» (запятая — «оператор», «вернёт» b); «возвращайте» «объект/массив».
WARN: «забыли» return «в» «функции» — undefined (логика «работает», «результат» «терян»): «проверяйте» «результат» «вызова».
WARN: «мутируете» «параметр» «и» «ожидаете» ««изменения» «у» «вызывающего»» — «для» «примитивов» «копия» (a = 5 «в» «функции» «не» «меняет» «аргумент»); «для» «объектов» — «ссылка» («меняет», урок 21).
