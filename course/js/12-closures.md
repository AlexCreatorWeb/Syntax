# Урок 12. Замыкания

## Цель
После урока студент сможет: объяснить, что такое замыкание (функция «помнит» свою «родительскую» область); собрать «счётчик» и «приватное» состояние через замыкание; предсказать, какие переменные «запомнит» вложенная функция.

## Теория
### Замыкание: «функция» «помнит» «свою» «область»
**Замыкание** (closure) — «функция» + «область», где «она» «была» «создана». «Вложенная» «функция» «видит» «переменные» «внешней» «(и» «помнит» «их», «даже» «когда» «внешняя» «уже» «отработала»):
```js
function makeCounter() {
  let count = 0; // «приватная» «переменная»
  return function () {
    count++;
    return count;
  };
}
const counter = makeCounter();
counter(); // 1
counter(); // 2 (count «не» «сбросился» — «замыкание»)
```
«Механика»: «когда» «makeCounter» «возвращает» «внутреннюю» «функцию», «область» makeCounter «не» «удаляется» (GC «держит» — «функция» «ссылается»). count «живёт» «в» «замыкании».

### «Что» «запоминает» «замыкание»
«Вложенная» «функция» «видит»: «свои» «параметры», «переменные» «внешней» «функции» («и» «меняет» «их»), «глобальные». «Каждый» «вызов» «внешней» — «своя» «копия» «области» (counter1 «и» counter2 — «разные» счётчики). «Параметры» «тоже» «в» «замыкании»: function f(x) { return () => x * 2; } — «внутренняя» «помнит» x.

### «Зачем» «замыкания»
1. **приватное** «состояние» (без классом, урок 26): count «недоступен» «снаружи» (только «через» «функцию»);
2. **фабрики** «функций»: makeLogger(prefix) → «логгер» «с» «своим» prefix;
3. **колбэки» «в** «асинхронном» коде (таймеры, fetch): «колбэк» «помнит» «контекст» («цикла», «обработчика»);
4. **«модули»** «в** «старом» «JS» (паттерн «модуля»: «приватные» «данные» + «публичный» API).

### «Ловушки» «замыканий»
- **цикл» «с** var: «все» «колбэки» «увидят» «последнее» i (var — «одна» «переменная»); let — «каждая» «итерация» «своё» (урок 11);
- **«ожидаете» «сброс» «счётчика» после «возврата» «из» «внешней» «функции» — «нет»: «область» «живёт» «в** «замыкании»;
- **«память»: «замыкание** «держит» «область» (GC «не» «собирает», «пока» «жива» «функция») — «для» «больших» «объектов» «в** «колбэках» — «утечка» (аудит: DevTools → Memory).

TIP: «узнаёте** «замыкание» «по** «структуре»: «функция» «возвращает» «функцию» (или «передаёт» «в** «колбэк»), «вложенная** «использует» «переменную» «внешней». «90%** «замыканий» «в** «практике» — «колбэки» (события, асинхронность, map/filter).

NOTE: «замыкание» — «не** «копия** «значений», а «ссылка** «на** «область**: «внешняя** «функция** «продолжает** «менять» «переменную» — «вложенная» «увидит» «новое» «значение» (не «снимок»). «Снимок» — «явно» (const snapshot = value).

## Пример
```js
// «Счётчик» (классика):
function makeCounter(step = 1) {
  let count = 0;
  return {
    inc: () => ++count,
    dec: () => --count,
    get: () => count,
  };
}
const c1 = makeCounter();
const c2 = makeCounter(2);
c1.inc(); c1.inc();
console.log(c1.get(), c2.get()); // 2 0 («разные» «счётчики»)

// «Фабрика» «логгеров»:
function makeLogger(prefix) {
  return (msg) => console.log(`[${prefix}] ${msg}`);
}
const logApi = makeLogger("API");
const logDb = makeLogger("DB");
logApi("fetch users"); // [API] fetch users
logDb("query ok");      // [DB] query ok

// «Параметр» «в» «замыкании»:
const double = (x) => () => x * 2;
const double5 = double(5);
console.log(double5()); // 10 (x «запомнен» = 5)

// «Внешняя» «меняет** — «вложенная** «видит»:
function demo() {
  let value = 1;
  const read = () => value;
  value = 99;
  return read;
}
console.log(demo()()); // 99 («не** «снимок» «1»)
```
Разбор: «каждый» «вызов» «внешней» — «своя» «область» (c1/c2 «разные»). «Замыкание» — «ссылка» («не» «копия»): «изменения» «внешней» «видны».

## Частые ошибки
WARN: «цикл» «с** var + «колбэки** (setTimeout «в** for var i) — «все** «увидят** «последнее» i; let «в** for (каждая «итерация» — «своё»).
WARN: «счётчик» «сбрасывается» «после» «возврата» «из** «внешней» — «нет**: «область» «живёт» «в** «замыкании» (GC «держит»). «Сброс» — «явно» (reset «метод»).
WARN: «ожидаете** «копию** «значения** «в** «замыкании» — «ссылка**: «внешняя» «меняет** → «вложенная» «видит» «новое». «Снимок» — const copy = value.
WARN: «большие** «объекты** «в** «колбэках** «на** «долгое» «время» (setTimeout 10 мин «с** «массивом» 1М) — «утечка» «памяти» (замыкание «держит»).
WARN: «this» «в** «стрелке** «в** «замыкании» — «из** «окружения» (урок 10): «методы» — «обычные» «функции» (или bind, урок 25).

## Практическое задание
1. В скелете задания реализуйте makeCounter(step): { inc, dec, get, reset }. Проверьте: «два» «счётчика» «независимы».
2. Напишите makeRange(from): «функция** () => «строка** "from-N" (N «растёт**). range(10)() → "10-1", «далее» "10-2".
3. Напишите once(fn): «обёртка», «вызывающая** fn «один» «раз» («дальше** — «результат** «кэширован**). once(() => console.log("hi")) — «два» «вызова» → «одно» «hi».
4. «Разберите» «Пример» «с** value=1/99 — «почему» 99, «а не» 1? («ссылка**, «не** «копия**)
5. Бонус: «память**: makeHuge() «создаёт** «массив» 100К «и» «возвращает** «счётчик» (без «ссылки» «на** «массив»). «Объясните», «сборётся** «ли» «массив» (GC «и» «замыкания»).
