# Урок 18. reduce: свёртка данных

## Цель
После урока студент сможет: написать reduce «с** «накопителем» (acc) «и** «понять** «параметры** (acc, item, index, array); «свернуть** «массив** «в** «число/объект/массив» (сумма, «группировка», «преобразование»); «распознать**, «где** «reduce** «лучше** «цикла».

## Теория
### reduce: «свести» «массив** «в** «ОДНО** «значение»
**reduce(cb, initial)** — «проходит** «по** «элементам», «накапливает** «результат» («аккумулятор** acc) «и** «возвращает** «одну** «значением»:
```js
const sum = nums.reduce((acc, x) => acc + x, 0); // «0** — «начальное** «значение** acc
```
«Параметры** «колбэка**: (accumulator, currentItem, index, array). «Порядок**: «начинаем** «с** initial (0-й «элемент** ««применяется** «к** initial), «идём** «вправо**.

«Пример** «по** «шагам** (nums = [1, 2, 3], initial = 0):
- acc = 0, x = 1 → 0 + 1 = 1
- acc = 1, x = 2 → 1 + 2 = 3
- acc = 3, x = 3 → 3 + 3 = 6
→ «результат** 6.

### «Что** «сворачиваем**
«Аккумулятор** — «любое** «значение» (число, «объект», «массив»):
- **число**: «сумма/макс/счётчик**: nums.reduce((m, x) => Math.max(m, x), -Infinity);
- **объект**: «группировка/подсчёт**: users.reduce((groups, u) => { (groups[u.city] ??= []).push(u); return groups; }, {});
- **массив**: «преобразование/разбиение**: «разделить** «на** «два** «массива** (чётные/нечётные).

«Правило**: «начальное** «значение** «того** «же» «типа**, что «и** «аккумулятор» (0 «для** «суммы**, {} «для** «группировки**, [] «для** «массива»).

### reduce «против** «цикла**
reduce «читается** «как** «свёртка» (декларативно), «но** «сложные** «логика** «в** «колбэке** — «гуще**, чем «цикл». «Правило**: «простая** «свёртка** (сумма, «группа», «макс) — reduce; «сложная** «много-шаговая** «логика** — for (яснее).

«Связь**: reduce — «универсальный** «обход»: «теоретически** «любой** «map/filter «выразить» «через** «reduce» (но «не** «стоит** — map/filter «чище).

TIP: «группировка** «через** reduce — «самый** «часто** «применение**: «объект** { key: [items] }. «Современный** «синтакс**: (groups[u.city] ??= []).push(u) (??= «присваивает**, если «не** «задано» — урок 5).

NOTE: reduce «без** initial — «первый** «элемент** «станет** acc (x «—» «второй** «элемент»). «Опасность**: «пустой** «массив** + «без** initial → TypeError. «Всегда** «пишите** initial.

## Пример
```js
const nums = [1, 2, 3, 4];

// «Сумма** (классика):
const sum = nums.reduce((acc, x) => acc + x, 0);
console.log(sum); // 10

// «Макс**:
const max = nums.reduce((m, x) => (x > m ? x : m), nums[0]);
console.log(max); // 4

// «Группировка**:
const users = [
  { name: "a", city: "MSK" },
  { name: "b", city: "SPB" },
  { name: "c", city: "MSK" },
];
const byCity = users.reduce((groups, u) => {
  (groups[u.city] ??= []).push(u.name);
  return groups;
}, {});
console.log(byCity); // { MSK: ["a", "c"], SPB: ["b"] }

// «Подсчёт** (count):
const words = ["a", "b", "a", "c", "b", "a"];
const counts = words.reduce((acc, w) => {
  acc[w] = (acc[w] ?? 0) + 1;
  return acc;
}, {});
console.log(counts); // { a: 3, b: 2, c: 1 }

// «Разбиение** «на** «два** (чётные/нечётные):
const [evens, odds] = [1, 2, 3, 4, 5].reduce((res, x) => {
  (x % 2 === 0 ? res[0] : res[1]).push(x);
  return res;
}, [[], []]);
console.log(evens, odds); // [2, 4] [1, 3, 5]
```
Разбор: «аккумулятор** — «число/объект/массив». «Группировка/подсчёт** — «объект** { key: value }. «Всегда** initial.

## Частые ошибки
WARN: reduce «без** initial — «первый** «элемент** = acc («сдвиг** «на** один**), «пустой** «массив** → TypeError; initial «всегда**.
WARN: «забыли** return acc «в** «колбэке** — undefined («свёртка** «прервана»). «Одно** «выражение** → «без** {}, «блок** → return «обязателен».
WARN: «группировка** «без** ??= (acc[key].push) — «ключ** «ещё** «не** «создан** → undefined.push → TypeError; (acc[key] ??= []).push(x).
WARN: reduce «для** «простого** «суммирования** «циклом** (и «наоборот**) — «выбирайте** «по** «читаемости: «простая** «свёртка** — reduce, «сложная** «логика** — for.
WARN: «порядок** «параметров** «колбэка** (acc, x) «перепутан** — acc «—» «накопитель» («первый**), x «—» «элемент» («второй**).
