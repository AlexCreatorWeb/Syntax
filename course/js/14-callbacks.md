# Урок 14. Колбэки: функция как значение

## Цель
После урока студент сможет: передать функцию в аргумент (колбэк) и вызвать её «в нужный» момент; объяснить «синхронный» vs «асинхронный» колбэк; распознать «callback hell» и понять, зачем появились Promise (задел на урок 39).

## Теория
### Функция — «значение» «первого» «класса»
Функция «может»: «храниться» «в» «переменной» (const f = ...), «передаваться» «в» «аргумент» (f(g)), «возвращаться» «из» «функции» (урок 12). **Колбэк** — «функция», «переданная» «вдругую» «функцию» «для» «вызова» ««позже»/«внутри»**:
```js
const nums = [1, 2, 3];
nums.forEach(function (x) { console.log(x * 2); }); // «колбэк» «вызывается» «для» «каждого» «элемента»
```
«Параметр» «для» «колбэка» — «обычный» «параметр» «функции» (callback). «Вызов**: callback(value) — «с» «аргументами» «по» «договору» «(API» «определяет»).

### «Синхронный» «vs** «асинхронный» «колбэк»
- **синхронный**: «вызывается» «сразу» «внутри» «функции» (forEach, map — «колбэк» «на** «каждом» «элемента» «по» «порядку»);
- **асинхронный**: «вызывается» «позже» (после «события»/«таймера»/«сети»): setTimeout(cb, 1000) — cb «через» «секунду», fetch(url).then(res => ...) — «когда» «пришёл» «ответ» (урок 41).

«Отличие** «в** «коде**: «синхронный** — «результат** «сразу** «после** «вызова»; «асинхронный** — «код** «дальше** «выполняется** «раньше**, чем «колбэк» (урок 38: event loop).

### «Порядок» «вызова» «и** «договор» «аргументов»
«Каждый** «API** «с** «колбэком** «имеет** «договор**: «сколько» «аргументов», «в каком порядке». «Классика** «Node-style**: callback(error, result) — «первый** «аргумент** — «ошибка» (null «если «ок»): fs.readFile(path, (err, data) => { if (err) ...; }). «В** «браузере**: element.addEventListener("click", handler) — handler «с** «объектом» «события» (урок 33).

### Callback hell: «пирамида» «ужаса»
«Вложенные» «асинхронные» «колбэки» «глубокой» «вложенности»:
```js
step1((r1) => step2(r1, (r2) => step3(r2, (r3) => { /* ... */ })));
```
«Проблема**: «глубина** «растёт** (не «линейно»), «ошибки** «размазаны**, «чтение** «сложно». «Решение** — Promise (урок 39) «и** async/await (40): «та же** «логика**, «но** «линейно**.

TIP: «названия** «колбэков** — «глагол/существительное** «действия**: onReady, onError, map(x => x * 2) (имя «не нужно»). «Один** «колбэк** «делает** ОДНО** («короткий**, «без** «вложенных** «колбэков** внутри» — «иначе» «пирамида»).

NOTE: «колбэк** «не** «обязан** «быть** «стрелкой»: function (x) {} «работает» «также». «Стрелка** — «короче» (урок 10) «и** «без** «своего» this. «Выбор** — «стиль» «проекта».

## Пример
```js
// «Синхронный» «колбэк» (forEach):
const users = ["A", "B", "C"];
users.forEach((name) => console.log("user:", name));

// map — «колбэк» «возвращает» «значение» (урок 17):
const upper = users.map((name) => name.toUpperCase());
console.log(upper); // ["A", "B", "C"]

// «Асинхронный» «колбэк» (setTimeout):
console.log("до");
setTimeout(() => console.log("через 300мс"), 300);
console.log("после"); // «выведется» «до» «колбэка» (event loop, урок 38)

// «Свой» «API» «с** «колбэком»:
function safeDivide(a, b, callback) {
  if (b === 0) { callback(null, null); return; } // (ok, result)
  callback(true, a / b);
}
safeDivide(10, 2, (ok, result) => console.log(ok, result)); // true 5
safeDivide(10, 0, (ok, result) => console.log(ok, result)); // null null

// «Callback hell» (демо — «не» «для» «практы»):
step("1", () => step("2", () => step("3", () => console.log("глубина 3"))));
function step(n, cb) { console.log(n); cb(); }
```
Разбор: «синхронный» — «сразу» (forEach/map), «асинхронный» — «позже» (setTimeout/fetch). «Договор» «аргументов» — «у» «каждого» API. «Пирамида» — «признак» «пора» «на» Promise.

## Частые ошибки
WARN: «забыли** «вызвать** «колбэк** (callback «объявлен», но «не» callback()) — «асинхронный» «поток» «замирает» («ожидание** «навсегда»). «Вызывайте** «кобэк** «во** «всех** «ветках» (включая «ошибочные»).
WARN: «колбэк** «с** «this» «в** «методах** «объекта» — «теряет» this (обычная «функция» «вызвана» «как» «колбэк»); стрелка «или» bind (урок 25).
WARN: «вложенные** «асинхронные** «колбэки** «глубокой** «вложенности» — «пирамида»: «переделайте» «на» Promise/async (уроки 39–40).
WARN: «колбэк** «вызывается** «дважды** (два «return» «с** callback() в «одной» «функции» «без» «остановки») — «двойная» «обработка»; «один** «вызов** «на** «ветку».
WARN: «синхронный** «код** «после** «асинхронного** «колбэка» «ждёт**: setTimeout(() => {}, 1000); console.log("после"); — «после» «выведется» «сразу» («не** «через» «секунду»); «порядок** — «урок» 38.
