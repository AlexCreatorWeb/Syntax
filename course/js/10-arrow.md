# Урок 10. Стрелочные функции

## Цель
После урока студент сможет: написать стрелочную функцию (все формы: с/без {}, с/без return, стрелка «с» «телом»); объяснить, чем стрелка «отличается» «от» «обычной» (this, arguments, new, hoisting); выбрать «между» «формами» «по» «читаемости».

## Теория
### Синтаксис: «короткая» «форма» «функции»
**Стрелочная** (arrow) «функция» — «короткая» «форма»:
```js
const add = (a, b) => a + b;              // «одно» «выражение» — return «не» «нужен»
const greet = (name) => `Привет, ${name}`; // «выражение» «=» «результат»

const calc = (a, b) => {                   // «блок» «тела» — return «явный»
  const sum = a + b;
  return sum * 2;
};

const noArgs = () => console.log("hi");    // «без» «аргументов» — () «обязателен»
const oneArg = (x) => x * 2;               // «один» «аргумент» — () «опционально»: x => x * 2
```
«Правило»: «одно» «выражение» → «без» {} (return «имплицитный»). «Несколько» «строк» → {} + return «явный». «Один» «аргумент» — () «можно» «опустить» (но «для» «единообразия» — «держите»).

### Чем «стрелка» «отличается» «от» «обычной»
1. **this**: стрелка «НЕ имеет» «своего» this — «берёт» «из» «окружающей» «области» (лексический, урок 11): «в» «методах» «объекта» стрелка «ломает» this (урок 25). «Для» «обычных» «функций»/«колбэков» — «разницы» «нет»;
2. **arguments**: «нет» (только rest ...args, урок 13);
3. **new**: «нельзя» «вызывать» «как» «конструктор» (new Arrow() → TypeError) — «не» «для» «классов»;
4. **hoisting**: «нет» (const/let — TDZ, урок 11) — «объявляйте» «до» «использования»;
5. **return**: «имплицитный» «для» «одного» «выражения» (короче).

«Вывод»: стрелка — «для» «коротких» «колбэков» (map/filter/onClick) «и» «помощников»; «обычная» — «для» «методов» «объекта» (this), «конструкторов», «рекурсии» «с» «именем».

### «Где» «стрелка» «хорошо», «где» «нет»
- **хорошо**: колбэки (arr.map(x => x * 2), button.onclick = () => ...), «короткие» «помощники» (const double = x => x * 2);
- **плохо**: «методы» «объекта» «с» this (урок 25), «конструкторы» (new), «рекурсия» «без» «имени» (function f() { f() } — «работает»; const f = () => f() — «тоже» «работает», но «менее» «ясно»).

TIP: «единый» «стиль» «в» «проекте»: «все» «короткие» «колбэки» — стрелки, «все» ««методы»» — «обычные» (или «метод-сокращение» { method() {} } в «объекте», урок 22). «Не» «перемешивайте» «в» «одном» «файле» «без» «системы».

NOTE: «стрелка» «не» «меняет» «логику» (только «синтаксис» + this/arguments/new/hoisting). «Ошибки» ««переводы»» «обычной» «в» «стрелку» «с» «изменением» «поведения» (this «в» «методах») — «главная» «ловушка» «этого» «урока».

## Пример
```js
// «Все» «формы»:
const square = (x) => x * x;           // «одно» «выражение»
const add = (a, b) => a + b;           // «два» «аргумента»
const one = x => x + 1;                // «один» «аргумент» «без» ()
const none = () => "ничего";           // «без» «аргументов»

const multi = (a, b) => {              // «блок» — return «явный»
  const product = a * b;
  return product + 1;
};

console.log(square(5), add(2, 3), one(0), none(), multi(3, 4)); // 25 5 1 "ничего" 13

// «Колбэки» (главное «применение»):
const nums = [1, 2, 3, 4];
const doubled = nums.map(x => x * 2);  // [2, 4, 6, 8] (урок 17)
console.log(doubled);

// this: «стрелка» «берёт» «из» «окружения»:
const obj = {
  value: 10,
  regular() { console.log(this.value); },  // «своё» this (obj)
  arrow: () => console.log(this.value),    // this «из» «окружения» (module/global)
};
obj.regular(); // 10
obj.arrow();   // undefined (this «не» obj!)
```
Разбор: «короткое» «выражение» — «без» {} (return «не» «нужен»). «Блок» — {} + return. «Колбэки» — «основное» «применение». this «в» «методах» — «ловушка».

## Частые ошибки
WARN: стрелка «в» «методах» «объекта» (this) — this «из» «окружения» (не «объект»): «методы» — «обычные» (function/метод-сокращение).
WARN: () «опустили» «для» «нуля» «аргументов» — () «обязателен» (=> без «скобок» — SyntaxError).
WARN: new ArrowFn() — TypeError («нет» «конструктора»); «классы» — «обычные» «функции» (class).
WARN: «забыли» return «в» «стрелке» «с» {} — const f = (x) => { x * 2; } → undefined ({} = «блок», return «явный»).
WARN: «рекурсия» «стрелки» «без» «имени» — const f = () => f(); «работает», но «имя» «в» «стектрейсе» «не» «ясно»; «рекурсию» — «обычной» «функцией».
