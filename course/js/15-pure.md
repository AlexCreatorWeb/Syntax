# Урок 15. Чистые функции и побочные эффекты

## Цель
После урока студент сможет: определить «чистую» функцию (одно значение → один результат, без побочных эффектов); найти побочные эффекты в коде (мутиация, console, глобальные); применить «чистую» архитектуру: «считать отдельно, показывать отдельно».

## Теория
### Чистая функция: «то же «вход» → тот же «выход»
**Чистая** функция: (1) «результат» «зависит» ТОЛЬКО «от аргументов» («без» «внешних» данных), (2) «без** «побочных** «эффектов** (ничего «снаружи» «не меняет»).
```js
const pure = (a, b) => a + b;        // 2 + 3 «всегда» 5
const impure = () => Math.random();  // «каждый» «раз» — «другое» «число»
```
«Чистота** «даёт**: «предсказуемость» («один» «результат»), «тестируемость» («без** «моков** «окружения»), «параллелизм» («нет** «гонки** «за** «данными»).

### Побочные эффекты: «что** «чистит** «функцию»
«Побочный** «эффект** — «всё**, «что** «функция** «делает** «помимо** «возврата** «значения»:
- **мутиация** «аргументов**/внешних** «объектов»: function f(arr) { arr.push(1); } («аргумент** «изменён» «снаружи»);
- **глобальные** «переменные** (чтение «и** «запись**): let count = 0; function f() { count++; return count; };
- **время/случайность** (Date.now(), Math.random()) — «вход» «не» «в** «аргументах»;
- **I/O**: console.log, fetch, DOM (document), alert — «внешний» «мир».

«Важно**: «побочные** «эффекты** — «не** «зло» (console.log «в** «главном** «скрипте** — «нормально»). «Чистота** — «для** ««логических**» «функций» (расчёты, «преобразования» данных): «считаем** «чисто**, «показываем** «отдельно».

### Паттерн: «считать отдельно, «показывать» «отдельно»
```js
// «Чистое» «ядро»:
const calcTotal = (items) => items.reduce((sum, i) => sum + i.price * i.qty, 0);
const formatMoney = (kopecks) => (kopecks / 100).toFixed(2) + " ₽";

// «Побочное» «обёртка» (показ):
function renderTotal(items) {
  const total = calcTotal(items);          // «чисто»
  console.log(formatMoney(total));          // «побочно» (I/O)
}
```
«Раскрытие**: «логика** — «чистые» «функции» (тестируются «без** «браузера»), «обёртка** — «тонкая» (I/O, DOM, «время»). «Это** «основа» «всякого» «тестирования» «и** «архитектуры».

### «Чистота» «и** «иммутабельность» (связь «с** «уроком» 21)
«Чистая** «функция** «не** «мутирует**: «возвращает** «НОВОЕ** «значение**:
```js
const incAll = (nums) => nums.map((x) => x + 1); // «новый» «массив» (map)
const incAllBad = (nums) => nums.forEach((x, i) => (nums[i] = x + 1)); // «мутирует» (нечисто)
```
«Связь**: «чистота** «функций** «и** «иммутабельность** «данных** — «одна** «монета**: «меньше** «сюрпризов**, «предсказуемее** «поток».

TIP: «проверка** «чистоты**: «вызовите** «функцию» «два» «раза» «с» «одними» «аргументами» — «если» «результат» «разный» (или «состояние» «внешнее» «изменилось») — «не» «чистая». «Тренировка**: «перепишите** «функции** «урока** «14** (safeDivide «с** «колбэком**) «как» «чистые** (return «вместо» callback) — «сравните».

NOTE: «полная** «чистота** «в** «приложении» «невозможна» (UI, сеть, «время» — «по** «определению** «побочные»). «Архитектура**: «максимум** «чистой** «логики**, «минимум** «побочных** «обёрток».

## Пример
```js
// «Чистые»:
const sum = (a, b) => a + b;
const calcTotal = (items) => items.reduce((s, i) => s + i.price * i.qty, 0);
const formatMoney = (k) => (k / 100).toFixed(2) + " ₽";

const items = [
  { name: "keyboard", price: 1990, qty: 1 },
  { name: "cup", price: 299, qty: 2 },
];
const total = calcTotal(items);
console.log(formatMoney(total)); // "25.88 ₽"

// «Нечистая» «мутиация»:
let stock = 10;
const buy = (qty) => { stock -= qty; return stock; }; // «меняет** «глобальный** stock
console.log(buy(3), buy(3)); // 7 4 («состояние** «накапливается»)

// «Чистая» «версия» (состояние «в** «аргументах»):
const buyPure = (stock, qty) => stock - qty;
console.log(buyPure(10, 3), buyPure(10, 3)); // 7 7 («один** «вход** → один «выход»)
```
Разбор: «чистые» (sum/calcTotal/formatMoney/buyPure) — «тестируются» «легко». buy — «нечистая» («глобальный» stock «меняется»). «Паттерн**: «считать** «чисто**, «показывать** «отдельно».

## Частые ошибки
WARN: «мутируете** «аргумент** «в** «функции** (arr.push, obj.x = ...) — «нечисто» («вызывающий** «не** «ожидал** «изменения»); «возвращайте** «новое» ([...arr, x], { ...obj, x }).
WARN: «Date.now()/Math.random()» «в** ««логике**» — «нечисто» («результат** «не** «повторить»); «передавайте** «время/seed» «в** «аргументы».
WARN: «console.log» «в** ««ядре** «логики» — «перемешиваете** «счёт** «и** «показ»; «логика** — «чисто», «лог» — «в** «обёртке».
WARN: «глобальный** «счётчик» «в** «функциях** (count++) — «состояние** «размазано**; «перенесите** «состояние** «в** «аргументы» (buyPure).
WARN: «ожидаете** «чистоты** «от** «map/filter** «с** «мутиацией** «внутри** — map «создаёт** «новый» «массив», «но** «элементы** «— «ссылки» (урок 21): «мутируете** «вложенный** «объект** — «оригинал** «тоже».
