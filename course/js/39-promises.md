# Урок 39. Promise: then, catch, finally

## Цель
После урока студент сможет: «создать** «Promise** («new Promise «с** «resolve/reject**); ««обработать** ««результат** «(.then) «и** ««ошибку** «(.catch); ««понять** ««состояния** (pending/fulfilled/rejected) «и** ««цепочки** «then** «(««конвейер** «асинхронности**); ««отличать** «Promise «от** ««колбэков** «(««конец** «callback hell**).

## Теория
### «Что** «такое** «Promise**: ««обещание** ««будущего** ««значения**
**Promise** — «объект**, «который** ««когда-нибудь** ««даст** ««значение** (fulfilled «/» «resolve** «(успех**) «или** ««упадёт** «(rejected «/» «reject** «(ошибка**). «Три** «состояния**:
- **pending** — ««ещё** ««работает** («не** ««определено** «(стартовое**);
- **fulfilled** (resolved) — ««готово** «с** ««значением** «(успех**);
- **rejected** — ««ошибка** «(с** ««объектом** «ошибки**).

«Создание**:
```js
const p = new Promise((resolve, reject) => {
  // ««асинхронная** «работа** (таймер**, «сеть**, ««ввод**):
  setTimeout(() => {
    const ok = Math.random() > 0.5;
    if (ok) resolve("успех");
    else reject(new Error("сбой"));
  }, 1000);
});
```
«resolve(value) — ««успех** «с** «value**, reject(err) — ««ошибка** «с** «err**. ««После** ««первого** «resolve/reject** «—» ««состояние** ««зафиксировано** («далее** «игнорируется**).

### «Обработка**: .then «и** .catch
```js
p.then((value) => console.log("успех:", value))  // «fulfilled**
 .catch((err) => console.error("сбой:", err.message)) // «rejected**
 .finally(() => console.log("«всегда**"));     // ««завершение** («как** «try/finally**
```
**then** «—» ««колбэк** «на** «успех** («получает** «value**). **catch** «—» ««колбэк** «на** «ошибку**. **finally** «—» ««всегда** («без** «аргументов**). «Каждый** «then** ««возвращает** ««новый** «Promise** «(««цепочка** «(««конвейер**).

### «Цепочки**: ««конвейер** «асинхронности**
```js
fetchUsers()
  .then((users) => fetchPosts(users))
  .then((posts) => render(posts))
  .catch((err) => console.error(err))
  .finally(() => hideLoading());
```
««Сравнивать** «с** «callback hell** «(урок** 14**): ««те же** ««шаги**, «но** ««линейно** («без** ««вложенности**), «ошибка** ««ловится** ««одним** «catch** (««все** ««шаги** ««ниже**). «Возврат** «Promise** «из** «then** «—» ««автоматически** ««раскроется** «(«вложенный** «Promise** ««не** ««двойной** «обёрткой**).

### ««Встроенные** «Promise-функции**
- **Promise.resolve(value)** — ««сразу** «fulfilled** (обёртка** ««значения** «в** «Promise**);
- **Promise.reject(err)** — ««сразу** «rejected**;
- **Promise.all([p1, p2])** — ««все** ««успешны** («массив** ««результатов**), «один** ««упал** — ««весь** ««упал** (урок** 40**);
- **Promise.race([p1, p2])** — ««первый** ««завершится** («успех** «или** «ошибка**).

TIP: «Promise** «—» ««интерфейс** ««асинхронности** («««когда** ««готово**, ««что** ««даст**). «async/await** «(следующий** «урок**) — ««синтаксис** ««над** «Promise** (««линейный** ««код** «с** «await** «вместо** «then-цепочек**). ««Понимание** «Promise** «—» ««основа** «async/await**.

NOTE: «then** ««колбэк** ««может** ««вернуть** «Promise** (««вложенный**) — ««автоматически** ««раскроется** («цепочка** ««ждёт** ««вложенный**). «Если** ««колбэк** «then** ««упал** («бросил** «ошибка**) — ««цепочка** ««падает** «в** ««следующий** «catch**.

## Пример
```js
// «Создание**:
const wait = (ms) => new Promise((resolve) => setTimeout(resolve, ms));
const result = (ok) => new Promise((resolve, reject) =>
  setTimeout(() => (ok ? resolve("ок") : reject(new Error("сбой"))), 500)
);

// «Обработка**:
result(true)
  .then((v) => console.log("успех:", v))
  .catch((e) => console.error("сбой:", e.message))
  .finally(() => console.log("«завершено**"));

// «Цепочка**:
wait(300)
  .then(() => console.log("«шаг** 1 «через** «300ms"))
  .then(() => wait(200))
  .then(() => console.log("«шаг** 2 «ещё** «200ms"))
  .catch((e) => console.error(e));

// ««Ошибочная** «цепочка**:
result(false)
  .then((v) => console.log("«не** ««вызовется**))
  .catch((e) => console.error("«поймали**:", e.message)) // "сбой"
  .finally(() => console.log("«всё равно**"));

// Promise.all:
Promise.all([wait(100), wait(50)])
  .then(() => console.log("«оба** ««готовы**"));
```
Разбор: «состояния** (pending → fulfilled/rejected). then/catch/finally — ««обработка**. «Цепочки** — ««конвейер** («линейно** «вместо** ««вложенности**).

## Частые ошибки
WARN: «забыли** «return «из** «then** «(«вложенный** «Promise** ««не** ««раскроется**: .then(() => fetch(...)) «без** «return** «—» «цепочка** ««не** ««ждёт** «fetch**; ««обязателен** «return.
WARN: «then** ««колбэк** ««бросает** «ошибка** — ««цепочка** ««падает** «в** ««следующий** «catch** (««тихий** «сбой** «без** «catch** «—» «unhandledrejection** «(«ошибка** «в** «консоли**).
WARN: «catch** ««выше** «then** «(цепочка** ««сверху** «вниз**) — ««ошибка** «из** «then** ««ниже** «catch** ««не** ««поймает**; «catch** ««в** ««конце** «цепочки**.
WARN: «Promise.all «с** ««ошибкой** «одного** — ««весь** ««падает** (««остальные** ««не** ««дождутся**); ««все** ««даже** «с** «ошибками** — Promise.allSettled (урок** 40** «в** ««задел**).
WARN: «new Promise ««без** «resolve/reject** «(««забыли** ««вызвать**) — ««навсегда** «pending** («цепочка** ««замирает**); ««вызывайте** «resolve/reject «во** «всех** «ветках**.
