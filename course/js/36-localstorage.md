# Урок 36. localStorage: сохранение данных

## Цель
После урока студент сможет: «сохранить** «и** «прочитать** «данные** «в** localStorage (строки** «↔** «JSON**); «понять**, localStorage «vs** sessionStorage «(где** «что** «хранится** «и** «когда** «сбрасывается**); «обработать** «ошибки** «(«битый** «JSON**, «переполнение** «квоты**); «применить** «к** «todo** «(урок** 35** «—» ««переживает** «перезагрузку**).

## Теория
### localStorage: «персистентные** «ключи** «→** «значения**
**localStorage** — «хранилище** «в** «браузере** «(«пары** «ключ:значение**, «только** «строки**). «Живёт** ««вечно** «(пока** «не** ««удалите** «в** ««настройках** «браузера** «или** ««очистят** «кэш**). «Лимит** «~5–10 МБ («зависит** «от** «браузера** «и** «домена**).

«API**:
```js
localStorage.setItem("key", "value");   // «сохранить**
const v = localStorage.getItem("key");  // «прочитать** (строка** «или** null)
localStorage.removeItem("key");         // «удалить**
localStorage.clear();                    // «всё** «удалить**
localStorage.key(i); localStorage.length; // «обход** «(ключи**)
```
«Все** «значения** — «строки** («числа/объекты** «—» «сериализуйте** «JSON**, урок 27**).

### «Паттерн**: «сохранить** «и** ««загрузить** «с** «fallback**
```js
const KEY = "todos";
function save(todos) {
  try { localStorage.setItem(KEY, JSON.stringify(todos)); }
  catch { /* «квота** «переполнена** «(тихий** «фолбэк** «или** «лог** «(урок** 29** «) */ }
}
function load() {
  try { return JSON.parse(localStorage.getItem(KEY)) ?? []; }
  catch { return []; } // «битый** «JSON** → «пустой** «массив**
}
let todos = load(); // ««восстановить** «при** «старте**
// «каждый** «изменение** «todos** → save(todos)
```
«Правило**: «обёртка** «с** «try/catch «(parse «может** «упасть** «на** ««битом** «тексте**, «setItem** «—» «квота**). ««Фолбэк** «—» ««безопасный** «значение** «(пустой** «массив/объект**).

### localStorage «vs** sessionStorage «vs** «cookies**
- **localStorage** — ««навсегда** «(до** «ручной** «очистки** «и** ««всё** ««вкладка** «(домен**);
- **sessionStorage** — ««вкладка** (сброс** «при** «закрытии** «вкладки**, «новый** «вкладка** «—» «пусто**);
- **cookies** — ««отправляются** «на** «сервер** «с** «каждым** «запросом** «(«аутентификация** «и** ««настройки** «(не «данные** «(лимит** ~4 КБ**).

«Для** ««данных** «приложения** «(todo**, «настройки** «пользователя**) → localStorage. «Для** ««временного** «состояния** «(«вкладка**) → sessionStorage.

### «Применение**: todo ««переживает** «перезагрузку**
«Урок** 35: «при** «старте** — load(), «при** ««каждом** «изменении** — save(todos). «Перезагрузка** «страницы** «—» «список** ««тот же** «(«восстановлен** «из** «localStorage**).

TIP: «ключи** «с** ««префиксом** («app.todos, «app.settings) — ««пространство** «имён** («не** ««конфликт** «с** ««другими** «скриптами** «на** «странице**). ««Версия** «(KEY = "todos-v1") — ««миграция** «формата** («старые** «ключи** «—» «fallback** «(load «с** ««новым** «именем** «даст** «пусто** «при** ««смене** «формата**).

NOTE: localStorage «синхронный** (setItem «блокирует** ««рендер** «при** ««больших** «значениях** «(1М JSON «—» ««задержка**). ««Большие** «данные** «(10М+) → IndexedDB («асинхронный** «(урок** 38** «в** «задел**).

## Пример
```js
const KEY = "app.counter";

// «Сохранить** / ««загрузить**:
function save(n) {
  try { localStorage.setItem(KEY, String(n)); } catch { console.warn("квота"); }
}
function load() {
  const v = localStorage.getItem(KEY);
  return v === null ? 0 : Number(v); // ««фолбэк** «(null** «—» «не** «было**)
}

let count = load();
console.log("старт:", count); // 0 «при** ««первом** «запуске**

count++;
save(count);
console.log("после**: ", count); // 1
// «перезагрузите** «страницу** «—» «старт** «будет** 1 «(«восстановлен** «из** «localStorage**)

// «Объект** (JSON**):
const settings = { theme: "dark", size: 16 };
localStorage.setItem("app.settings", JSON.stringify(settings));
const loaded = JSON.parse(localStorage.getItem("app.settings"));
console.log(loaded); // { theme: "dark", size: 16 }

// «Обход**:
for (let i = 0; i < localStorage.length; i++) {
  const k = localStorage.key(i);
  console.log(k, "→", localStorage.getItem(k));
}
```
Разбор: setItem/getItem — «строки** («объекты** «—» JSON.stringify/parse. ««Фолбэк** «при** «null** («не** «было** «ключ**). ««Обёртка** «с** «try/catch «(квота** «и** ««битый** «JSON**).

## Частые ошибки
WARN: localStorage.setItem(KEY, obj) «ожидаете** «объект** «— «строка** «"[object Object]"** (нужен** JSON.stringify). ««Чтение** «—» JSON.parse.
WARN: JSON.parse «без** try/catch «для** ««хранилища** — «падение** «на** ««битом** «JSON** «(«чистый** «кэш** «в** «браузере**); ««обёртка** «с** ««фолбэком**.
WARN: «сравниваете** getItem «с** «null** «вместо** «""** «(пустая** «строка**) — ««пустое** «значение** «≠** ««не** «было** «(null**); «проверяйте** «конкретное** «значение**.
WARN: ««большие** «объекты** «(1М+) «в** ««каждом** «тик** «анимации** — «синхронный** «setItem** ««тормозит** ««рендер** «(IndexedDB «или** ««уменьшите** «частоту**).
WARN: «ожидаете** ««очистку** «localStorage** «при** ««очистке** «кэша** — ««настройки** «браузера** ««очистить** «cookies** «и** ««сайт-данные** «(localStorage ««живёт** ««дольше**).
