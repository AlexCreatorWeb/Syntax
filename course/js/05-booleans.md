# Урок 5. Булевы, null/undefined, truthy и falsy

## Цель
После урока студент сможет: объяснить разницу == и === и почему «всегда» строгое равенство; перечислить ВСЕ falsy-значения JS; предсказать результат условий с null/undefined/пустой строкой.

## Теория
### Булевы и «логические» операторы
**boolean** — только true и false. Условия if/while «принимают» ЛЮБОЕ значение (и «переводят» в boolean — урок о truthy ниже). Логические операторы:
- **&&** («И») — «первое» false (falsy) «или» «последнее» значение: "hi" && 0 → 0, "hi" && "there" → "there";
- **||** («ИЛИ») — «первое» truthy «или» последнее: 0 || "hi" → "hi";
- **??** («нулевой коалесинг») — «правая» часть, только если «левая» null/undefined: null ?? "default" → "default", 0 ?? 0 → 0 (0 «не null» — «забирает» 0!).

**?? против ||**: `count || 10` «заменит» И 0, И "", И false; `count ?? 10` — ТОЛЬКО null/undefined. Для «дефолтов» — ?? (точнее).

### == vs ===: «мягкое» и «строгое»
- **===** (строгое) — «равны, если» ТИП и значение совпадают: 5 === "5" → false, null === undefined → false;
- **==** (мягкое) — «сначала «превращает» типы (урок 6), потом сравнивает»: 5 == "5" → true, "" == 0 → true, null == undefined → true.

Правило современности: **всегда ===**. Два «допустимых» исключения: x == null (ловит null И undefined — «пусто в любом смысле») и, возможно, сравнение с «неизвестным» пользовательским вводом (но лучше — явное превращение).

### truthy и falsy: «что считается ложью»
**falsy** (переводится в false) — ровно 7 значений: **false, 0, "" (пустая строка), 0n, null, undefined, NaN**. ВСЁ остальное — **truthy** (включая "0" (строка!), [] (пустой массив!), {} (пустой объект!)).

Классические «сюрпризы»: if ([]) → true (пустой массив — truthy!), if ("0") → true (строка — truthy), if ("") → false (ПУСТАЯ строка — falsy). Проверка «пустой ли массив» — arr.length === 0 (не if (arr)).

### null и undefined «на практике»
- **undefined** — «не задано»: let x; (x → undefined), obj.missing (→ undefined), функция без return (→ undefined);
- **null** — «осознанная пустота»: user = null «до загрузки», результат поиска: find «не нашёл» (→ undefined, но «договор» функции).

«Заглушки» (default values): count ?? 0, name ?? "Гость", items ?? [].

TIP: «проверка» «заполнено ли поле»: if (!value) — «покроет» все falsy (включая "" и 0). Но если 0 — «валидное» значение (номер, счётчик) — if (value === null || value === undefined) или if (value ?? fallback).

NOTE: в JS «нет» третьего состояния «может быть true/false/ничего» — «ничего» выражается через undefined (автоматически) или null (вручную). «Флаги» — всегда true/false (не 0/1, не "yes"/"no" — «ломает» ===).

## Пример
```js
// == vs ===:
console.log(5 === "5");    // false (разный тип)
console.log(5 == "5");     // true (== «превратил» строку)
console.log(null === undefined); // false
console.log(null == undefined);  // true (единственный «уместный» ==)

// truthy/falsy:
const values = [false, 0, "", 0n, null, undefined, NaN, "0", [], {}, "hi", 42];
for (const v of values) {
  console.log(Boolean(v), "←", v === 0 ? "0" : JSON.stringify(v) ?? String(v));
}

// ?? против ||:
console.log(0 || 10);   // 10 (0 falsy — «заменит»)
console.log(0 ?? 10);   // 0 (0 «не null» — «заберёт»)
console.log(null ?? "default"); // "default"
```
Разбор: === — «по умолчанию» (без «сюрпризов»). falsy — 7 «конкретных» значений (запомните: false, 0, "", 0n, null, undefined, NaN). ?? — «для» «пустых» (null/undefined), || — «для» «лживых» (все falsy).

## Частые ошибки
WARN: == «для» «надёжности» — «мягкое» сравнение «превращает» типы: "" == 0, " " == false, null == undefined — «сюрпризы»; «всегда» === (исключение: x == null).
WARN: if (arr) «для» «пустого ли» — [] truthy! (пустой массив «пройдёт»); проверка — arr.length === 0 (или !arr.length).
WARN: "0" «считаете» falsy — «нет»: НЕПУСТАЯ строка — truthy (даже "0", "false"); ПУСТАЯ "" — falsy.
WARN: count || 10 «дёте» «дефолт» для 0 — «заменит» 0 на 10 (0 falsy); «дефолт» «только для» null/undefined — ?? 10.
WARN: «сравниваете» null «и» undefined «раздельно» — x === null || x === undefined → «замените» x == null (короче, «то же»).
