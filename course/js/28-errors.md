# Урок 28. try/catch/finally и throw

## Цель
После урока студент сможет: «поймать** «ошибку** (try/catch) «и** «выполнить** «завершение** (finally); «бросить** «свою** «ошибку** (throw); «различать** «ошибки** «выполнения** (runtime) «и** «синтаксические**; «строить** «надёжный** «код** «с** «fallback**.

## Теория
### try/catch/finally: «обработка** «ошибок**
```js
try {
  riskyCode();       // «может** «упасть**
} catch (err) {
  console.error(err); // «поймали** («err — «объект** «ошибки**)
} finally {
  cleanup();         // «всегда** («выполнится** «после** try/catch, «даже** «при** return)
}
```
- **try** — «риск** «код**;
- **catch (err)** — «обработка** (err — «объект** «ошибки**: .message «—» «текст**, .name «—» «тип** ("TypeError", "ReferenceError"...));
- **finally** — «завершение** («всегда** «выполнится** (после «успеха**, «ошибки**, «даже** «return** «в** try).

«Правила**: «ловите** «только** «ожидаемые** «ошибки** (JSON.parse, «внешние** «данные**); «не** ««глотаю** «тихо** (catch «без** «обработки** — «баг** «прячется**). «Одна** «ветка** «—» «один** catch (err instanceof TypeError) «для** «разных** «типов**.

### throw: «своя** «ошибка**
```js
function assertPositive(n) {
  if (n < 0) throw new Error("n «должен** «быть** «положительным");
  return n;
}
try { assertPositive(-1); } catch (e) { console.error(e.message); }
```
**throw** — «бросить** ««исключение»** (выполнение** «прекращается**, «идёт** «в** «ближайший** catch). «Новый** «Error**: new Error(message) («свой** «текст**). «Встроенные**: TypeError, ReferenceError, RangeError, SyntaxError, URIError («используйте** «по** «смыслу**).

### «Ошибки** «выполнения** «vs** «синтаксические**
- **runtime** (TypeError, ReferenceError) — «в** «процессе** «выполнения** («ловятся** try/catch);
- **syntax** (SyntaxError «в** «скрипте** «(опечатка**)) — «на** «этапе** «парсинга** («весь** «скрипт** «не** «выполняется**, «не** «ловится** «try «в** «том** «же** «скрипте** (но «ловится** «в** «динамическом** import/eval**).

«В** «редакторе** Syntax: «ошибка** «в** «файле** → «консоль** «покажет** «(с «номером** «строки**). «Синтаксическая** «ошибка** «— весь «файл** «не** «запустится**.

### «Надёжный** «паттерн**: «fallback** «вместо** ««падения**
```js
function loadConfig(key) {
  try {
    return JSON.parse(localStorage.getItem(key)) ?? {};
  } catch {
    return {}; // «битый** «JSON** → «пустой** «объект
  }
}
```
«Идея**: «внешние** «данные** (localStorage, API, «ввод** «пользователя**) — ««недоверенные**; «обработайте** «ошибку** «и** «верните** ««безопасный** «fallback.

TIP: «имя** «переменной** «в** catch — err «или** e («коротко**); «не** «перекрывайте** «глобальные** (error «—» «ок», «но** «лучше** err). «В** «catch** «—» «минимум**: «лог** + «fallback** «+ «переброс** «(throw) «если** ««не** «разобрались**.

NOTE: «finally** «выполнится** «даже** «при** return «в** try (но «не** «изменит** ««возвращаемое** «значение**, «кроме** «throw). «Если** «нет** ««завершения** — «finally** «не** «нужен**.

## Пример
```js
// «Ловим** «ошибку**:
try {
  console.log(unknownVar); // ReferenceError
} catch (err) {
  console.error(err.name, err.message); // "ReferenceError" "unknownVar «is** «not** «defined"
}

// finally:
function demo() {
  try {
    return 42;
  } finally {
    console.log("finally"); // «выведется** «перед** «return
  }
}
console.log(demo()); // "finally" «потом** «42»

// throw:
function divide(a, b) {
  if (b === 0) throw new Error("деление «на** «0");
  return a / b;
}
try {
  divide(10, 0);
} catch (err) {
  console.error(err.message); // "деление «на** «0"
}

// «Fallback**:
function safeParse(text) {
  try { return JSON.parse(text); }
  catch { return null; }
}
console.log(safeParse('{"a":1}'), safeParse("«битый")); // {a:1} null
```
Разбор: try/catch — «ловим**, finally — «завершение**, throw — «своя** «ошибка**. «Fallback** — «надёжный** «паттерн**.

## Частые ошибки
WARN: catch «без** «обработки** («пустой** «блок** «или** «только** «console.log) — «баг** «прячется** (тихий** «сбой**); «лог** + «fallback** «+ «переброс**.
WARN: try «вокруг** ««всего** «(большой** «блок** «в** try) — «трудно** «найти** ««источник** «ошибки**; «меньший** «try** «вокруг** ««риск** «строк**.
WARN: «забыли** return «в** «catch** «(после** «fallback**) — undefined («функция** ««прервана**); «верните** ««безопасный** «результат**.
WARN: finally «с** return «—» «перекроет** «return** «из** try/catch (редко** «уместно**); «обычно** finally — «только** ««завершение** (без** return).
WARN: «ожидаете** «ловить** «SyntaxError «в** «том** «же** «скрипте** — «весь** «файл** «не** «запустится** (ошибка** «на** «этапе** «парсинга**); «ловится** «в** «динамическом** «импорте**.
