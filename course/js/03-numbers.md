# Урок 3. Числа и Math: NaN, float, округления

## Цель
После урока студента сможет: объяснить, что такое NaN и почему он «не равен» себе; предсказать, почему 0.1 + 0.2 «не равно» 0.3, и как сравнивать дроби безопасно; выбрать способ округления (toFixed, Math.round, precision).

## Теория
### NaN: «не число» типа number
**NaN** (Not-a-Number) — особое число, появляющееся, когда «числовая» операция «не дала» числа: 0 / 0, Number("abc"), Math.log(-1). Две «болезни» NaN:
1. **NaN !== NaN** — NaN «не равен» даже самому себе (по спецификации). Проверка: Number.isNaN(x) (строгая, «только для» number) или x !== x (кратко, работает всегда);
2. **typeof NaN === "number"** — «тип» number, но «смысл» «не число». Для «настоящей» проверки числа — Number.isFinite(x) (true только для «конечных» чисел: не NaN, не Infinity).

**Infinity** — «бесконечность»: 1 / 0 → Infinity, -1 / 0 → -Infinity. Арифметика «работает»: Infinity + 1 → Infinity, Infinity - Infinity → NaN.

### Float: 0.1 + 0.2 !== 0.3
Все числа в JS — **double-precision float** (64 бит, как в Python/Java). Двоичная запись 0.1 — бесконечная (как 1/3 в десятичной), и «хранится» с округлением: 0.1 + 0.2 → 0.30000000000000004. «Сюрпризы»: 0.3 - 0.1 → 0.19999999999999998, 1.005.toFixed(2) → "1.00" (а не "1.01" — 1.005 «хранится» как 1.00499999...).

Как сравнивать дроби «без сюрпризов»:
- **epsilon**: Math.abs(a - b) < 1e-9 — «равны с точностью до погрешности»;
- **целые «копейки»**: цены храните в копейках (1990, не 19.90) — арифметика «честная»;
- **Math.round** «для отображения» — не «для сравнения».

### Math: округления и полезное
- **Math.round(x)** — «до целого» (0.5 → 1, -0.5 → 0 — «в плюс»);
- **Math.floor(x)** — «вниз» (2.9 → 2, -2.1 → -3), **Math.ceil(x)** — «вверх» (2.1 → 3);
- **x.toFixed(2)** — «строка» с 2 знаками (4.5 → "4.50") — для отображения денег/процентов;
- **x.toPrecision(n)** — n «значимых» знаков;
- **Math.min(...arr), Math.max(...arr)** — «мин/макс» массива (spread, урок 13);
- **Math.random()** — [0, 1) — «случайное»; **Math.trunc(x)** — «отбросить» дробь.

TIP: для «денег» — храните целые (копейки/центы), считаете в целых, «показываете» через / 100 с toFixed(2). «Классика» бага: 19.9 * 3 → 59.699999999999996 — а «в копейках» 1990 * 3 → 5970 — «честно».

NOTE: JS «не различает» int/float (одный тип number). Для «больших» целых (> 2^53 ≈ 9 * 10^15) — bigint: 9007199254740993n + 1n (операции — только «между» bigint и bigint: 1n + 1 → TypeError).

## Пример
```js
// NaN и его «болезни»:
console.log(0 / 0);                    // NaN
console.log(NaN === NaN);              // false (знаменитое)
console.log(Number.isNaN(NaN));        // true
console.log(Number.isFinite(1 / 0));   // false (Infinity)

// Float:
console.log(0.1 + 0.2);                // 0.30000000000000004
console.log(0.1 + 0.2 === 0.3);        // false
console.log(Math.abs((0.1 + 0.2) - 0.3) < 1e-9); // true (epsilon)

// Округления:
console.log(Math.round(2.5), Math.round(-2.5)); // 3 0
console.log(Math.floor(2.9), Math.ceil(2.1));   // 2 3
console.log((4.5).toFixed(2));         // "4.50" (строка!)
console.log((19.9 * 3).toFixed(2));    // "59.70" — но храните в копейках

// Мин/макс:
const temps = [3, 17, -4, 25];
console.log(Math.min(...temps), Math.max(...temps)); // -4 25
```
Разбор: NaN «ловите» через Number.isNaN/Number.isFinite (не через ===). Дроби «сравнивайте» через epsilon или целые. toFixed «возвращает» строку (для «показа», не для «дальнейших» вычислений).

## Частые ошибки
WARN: a === b «для» float-результатов — 0.1 + 0.2 «не равно» 0.3; «сравнивайте» через Math.abs(a - b) < 1e-9 или целые (копейки).
WARN: NaN «проверяете» через === null / === undefined / isNaN «без» Number. — глобальный isNaN("5") → false («превращает» строку!); используйте Number.isNaN (строгий).
WARN: toFixed «для» вычислений — возвращает СТРОКУ: 1.5 + 0.1 «не сработает»; «считайте» числами, «показывайте» строкой.
WARN: Math.round(-2.5) «ждёте» -3 — «даст» 0 (округление «в плюс»); для «симметричного» — Math.trunc + «свои» правила.
WARN: «храните» цены/проценты как float «и» складываете — копейки «теряются»; целые (копейки) — «всегда».
