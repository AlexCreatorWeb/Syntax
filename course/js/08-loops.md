# Урок 8. Циклы: for, while, for...of, break/continue

## Цель
После урока студент сможет: выбрать цикл под задачу (for — «по счётчику», for...of — «по элементам», while — «по условию»); использовать break/continue «осмысленно»; избегать «бесконечных» циклов и «ошибок» границы.

## Теория
### for: «классический» цикл «по счётчику»
```js
for (let i = 0; i < n; i++) { ... }
```
Три «части»: инициализация (let i = 0), условие (i < n), шаг (i++). «Порядок»: init → проверка → тело → шаг → проверка... Цикл «заканчивается», когда условие «стало» false. **i < n** — «правильная» граница (индексы 0..n-1); i <= n — «лишний» «проход» (классика «ошибки границы»).

### for...of: «по элементам» коллекции
```js
const fruits = ["яблоко", "груша", "слива"];
for (const fruit of fruits) { console.log(fruit); }
```
for...of «ходит» по «значениям» (массив, строка, Map, Set). «Без» «счётчика» — «чисто» и «безопасно» (нет «ошибки границы»). Для «индекса» — for...of «с» [...arr.entries()] «или» классический for (урок 17: forEach/map — «функциональный» «обход»).

### while и do...while: «по условию»
```js
while (condition) { ... }        // «проверяет» ДО «тела»
do { ... } while (condition);    // «тело» «хотя бы» 1 раз
```
while — «когда» «не знаете» «число» «проходов» («пока» «не найдено», «пока» «не валидно»). **Обязательно** «меняйте» «условие» «внутри» (иначе «бесконечный» цикл). do...while — «когда» «тело» «должно» «выполниться» «хотя бы» 1 раз (даже «если» условие «сразу» false).

### break и continue
- **break** — «выход» из цикла «сразу»: for (...) { if (found) break; ... };
- **continue** — «пропустить» «текущую» итерацию («дальше»): for (...) { if (skip) continue; ... };

«Уместно»: break — «нашли» «что искали» («дальше» «бесполезно»). continue — «этот» элемент «не подходит» («пропустить»). «Неуместно»: break «из» «вложенного» цикла «внешний» (break «только» «ближайший» — для «внешнего» — label «или» «флаг»).

TIP: «цикл «по массиву» «с» «счётчиком» (for i < arr.length) — «работает», но for...of «чище» (нет «индекса», нет «ошибки границы»). for (i) — «когда» «нужен» «индекс» (или «переделка» «на» forEach/map — урок 17).

NOTE: «бесконечный» цикл (while (true) «без» break, for («без» «шага»)) — «зависнет» «страницу» (JS «однопоточный» — урок 38). «Остановите» — F5 (обновить) / DevTools → Pause. «Защита»: «счётчик» «максимум» «итераций» (let tries = 0; while (!ok && tries < 100) { ...; tries++; }).

## Пример
```js
// for «по счётчику»:
let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}
console.log(sum); // 55

// for...of «по элементам»:
const items = ["js", "css", "html"];
for (const item of items) {
  console.log("item:", item);
}

// while «по условию»:
let n = 32;
let steps = 0;
while (n > 1) {
  n = n / 2;
  steps++;
}
console.log("steps:", steps); // 5 (32→16→8→4→2→1)

// break: «нашли» — «стоп»:
const list = [3, 7, 12, 42, 99];
for (const x of list) {
  if (x > 40) { console.log("нашли:", x); break; }
}

// continue: «пропустить» чётные:
for (let i = 1; i <= 6; i++) {
  if (i % 2 === 0) continue;
  console.log("нечётный:", i);
}
```
Разбор: for — «счётчик», for...of — «элементы» (чище), while — «пока» «условие». break — «стоп» («нашли»), continue — «пропустить» («этот» «не тот»).

## Частые ошибки
WARN: i <= n «вместо» i < n — «лишний» «проход» (индекс n «вне» «границы» → undefined); «граница» — «строго» < (для 0-based).
WARN: while («без» «изменения» «условия» в «теле» — «бесконечный» цикл (страница «зависнет»); «меняйте» «условие» «каждую» «итерацию».
WARN: for (let i = 0; i < n) («без» i++) — «бесконечный»; «шаг» — «обязателен» (и «не» i = i + 0).
WARN: break «из» «вложенного» цикла «хотите» «внешний» — break «только» «ближайший»; «внешний» — «флаг» «или» «функция» «с» return.
WARN: for...in «по» «массиву» — for...in «ходит» по «ключам» (строки "0","1",...) «и» «наследованным»; «по массиву» — for...of (или forEach).
