# Урок 17. Обход массива: forEach, map, filter

## Цель
После урока студент сможет: выбрать между forEach (действие), map (преобразование), filter (отбор); написать «цепочки» методов (arr.filter(...).map(...)); объяснить, что «все» «возвращают» «новый» «массив», «кроме** forEach (undefined).

## Теория
### «Три» «основных** «обхода**
- **forEach(cb)** — «действие** «для** «каждого** «элемента» («без** «результата»: «возвращает** undefined). cb «получает» (element, index, array). «Для** «побочных** «эффектов** (console, «сбор» «в** «другой» «массив»).
- **map(cb)** — «преобразование**: «новый** «массив** «того** «же» «длина», «элементы** = cb(element, index, array). «Классика**: nums.map(x => x * 2).
- **filter(cb)** — «отбор**: «новый** «массив** «из** «элементов**, «где** cb «вернул** truthy: nums.filter(x => x > 0).

«Все** «три** «не** «мутируют** «исходный** (map/filter «создают** «новые»). «Разница**: map «превращает** «каждый** → «новый», filter «выбирает** «часть», forEach «ничего** «не** «возвращает**.

### «Цепочки** «методов** (пайплайны)
«Методы** «возвращают** «массивы** → «цепляются**:
```js
const result = users
  .filter((u) => u.active)          // «только** «активные»
  .map((u) => u.name.toUpperCase()) // «имена** «вверх»
  .sort();                           // «по** «алфавиту»
```
«Читаемость**: «каждый** «шаг** — «одна** «операция» (как «конвейер»). «Это** «функциональный** «стиль** (чистые «преобразования», урок 15).

### «Каждый** «когда**
- **forEach** — «эффекты** (лог, «сбор» «в** «состояние», «вызовы** API «по** «элементам») — «но** «часто** «можно** «заменить** «на** map/filter (чистей);
- **map** — «из** «каждого** «элемента** «создать** «новый» (преобразование, «проецирование» «свойств»);
- **filter** — «оставить** «подходящие» (условие).

«Паттерн** «извлечения** «свойств**: users.map(u => u.name) — «массив** «имён** «из** «объектов» (очень «часто»).

TIP: «forEach** «с** ««сборкой** «в** «массив» (acc.push) — «замените** «на** map (короче, «чище»: map «делает** «то же» «встроенно»). «Исключение**: «сбор** «с** «условием** «и** «преобразованием» — «иногда» «удобнее» filter(...).map(...).

NOTE: «порядок** «вызова** «колбэка» — «от** 0 «до** length - 1 (как for). «Мутация** «массива** «во** «время** «обхода** (push «в» forEach) — «непредсказуемо» (length «меняется**); «избегайте**.

## Пример
```js
const users = [
  { name: "a", age: 15, active: true },
  { name: "b", age: 25, active: false },
  { name: "c", age: 35, active: true },
];

// forEach — «действие»:
users.forEach((u, i) => console.log(i, u.name));

// map — «преобразование»:
const names = users.map((u) => u.name);          // ["a", "b", "c"]
const labels = users.map((u) => `${u.name}: ${u.age}`); // ["a: 15", ...]
console.log(names, labels);

// filter — «отбор»:
const adults = users.filter((u) => u.age >= 18); // [b, c]
const active = users.filter((u) => u.active);    // [a, c]
console.log(adults.length, active.length);

// «Цепочка»:
const activeNames = users
  .filter((u) => u.active)
  .map((u) => u.name.toUpperCase());
console.log(activeNames); // ["A", "C"]
```
Разбор: forEach — «эффекты», map — «из каждого → новый», filter — «оставить подходящие». «Цепочки** — «конвейер» (filter → map → sort).

## Частые ошибки
WARN: «забыли** return «в** «колбэке** «map» (стрелка «с** {}: (x) => { x * 2 } → undefined в «каждом» «слоте»); «одно** «выражение** → «без** {}.
WARN: forEach «для** «преобразования** — «сборка** «через** acc.push (можно map); «результат** forEach — «всегда** undefined (не «массив»).
WARN: «мутация** «массива** «во** «forEach» (push «в** «обходимый**) — «длина** «меняется**, «поведение** «непредсказуемо».
WARN: map «ожидаете** «изменение** «оригинала** — «нет**: «новый** «массив» (orig «не» «изменён», «кроме** «вложенных** «ссылок», урок 21).
WARN: «порядок** «цепочки** (filter «после** «map») — «иногда** «дороже** (map «создаёт** «больше** «элементов»); «отбирайте** «сначала» (filter → map).
