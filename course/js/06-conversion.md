# Урок 6. Преобразование типов: неявное и явное

## Цель
После урока студент сможет: объяснить, как JS «превращает» типы в арифметике (+, -, сравнениях); выбрать явное преобразование (Number, String, Boolean) и «прочитать» его результат (NaN, "null", "12,34"); предсказать результат «экспериментов» (5 + "5", "5" - 1, [] + []).

## Теория
### «Правила» неявных превращений
JS «превращает» типы «сам» в «определённых» местах:
- **арифметика** (+, -, *, /, %, **): «операнд» → number: "5" - 1 → 4, "5" * 2 → 10;
- **исключение — + (конкатенация)**: если ХОТЯ БЫ один операнд — string → «оба» в строку: 5 + "5" → "55", "a" + "b" → "ab", [] + [] → "";
- **сравнения** (<, >, <=, >=): «оба» → number: "5" > "42" → false (5 < 42, а НЕ "5" > "4"!), "10" < "9" → true;
- **=== / !==**: «НЕ превращают» (строгое, урок 5);
- **==**: «превращают» по «сложным» правилам (null/undefined «равны», string/number — через Number).

**Операторы с «точным» преобразованием**:
- **unary - (унарный минус)**: -"5" → -5 (string → number);
- **+ (унарный плюс)**: +"5" → 5 (string → number, «как» Number());
- **!" " (двойное отрицание)**: !!value → boolean («перевод» в boolean «в чистом» виде).

### Явные превращения: Number, String, Boolean
- **Number(x)**: "5" → 5, "  5  " → 5 (пробелы «обрезаются»), "" → 0 (пустая строка — 0!), "5px" → NaN, null → 0, true → 1, undefined → NaN;
- **String(x)**: 5 → "5", true → "true", null → "null" (не "undefined"!), undefined → "undefined", {a:1} → "[object Object]" (урок 27: JSON.stringify);
- **Boolean(x)**: truthy → true, falsy → false (урок 5).

**Числовые «функции-помощники»**: parseInt("42px") → 42 (читает «число» «с начала»), parseFloat("3.14px") → 3.14, Number("3.14px") → NaN (строгий). Для «размера с единицей» — parseInt/parseFloat.

### «Эксперименты» (запомните «логику», не «результаты»)
- 5 + "5" → "55" (+ «видит» string → конкатенация)
- "5" + 5 + 5 → "555" (слева направо: "5" + 5 → "55", "55" + 5 → "555")
- 5 + 5 + "5" → "105" (сначала 5 + 5 → 10, 10 + "5" → "105")
- "5" - 1 → 4 (- «только» number → «превратил» "5")
- [] + [] → "" (оба → String: "" + ""), [] + {} → "[object Object]", {} + [] → 0 ({} «съедается» как блок — «сюрприз»!)
- "0" || true → "0" ("0" truthy — «заберёт» строку)

TIP: «неуверены» в результате «эксперимента» — «проверьте» в консоли (10 секунд). «Лучший» «предсказатель» — «ваш» опыт: «запишите» «сюрприз» в код-комментарий («5 + "5" → "55", потому что + конкатенация»).

NOTE: преобразование «в одну сторону» «необратимо»: Number("hi") → NaN («информация потеряна»), а String(5) → "5" (Number("5") вернёт 5). «Храните» данные «в нужном» типе (числа — number, тексты — string) — «не превращайте» «на лету» «повторно».

## Пример
```js
// Неявные:
console.log(5 + "5");     // "55" (+ конкатенация)
console.log("5" - 1);     // 4   (- только number)
console.log("10" < "9");  // true (сравнение → number: 10 < 9? нет, 10 > 9... проверьте!)
console.log(-"5");        // -5
console.log(!!"hi");      // true
console.log(!!"");        // false

// Явные:
console.log(Number("5"));      // 5
console.log(Number("  5  "));  // 5 (пробелы)
console.log(Number(""));       // 0 (пустая строка!)
console.log(Number("5px"));    // NaN
console.log(Number(null));     // 0
console.log(Number(undefined));// NaN

console.log(String(null));     // "null" (не "undefined"!)
console.log(String(undefined));// "undefined"
console.log(String({ a: 1 })); // "[object Object]"

console.log(parseInt("42px"));     // 42
console.log(parseFloat("3.14px")); // 3.14

// «Эксперименты»:
console.log("5" + 5 + 5);   // ???
console.log(5 + 5 + "5");   // ???
console.log([] + []);       // ???
```
Разбор: + «двойственный» (число/конкатенация — зависит от операнда), - «честный» (только число). Number — «строгий» (NaN при «мусоре»), parseInt — «терпимый» (читает «число» «с начала»).

## Частые ошибки
WARN: a + b «для» чисел, где a — строка (из input/API) — конкатенация ("5" + 3 → "53"); «превращайте» явно: Number(a) + b.
WARN: Number("5px") «дёте» «размер» — NaN; для «числа с единицей» — parseInt("5px") → 5.
WARN: "10" < "9" «ждёте» false (лексикографически "1" < "9") — «даст» true (< «превратил» в числа: 10 > 9... проверьте, что «на самом деле»).
WARN: String(obj) «дёте» «красивый» объект — "[object Object]"; «сериализуйте» JSON.stringify(obj) (урок 27).
WARN: input.value «сравниваете» === (числом): input.value — СТРОКА: "5" === 5 → false; Number(input.value) === 5.

## Практическое задание
1. В скелете задания прогоните «эксперименты» — «прочитайте» результаты, «объясните» каждый одной фразой (в комментарии).
2. Напишите toNumber(s): Number(s), если «валидное» число (не NaN), иначе 0. Проверьте: "5", "5px", "", null, "hi".
3. Напишите concat(a, b): «числовое» сложение, если оба «числовые» (Number «без» NaN), иначе «строковая» конкатенация.
4. «Разберите» "12,34" (европейский формат) → 12.34 (replace(",", ".") + Number).
5. Бонус: напишите isNumeric(s): true, если Number(s) «не NaN» (и s «не пустая»). Проверьте: "5", "5.5", "", "  ", "hi".
