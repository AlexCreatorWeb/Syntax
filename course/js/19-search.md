# Урок 19. find, some, every и includes

## Цель
После урока студент сможет: найти элемент (find/findIndex) и «индекс» «первого» «подходящего»; проверить «есть ли» (some) / «все ли» (every) / «содержит ли» (includes); выбрать «правильный» «метод» «под» «вопрос» («один» / «какой-то» / «все»).

## Теория
### «Вопросы» «о** «массиве** (и «методы» «на** «них»)
- **«есть** «ли» «элемент**?» — **includes(x)** → true/false (строгое ===). «Для** «объектов** — «ссылка» (урок 21): «поищите** «свойство** через** some.
- **«какой-то** «подходит**?» — **some(cb)** → true, «если** ХОТЯ БЫ ОДИН «вернул** truthy». «Останавливается** «на** «первом» (остальные «не» «проверяются»);
- **«все** «подходят**?» — **every(cb)** → true, «если** ВСЕ «вернули** truthy». «Пустой** «массив** → true (нет «контрпримеров»!);
- **«найди** «первый** «подходящий**» — **find(cb)** → «элемент** (или undefined). «Останавливается** «на** «первом»;
- **«найди** «индекс**» — **findIndex(cb)** → «индекс** (или -1).

«Паттерн** «колбэка**: (item, index, array) => boolean (условие). «Все** «пять** «не** «мутируют**.

### «Как** «читать** «результаты**
- find «не** «нашёл** → undefined (проверка: if (found) { ... }, «не** === undefined «— «короче);
- findIndex «не** «нашёл** → -1 (проверка: if (i !== -1) { ... });
- some/every — true/false («используйте** «в** «условиях**);
- includes — true/false («только** «примитивы** «надежно»; «объекты** — «по** «ссылке»).

### «Когда** «что** «выбирать**
- «один** «конкретный** «элемент** (первый) → find;
- «индекс** «для** «замены/удаления** → findIndex;
- «есть** «ли** «хотя бы» → some («дешевле**, чем filter().length — «останавливается** «раньше»);
- «все** «подходят** → every;
- «содержит** «значение** → includes.

«Анти-паттерн**: arr.filter(cb).length > 0 «вместо** some (filter «обходит** «все», some «останавливается** «на** «первом»).

TIP: find «в** ««большом** «массиве** (10К+) — «линейный** (O(n)). «Частые** «поиски** «по** «ключу** — «объект/Map» (ключ → «значение**, O(1)): const byId = Object.fromEntries(items.map(i => [i.id, i])).

NOTE: «пустой** «массив**: every → true (нет «контрпримеров»), some → false (нет «примеров»), find → undefined, includes → false. «Казус**: [].every(() => false) → true («логика**: «все» «подходят», «потому что «их** «нет»).

## Пример
```js
const users = [
  { id: 1, name: "a", age: 15 },
  { id: 2, name: "b", age: 25 },
  { id: 3, name: "c", age: 35 },
];
const tags = ["js", "css", "html"];

// find / findIndex:
const adult = users.find((u) => u.age >= 18);
console.log(adult?.name); // "b" («первый** «взрослый»)
const i = users.findIndex((u) => u.id === 3);
console.log(i); // 2

// some / every:
console.log(users.some((u) => u.age < 18));  // true («есть** «ребёнок»)
console.log(users.every((u) => u.age >= 18)); // false («не** «все** «взрослые»)

// includes:
console.log(tags.includes("css"));  // true
console.log(tags.includes("go"));   // false

// «Анти-паттерн** vs some:
console.log(users.filter((u) => u.age < 18).length > 0); // true («медленнее» some)

// find «по** «ключу** «объекта** («по** «свойству», «не** «ссылке»):
const byName = (name) => users.find((u) => u.name === name);
console.log(byName("c")?.id); // 3
```
Разбор: «вопрос** → «метод»: «один** → find, «какой-то** → some, «все** → every, «содержит** → includes. find «по** «свойству** (не «ссылке»).

## Частые ошибки
WARN: filter(cb).length > 0 «вместо** some — «медленнее** (полный «обход** vs «остановка** «на** «первом»).
WARN: find «ожидаете** «ВСЕ** «подходящие** — «только** «ПЕРВЫЙ»; «все** — filter.
WARN: includes «для** «объектов** — «по** «ссылке** (всегда false «для** ««нового**» {a:1}); «ищите** «свойство** через** some/find.
WARN: findIndex «проверяете** === 0 (первый «элемент**) — «перепутаете** «с** ««не** «нашёл**» (-1); «проверяйте** !== -1.
WARN: «пустой** «массив** + every — true («сюрприз»: [].every(x => false) → true); «учитывайте** «длинку** «до** «every».

## Практическое задание
1. В скелете задания реализуйте findBy(users, key, value): find «по** «свойству**.
2. Напишите hasAdults(ages): some (есть «кто-то** ≥ 18).
3. Напишите allUnique(arr): «все** «элементы** «уникальные» (every + includes, «индекс** «не** «текущий»).
4. Напишите firstIndex(arr, pred): findIndex + «обёртка** «на** undefined/-1 (return -1 «если» «нет»).
5. Бонус: «поиск** «по** «ключу** «в** «10К** «элементов**: «цикл** «vs** «Object.fromEntries — «сравните** «идею** (O(n) «каждый** «раз** vs «однократная** «таблица»).
