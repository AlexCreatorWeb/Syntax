# Урок 23. Деструктуризация и spread для объектов

## Цель
После урока студент сможет: «разобрать** «объект/массив** «в** «переменные» (деструктуризация), «переименовать** «и** «задать** «дефолты**; «расширить** «объект** через** spread; «применить** «деструктуризацию** «к** «параметрам** «функции**.

## Теория
### Деструктуризация: «извлечь** «свойства** «в** «переменные»
**Объект**:
```js
const user = { name: "A", age: 25, city: "MSK" };
const { name, age } = user;        // name = "A", age = 25
const { city: c, zip = "101000" } = user; // «переименование** (city → c), «дефолт** (zip «если» «нет»)
const { address: { city } } = user; // «вложенная** (user.address.city → city)
```
«Правила**: «имя** «переменной** = «ключ** (по «умолчанию»); «переименование**: { key: newName }; «дефолт**: { key = default } («срабатывает** «только** «при» undefined); «вложенная**: «вложенные** «скобки».

**Массив**:
```js
const [first, second, ...rest] = [1, 2, 3, 4]; // first=1, second=2, rest=[3,4]
const [a, , c] = [1, 2, 3];                    // «пропустить** «второй» (a=1, c=3)
const [x = 10] = [];                           // «дефолт** (x=10)
```
«Порядок** «важен** (позиции**, «не** «имена»). «Swap**: [a, b] = [b, a] — «классика**.

### Spread: «расширить** «объект** «и** «массив**
«Объект**: const extended = { ...base, ...overrides, extra: 1 } — «поверхностное** «объединение** («позднее** «перебивает**):
```js
const defaults = { theme: "dark", size: 16 };
const options = { ...defaults, size: 20 }; // { theme: "dark", size: 20 }
```
«Массив**: const merged = [...a, ...b] (урок 13). «С** «объектом** «в** «массиве**: [{ ...item, active: true }].

### Деструктуризация «в** «параметрах** «функции**
```js
function greet({ name, greeting = "Привет" }) {
  return `${greeting}, ${name}!`;
}
greet({ name: "A" }); // "Привет, A!"
```
«Параметр** — «объект**, «разбирается** «в** «локальные** «переменные». «ЧИТАЕМЕЕ** «API** (имена «аргументов** «видны** «по** «ключам), «дефолты** «в** «одном** «месте. «Массив**: function f([x, y]) { return x + y; } f([1, 2]) → 3.

TIP: «извлекайте** «только** «нужное** (const { name } = user, «не** «весь** «объект** «в** «переменную»). «В** «компонентах/функциях** «с** «объектами** «аргументов** — «деструктуризация** «в** «подписи** (чище, «дефолты** «видны).

NOTE: «деструктуризация** «создаёт** «копии** «значений** (ссылки «для** «объектов**): const { address } = user — address «—» «та же** «ссылка** (мутация «изменит** user.address). «Объект** «с** «несколькими** «свойствами** «не** ««разберётся** «в** «одну** «переменную** — «только** «по** «свойствам».

## Пример
```js
const user = {
  name: "A",
  age: 25,
  address: { city: "MSK", zip: "101000" },
};

// «Объект**:
const { name, age } = user;
console.log(name, age); // A 25
const { city } = user.address;
console.log(city); // MSK
const { phone = "нет" } = user;
console.log(phone); // "нет" («дефолт»)
const { name: userName } = user;
console.log(userName); // A («переименование»)

// «Массив**:
const [first, ...rest] = [10, 20, 30];
console.log(first, rest); // 10 [20, 30]
let a = 1, b = 2;
[a, b] = [b, a];
console.log(a, b); // 2 1 («swap»)

// Spread:
const defaults = { theme: "dark", size: 16 };
const options = { ...defaults, size: 20 };
console.log(options); // { theme: "dark", size: 20 }

// «В** «параметрах**:
function greet({ name, greeting = "Привет" }) {
  return `${greeting}, ${name}!`;
}
console.log(greet({ name: "B" })); // "Привет, B!"
```
Разбор: «извлечь** → деструктуризация, «расширить** → spread. «В** «параметрах** — «ЧИТАЕМЫЙ** «API**.

## Частые ошибки
WARN: const { a, b } = obj «ожидаете** «объект** «с** «ключами** a/b — «нет** «ключа** → undefined («без** «дефолта»); «проверьте** «ключи** «или** «дайте** «дефолт** (a = default).
WARN: «порядок** «массива** «в** «деструктуризации** «важен** (позиции**, «не** «имена»: [x, y] = [1, 2] → x=1 «всегда**).
WARN: «вложенная** «деструктуризация** «без** «проверки**: const { a: { b } } = obj — «если** obj.a «—» null → TypeError; «дефолт**: { a: { b } = {} } «или** «проверка».
WARN: spread «ожидаете** «глубокое** «объединение** — «поверхностное»: { ...a, ...b } «с** «вложенными** «объектами** — «целиком** «из** b (не «слить** «свойства»); «глубокое** — «вручную** «или** «библиотека».
WARN: [a, b] = [b, a] «забыли** «скобки** «слева** — SyntaxError (а «—» «присваивание** «в** «массиве»); «скобки** «обязательны».
