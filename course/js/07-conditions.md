# Урок 7. Условные конструкции: if, тернарник, switch

## Цель
После урока студент сможет: написать if/else if/else с «осмысленными» условиями; выбрать между if-цепочкой, тернарником и switch; собрать «мультисостояние» (статусы, уровни, роли) без вложенного «спагетти».

## Теория
### if/else if/else: «ветвление» по условию
```js
if (condition1) { ... }
else if (condition2) { ... }
else { ... }
```
Условие — «любое» выражение (переводится в boolean, урок 5). if «без» else — «опциональный» блок. else if — «цепочка» (проверяются «по порядку», «первое» truthy — «остановка»). else — «иначе» (без условия).

**Правило «одного» смысла**: условие «читается» как «предложение»: if (user.isAdmin) — «хорошо», if (user.role === "admin") — «явнее». Избегайте «двойных» отрицаний: if (!!flag) → if (flag), if (!(a === b)) → if (a !== b).

### Тернарный оператор: «короткий» if/else
`condition ? valueIfTrue : valueIfFalse` — «выражение» (возвращает значение, «не блок»):
```js
const label = age >= 18 ? "взрослый" : "ребёнок";
```
«Хорошо» для «одного» значения/вызова: const x = flag ? a : b; console.log(flag ? "ok" : "err"). «Плохо» для «блоков» (несколько строк) — «читаемость» «падает» (и «вложенные» тернарники — «анти-паттерн»).

### switch: «мультиветвление» по значению
```js
switch (status) {
  case "active":   doActive();  break;
  case "paused":   doPaused();  break;
  default:         doUnknown();
}
```
switch «сравнивает» === (строгое, урок 5): case "1" «не поймает» 1. **break** «обязателен» в «конце» case (иначе «сквозь» в «следующий»). default — «иначе» (как else). switch «хорош» для «перечисления» конкретных значений (статусы, роли, команды); «плох» для «диапазонов»/«сложных» условий (тут if-цепочка).

### Паттерны «мультисостояний»
- **ранний выход** (early return): «плохие» случаи «сначала», «основной» — «без» вложенности: if (!user) return; if (!user.active) return; // «дальше» — «активный» user;
- **таблица-объект** вместо switch: const handlers = { active: fn1, paused: fn2 }; handlers[status]?.(); — «расширяется» «без» правки «цепочки».

TIP: «вложенные» if «глубже» 2–3 уровней — «запах» «спагетти»: «разбейте» на функции (early return + «названия» условий: const isValid = a && b && c; if (!isValid) return;).

NOTE: if («без» скобок) — «одно» выражение: if (x) doA(); doB(); — doB «выполнится» «всегда» (не «в» if)! Фигурные скобки «всегда» (даже для «одной» строки).

## Пример
```js
const score = 85;
const role = "admin";
const status = "paused";

// if/else if:
const grade = score >= 90 ? "A" : score >= 75 ? "B" : score >= 60 ? "C" : "D";
console.log(grade); // B (вложенный тернарник — «для» «демо», «не» для «практы»)

// if-цепочка «честная»:
let label;
if (score >= 90) label = "отлично";
else if (score >= 75) label = "хорошо";
else if (score >= 60) label = "удовлетворительно";
else label = "слабо";
console.log(label); // хорошо

// switch:
switch (status) {
  case "active": console.log("идёт"); break;
  case "paused": console.log("пауза"); break;
  default: console.log("неизвестно");
}

// switch «как» таблица:
const messages = { admin: "полный доступ", user: "основной", guest: "только чтение" };
console.log(messages[role] ?? "гость"); // полный доступ

// early return:
function checkUser(user) {
  if (!user) return "нет пользователя";
  if (!user.active) return "неактивен";
  return "ok: " + user.name;
}
console.log(checkUser({ name: "A", active: true })); // ok: A
console.log(checkUser(null));                         // нет пользователя
```
Разбор: тернарник — «одна» «ценность», if-цепочка — «диапазоны», switch — «конкретные» значения, таблица — «расширяемое» «мульти». early return — «чистый» «поток».

## Частые ошибки
WARN: if («без» {}) «для» «двух» строк — вторая «выполнится» «всегда»; {} «всегда» (даже «одна» строка).
WARN: switch «без» break — «сквозь» в «следующий» case (val «не тот», но «код» «следующего» «выполнится»); break «в конце» каждого case.
WARN: === «в» case «не» для «числа»: case "1" «не поймает» 1 (switch ===); «приведите» «тип» «до» switch (Number(x)).
WARN: «вложенные» тернарники (a ? b : c ? d : e) — «нечитабельно»; if-цепочка «или» функция «с» «названиями».
WARN: if (x = 5) «вместо» if (x === 5) — «присваивание» «в» условии (x «станет» 5, условие truthy); «опечатка» «классика».
