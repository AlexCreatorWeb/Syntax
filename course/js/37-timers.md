# Урок 37. Таймеры, debounce и throttle

## Цель
После урока студент сможет: «отложить** «код** (setTimeout) «и** ««повторять** (setInterval) «с** «очисткой** (clearTimeout/clearInterval); «понять**, «почему** ««точное** «время** «не** «гарантируется** (event loop**); «написать** «debounce** «и** «throttle** «и** «применить** «к** «поиску/ресайзу**.

## Теория
### setTimeout «и** setInterval: «отложенный** «код**
```js
const id = setTimeout(() => console.log("через 1с"), 1000);
clearTimeout(id); // «отменить** («до** ««срабатывания**
const id2 = setInterval(() => console.log("тик"), 500);
clearInterval(id2); // «остановить** ««повтор**
```
**setTimeout(fn, ms)** — «вызвать** fn «через** ms (один** «раз**). **setInterval(fn, ms)** — «вызывать** «каждые** ms (пока** «не** «clearInterval**). «Возвращают** «id** «(для** «очистки**).

«Важно**: ««точное** «время** «не** «гарантируется** «(event loop, «урок** 38**): «если** ««поток** «занят** «(«тяжёлый** «цикл**), «таймер** ««сработает** «позже**. «Минимальный** ««задержка** «~4мс «(«вложенные** «setTimeout** «(4+ уровня** — 1мс**).

### «Почему** «debounce/throttle**
«События** ««срабатывают** ««часто** (input «каждый** «символ**, «resize** «каждый** «пиксель** «окна**, «scroll** «каждый** ««пиксель** «скролла**). «Вызывать** ««тяжёлый** «код** «(fetch «поиску**, «перерасчёт** «layout** «каждый** «раз** «—» ««тормоз** (««отправляем** «100 «запросов** «на** ««слово**).

- **debounce** ( ««отложить** ««до** ««тишины** «): «вызвать** «функцию** «через** «N ms «после** ««последнего** «вызова** («пока** ««события** ««идут** — «таймер** ««перезапускается**). «Для** «поиска** «(«отправить** «запрос** «через** 300ms «после** ««последнего** «символа**), «авто-сохранения**.
- **throttle** ( ««не** ««частее** «каждых** N ms «): «вызвать** ««не** ««реже** «одного** «раза** «в** «N ms (промежуточные** ««сигналы** ««схлопываются**). «Для** «scroll/resize** «(«обновлять** ««позицию** «каждые** 100ms «вместо** ««каждого** «пикселя**).

### «Реализация** («закрытия** «(урок** 12** «—» ««классика**):
```js
function debounce(fn, ms) {
  let id;
  return (...args) => {
    clearTimeout(id);
    id = setTimeout(() => fn(...args), ms);
  };
}
function throttle(fn, ms) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= ms) { last = now; fn(...args); }
  };
}
```
«Применение**: const search = debounce((q) => fetchAPI(q), 300); input.addEventListener("input", (e) => search(e.target.value));

TIP: «debounce** «для** ««действия** «после** ««серии** «событий** «(поиск**, «сохранение** «(«один** ««итог** «вместо** ««сери**). «Throttle** «для** ««поточных** «(scroll**, «resize** «(««регулярные** ««обновления** «(«не** ««пропускать** ««последнее** «состояние** «—» «trailing** «call** «(продвинутый** «вариант**).

NOTE: ««фоновые** «вкладки** (браузер** ««уходит** «в** ««фон**) — «таймеры** ««гаснут** «(throttle «до** «1/с** «и** ««больше** «задержка**). «Не** ««зависите** «от** ««точной** ««периодичности** «в** ««фоне**.

## Пример
```js
// setTimeout / «очистка**:
const id = setTimeout(() => console.log("поздно"), 2000);
clearTimeout(id); // «не** «сработает**

// setInterval «с** ««остановкой**:
let ticks = 0;
const int = setInterval(() => {
  ticks++;
  console.log("тик", ticks);
  if (ticks >= 3) clearInterval(int); // «стоп** «после** «3
}, 300);

// ««Дембос**:
function debounce(fn, ms) {
  let id;
  return (...args) => { clearTimeout(id); id = setTimeout(() => fn(...args), ms); };
}
const search = debounce((q) => console.log("поиск:", q), 500);
search("j"); search("js"); search("jss"); // «только** «"jss"** «после** ««тишины**

// ««Троттл**:
function throttle(fn, ms) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= ms) { last = now; fn(...args); }
  };
}
const onScroll = throttle(() => console.log("scroll:", Date.now()), 1000);
for (let i = 0; i < 10; i++) onScroll(); // «только** «первый** «(остальные** ««схлопаны**
```
Разбор: setTimeout «—» «отложенный**, setInterval «—» «повторный**, debounce «—» ««после** ««тишины**, throttle «—» ««не** ««реже** ««раз** «в** N ms.

## Частые ошибки

WARN: «зависите** «от** ««точного** ««времени** «(«считать** ««секунды** «через** «setInterval «×60) — «event loop** ««сдвигает** «(«потеря** ««тика** «при** ««загрузке**); ««точное** ««время** — Date.now() «дифф**.
