# Урок 25. this и связывание: call, apply, bind

## Цель
После урока студент сможет: предсказать, «кто** this» «в** «разных** «контекстах** (метод, «обычная** «функция, «стрелка», «конструктор**); «связать** «this** «явно** (call/apply/bind); «избежать** «классических** «потерь** «this».

## Теория
### «Кто** this**: «правило** «вызова**
**this** — «ссылка** «на** «объект**, «через** «который** «вызвана** «функция». «Правила** «(по** «приоритету**):
1. **«вызов** «через** «объект** (obj.fn()) → this = obj;
2. **«вызов** «через** «call/apply/bind** (fn.call(obj)) → this = obj («явно**);
3. **«new** (new Fn()) → this = «новый** «объект» (конструктор**);
4. **«прямой** «вызов** (fn()) → this = «глобальный** «объект** (window) «или** undefined («в** «strict**);
5. **стрелка** — «нет** «своего** this: «берёт** «из** «окружения» (лексический, «место** «создания**).

«Примеры**:
```js
const obj = {
  value: 1,
  method() { return this.value; },
  arrow: () => this.value,
};
console.log(obj.method()); // 1 (this = obj)
console.log(obj.arrow());  // undefined (this «из** «окружения» — «не** obj)

const f = obj.method;
console.log(f());          // undefined (this «потерян** — «прямой** «вызов»)
console.log(f.call(obj));  // 1 («явное** «связывание**)
```

### call, apply, bind: «явное** «связывание**
- **fn.call(thisArg, arg1, arg2)** — «вызвать** «сразу** «с** «this» «и** «аргументами** («по** «одному»);
- **fn.apply(thisArg, [arg1, arg2])** — «то же**, «аргументы** «массивом**;
- **fn.bind(thisArg, ...preArgs)** — «новый** «функция** «с** «закреплённым** this» («вызвать** «позже**):
```js
const bound = obj.method.bind(obj);
console.log(bound()); // 1 («this** «закреплён»)
```
«Когда**: «колбэк** «теряет** this (setTimeout(() => ...) — «стрелка** «спасает**; «обычная** «функция** — bind); «займ** «функции** «из** «объекта** «и** «вызвать** «позже** (bind); «вызов** «с** ««чужим** this (call/apply «для** «переиспользования** «методов»).

### «Классические** «потери** «this
1. «метод** «извлечён** «в** «переменную**: const f = obj.method; f() — this «потерян**;
2. «колбэк** «обычной** «функции**: setTimeout(function () { this.x }, 100) — this «глобальный**;
3. «событие** «обработчик** «обычной** «функции**: el.onclick = function () { this } — this = «элемент** (ок), «но** «в** «вложенной** «функции** — «глобальный».

«Решения**: «стрелка** (берёт** «из** «окружения»), bind (явно**), «вызов** «через** «объект**.

TIP: «в** «модерном** «коде** «проблемы** «with** this «меньше**: «стрелки** «в** «колбэках** «(берут** «this** «из** «окружения»), «классы** «с** «стрелочными** «свойствами**. «this** «нужен** «в** «методах** «объектов/классов** — «там** «и** «работает**.

NOTE: «в** «модулях** (ES modules) «топ-уровневый** this — undefined («не** «window**). «Строгий** «режим** («модули** «— «всегда** «строгий**): «прямой** «fn() «даст** this = undefined (не window).

## Пример
```js
const obj = {
  value: 1,
  method() { return this.value; },
  arrow: () => this.value,
};

console.log(obj.method()); // 1 (this = obj)
console.log(obj.arrow());  // undefined (this «из** «окружения»)

const f = obj.method;
console.log(f());         // undefined (this «потерян**)
console.log(f.call(obj)); // 1 (call)

const bound = obj.method.bind(obj);
console.log(bound()); // 1 (bind)

// «Колбэк** «с** this (setTimeout):
const timer = {
  tick() { console.log("tick", this.value); },
  start() {
    setTimeout(() => this.tick(), 100);     // «стрелка** (this «из** «start»)
    // setTimeout(function () { this.tick(); }, 100); // this «потерян**
  },
  value: "A",
};
timer.start(); // "tick A" «через** «100мс

// «Конструктор**:
function User(name) { this.name = name; }
const u = new User("B");
console.log(u.name); // "B" (this = «новый** «объект»)
```
Разбор: this — «по** «вызову**: «объект** → obj, «call/apply/bind** → «явно**, «new** → «новый**, «прямой** → «глобальный/undefined, «стрелка** → «окружение».

## Частые ошибки
WARN: const f = obj.method; f() — this «потерян** (undefined «в** «strict**); «вызывайте** obj.method() «или** f.call(obj) «или** «стрелка** «в** «объекте**.
WARN: setTimeout(function () { this.x }, 100) — this «глобальный** («потерян**); «стрелка** () => this.x «или** .bind(this).
WARN: «стрелка** «в** «методах** «объекта** — this «из** «окружения** («не** «объект**): «методы** — «обычные** (или «метод-сокращение**), «стрелка** «—» «колбэки**.
WARN: bind «вызываете** «дважды** «с** «разными** this — «позднее** «игнорируется** (this «закреплён** «первым** bind); «аргументы** «накапливаются**.
WARN: «new** «с** «стрелкой** — TypeError («нет** «конструктора»); «классы** — «обычные** «функции**.
