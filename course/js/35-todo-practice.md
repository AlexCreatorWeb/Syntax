# Урок 35. Практика: todo-компонент

## Цель
Собрать «вместе** «всё** «из** «DOM-модуля** «(30–34): «интерактивный** «todo** «список** «с** ««добавлением**, «отметкой**, «удалением**. «Результат** — ««компонент** «(HTML-каркас + JS-логика** «+** «CSS-классы**).

## Теория
### «Архитектура** «компонента**: «состояние** «+** ««отрисовка**
«Паттерн** ««состояние** → ««отрисовка** «(«основа** «всякого** «UI-фреймворка** «в** ««кратких** «чертах**):
- **«состояние** — «массив** «объектов** (todos = [{ id, text, done }]) «—» ««источник** «правды**;
- **«отрисовка** — render(todos): «очистить** «список** «и** «пересобрать** «из** «состояния** «(создание** «элементов**, «классы** «по** «состоянию**);
- **«события** — «изменяют** «состояние** «и** «вызывают** «render** (добавить/отметить/удалить**).

«Правило**: «состояние** «—» «данные** («массив** «в** «переменной**), «DOM** «—» ««зеркало** («всегда** «синхронизировано** «с** «состоянием** «через** render**). «Не** ««хранилище** «в** «DOM** («class** «active** «—» «не** ««источник** «правды**, «данные** «—» «в** «массиве**).

### «События** «и** «делегирование** «в** «списке**
«Делегирование** «на** «списке** «(один** «обработчик** «click** «для** «всех** «кнопок** «(включая** ««новые** «(render** «создаёт** «новыми** «(без** ««повторного** «присоединения**). «Определение** ««что** «нажали**: e.target.closest(".toggle") / closest(".del").

### «Идентификаторы** «(id) «и** ««почему** ««индекс** «—** ««плохой** «ключ**
«Каждый** «todo** «с** «уникальным** id (let nextId = 1; «или** crypto.randomUUID()). «Почему** «не** «индекс**: «удаление** «серединного** «сдвигает** «индексы** («обработчик** ««запоминает** ««старый** «индекс** → «удаляет** ««не** «тот**). «id** «—» «стабилен**.

### «Полный** «код** «(«скелет** «в** «задании**):
```js
let todos = [{ id: 1, text: "научиться** «JS", done: false }];
let nextId = 2;

function render() {
  list.innerHTML = "";
  for (const t of todos) {
    const li = document.createElement("li");
    li.className = "todo" + (t.done ? " done" : "");
    li.dataset.id = t.id; // «id** «в** «атрибуте** «(для** «обработчика**
    li.innerHTML = `<span class="txt">${t.text}</span>
      <button class="toggle">✓</button>
      <button class="del">×</button>`;
    list.append(li);
  }
}
```
«Обработчик** «(делегирование**):
```js
list.addEventListener("click", (e) => {
  const li = e.target.closest(".todo");
  if (!li) return;
  const id = Number(li.dataset.id);
  if (e.target.closest(".toggle")) {
    todos = todos.map((t) => t.id === id ? { ...t, done: !t.done } : t);
  } else if (e.target.closest(".del")) {
    todos = todos.filter((t) => t.id !== id);
  }
  render();
});
```
«Добавление** «(форма/инпут**): input «+** «клик** «/Enter** «→» todos = [...todos, { id: nextId++, text: input.value, done: false }]; render().

TIP: «состояние** «—» «массив** «объектов** («данные**), «DOM** «—» ««зеркало** (render). «Не** ««изменяйте** «DOM** «вручную** («class** «toggle** «без** «обновления** «массива** — ««разрыв** «синхронизации**). ««Имутабельные** «обновления** (map/filter «с** «созданием** «новых** «объектов** «(урок** 21** — ««предсказуемо**.

NOTE: «этот** «компонент** «—» ««прототип** «React/Vue** («состояние** «→** ««отрисовка**, ««иммутабельные** «обновления**, «id** «ключи**). «Понимание** «этого** «паттерна** «—» ««мост** «к** «фреймворкам**.
