# Курс «JavaScript с нуля (ES6+)» — дорожная карта (42 урока)

Целевая аудитория: студент, прошедший курсы HTML+CSS (знает разметку и базовую стилизацию). Результат: студент пишет современный Vanilla JS (ES6+): типы и преобразования, функции и замыкания, массивы/объекты и их методы, DOM и события, storage, таймеры, асинхронность (Promise/async/await/fetch) — без фреймворков.

Источники: MDN Web Docs (JavaScript Guide, JavaScript Reference), javascript.info (Modern JavaScript), ECMAScript 2023+ (tc39.es).

## Логика цепочки
01 → 02: переменные хранят значения — какие типы бывают. 02 → 03: числовой тип → арифметика и float-подводники. 03 → 04: числа → строки (и преобразования между ними). 04 → 05: строки и числа — а булевы? null/undefined и «равно». 05 → 06: сравнения «сюрпризят» → как типы превращаются (явно/неявно). 06 → 07: сравниваем → ветвимся (if/тернарник/switch). 07 → 08: повторять код — циклы. 08 → 09: блоки кода выносим в функции. 09 → 10: современный синтаксис функций — стрелки. 10 → 11: стрелки «не любят» this/arguments — сначала разобраться в области видимости. 11 → 12: область видимости → замыкания (главная «магия» JS). 12 → 13: аргументы функций: default/rest/spread. 13 → 14: функции передают друг другу — колбэки. 14 → 15: качество кода: чистые функции. 15 → 16: основной тип данных — массив. 16 → 17: обход массива без цикла — forEach/map/filter. 17 → 18: map/filter дают массив, а reduce — любое значение. 18 → 19: поиск/проверка в массиве. 19 → 20: порядок и структура массива (sort/slice/flat). 20 → 21: копии и «независимость» — классика багов. 21 → 22: иерархия данных — объект. 22 → 23: работа с объектом «без мусора» — деструктуризация. 23 → 24: служебные методы объекта. 24 → 25: «кто я» в функции — this и связывание. 25 → 26: классы — шаблон объектов. 26 → 27: объект ↔ текст (JSON) — обмен с API/storage. 27 → 28: что делать, когда код «падает» — ошибки. 28 → 29: как находить ошибки — отладка. 29 → 30: JS выходит из консоли — DOM. 30 → 31: нашли элемент — меняем его. 31 → 32: создаём новые элементы. 32 → 33: реагируем на действия пользователя — события. 33 → 34: события «мудро»: делегирование и формы. 34 → 35: практика — собираем компонент. 35 → 36: данные «переживают» перезагрузку — localStorage. 36 → 37: время в JS — таймеры и debounce. 37 → 38: долгая работа (сеть, таймеры) — как устроен event loop. 38 → 39: современный интерфейс асинхронности — Promise. 39 → 40: читаемый асинхронный код — async/await. 40 → 41: главный источник асинхронности — fetch/API. 41 → 42: всё вместе — финальный проект.
