# Урок 2. Типы данных и typeof

## Цель
После урока студент сможет: перечислить базовые типы JS и привести пример каждого; объяснить, что делает typeof и почему у null он «лжёт»; отличать «пустое» значение (null) от «не заданного» (undefined).

## Теория
### Базовые типы и «вещественный» объект
JS имеет 7 базовых (primitive) типов:
- **number** — число (целое и дробное — один тип): 42, 3.14, -7;
- **bigint** — «большое» целое (с суффиксом n): 9007199254740993n (когда Number «не хватает»);
- **string** — строка: "text", 'text', `text`;
- **boolean** — true/false;
- **undefined** — «объявлено, но не присвоено» (автоматически);
- **null** — «осознанная пустота» (присваивается вручную);
- **symbol** — уникальный «токен» (реестр Symbol(), «под капотом» библиотек — в курс-практике встречается редко).

Всё остальное — **объекты** (урок 22): массивы, функции, даты и «вещественные» структуры. Проверка «это объект»: typeof возвращает "object" (плюс особые случаи: typeof null → "object" (исторический баг), typeof function → "function").

### typeof: «какой тип у значения»
Оператор **typeof** возвращает строку с типом: typeof 42 → "number", typeof "hi" → "string", typeof true → "boolean". Полезен для «страховочных» проверок: `if (typeof x === "undefined")` — безопасный способ спросить «а есть ли переменная x?» (в отличие от console.log(x), который упадёт, если x не объявлена).

### null vs undefined: «пусто» и «не задано»
- **undefined** — «значения нет»: переменная объявлена без присваивания, свойство объекта не существует, аргумент не передан;
- **null** — «значения осознанно нет»: «чистый лист» (user = null «до загрузки»);

На практике: undefined — «состояние» языка (сам «назначает»), null — «договорённость» программиста («пусто»). Сравнивать: x === null (строгое равенство, урок 5). Проверка «пусто или не задано»: `x == null` (не-строгое равенство) — единственный случай, когда двойное равно «уместно»: оно ловит И null, И undefined.

### Сводная «таблица типов»
Числа: 0, -1.5, NaN (особое «не-число», урок 3). Строки: "а", '', "строка с пробелами". Булевы: только true и false. undefined: одно значение. null: одно значение. Объекты: {}, [], function(){}, new Date().

TIP: «проверка на число» — typeof x === "number" && !Number.isNaN(x): typeof NaN тоже "number", но NaN «не число по смыслу» (урок 3). Для «проверки на массив» — Array.isArray(x) (typeof массива — "object").

NOTE: JS — динамически типизированный: переменная «не помнит» тип. const x = 5; x = "5"; — TypeError (const), а let x = 5; x = "5"; — «просто работает» (и «ломает» логику, если где-то x + 1). Типы — за «вашей» дисциплиной (или за TypeScript — вне курса).

## Пример
Скопируйте в index.js:
```js
const values = [42, 3.14, "hello", true, null, undefined, 10n, Symbol("id")];

for (const v of values) {
  console.log(typeof v, "→", v);
}

// Особые случаи:
console.log(typeof null);        // "object" (исторический баг JS)
console.log(typeof undefined);   // "undefined"
console.log(typeof "5" === 5);   // ??? (попробуйте угадать)

// Безопасная проверка «есть ли переменная»:
console.log(typeof maybeNotDefined === "undefined"); // true, без ошибки
// console.log(maybeNotDefined); // TODO: раскомментируйте → ReferenceError

const arr = [1, 2];
console.log(typeof arr, Array.isArray(arr)); // "object" true
```
Разбор: typeof «ходит» по типам. null → "object" — знаменитый баг 1995 года (исправлен «для истории» — все браузеры «совместимы»). Строка "5" «равна» числу 5 при ==, но НЕ при === (строгое, урок 5). `typeof maybeNotDefined` — единственный способ «спросить» о несуществующей переменной без падения.

## Частые ошибки
WARN: сравнение x === undefined «для» null-значений — пропустит null (и наоборот); «пусто в любом смысле» — x == null (редкий «допустимый» ==).
WARN: typeof null === "undefined" «для» проверки «пустоты» — «нет»: null даёт "object"; используйте x == null или явные проверки.
WARN: NaN «типа» number, но !== NaN — NaN «не равно» самому себе (урок 3); проверка «число по смыслу» — Number.isFinite(x) / !Number.isNaN(x).
WARN: «перемешиваете» строку и число «тихомолком»: let s = "5" + 1 → "51" (конкатенация), "5" - 1 → 4 (число); тип операции зависит от Оператора (урок 6).
WARN: «заводите» свой «null-объект»: user = {} «вместо» user = null «до загрузки» — и «проверка» «загружен ли» (user == null) «не работает» (пустой объект — «не null»).
