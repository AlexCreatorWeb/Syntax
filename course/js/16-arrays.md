# Урок 16. Массивы: создание и базовые методы

## Цель
После урока студент сможет: создать массив (все способы) и получить элементы (индекс, отрицательные, length); менять элементы (push/pop/shift/unspoke, splice, fill); объяснить, что массив — «объект» (ссылка, мутирует).

## Теория
### Массив: «упорядоченная» «коллекция»
**Массив** — «упорядоченный» «список» «значений» (тип object, typeof [] → "object"). «Индексы** — «целые** «с** 0: arr[0] — «первый**, arr.length - 1 — «последний**. «Отрицательные** «индексы** «не** «работают** (undefined) — «с** «конца** «через** slice(-n).

«Создание**:
- «литерал**: const a = [1, 2, 3]; («основной** способ);
- «конструктор**: new Array(3) → «массив** «длина** 3 («пустые** «слоты**), new Array(1, 2, 3) → [1, 2, 3];
- «из** ««страницы**/строк**: Array.from("abc") → ["a","b","c"], Array.from({length: 3}, (_, i) => i) → [0,1,2];
- «методы**: Array.of(1) → [1] («без** ««двойных** «смыслов» «у** «конструктора).

### «Базовые** «методы** ««конца**» (мутации)
- **push(...x)** — «добавить** «в** «конец» (возвращает «новую» «длинку»): a.push(4) → a = [1,2,3,4];
- **pop()** — «снять** «с** «конца** (возвращает «элемент», «меняет** «длинку»);
- **shift()** — «снять** «с** «начала** (дорого: «все** «сдвигаются»), unshift(...x) — «добавить** «в** «начало»;
- **splice(i, n, ...items)** — «удалить** n «элементов» «с** i «и** «вставить** items: a.splice(1, 1, "X") — «заменить** a[1] «на** "X"; a.splice(1, 0, "Y") — «вставить** «без** «удаления»;
- **fill(x, start, end)** — «заполнить** «диапазон» «значением»: [0,0,0].fill(7) → [7,7,7].

«Все** «выше** — «мутируют** «исходный** «массив» (урок 21: «копии** «через** slice/spread).

### «Полезные** «не-мутации** (базовые)
- **indexOf(x) / lastIndexOf(x)** — «индекс** «первого/последнего» «вхождения» (-1 «если» «нет»);
- **includes(x)** — true/false «есть** «ли» x «в** «массиве»;
- **join(sep)** — «в** «строку**: [1,2,3].join("-") → "1-2-3" (урок 4: split — «обратный»);
- **toString()** — «как** join(",");
- **length** — «свойство** (не «метод**), «можно** «менять** вручную (a.length = 0 — «очистить»).

TIP: «добавление/снятие** «с** «конца** (push/pop) — «быстро» (O(1)). «С** «начала** (shift/unshift) — «медленно** (O(n): «все** «сдвигаются). «Частые** «операции** «с** «началом** — «подумайте** «о** ««другом** «порядке**» (push «в** «конец**, «читать** «с** «конца»).

NOTE: «массив** — «объект** (ссылка): const b = a; b.push(4) — a «тоже» [.., 4]! «Копия**: const b = [...a] (или a.slice()). «Проверка** ««массив**: Array.isArray(a) (typeof — "object").

## Пример
```js
// «Создание»:
const a = [1, 2, 3];
const b = new Array(3);          // [ , , , ] («длина» 3, «пустые**)
const c = Array.from("abc");     // ["a", "b", "c"]
const d = Array.from({ length: 3 }, (_, i) => i * 2); // [0, 2, 4]

// «Индексы**:
console.log(a[0], a[a.length - 1], a[-1]); // 1 3 undefined

// «Мутации**:
const stack = [1, 2];
stack.push(3);      // [1, 2, 3]
console.log(stack.pop()); // 3 («снять** «с** «конца»)
stack.unshift(0);   // [0, 1, 2]
console.log(stack.shift()); // 0

const s = [1, 2, 3, 4];
s.splice(1, 2, "X", "Y"); // [1, "X", "Y", 4] («удалить** 2 «с** 1, «вставить** "X","Y")
console.log(s);

// «Не-мутации**:
console.log([5, 10, 15].indexOf(10));   // 1
console.log([5, 10, 15].includes(99));  // false
console.log([1, 2, 3].join("-"));       // "1-2-3"

// «Ссылка** vs «копия»:
const orig = [1, 2];
const ref = orig;        // «ссылка** (не «копия)
ref.push(3);
console.log(orig);       // [1, 2, 3] («изменился** «оригинал»!)
const copy = [...orig];  // «копия**
copy.push(4);
console.log(orig);       // [1, 2, 3] («оригинал** «цел»)
```
Разбор: push/pop — «конец» (быстро), shift/unshift — «начало» (медленно). splice — «хирургия». «Массив** — «ссылка» (копия через [...]).

## Частые ошибки
WARN: const b = a «для** «копии** «массива** — «ссылка» (b.push «изменит** a); [...a] / a.slice().
WARN: a[-1] «для** «последнего** — undefined (отрицательные «индексы** «не** «работают**); a[a.length - 1] «или** a.at(-1).
WARN: «удаление** «элемента** «по** «значению** через «filter» (урок 17) «или** «индексом** (splice). a.splice(1) «без** «второго** «аргумента** — «удалит** «ВСЕ** «с** 1 (до «конца»)!
WARN: new Array(3) «ожидаете** [0,0,0] — «даст** ««пустые** «слоты» (length 3); new Array(1,2,3) → [1,2,3]. «Используйте** [].
WARN: shift/unshift «в** ««горячем** «цикле** «с** «большим** «массивом** — «медленно** (O(n) «на** «операцию»); push/pop — «быстро.
