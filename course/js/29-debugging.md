# Урок 29. Отладка: console.* и DevTools

## Цель
После урока студент сможет: «выбрать** «правильный** «метод** console (log/info/warn/error/table/time); «посмотреть** ««внутренности** «объекта/массива** «в** «консоли**; «использовать** «DevTools** (брейкпоинт, «инспекция** «DOM, «просмотр** «сети** «и** «памяти**); «найти** «ошибку** «по** «стектрейсу**.

## Теория
### console.*: «уровни** «и** ««формы** «вывода**
- **console.log(value, ...)** — «основной** («любой** «тип**); «несколько** «аргументов** «—» «рядом**;
- **console.info** — «информация** («как** «log**, «другой** «цвет**);
- **console.warn** — «предупреждение** («жёлтый**);
- **console.error** — «ошибка** («красный**, «с** «стектрейсом** «по** «클лик**);
- **console.table(arr)** — «массив/объект** «таблицей** («отлично** «для** «данных**);
- **console.group/groupEnd** — «группировка** («сворачиваемые** «блоки**);
- **console.count(label)** — «счётчик** («сколько** «раз** «вызвано**);
- **console.time/trace/timeEnd** — «замер** «времени** (time «—» «секунды**, trace «—» «стек** «вызовов**).

«Вывод** «объекта**: console.log(obj) — «ссылка** («раскроется** «в** «консоли** «с** «текущим** «состоянием** «(live**). «Снимок**: console.log(JSON.stringify(obj, null, 2)) «или** console.log({ ...obj }) («копия** «на** «момент** «вывода**).

### «Стрек-трейсы** «и** ««диагностика**
«Ошибка** «в** «консоли** «показывает** «строку** «и** «стек** «вызовов** («кто** «вызвал** «функцию**, «где**). «Клик** «по** «строке** «стек** → «переход** «к** «коду**. «В** «редакторе** Syntax: «ошибка** «с** «номером** «строки** «файла** «(клик** → «переход** «к** «строке** «в** «редакторе**).

«Приёмы**:
- «лог** «до** «и** «после** ««подозрительной** «строки** (bisection: «половина** «кода** «закомментирована**);
- «лог** «значений** «в** «ключевых** «точках** (аргументы, «результаты**);
- console.table «для** «массивов** «объектов** («структура** «на** «глаз**);
- «комментирование** ««половиной** (бинарный «поиск** «ошибки**).

### DevTools: «главные** «вкладки**
- **Elements** — «Дерево** «DOM** («инспекция** «элемента**, «стили**, «атрибуты**);
- **Console** — «лог/ошибки** + « REPL** («выполнить** «код** «в** «контексте** «страницы**);
- **Sources** — «брейкпоинты** («остановка** «по** «строке**), «просмотр** «переменных** «в** «момент** «остановки**);
- **Network** — «запросы** («fetch/XHR**, «время**, «ответы** «—» «урок** 41);
- **Application** — «localStorage/cookies** («урок** 36);
- **Performance** — «профиль** «выполнения** («медленные** «места**).

«Брейкпоинт**: «клик** «по** «номеру** «строки** «в** Sources → «код** «остановится** «на** «этой** «строке** (Step Over/Into/Out, «переменные** «в** «панели** «Scope**).

TIP: «первый** «вопрос** «при** ««не** «работает**: «какая** «ошибка** «в** «консоли**? «Если** «тихо** — «лог** «в** «ключевых** «точках** («где** «код** ««должен** «сработать**). «console.log «—» ««нормально** «в** «отладке** (не «стыдно** «в** «разработке**).

NOTE: «в** «редакторе** Syntax: «консоль** «видит** «console.log/warn/error» «из** «файла** «(перехват** «через** «iframe**). «Номера** «строк** «ошибок** — «в** «координатах** «файла** «(клик** → «переход** «в** «редакторе**).

## Пример
```js
// «Уровни**:
const users = [
  { id: 1, name: "a", age: 15 },
  { id: 2, name: "b", age: 25 },
];
console.log("users:", users);        // «основной**
console.info("info:", users.length); // «информация**
console.warn("warn: «мало** «пользователей"); // «предупреждение**
console.error("error: «нет** «данных"); // «ошибка** («с** «стектрейсом**)
console.table(users);                 // «таблица**

// «Группировка**:
console.group("отчёт");
console.log("count:", users.length);
console.log("adults:", users.filter((u) => u.age >= 18).length);
console.groupEnd();

// «Счётчик** «и** «замер**:
let n = 0;
for (let i = 0; i < 3; i++) { n++; console.count("цикл"); }
console.time("замер");
const sum = users.reduce((s, u) => s + u.age, 0);
console.timeEnd("замер"); // «~0.05ms"
console.log("sum:", sum);
```
Разбор: log/warn/error — «уровни**, table — «данные**, group — «блоки**, count/time — «замеры**. «Ссылка** «на** «объект** «в** «log** — «live** «(текущее** «состояние**).

## Частые ошибки
WARN: console.log(obj) «ожидаете** «снимок** «на** «момент** «вывода** — «ссылка** («раскроется** «с** ««последним** «состоянием** «(после** «изменений**); «снимок** — { ...obj } «или** JSON.
WARN: «ошибка** «в** «консоли** «без** «стектрейса** «—» «трудно** «найти** «источник**; «клик** «по** «строке** «стек** → «переход** «к** «коду** «(DevTools**).
WARN: «лог** ««всё** «и** «всегда** «в** «продакшене** — «шум** («удалите** «перед** ««релизом** «или** ««уровни** «(warn/error** «—» «нормально**).
WARN: console.log «с** ««тяжёлым** «объектом** «(1М «массив** «в** «цикле** «10К) — ««тормоз** «консоли** (раскрытие** «дорого**); «лог** «длинку/«часть**.
WARN: «брейкпоинт** «в** ««чужом** «коде** (библиотека** «в** Sources) — «полезно** «для** ««чужих** «багов** («пошагово** «через** «внутренности**).

## Практическое задание
1. В скелете задания «вызовите** «все** «уровни** console (log/info/warn/error/table/group/count/time).

4. «Поставьте** «брейкпоинт** «в** DevTools** (Sources) «на** «свою** «функцию** — «проверьте** «переменные** «в** «момент** «остановки**).
5. Бонус: console.table «для** «массива** «объектов** «—» «сравните** «с** «console.log (читаемость**).
