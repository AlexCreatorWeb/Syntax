# Урок 11. Область видимости и TDZ

## Цель
После урока студент сможет: объяснить «глобальную» и «функциональную» (блочную) область видимости; предсказать, где «видна» переменная (и где — нет); объяснить TDZ (Temporal Dead Zone) и почему let/const «не всплывают» как var.

## Теория
### «Глобальная» и «локальная» «области»
**Область видимости** (scope) — «часть» кода, где «имя» «доступно». «Иерархия»:
- **глобальная** — «весь» «скрипт» (window в «браузере»). «Переменные» «на» «верхнем» «уровне» — «глобальные»;
- **функциональная** — «внутри» «функции»: «переменные» «функции» «видны» «только» «внутри» («и» «в» «вложенных» «блоках»);
- **блочная** — «внутри» {} (if/for/while/{}): let/const «живут» «в» «блоке».

«Правило» «поиска»: «внутрь» «наружу» — «сначала» «текущий» «блок», «потом» «функция», «потом» «глобальная». «Нашли» — «стоп» («не» «ищем» «дальше»).

### Всплытие (hoisting): «как» «работает» «объявление»
При «парсинге» «скрипта» «объявления» «переезжают» «наверх» «своей» «области»:
- **var** — «объявление» «всплывает», «присваивание» — «на» «месте»: `if (true) { var x = 1; } console.log(x);` → 1 (x «объявлен» «сверху» «глобальной», «присвоен» «в» if);
- **function** — «объявление» «И» «тело» «всплывают»: «функция» «доступна» «выше» «строки» «объявления»;
- **let/const** — «объявление» «запоминается» «наверху», но «не» «инициализируется» («до» «строки») — «это» **TDZ**.

### TDZ: «временная» «мёртвая» «зона»
«До» «строки» let/const «переменная» «существует» «в» «области», но «не» «инициализирована»: «обращение» → ReferenceError:
```js
console.log(a); // ReferenceError (a «в» TDZ)
let a = 1;
```
«В» «отличие» «от» var (undefined «до» «строки»). «Смысл» TDZ — «защита» «от» «опечаток» «и» ««всплывших»» «неприсвоенных» «значений» (undefined «вместо» «ошибки» — «тихий» «баг»).

«Сюрпризы» TDZ:
- for (let i = 0; ...) — i «виден» «только» «в» «цикле» (TDZ «снаружи»: «до» «цикла» «и» «после»);
- «стрелка» «с» «областью» «(x) => x» «с» «let» «выше» — «работает» «только» «после» «присваивания»;
- «функция» «вызвана» «до» «let» «сверху» (через «таймер»/«колбэк») — TDZ «до» «вызова».

### «Глобальные» «загрязнения»
«Переменные» «без» let/const/var (x = 5) — «глобальные» (загрязнение window). «В» «модулях» (import/export) — ReferenceError (strict). «Правило»: let/const «всегда» (урок 1). «Объекты» «на» «верхнем» «уровне» — «тоже» «глобальные» (для «сборки» «скриптов» — «не» «плохо», «для» ««одного»» «файла» — «хорошо»).

TIP: «отладка» ««где»» «определена» «переменная»: «нажмите» «F12» → Console → «напишите» «имя» — «если» «глобальная», «найдётся»; «если» «нет» — «в» «функции/блоке» (Scope «в» «DevTools» «покажет» «цепочку» «областей»).

NOTE: «аргументы» «функции» — «локальные» «переменные» «этой» «функции» (не «глобальные»). «Параметр» «с» «именем» «глобальной» «переменной» ««затеняет»» (shadowing) «её» «внутри»: let x = 1; function f(x) { return x * 2; } — «внутри» f x — «параметр».

## Пример
```js
// «Глобальная» «область»:
const globalVar = 1;

function demo() {
  // «Функциональная»:
  const local = 2;
  if (true) {
    // «Блочная»:
    const blockOnly = 3;
    console.log(globalVar, local, blockOnly); // 1 2 3 («в» «блоке» — «все» «видны»)
  }
  // console.log(blockOnly); // ReferenceError («вне» «блока»)
  return local;
}
console.log(demo()); // 2
// console.log(local); // ReferenceError («вне» «функции»)

// var «всплывает»:
if (true) {
  var hoisted = "yes";
}
console.log(hoisted); // "yes" («утёк» «в» «глобальную»)

// TDZ:
// console.log(early); // ReferenceError
let early = "late";
console.log(early); // "late"

// for + let: «i» «локален»:
for (let i = 0; i < 3; i++) { /* ... */ }
// console.log(i); // ReferenceError
```
Разбор: «поиск» «внутрь» «наружу» (блок → функция → глобальная). var «всплывает» (и «утекает»), let/const — «в» «блоке» (TDZ «до» «строки»).

## Частые ошибки
WARN: var «в» «цикле/if» — «утёк» «в» «глобальную» (hoisting): «два» «цикла» «с» var i — «одна» «переменная»; let «всегда».
WARN: «обращение» «к» let/const «до» «строки» — ReferenceError (TDZ), «не» undefined: «перестановка» «кода» «ломает» «не» «очевидно».
WARN: «глобальная» «переменная» «без» let (x = 5) — «загрязнение» window («конфликты» «между» «скриптами»); let/const «всегда».
WARN: «теневые» «параметры» (function f(x) «с» «глобальным» x) — «внутри» «локальный» x («глобальный» «не» «виден»); «имена» «параметров» — «не» «копируйте» «от» «глобальных».
WARN: «колбэк» «с» «var» «в» «цикле» (setTimeout «с» var i) — «все» «колбэки» «увидят» «последнее» i (hoisting); let i «в» for — «каждая» «итерация» «с» «своим» i.

## Практическое задание
1. В скелете задания «прочитайте» «вызовы» «и» «объясните» (в «комментариях»), «почему» «каждый» «результат».
2. «Найдите» «ошибку»: function f() { console.log(x); let x = 1; } — «почему» ReferenceError? (TDZ «внутри» «функции»).
3. Напишите «демо» «hoisting»: var vs let «в» if — «что» «видно» «снаружи»?
4. «Цикл» «с» setTimeout: for (var i = 0; i < 3; i++) setTimeout(() => console.log(i)); — «что» «выведет»? «Почему»? «Исправьте» let.
5. Бонус: «функция» «с» «теневым» «параметром»: let mode = "light"; function setMode(mode) { return mode; } — setMode("dark") «и» «что» «даст» «внутри» «глобальная» mode?
