# Урок 22. Объекты: свойства и методы

## Цель
После урока студент сможет: создать объект (литерал, «новый** «свойство**, «удалить** (delete); «читать/писать** «свойства** через** dot/bracket; «вызывать** «методы»; «работать** «с** «динамическими** «ключами**.

## Теория
### Объект: «связка** «ключ → «значение»
**Объект** — «несупорядоченная** «коллекция** «пар» «ключ:значение» (ключ — «строка» «или** Symbol, значение — «любое** «(примитив, «объект, «функция).
```js
const user = {
  name: "A",            // «строка** «ключ** (без** «кавычек** — «если** «идентификатор»)
  "full name": "A B",   // «произвольная** «строка** «— «в** «кавычках»
  age: 25,
  address: { city: "MSK" }, // «вложенный** «объект»
  greet() { return `Привет, ${this.name}`; }, // «метод** (функция-свойство)
};
```
«Литерал** {} — «основной** «способ». new Object() — «редко** («стиль»). «Пустой** «объект**: {}.

### «Доступ**: «dot» «vs** «bracket»
- **dot**: user.name — «кратко**, «только** «идентификатор** (без «пробелов», «начинается** «с** «буквы»);
- **bracket**: user["name"] — «любые** «ключи** (строки «с** «пробелами», «динамические** «ключи**): user[key], user[computed].

«Правило**: «известный** «ключ** → dot (чище), «динамический** → bracket. «Проверка** «существования**: "name" in user, user.hasOwnProperty("name") (урок 24), user.name === undefined.

### «Методы** «и** «вызов**
«Функция-свойство** — «метод». «Вызов**: user.greet() — this «связан** «с** «объектом» (урок 25). «Ссылка** «на** «метод** «без** «объекта** — this «теряется**: const g = user.greet; g() → this «не** user (undefined/глобальное).

### «Изменение**: «добавление/удаление, «операторы**
- «добавление/изменение**: user.email = "a@b.c"; user["phone"] = "123";
- «удаление**: delete user.phone; (свойство «исчезает** (не undefined));
- «расширение** «объекта**: user = { ...user, email: "new" } («новый** «объект**, урок 21);
- «операторы** «??= «и** ||= (урок 5): user.count ??= 0; user.active ||= true;

TIP: «ключи** «объекта** — «имена** «сущностей** (name, age, isActive), «не** «index_0/key_1. «Вложенные** «объекты** — «группировка** (user.address.city, «не** user_city_user_street). «Глубина** «вложенности** — «до** 2–3 «уровней» («больше** — «спроектируйте** «иначе»).

NOTE: «порядок** «свойств** — «порядок** «объявления» (для «строк** — «вставка**, «числовые** «ключи** «— «сортировка** «по** «числу»). «Не** «зависите** «от** «порядка** «в** «логике** (Object.keys «—» «для** «обхода**, урок 24).

## Пример
```js
const user = {
  name: "A",
  "full name": "A B",
  age: 25,
  address: { city: "MSK", zip: "101000" },
  greet() { return `Привет, ${this.name}!`; },
};

// «Доступ**:
console.log(user.name);                 // "A" (dot)
console.log(user["full name"]);         // "A B" (bracket)
console.log(user.address.city);         // "MSK" (вложенный)
const key = "age";
console.log(user[key]);                 // 25 (динамический «ключ**)

// «Метод**:
console.log(user.greet());              // "Привет, A!"
const g = user.greet;
console.log(g());                        // "Привет, undefined!" (this «потерян**)

// «Изменение**:
user.email = "a@b.c";
delete user.email;
user.count ??= 0;
user.count++;
console.log(user.count);                // 1

// «Новый** «объект** (без «мутации»):
const updated = { ...user, name: "B" };
console.log(updated.name, user.name);   // "B" "A" («оригинал** «цел»)
```
Разбор: dot — «известный** «ключ**, bracket — «динамический». «Метод** «с** this (урок 25). { ...user, ... } — «обновление** «без** «мутации».

## Частые ошибки
WARN: user.name «для** «ключа** «с** «пробелом/цифрой** — SyntaxError; «кавычки**: user["full name"] «или** user["2fa"].
WARN: const g = obj.method; g() — this «теряется** (undefined «в** «strict**); «вызывайте** obj.method() «или** «стрелка** «в** «объекте** (урок 25).
WARN: «сравнение** «объектов** «по** «значению» (a === b) — «ссылка**: «два** «одинаковых** «объекта** «— «разные» «ссылки»; «сравнивайте** «свойства** «или** JSON (урок 27).
WARN: delete «для** «очистки** «объекта** — «медленно** «и** «не** ««полностью** «(свойства** «в** «прототипе** «остаются**); «создайте** «новый** {}.
WARN: «ключи** «без** «кавычек** «с** ««странными** «символами** (2fa, a-b) — SyntaxError; «кавычки**: { "2fa": true, "a-b": 1 }.
