# Урок 13. Default, rest и spread в функциях

## Цель
После урока студент сможет: задать значения по умолчанию для параметров; собрать «лишние» аргументы в массив (rest ...); «разобрать» массив/объект в аргументы (spread ...); отличать rest (в параметрах) от spread (в вызовах).

## Теория
### Default-параметры: «заглушки» «для» «непереданных»
```js
function connect(host, port = 8080, secure = false) { ... }
connect("localhost");        // port = 8080, secure = false
connect("localhost", 3000);  // secure = false
```
Default «срабатывает», только при **undefined** (не при 0/""/false): connect(null, 0) → port = 0 (0 «не undefined»). Default «вычисляется» «на» «вызове» (может «использовать» «предыдущие» параметры: function f(a, b = a) {}). «Порядок»: default — «в» «конце» (или «явные» «значения» «между»).

### Rest: «собрать» «все» «остальные» «аргументы» «в» «массив»
```js
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
sum(1, 2);      // 3   (nums = [1, 2])
sum(1, 2, 3);   // 6   (nums = [1, 2, 3])
```
**...name** «в** «параметрах** — rest: «собирает» «все» «остальные» «аргументы» «в** «массив». «Один» «rest» «на** «функцию», «обязательно» «в конце». «Паттерн»: (fixed, ...rest): function log(level, ...messages) — level «первый», messages — «остальные».

### Spread: «разобрать» «коллекцию» «в** «аргументы»/«элементы»
**...coll** «в** «вызове/литерале** — spread: «разворачивает» «массив/объект»:
```js
const nums = [3, 1, 2];
console.log(Math.max(...nums));       // 3 («равно» Math.max(3, 1, 2))
const a = [1, 2], b = [3, 4];
const merged = [...a, ...b];          // [1, 2, 3, 4]
const base = { x: 1, y: 2 };
const extended = { ...base, y: 99, z: 3 }; // { x: 1, y: 99, z: 3 }
```
Spread «в** «массиве** — «копирует/соединяет» «элементы» (поверхностно, урок 21). «В** «объекте** — «копирует/объединяет» «свойства» («позднее» «перебивает»). «В** «вызове** — «распаковывает» «в** «аргументы».

### Rest vs Spread: «одно» «имя», «два» «места»
- **rest** — «в** «параметрах** «функции» (и «в** деструктуризации): «собирает» «остаток» «в** «коллекцию»;
- **spread** — «в** «вызовах/литералах**: «разворачивает» «коллекцию».

«Мнемоника»: rest — «много → одно» (аргументы → массив), spread — «одно → много» (массив → аргументы/элементы).

TIP: «копирование** «массива/объекта** «для** «изменения** «части»: const copy = [...arr]; copy[0] = X («оригинал» «не» «изменён» — «поверхностная» «копия», урок 21). «Объект**: const copy = { ...obj }. «Классика** «паттерна** ««изменить** «один** «элемент**: [...arr.slice(0, i), newVal, ...arr.slice(i + 1)].

NOTE: rest «в** «параметрах** «работает** «и» «с** «default**: function f(a, b = 1, ...rest) — «допустимо» (b «перед» rest). «Но** «default» «после» rest — SyntaxError (rest — «последний»).

## Пример
```js
// Default:
function power(base, exp = 2) { return base ** exp; }
console.log(power(5), power(5, 3)); // 25 125

// Rest:
function sum(...nums) { return nums.reduce((a, b) => a + b, 0); }
console.log(sum(1, 2), sum(1, 2, 3, 4)); // 3 10

function log(level, ...messages) {
  console.log(`[${level}]`, messages.join(" "));
}
log("WARN", "disk", "full"); // [WARN] disk full

// Spread:
const nums = [3, 1, 2];
console.log(Math.max(...nums)); // 3

const a = [1, 2], b = [3, 4];
console.log([...a, ...b]); // [1, 2, 3, 4]

const base = { x: 1, y: 2 };
const extended = { ...base, y: 99, z: 3 };
console.log(extended); // { x: 1, y: 99, z: 3 }

// Rest «в** «деструктуризации»:
const [first, ...others] = [10, 20, 30];
console.log(first, others); // 10 [20, 30]
```
Разбор: default — «заглушки» (undefined), rest — «собрать» (параметры → массив), spread — «разобрать» (массив/объект → аргументы/элементы).

## Частые ошибки
WARN: default «для** «0/""/false» — «не» «сработает» (default «только» «при» undefined): f(0) «с** (x = 10) → 0; «заглушка» «для** «falsy» — x ?? 10 (урок 5).
WARN: rest «не» «в конце» (function f(...rest, x)) — SyntaxError; rest — «последний» «параметр».
WARN: Math.max(arr) «вместо» Math.max(...arr) — NaN (max «ожидал** «числа», «а не** «массив»); spread «распакует**.
WARN: «копирование** «через** = «для** «массива/объекта** — «ссылка» («не» «копия»): const b = a; b.push → a «тоже» «изменится»; [...a] / { ...obj } (урок 21).
WARN: spread «объекта** «с** «вложенными** «объектами** — «поверхностная» «копия» (вложенные — «ссылки»): «глубокое» «копирование** — structuredClone (урок 21).
