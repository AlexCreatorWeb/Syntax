# Урок 27. JSON: сериализация и ловушки

## Цель
После урока студент сможет: «превратить** «объект** «↔** «строку** (JSON.stringify/parse); «понять**, «что** «теряется** «при** «сериализации** (undefined, «функции», Date, «циклы**); «использовать** «reviver/replacer «для** «управления** «процессом**.

## Теория
### JSON: «формат** «данных** «для** «обмена**
**JSON** (JavaScript Object Notation) — «текстовый** «формат** «данных** (объекты/массивы/примитивы). «В** «JS**:
- **JSON.stringify(value, replacer, space)** → «строка** («сериализация**: «объект** → «текст**);
- **JSON.parse(text, reviver)** → «объект** («де-сериализация**: «текст** → «объект**).

«Пример**:
```js
const user = { name: "A", age: 25, tags: ["js", "css"] };
const text = JSON.stringify(user);
console.log(text); // {"name":"A","age":25,"tags":["js","css"]}
const obj = JSON.parse(text);
console.log(obj.name); // "A"
```
«Параметры**: space («красивый** «вывод**: JSON.stringify(obj, null, 2)), replacer («функция** «преобразования** «каждого** «значения** «при** «сериализации**), reviver («при** «parse**).

### «Что** «теряется** «при** «stringify**
- **undefined** (свойство/элемент) — «удаляется** («в** «объекте** «свойство** «исчезает**, «в** «массиве** — null);
- **функции** — «удаляются** (аналогично);
- **Date** → «строка** ISO ("2026-01-01T00:00:00.000Z") («обратно** «parse «даст** «строку**, «не** Date);
- **NaN/Infinity** → null;
- **«циклы** (a.b → a) — «бесконечный** «рекурсия** → «ошибка** (JSON «не** «поддерживает** «циклы**);
- **«symbol** «ключи** — «удаляются**.

«Обратно** (parse**: «числовые** «ключи** «—» «строки** («в** «объекте**), «дублирующиеся** «ключи** — «последний** «побеждает**.

### «Для** «чего** «JSON** «в** «практике**
- «обмен** «с** «API** (fetch «возвращает** «JSON**, урок 41);
- «хранилище** (localStorage «—» «только** «строки**, урок 36: JSON.stringify «при** «сохранении**, JSON.parse «при** «чтении**);
- «копирование** «(JSON.parse(JSON.stringify(obj)) — «глубокая** «копия** «с** ««потерями** (Date → «строка**);
- «лог** «объектов** (console.log(JSON.stringify(obj)) — ««плоский** «вывод**).

TIP: «сериализация** «для** «хранения** (localStorage) — «оборачивайте** «в** «try/catch (parse «может** «упасть** «на** ««битом** «тексте**):
```js
function load(key, fallback) {
  try { return JSON.parse(localStorage.getItem(key)) ?? fallback; }
  catch { return fallback; }
}
```

NOTE: «JSON** «—** «не** ««всё** «JS**: «нет** «Date/Map/Set/undefined/функций/«циклов». «Для** ««полных** «данных** — «другие** «форматы** (YAML, MessagePack) «или** ««ручные** «обёртки** (reviver «для** «Date).

## Пример
```js
const user = {
  name: "A",
  age: 25,
  temp: undefined,      // «исчезнет**
  fn: () => {},          // «исчезнет**
  born: new Date(2000, 0, 1), // → «строка** ISO
  tags: ["js", null, "css"],  // null «останется**
};

const text = JSON.stringify(user);
console.log(text);
// {"name":"A","age":25,"born":"2000-01-01T00:00:00.000Z","tags":["js",null,"css"]}

const obj = JSON.parse(text);
console.log(obj.temp);      // undefined («свойство** «не** «было»)
console.log(typeof obj.born); // "string" (Date «→** «строка»)
console.log(obj.born);       // "2000-01-01T00:00:00.000Z"

// «Красивый** «вывод**:
console.log(JSON.stringify({ a: 1, b: [1, 2] }, null, 2));

// «Глубокая** «копия** («с** ««потерями**):
const orig = { a: 1, b: { c: 2 }, d: new Date() };
const copy = JSON.parse(JSON.stringify(orig));
console.log(copy === orig, copy.b === orig.b); // false false («новые** «объекты»)
console.log(copy.d instanceof Date); // false (Date → «строка»)
```
Разбор: stringify — «объект** → «строка» (теряет** undefined/функции/Date), parse — «обратно** (Date «не** «восстанавливается**).

## Частые ошибки
WARN: JSON.parse «без** try/catch «для** ««внешнего** «текста** (localStorage, API) — «падение** «на** ««битом** «JSON»; «обёртка** «с** «fallback.
WARN: «ожидаете** Date «после** parse — «строка** («ISO**); «восстановите** «вручную** (new Date(str)) «или** «reviver.
WARN: «циклы** «в** «объекте** (a.b = a) + stringify — «бесконечный** «рекурсия** → «ошибка**; «уберите** «цикл** «или** ««ручной** «формат.
WARN: «храните** «функции** «в** «объекте** «и** «сериализуете** — «исчезнут** («без** «ошибки**); «проверьте** «результат**.
WARN: «сравниваете** «объекты** «через** JSON.stringify (a === b) — «порядок** «ключей** «важен** ({a:1,b:2} «≠** {b:2,a:1} «в** «строке**); «надёжно** «— «свойство** «по** «свойству**.
