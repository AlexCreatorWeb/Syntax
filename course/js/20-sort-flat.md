# Урок 20. sort, slice, flat и «порядок** «массива**

## Цель
После урока студент сможет: отсортировать «числа» «правильно» (компаратор); работать «с** «порядком** (reverse, sort «по** «свойству», slice «для** «копии»); «разобрать** «вложенные** «массивы** (flat/flatMap); «распознать**, «когда** sort ««портит** «оригинал**.

## Теория
### sort: «по** «порядку** «и** «ловушки** «строки**
**sort(cb)** — «сортирует** «МАССIV «на** «месте» (мутирует!), «по** «возврату** «колбэка**:
- «отрицательный** → a «перед** b;
- «положительный** → b «перед** a;
- 0 → «порядок** «не** «меняется».

**«Главная** «ловушка**: sort «без** «колбэка** «превращает** «в** «строки** «и** «сортирует** «лексикографически**: [10, 9, 2].sort() → [10, 2, 9] («строка** "10" < "2"!). «Числа**: nums.sort((a, b) => a - b). «Строки**: arr.sort() (лексикографически) «или** arr.sort((a, b) => a.localeCompare(b)) («с** «учётом** «языка»).

«Сортировка** «по** «свойству**: users.sort((a, b) => a.age - b.age). «Сложная** «логика** (мульти-ключ**: users.sort((a, b) => a.city.localeCompare(b.city) || a.age - b.age).

### slice: «копия** «и** «кусочек**
**slice(start, end)** — «новый** «массив** [start, end) («не** «мутирует**):
- nums.slice() — «поверхностная** «копия» (как [...nums]);
- nums.slice(1, 3) — «элементы** 1..2;
- nums.slice(-2) — «последние** «два»;
- nums.slice(0, i) + [x] + nums.slice(i + 1) — «замена** «элемента** i (урок 13).

### reverse, flat, flatMap
- **reverse()** — «переворачивает** «на** «месте» (мутирует!): [1,2,3].reverse() → [3,2,1]; «копия** «перевёрнутая**: [...arr].reverse();
- **flat(depth)** — «расплющивает** «вложенные** «массивы**: [[1, [2, [3]]]].flat(2) → [1, 2, [3]]; .flat(Infinity) → [1,2,3];
- **flatMap(cb)** — map + flat(1) «за** «один** «проход**: arr.flatMap(x => [x, x * 2]) → «расплющенный** «результат** «map».

### «Мутация** «порядка** (sort/reverse) «vs** «копия**
sort/reverse «меняют** «исходный** «массив». «Если** «оригинал** «нужен** «в** «том** «же** «порядке** — «копия** «сначала**: const sorted = [...nums].sort((a, b) => a - b);

TIP: «сортировка** «объектов** «по** «строке**: localeCompare («учитывает** «регистр/язык**): names.sort((a, b) => a.localeCompare(b, "ru")). «Для** «чисел** «— a - b («не** Math.sign «— «то же», но «короче»).

NOTE: «стабильность**: «современные** «движки** (ES2019+) — sort «стабилен** (равные «элементы** «сохраняют** «порядок»). «Зависайте** «на** ««старых** «браузерах** «без** «порядка** «равных**.

## Пример
```js
const nums = [10, 9, 2, 40];

// «Сортировка** «чисел** («обязательный** «компаратор»):
console.log([...nums].sort((a, b) => a - b)); // [2, 9, 10, 40]
console.log([...nums].sort((a, b) => b - a)); // [40, 10, 9, 2]
console.log(nums.sort());                     // [10, 2, 40, 9] («ловушка** «строки»)

// «По** «свойству»:
const users = [
  { name: "c", age: 35 },
  { name: "a", age: 15 },
  { name: "b", age: 25 },
];
const byAge = [...users].sort((a, b) => a.age - b.age);
console.log(byAge.map((u) => u.name)); // ["a", "b", "c"]

// slice:
console.log(nums.slice(1, 3));  // «кусочек** (не «мутация»)
console.log(nums.slice(-2));    // «последние** «два»
const copy = nums.slice();      // «копия**

// flat / flatMap:
console.log([[1, 2], [3, 4]].flat());        // [1, 2, 3, 4]
console.log([[1, [2, [3]]]].flat(Infinity)); // [1, 2, 3]
console.log([1, 2].flatMap((x) => [x, x * 2])); // [1, 2, 2, 4]
```
Разбор: «числа** → a - b. «Оригинал** → «копия** ([...]) «перед** sort/reverse. flat — «вложенные**, flatMap — «map+flat.

## Частые ошибки
WARN: sort «без** «колбэка** «для** «чисел** — [10, 2, 9] («строки**: "10" < "2"); «числа** → (a, b) => a - b.
WARN: sort «изменяет** «оригинал** — «копия** «сначала**: [...arr].sort(...) (иначе «оригинал** «в** «новом** «порядке»).
WARN: localeCompare «забыли** «для** «русских** «строк** — «порядок** ««не** «тот» (латиница «вперёд**); str.localeCompare(other, "ru").
WARN: flat(1) «для** «глубоких** «вложенностей** — «только** «один** «уровень»; .flat(Infinity) «для** «всех.
WARN: reverse «ожидаете** «новый** «массив** — «нет**: «мутация» (как sort); «копия** «перевёрнутая**: [...arr].reverse().
